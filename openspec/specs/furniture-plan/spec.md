# furniture-plan Specification

## Purpose
План «Мебель»: поверх результата плана «Реконструкция» (только для чтения) пользователь расставляет мебель — пока столы. Стол — прямоугольник с шириной, длиной и углом поворота; он свободно перемещается и поворачивается, а пересечения с другими объектами подсвечиваются и сопровождаются предупреждением. Обмер, «Демонтаж», «Монтаж», «Черновые работы» и «Реконструкция» этим планом никогда не меняются.

## Requirements

### Requirement: Состав плана «Мебель»
План «Мебель» (`furniture`) ДОЛЖЕН хранить только собственные столы и размеры плана, а также собственные выноски (`callout`) и примечания (`plan-notes`), как каждый план. Собственных стен, проёмов, дверей, окон, батарей, пометок штукатурки и стяжки и стен гипсокартона у плана НЕТ. Подложка плана — результат плана «Реконструкция» (`reconstruction-plan`): остатки обмера после сноса, собственные стены, проёмы, двери и окна «Монтажа» с батареями, действующая штукатурка (серая) и стены гипсокартона (зелёные); стяжка, подписи стяжки, подписи площадей, блоки помещений и таблица экспликации на плане не показываются, размеры подложки и размеры плана «Реконструкция» не показываются. Коммуникации (`communications`) показываются, как на других планах, только для чтения. Подложка ДОЛЖНА быть живой производной: любая правка обмера, сноса, «Монтажа», «Черновых работ» и «Реконструкции» (включая отмену и повтор на любом из этих планов) ДОЛЖНА отражаться на плане «Мебель» сразу. Подложка НЕ ДОЛЖНА выделяться и правиться ни кликом, ни рамкой, ни ластиком, ни клавишами. Стены, размеры, элементы стены, коммуникации, пометки сноса, объекты «Монтажа», пометки штукатурки и стяжки, стены гипсокартона и данные помещений НЕ ДОЛЖНЫ изменяться никакой операцией плана «Мебель».

#### Scenario: Подложка — результат «Реконструкции»
- **WHEN** на обмерочном плане стена W, на «Черновых работах» штукатурка на грани W, на «Реконструкции» стена гипсокартона, и открыт план «Мебель»
- **THEN** показаны W, полоса штукатурки серым и зелёная стена гипсокартона; штриховки стяжки, размеров подложки и блоков помещений нет

```
 вид сверху, схематично, не в масштабе

   WWWWWWWWWWWWWWWWWW    W = стена обмера (подложка, серая)
   pppppppppppppppppp    p = штукатурка (серая)
        gggggggg         g = стена гипсокартона (зелёная)
```

#### Scenario: Правка нижних планов отражается
- **WHEN** на «Реконструкции» удалена стена гипсокартона, и пользователь перешёл на «Мебель»
- **THEN** зелёной стены на подложке нет

#### Scenario: Подложка не правится
- **WHEN** на плане без инструмента пользователь кликает по телу стены подложки, по штукатурке, гипсокартону, проёму или батарее, либо выделяет их рамкой
- **THEN** ничего не выделено

#### Scenario: Прочие планы не затронуты
- **WHEN** на плане «Мебель» поставлены, правлены и стёрты любые объекты
- **THEN** стены, размеры, элементы стены, коммуникации, пометки сноса, объекты «Монтажа», штукатурка, стяжки, стены гипсокартона и данные помещений остались такими же, как до операций

### Requirement: Стол
Стол — прямоугольный объект плана «Мебель» с центром, шириной, длиной и углом поворота. При угле 0 ширина измеряется вдоль оси X чертежа, длина — вдоль оси Y. Угол измеряется в градусах по часовой стрелке на экране; поворот выполняется вокруг центра стола, так что центр стола при повороте не смещается. Допустимый угол — число от 0 включительно до 360 не включая: введённое значение ДОЛЖНО приводиться к этому диапазону (360 даёт 0, отрицательное значение дополняется до диапазона, например −90 даёт 270). Ширина и длина — положительные числа в текущей единице длин; некорректные значения (нечисло, ноль, отрицательное число) НЕ ДОЛЖНЫ применяться. Столы НЕ ДОЛЖНЫ привязываться ни к стенам, ни к сетке, ни к другим столам.

```
 вид сверху, схематично, не в масштабе; стол 80 x 160, угол 0 и угол 30

   угол 0                          угол 30 (по часовой)
   W = 80 вдоль X                  центр C на месте, фигура повёрнута вокруг C
   +--------+                           /\
   |        |                          /  \
   |   C    | L = 160 вдоль Y         /  C \
   |        |                         \    /
   +--------+                          \  /
                                        \/
```

#### Scenario: Ширина вдоль X, длина вдоль Y
- **WHEN** стол с центром `(200, 100)`, шириной 80 см, длиной 160 см и углом 0
- **THEN** стол занимает прямоугольник от `(160, 20)` до `(240, 180)`

#### Scenario: Поворот вокруг центра
- **WHEN** тот же стол повёрнут на угол 90
- **THEN** центр остался `(200, 100)`, стол занимает прямоугольник от `(120, 60)` до `(280, 140)`: ширина 80 теперь вдоль Y, длина 160 — вдоль X

#### Scenario: Направление угла
- **WHEN** у стола с центром `(0, 0)`, шириной 80 и длиной 160 угол равен 90
- **THEN** точка стола, лежавшая при угле 0 в `(0, -80)` (середина верхней стороны на экране), оказалась в `(80, 0)`: вправо от центра на экране, то есть поворот по часовой

#### Scenario: Приведение угла
- **WHEN** в поле «Угол» введено 360, затем −90, затем 450
- **THEN** угол стола становится 0, затем 270, затем 90

#### Scenario: Некорректный размер
- **WHEN** в поле «Ширина» введено 0, отрицательное число или текст
- **THEN** ширина стола не изменилась, шага истории нет, поле показывает прежнее значение

### Requirement: Постановка стола
Инструмент «Стол» ДОЛЖЕН ставить стол одним кликом по холсту: центр стола — точка клика, ширина, длина и угол — значения панели «Стол». Постановка ДОЛЖНА записываться одним шагом истории плана «Мебель» и после неё инструмент ДОЛЖЕН деактивироваться, а поставленный стол — быть выделенным (как установка двери, `canvas-app` «Панель группы «Проёмы»»). Постановка НЕ ДОЛЖНА зависеть от того, свободно ли место: если стол пересёк бы другие объекты, он всё равно ставится, а пересечение показывается по требованию «Пересечения стола». До клика под указателем ДОЛЖЕН отображаться полупрозрачный призрак стола с теми же размерами и углом; пересечения призрака подсвечиваются так же, как у поставленного стола. Клик по пустому месту при активном инструменте выделение не меняет до постановки (требование «Выделение и правка только без инструмента», `canvas-app`).

#### Scenario: Постановка кликом
- **WHEN** в панели заданы ширина 80, длина 160, угол 0, и пользователь кликает в точке `(300, 200)`
- **THEN** поставлен стол с центром `(300, 200)`, шириной 80, длиной 160, углом 0; он выделен, инструмент деактивирован, в истории один шаг

#### Scenario: Призрак перед кликом
- **WHEN** инструмент «Стол» активен и указатель находится над холстом
- **THEN** под указателем нарисован полупрозрачный стол с центром в точке указателя

#### Scenario: Постановка на занятое место
- **WHEN** клик пришёлся так, что стол пересёк бы стену подложки
- **THEN** стол поставлен; пересечение подсвечено красным и показана плашка (`Пересечения стола`)

```
 вид сверху, схематично, не в масштабе

   ################                  клик *  (центр стола)
   ################
   ######+------------+              стол поставлен как есть;
   ######|xxxxx *     |              xxxxx = область пересечения со стеной,
   ######+------------+              подсвечена красным
```

#### Scenario: Клик по столу при активном инструменте
- **WHEN** инструмент «Стол» активен и пользователь кликает по уже стоящему столу
- **THEN** новый стол поставлен в точке клика поверх старого, старый не выделен; пересечение двух столов подсвечено

### Requirement: Выделение, перемещение и правка столов
Стол ДОЛЖЕН выделяться кликом по его телу (в состоянии «Без инструмента», `canvas-app` «Выделение и правка только без инструмента») и рамкой по тем же правилам, что стены (`wall-selection`, `multi-selection`); рамка выделяет только собственные объекты плана. Выделенный стол ДОЛЖЕН перетаскиваться за тело мышью; вместе с ним перемещаются все выделенные столы. Перемещение ДОЛЖНО быть свободным: без привязок и без ограничений препятствиями. Стрелки клавиатуры ДОЛЖНЫ сдвигать выделенные столы на шаг сетки (10 см), а с зажатым Shift — на 1 см; серия подряд идущих нажатий записывается одной записью истории (`multi-selection` «Сдвиг выделения стрелками»). Delete удаляет выделенные столы. Каждая правка (перетаскивание — один жест, ввод в поле панели, сдвиг серии стрелок, удаление) ДОЛЖНА быть одним шагом истории плана «Мебель»; перетаскивание, не сдвинувшее стол, шага не создаёт. Когда ничего не выделено, стрелки на этом плане ничего не меняют.

#### Scenario: Выделение кликом
- **WHEN** без инструмента пользователь кликает по телу стола
- **THEN** стол выделен, панель «Стол» открыта и показывает его ширину, длину и угол

#### Scenario: Свободное перетаскивание
- **WHEN** стол перетаскивают на 150 см вправо, и на пути стоит стена подложки
- **THEN** стол смещён на 150 см вправо и стоит поверх стены; пересечение подсвечено; в истории один шаг

```
 вид сверху, схематично, не в масштабе

   до                            после перетаскивания на 150 вправо
   +------+      ###              ###
   | стол |      ###              ###+------+      стол стоит поверх стены,
   +------+      ###              ###|xx    |      xx = пересечение (красное)
                                   ###+------+
```

#### Scenario: Стрелка сдвигает на шаг сетки
- **WHEN** выделен стол с центром `(200, 100)`, и пользователь нажал стрелку вправо
- **THEN** центр стола `(210, 100)`

#### Scenario: Shift и стрелка — мелкий шаг
- **WHEN** выделен стол, и пользователь нажал Shift+стрелка вниз
- **THEN** стол сдвинут на 1 см вниз

#### Scenario: Серия стрелок — один шаг
- **WHEN** пользователь нажал стрелку вправо пять раз подряд и выполнил одно «Отменить»
- **THEN** стол вернулся на исходное место

#### Scenario: Удаление
- **WHEN** выделен стол и пользователь нажал Delete
- **THEN** стол удалён одним шагом истории; подложка на месте

#### Scenario: Рамка захватывает только своё
- **WHEN** рамка охватывает стены подложки и стол
- **THEN** выделен только стол

#### Scenario: Стрелки без выделения
- **WHEN** ничего не выделено и пользователь нажимает стрелку
- **THEN** ничего не изменилось

### Requirement: Панель группы «Мебель» и инструмента «Стол»
Кнопка группы «Мебель» ДОЛЖНА иметь собственную иконку в стиле остальных иконок панели и вспомогательную панель правее неё по образцу панели группы «Проёмы» (`canvas-app` «Панель группы «Проёмы»») и по правилу `ui.md` для групп: панель группы содержит кнопки инструментов группы (пока одну — «Стол», выделена как текущий инструмент группы) и параметры активного инструмента. Параметры инструмента «Стол» — три поля в текущей единице измерения длин и в градусах: «Ширина», «Длина», «Угол»; по умолчанию ширина 80 см, длина 160 см, угол 0. Значения панели применяются к новым столам. Если выделен ровно один стол, панель показывает его значения, и правка поля меняет выделенный стол одним шагом истории и НЕ ДОЛЖНА менять значения для новых столов; при пустом выделении или нескольких выделенных столах поля показывают и меняют значения для новых столов. Выделение стола открывает закрытую панель группы. Клик по кнопке группы ведёт себя как у группы «Проёмы»: делает инструмент «Стол» активным и открывает панель, повторный клик по кнопке активного инструмента переключает видимость панели. Значения для новых столов запоминаются в сеансе и НЕ ДОЛЖНЫ сохраняться в чертеже. Установка стола деактивирует инструмент, выделяет поставленный стол и оставляет панель открытой (при необходимости открывает её): панель показывает значения поставленного стола, чтобы их можно было сразу поправить.

#### Scenario: Значения по умолчанию
- **WHEN** впервые открыта панель группы «Мебель»
- **THEN** в панели кнопка «Стол» (выделена) и поля «Ширина» 80 см, «Длина» 160 см, «Угол» 0

#### Scenario: Применение к новым
- **WHEN** в панели задано ширина 100, длина 200, угол 45 и поставлен стол
- **THEN** стол имеет ширину 100, длину 200 и угол 45

#### Scenario: Правка выделенного стола
- **WHEN** выделен стол шириной 80 и в панели введено 90
- **THEN** ширина выделенного стола 90 одним шагом истории; значение для новых столов осталось 80

#### Scenario: Правка угла выделенного стола
- **WHEN** выделен стол с углом 0 и в поле «Угол» введено 30
- **THEN** стол повёрнут на 30° по часовой вокруг центра одним шагом истории

#### Scenario: Выделение открывает панель
- **WHEN** панель закрыта и пользователь выделяет стол кликом
- **THEN** панель открыта и показывает ширину, длину и угол выделенного стола

#### Scenario: Два стола выделены
- **WHEN** выделены два стола и в панели введена ширина 120
- **THEN** ширина обоих выделенных столов не изменилась; значение для новых столов стало 120

#### Scenario: Панель после постановки
- **WHEN** инструмент «Стол» активен, панель закрыта, и пользователь ставит стол кликом
- **THEN** инструмент деактивирован, стол выделен, панель открыта и показывает ширину, длину и угол поставленного стола

#### Scenario: Единицы
- **WHEN** выбрана единица «мм»
- **THEN** подписи полей «Ширина» и «Длина» показывают миллиметры, подпись «Угол» — градусы

### Requirement: Пересечения стола
Если предмет мебели (стол) пересекается с другим объектом, область пересечения ДОЛЖНА быть подсвечена на холсте красным цветом схемы поверх обоих объектов, а пока на плане есть хотя бы одно пересечение, в правом верхнем углу области холста (с отступом 12 px от краёв, поверх холста, как плавающие блоки `canvas-app`) ДОЛЖНА показываться плашка-предупреждение. Плашка ДОЛЖНА называть, с чем пересекается мебель (например «Стол пересекается: стена, штукатурка»; перечень видов объектов без повторов в порядке: стена, гипсокартон, штукатурка, проём, дверь, окно, батарея, коммуникация, затем слова видов мебели в порядке каталога), и ДОЛЖНА исчезать, когда пересечений не осталось. Начало плашки — слово вида, если пересекающиеся предметы одного вида («Стол пересекается: …»), и слово «Мебель» («Мебель пересекается: …»), если среди них есть предметы разных видов. Другой предмет мебели называется словом его вида («стол»). Плашка не интерактивна: не закрывается, не перехватывает клики и не открывает диалогов. Пересечением ДОЛЖНО считаться наложение тел глубиной больше 0.01 см; касание граней пересечением не является. Препятствиями считаются: тела стен подложки (обмер, «Монтаж») и стены гипсокартона; действующие полосы штукатурки; проёмы, двери и окна — в пределах толщины стены и ширины элемента (так что предмет в проёме пересекает его); батареи; все коммуникации (стояки и воздуховоды); другие предметы мебели. Подсветка вычисляется по текущему состоянию чертежа и подложки и НЕ ДОЛЖНА храниться: любая правка предмета или нижних планов, отмена и повтор обновляют её сразу. Подсвечиваются пересечения всех предметов плана, не только выделенного. Пересечения не мешают правке, сохранению, истории, переключению планов и экспорту PDF; в PDF подсветки и плашки нет.

```
 вид сверху, схематично, не в масштабе

   стена ########        стол +----------+
         ########              |          |
         ######## +-----------+--xx       |    xx = область пересечения
         ######## | стол А    |  xx       |         стола А и стола Б
         ######## +-----------+--xx-------+         (красная)
                   пересечение стола с   +--+
                   стеной: красное       плашка: [ Стол пересекается: стена, стол ]
```

#### Scenario: Пересечение со стеной
- **WHEN** стол накладывается на тело стены подложки на 10 см
- **THEN** полоса наложения подсвечена красным, плашка в правом верхнем углу показывает «Стол пересекается: стена»

#### Scenario: Касание не пересечение
- **WHEN** грань стола лежит на грани стены, наложения нет
- **THEN** подсветки и плашки нет

#### Scenario: Стол в проёме
- **WHEN** стол стоит так, что его тело заходит в проём (между откосами, в пределах толщины стены)
- **THEN** область наложения на проём подсвечена, плашка называет «проём»

```
 вид сверху, схематично, не в масштабе

   ########        ########    # = стена; пробел между ними = проём (ширина 90)
   ########  xxxx  ########    xxxx = пересечение стола с проёмом
          +--xxxx--+
          | стол    |
          +---------+
```

#### Scenario: Штукатурка и гипсокартон
- **WHEN** стол заходит на полосу штукатурки подложки и на стену гипсокартона
- **THEN** обе области подсвечены, плашка называет «гипсокартон, штукатурка»

#### Scenario: Коммуникации
- **WHEN** стол накладывается на стояк и на воздуховод
- **THEN** области наложения подсвечены, плашка называет «коммуникация»

#### Scenario: Столы друг на друге
- **WHEN** два стола накладываются друг на друга
- **THEN** общая область подсвечена, плашка называет «стол»; подсветка видна независимо от того, какой из столов выделен

#### Scenario: Предметы разных видов
- **WHEN** в каталоге несколько видов, и предмет вида A накладывается на предмет вида B
- **THEN** общая область подсвечена, плашка начинается словом «Мебель» и называет слова видов A и B в порядке каталога

#### Scenario: Повёрнутый стол
- **WHEN** стол 80 x 160 с углом 45 своим углом заходит в стену
- **THEN** подсвечен только треугольник наложения повёрнутого прямоугольника со стеной, а не описанный прямоугольник

#### Scenario: Пересечение исчезает
- **WHEN** стол отодвинут от стены (или действие отменено) так, что наложения нет
- **THEN** подсветка и плашка исчезли

#### Scenario: Изменение нижнего плана
- **WHEN** на «Черновых работах» добавлена штукатурка, заходящая под стол, и пользователь вернулся на «Мебель»
- **THEN** область наложения подсвечена, плашка показана; данные стола не изменились

#### Scenario: Пересечения нет в PDF
- **WHEN** экспортируется чертёж, где стол пересекает стену
- **THEN** на странице «Мебель» стол нарисован, красной подсветки нет и плашки нет

### Requirement: Отображение плана «Мебель» и цвет стола
Холст плана ДОЛЖЕН рисовать слои снизу вверх: подложка с коммуникациями (результат плана «Реконструкция» — как на плане «Реконструкция», `reconstruction-plan` «Отображение плана «Реконструкция»»), предметы мебели, подсветка пересечений, размеры плана; так подсветка пересечения со стояком или воздуховодом видна поверх них. Предмет мебели рисуется схематичным видом сверху — линиями рисунка своего вида (требование «Каталог видов мебели») в реальном масштабе размеров, без заливки и без штриховки: внутри рисунка предмет не закрашен, подложка и сетка видны сквозь него; предмет ДОЛЖЕН лежать поверх подложки и штукатурки. У вида нет собственного цвета: линии рисунка — цвета контуров чертежа по схеме (`color-theme`), толщиной контура чертежа, различимы от серой подложки, зелёного гипсокартона и красной подсветки на светлой и на тёмной схеме; цвет подсветки пересечения тоже задаётся схемой. Выделение и ластик обводят контур рисунка (силуэт предмета) цветом выделения или ластика, внутри контура не закрашивая. В PDF линии рисуются цветом контуров светлой схемы; PDF не зависит от выбранной схемы (`color-theme` «PDF не зависит от схемы»). Сетка холста — как на других планах. Инструменты других планов (стена, проём, дверь, окно, батарея, коммуникации, демонтаж, штукатурка, стяжка, гипсокартон) на плане недоступны.

#### Scenario: Стол над подложкой
- **WHEN** стол лежит рядом с полосой штукатурки и частично над ней
- **THEN** линии рисунка стола нарисованы поверх подложки и не закрыты ею, внутри стола подложка видна сквозь него, поверх неё в зоне наложения — красная подсветка

#### Scenario: Масштаб стола
- **WHEN** стол шириной 80 и длиной 160 см
- **THEN** на холсте габариты его рисунка в масштабе чертежа равны 80 и 160 см

#### Scenario: Без заливки
- **WHEN** на плане есть стол и стул на пустом месте
- **THEN** внутри рисунков цвет фона холста и сетка; цветной заливки у предметов нет

#### Scenario: Тёмная схема
- **WHEN** выбрана тёмная схема и на плане есть стол рядом с серой подложкой и зелёной стеной
- **THEN** линии стола светлые, различимы на тёмном фоне, на серой подложке и от зелёного гипсокартона

#### Scenario: Выделенный предмет
- **WHEN** выделен стол
- **THEN** вдоль контура рисунка стола (со скруглёнными углами) проходит обводка цвета выделения, внутри контура заливки выделения нет

#### Scenario: Ластик над предметом
- **WHEN** активен «Ластик» и указатель над стулом
- **THEN** вдоль силуэта стула проходит обводка цвета ластика, внутри силуэта заливки нет

#### Scenario: PDF не зависит от схемы
- **WHEN** пользователь экспортирует PDF при тёмной схеме
- **THEN** линии рисунков предметов в PDF того же цвета, что при светлой схеме

#### Scenario: Инструменты других планов недоступны
- **WHEN** открыт план «Мебель»
- **THEN** кнопок «Стена», «Проём», «Дверь», «Окно», «Батарея», «Коммуникации», «Демонтаж», «Штукатурка», «Стяжка», «Гипсокартон» нет

### Requirement: Инструменты плана «Мебель»
План ДОЛЖЕН иметь инструменты группа «Мебель» («Стол»), «Размер», «Выноска», «Линейка», «Примечания» и «Ластик» (`drawing-plans` «Инструменты плана»); по умолчанию «Стол». «Размер» ставит размеры между гранями стен подложки (включая стены гипсокартона) и по откосам элементов подложки по правилам `dimension-tool`; привязок к столам нет. Размеры сохраняются на плане «Мебель» и пропадают из показа, пока опорная стена отсутствует. «Линейка» измеряет по подложке. «Ластик» удаляет столы, размеры плана и выноски плана, каждое удаление — один шаг истории плана; клик по подложке, штукатурке и пустому месту ничего не удаляет. «Выноска» и «Примечания» работают, как на других планах (`callout`, `plan-notes`); выноски и примечания плана хранятся отдельно от других планов и не показываются на них. Ластики других планов НЕ ДОЛЖНЫ удалять объекты плана «Мебель».

#### Scenario: Состав инструментов
- **WHEN** активен план «Мебель»
- **THEN** на панели инструментов «Мебель», «Размер», «Выноска», «Линейка», «Примечания», «Ластик»; активен «Стол»

#### Scenario: Размер до подложки
- **WHEN** пользователь ставит размер между гранями двух стен подложки
- **THEN** размер нарисован и сохранён на плане «Мебель»; на других планах его нет

#### Scenario: Ластик удаляет стол
- **WHEN** активен «Ластик» и пользователь кликает по столу
- **THEN** стол удалён одним шагом истории

#### Scenario: Ластик не трогает подложку
- **WHEN** активен «Ластик» и пользователь кликает по стене подложки, штукатурке или гипсокартону
- **THEN** ничего не удалено, шага истории нет

#### Scenario: Выноски плана отдельные
- **WHEN** на плане «Мебель» поставлена выноска, и пользователь переключился на «Реконструкцию»
- **THEN** выноски на «Реконструкции» нет

### Requirement: Старые чертежи
Чертёж, сохранённый до введения плана «Мебель», ДОЛЖЕН открываться без потерь: план показывает подложку и не содержит собственных объектов; в чертёж при загрузке ничего не дописывается.

#### Scenario: План у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Мебель»
- **THEN** план «Мебель» показывает результат плана «Реконструкция» и не содержит столов

### Requirement: Каталог видов мебели
Предметы плана «Мебель» ДОЛЖНЫ быть предметами одного устройства: центр, ширина, длина, угол (требование «Стол» описывает это устройство для вида «Стол»; те же правила действуют для любого вида), и различаться ДОЛЖНЫ только видом. Вид задаётся каталогом, а запись каталога определяет для вида: название («Стол»), слово для плашки пересечений («стол»), размеры по умолчанию, рисунок вида и иконку кнопки в панели группы «Мебель». Все остальное поведение (постановка кликом, призрак, выделение, перемещение, правка полей, стрелки, Delete, ластик, пересечения, история, хранение, PDF) НЕ ДОЛЖНО зависеть от вида; пересечения, выделение по клику и рамкой считаются по прямоугольнику предмета (центр, ширина, длина, угол), а не по линиям рисунка. Сейчас в каталоге два вида, в этом порядке: «Стол» (ширина 80 см, длина 160 см, угол 0) и «Стул» (ширина 45 см, длина 45 см, угол 0; слово плашки «стул»); все требования плана, где говорится о столе, действуют и для стула, с заменой названия и значений вида.

Рисунок вида — схематичный вид сверху, набор линий в системе координат предмета: начало в углу прямоугольника предмета при угле 0 слева сверху (ось X — вдоль ширины, ось Y — вдоль длины, вниз), рисунок целиком лежит внутри прямоугольника предмета и поворачивается и смещается вместе с ним. Размеры деталей рисунка (радиусы скруглений, отступы линий, толщина подлокотника и спинки) заданы в сантиметрах и не растягиваются вместе с предметом: у предмета другой ширины или длины контур и линии идут по его сторонам, а детали остаются тех же размеров; если меньшая сторона предмета меньше меньшей стороны его размеров по умолчанию (80 см у стола, 45 см у стула), все детали уменьшаются в отношении этих двух сторон, чтобы рисунок не выходил за прямоугольник и линии не пересекались. Рисунок вида «Стол» — прямоугольник со скруглёнными углами радиуса 10 см и внутренняя линия кромки с отступом 6 см от контура (углы внутренней линии скруглены радиусом 5 см). Рисунок вида «Стул» — силуэт, у которого верхние (при угле 0) углы скруглены дугой радиуса 18 см, а нижние прямые, внутренняя линия спинки и подлокотников с отступом 7 см от боковых сторон и верхнего края (две вертикальные линии, соединённые дугой) и сиденье — прямоугольник со скруглёнными углами радиуса 6 см с отступом 11 см от боковых сторон, 13 см от верхнего края и 4 см от нижнего. Спинка стула обращена к верху предмета при угле 0 и поворачивается вместе с предметом.

```text
 вид сверху, схематично, не в масштабе; угол 0, размеры в см

 Стол 80 x 160 (ширина по X, длина по Y)       Стул 45 x 45

   .-----------------.   <-- радиус 10               .---------------.   <-- дуга радиуса 18
  /  .-------------.  \                             .'  .-----------.  '.
 |  /               \  |                            |   /             \   |   <-- спинка, 7 от верха
 | |                 | |                            |  |  .---------.  |  |
 | |                 | |   160                      |  |  |  сиденье|  |  |
 | |                 | |                            |  |  '---------'  |  |
 |  \               /  |                            |  |               |  |   <-- подлокотники, 7 от боков
  \  '-------------'  /     6 = отступ кромки        +--+---------------+--+
   '-----------------'                                          45
           80
```

Панель группы «Мебель» ДОЛЖНА содержать по одной кнопке инструмента на каждый вид каталога, в порядке каталога; поля «Ширина», «Длина», «Угол» общие для всех видов и показывают значения для новых предметов активного вида. Значения для новых предметов запоминаются в сеансе отдельно по каждому виду, начальные — из каталога, и в чертеже не сохраняются. Правка выделенного предмета меняет его, а не значения вида (требование «Панель группы «Мебель» и инструмента «Стол»»). Рисунки видов каталога различимы между собой на светлой и тёмной схеме: по форме рисунка, а не по цвету. Легенда страницы «Мебель» в PDF содержит запись с названием и образцом — миниатюрой рисунка — для каждого вида, чьи предметы есть на странице, в порядке каталога (`pdf-export` «Легенда на странице PDF»); записи вида без предметов на странице нет.

#### Scenario: Единственный вид — стол
- **WHEN** открыта панель группы «Мебель»
- **THEN** (название сценария сохранено для архива, в каталоге теперь два вида) в ней две кнопки в порядке «Стол», «Стул»; размеры по умолчанию стола: ширина 80, длина 160, угол 0; стула: ширина 45, длина 45, угол 0

```text
План, вид сверху (схематично, не в масштабе). Т — стол 80×160, С — стул 45×45 (см)

  +--------+
  |   Т    |  160
  |        |        +----+
  +--------+        | С  | 45
     80             +----+
                      45
```

#### Scenario: Рисунок стола
- **WHEN** поставлен стол 80 x 160 с углом 0
- **THEN** нарисованы контур со скруглёнными углами радиуса 10 см и внутренняя линия на расстоянии 6 см от контура по всем сторонам; заливки нет

#### Scenario: Рисунок стола другого размера

#### Scenario: Пересечение считается по прямоугольнику
- **WHEN** угол прямоугольника стула 45 x 45, не занятый дугой спинки, заходит в стену на 3 см
- **THEN** область наложения подсвечена (пересечение считается по прямоугольнику предмета), плашка называет «стена»

#### Scenario: Запись легенды по виду
- **WHEN** на странице «Мебель» есть стол
- **THEN** в легенде запись «Стол» с миниатюрой рисунка стола; если столов нет, записи нет; так же для стула — запись «Стул» с миниатюрой рисунка стула, только если на странице есть стулья

#### Scenario: Значения новых предметов по видам

#### Scenario: Плашка пересечений называет стул

- **THEN** плашка читает «Стул пересекается: стена»; если стул пересекает ещё и стол — «Стул пересекается: стена, стол»
