## Purpose

Файл чертежа: сохранение активной вкладки со всеми её планами в файл и загрузка такого файла обратно в программу новой вкладкой. Позволяет передать чертёж другому человеку, сделать резервную копию и перенести работу на другую машину.

## Requirements

### Requirement: Кнопки файла чертежа
На панели справа сверху (рядом с кнопкой «Сохранить в PDF») ДОЛЖНЫ быть две кнопки в стиле соседних кнопок панели: «Сохранить в файл» и «Открыть из файла». Кнопки ДОЛЖНЫ иметь подсказки с этими названиями и ДОЛЖНЫ быть доступны на любом плане.

#### Scenario: Кнопки на панели
- **WHEN** приложение открыто на любом плане
- **THEN** на панели есть кнопки «Сохранить в файл» и «Открыть из файла» с подсказками, обе доступны

### Requirement: Формат файла чертежа
Файл чертежа ДОЛЖЕН быть текстовым JSON-документом в кодировке UTF-8 с признаком формата, номером версии формата файла (сейчас 1) и одним чертежом. Чертёж в файле ДОЛЖЕН содержать те же поля и в тех же единицах, что чертёж в документе хранилища версии 3 (`drawing-storage`): стены, размеры, элементы стены, содержимое всех планов, выноски, примечания, помещения, вид и активный план. Масштаб печати, история правок и корзина в файл НЕ ДОЛЖНЫ записываться.

#### Scenario: Файл содержит все планы вкладки
- **WHEN** во вкладке есть стены и проём на обмерочном плане, пометка сноса на плане «Демонтаж», стол на плане «Мебель» и выключатель, и пользователь сохраняет её в файл
- **THEN** в файле лежит один чертёж с признаком формата и версией 1, в котором есть стены, проём, пометка сноса, стол и выключатель

#### Scenario: История в файл не входит
- **WHEN** во вкладке сделано несколько правок, доступных для отмены, и пользователь сохраняет её в файл
- **THEN** в файле нет истории правок и корзины закрытых вкладок

### Requirement: Сохранение активной вкладки в файл
Кнопка «Сохранить в файл» ДОЛЖНА скачивать файл чертежа активной вкладки со всеми её планами. Имя файла ДОЛЖНО строиться из имени чертежа с расширением `.json`; символы, недопустимые в именах файлов, ДОЛЖНЫ заменяться безопасными, пустое имя — именем по умолчанию. В файл ДОЛЖНО попадать актуальное состояние вкладки, включая последнюю завершённую правку. Сохранение в файл НЕ ДОЛЖНО менять чертёж, вкладки и историю.

#### Scenario: Скачивание файла
- **WHEN** активна вкладка «Кухня» и пользователь нажимает «Сохранить в файл»
- **THEN** браузер скачивает файл `Кухня.json` с чертежом этой вкладки

#### Scenario: Недопустимые символы в имени
- **WHEN** вкладка называется `Кухня: 2/3` и пользователь нажимает «Сохранить в файл»
- **THEN** имя скачанного файла не содержит символов `:` и `/`, расширение `.json`

#### Scenario: Последняя правка попадает в файл
- **WHEN** пользователь только что поставил стену и сразу нажимает «Сохранить в файл»
- **THEN** стена есть в скачанном файле

#### Scenario: Сохранение ничего не меняет
- **WHEN** пользователь сохраняет вкладку в файл
- **THEN** набор вкладок, активная вкладка, содержимое чертежа и доступность отмены остаются прежними

### Requirement: Загрузка файла новой вкладкой
Кнопка «Открыть из файла» ДОЛЖНА открывать стандартный выбор файла. Прочитанный чертёж ДОЛЖЕН добавляться **новой вкладкой** в конец списка и становиться активной; существующие вкладки НЕ ДОЛЖНЫ заменяться или изменяться. Чертёж ДОЛЖЕН получать новый уникальный идентификатор. Имя чертежа ДОЛЖНО сохраняться из файла, а если оно совпадает с именем открытой вкладки, ДОЛЖНО дополняться так, чтобы стать уникальным среди открытых чертежей. Вид и активный план ДОЛЖНЫ восстанавливаться из файла. У загруженной вкладки ДОЛЖНА быть пустая история правок. Загруженная вкладка ДОЛЖНА сохраняться автоматически, как любая другая.

#### Scenario: Файл открывается новой вкладкой
- **WHEN** открыты вкладки «Чертёж 1» и «Чертёж 2» и пользователь загружает файл с чертежом «Кухня»
- **THEN** появляется третья вкладка «Кухня» с содержимым файла, она активна, вкладки «Чертёж 1» и «Чертёж 2» не изменились

#### Scenario: Повторная загрузка того же файла
- **WHEN** пользователь дважды загружает один и тот же файл чертежа «Кухня»
- **THEN** появляются две отдельные вкладки с разными идентификаторами и разными уникальными именами, правки одной не меняют другую

#### Scenario: Имя занято
- **WHEN** открыта вкладка «Кухня» и пользователь загружает файл чертежа с именем «Кухня»
- **THEN** новая вкладка получает имя, не совпадающее с именем ни одной открытой вкладки

#### Scenario: Вид и активный план восстановлены
- **WHEN** в файле чертёж с активным планом «Мебель» и масштабом экрана 2
- **THEN** загруженная вкладка открывается на плане «Мебель» с тем же масштабом экрана и панорамированием

#### Scenario: История пуста
- **WHEN** пользователь загрузил файл и сразу нажимает «Отменить»
- **THEN** загруженная вкладка остаётся на месте, отменять нечего

#### Scenario: Загруженная вкладка сохраняется
- **WHEN** пользователь загрузил файл и перезагрузил страницу
- **THEN** загруженная вкладка на месте с тем же содержимым

#### Scenario: Отмена выбора файла
- **WHEN** пользователь нажимает «Открыть из файла» и закрывает выбор файла, ничего не выбрав
- **THEN** ничего не меняется

### Requirement: Сохранение и загрузка без потерь
Чертёж, сохранённый в файл и загруженный обратно, ДОЛЖЕН иметь то же содержимое всех планов, что исходная вкладка: стены с идентификаторами, размеры, элементы стены, пометки, объекты, выноски, примечания, помещения, вид и активный план. Не совпадать МОГУТ только идентификатор чертежа и имя (уникализация).

#### Scenario: Круговой обмен
- **WHEN** вкладка со стенами, размерами, проёмом, окном, дверью, пометками сноса, мебелью, выноской и примечанием сохранена в файл и загружена обратно
- **THEN** загруженная вкладка содержит тот же набор объектов с теми же параметрами на каждом плане

### Requirement: Повреждённое содержимое файла
Если файл читается как файл чертежа, но отдельные элементы чертежа не соответствуют формату, чертёж ДОЛЖЕН загружаться по тем же правилам чтения, что и чертёж из хранилища (`drawing-storage`): несоответствующие элементы отбрасываются, остальные данные восстанавливаются, масштаб печати в файле игнорируется.

#### Scenario: Битые элементы отбрасываются
- **WHEN** в файле чертежа есть проём с нулевой шириной, проём, ссылающийся на отсутствующую стену, и корректная стена
- **THEN** вкладка открывается, оба некорректных проёма отброшены, стена восстановлена

### Requirement: Отклонение нечитаемого файла
Файл, который не удаётся прочитать как файл чертежа, ДОЛЖЕН отклоняться: пользователю ДОЛЖНО показываться сообщение с причиной, вкладки, активная вкладка, содержимое и история НЕ ДОЛЖНЫ меняться. Отклоняются: файл, не являющийся JSON; JSON без признака формата чертежа; файл без чертежа или с чертежом, структура которого не соответствует формату; файл с версией формата больше поддерживаемой (сообщение ДОЛЖНО сообщать, что файл создан более новой версией программы).

#### Scenario: Не JSON
- **WHEN** пользователь выбирает текстовый файл, не являющийся JSON
- **THEN** показано сообщение, что файл не является файлом чертежа, вкладки не изменились

#### Scenario: Чужой JSON
- **WHEN** пользователь выбирает валидный JSON без признака формата чертежа
- **THEN** показано сообщение, что файл не является файлом чертежа, вкладки не изменились

#### Scenario: Чертёж неверной структуры
- **WHEN** в файле верный признак формата, но вместо чертежа число или список стен имеет неверный тип
- **THEN** показано сообщение, что файл повреждён, вкладки не изменились

#### Scenario: Версия новее поддерживаемой
- **WHEN** пользователь выбирает файл с версией формата 2 при поддерживаемой 1
- **THEN** показано сообщение, что файл создан более новой версией программы, вкладки не изменились

#### Scenario: Документ хранилища не принимается как файл чертежа
- **WHEN** пользователь выбирает копию документа localStorage с набором чертежей
- **THEN** файл отклоняется как не являющийся файлом чертежа, вкладки не изменились
