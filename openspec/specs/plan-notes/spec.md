## Purpose

Примечания плана: у каждого плана чертежа свой список пояснений («Все размеры указаны в мм» и т. п.), который правится в панели инструмента и выводится блоком «Примечание:» на странице PDF этого плана над основной надписью.

## Requirements

### Requirement: Данные примечаний плана
У каждого плана («Обмерочный план», «Демонтаж», «Монтаж») ДОЛЖЕН быть собственный упорядоченный список примечаний; пункт — непустая строка текста без переводов строки. Начальное содержимое — пустой список (у нового чертежа и у чертежа, сохранённого до введения примечаний). Список плана НЕ ДОЛЖЕН влиять на списки других планов. Нумерация пунктов НЕ хранится: номер пункта — его позиция в списке, начиная с 1. Пункт при сохранении обрезается по пробелам с краёв; пункт из одних пробелов не существует. В списке не более 15 пунктов, пункт не длиннее 300 символов; лишнее при вводе отбрасывается.

#### Scenario: Новый чертёж без примечаний
- **WHEN** создан новый чертёж
- **THEN** списки примечаний всех трёх планов пусты

#### Scenario: Списки планов независимы
- **WHEN** на плане «Демонтаж» заданы два пункта, затем пользователь открывает «Монтаж» и «Обмерочный план»
- **THEN** на «Монтаже» и обмере панель примечаний пуста; на «Демонтаже» остаются два пункта

#### Scenario: Пустые и пробельные строки не становятся пунктами
- **WHEN** в поле введено «Первый», пустая строка, строка из пробелов, «  Второй  »
- **THEN** список содержит два пункта «Первый» и «Второй»

#### Scenario: Ограничения
- **WHEN** в поле введено 16 непустых строк или строка длиннее 300 символов
- **THEN** сохраняются первые 15 пунктов, лишняя часть строки после 300-го символа отбрасывается

### Requirement: Кнопка и панель «Примечания»
Панель инструментов каждого плана ДОЛЖНА содержать кнопку инструмента «Примечания» в группе измерения и пометки, последней перед разделителем «Ластика» (после «Линейки»), по образцу существующих кнопок с вспомогательной панелью (`canvas-app` «Вспомогательная панель инструмента»). Инструмент не имеет жестов на холсте. Клик по кнопке делает инструмент активным и переключает видимость его панели; повторный клик по кнопке активного инструмента переключает видимость панели. Значок кнопки ДОЛЖЕН быть в том же стиле, что значки соседних инструментов (лист с пунктами). Панель содержит заголовок «Примечание» и одно многострочное поле, в котором один пункт занимает одну строку; перед полем номера не показываются, под ним нумерации тоже нет. Панель показывает список примечаний активного плана и обновляется при переключении плана, вкладки, отмене и повторе. Поле пустого списка пустое.

Правка применяется при снятии фокуса с поля, при закрытии панели, при выборе другого инструмента или плана и по Esc: введённый текст разбивается по строкам, строки обрезаются по пробелам, пустые отбрасываются, применяются ограничения (`plan-notes` «Данные примечаний плана»). Применение ДОЛЖНО создавать один шаг истории активного плана, если список изменился (`drawing-history` «Примечания в истории»); если список не изменился, шага нет. Нажатия клавиш в поле (Delete, Backspace, стрелки, буквы-горячие клавиши) НЕ ДОЛЖНЫ действовать на объекты чертежа.

#### Scenario: Кнопка на каждом плане
- **WHEN** открыт любой из трёх планов
- **THEN** на панели инструментов есть кнопка «Примечания» после «Линейки»

#### Scenario: Открытие и закрытие панели
- **WHEN** пользователь нажимает кнопку «Примечания», затем нажимает её ещё раз
- **THEN** после первого нажатия инструмент активен и панель открыта; после второго панель закрыта

#### Scenario: Панель показывает примечания активного плана
- **WHEN** на плане «Монтаж» заданы примечания, и пользователь открывает панель на «Демонтаже», затем на «Монтаже»
- **THEN** на «Демонтаже» поле пусто, на «Монтаже» — строки с пунктами в порядке списка

#### Scenario: Правка создаёт один шаг истории
- **WHEN** пользователь ввёл три пункта и снял фокус с поля
- **THEN** список плана содержит три пункта, в истории плана один шаг

#### Scenario: Без изменений шага нет
- **WHEN** пользователь поставил курсор в поле, ничего не изменил и снял фокус
- **THEN** шага истории нет

#### Scenario: Клавиши в поле не трогают объекты
- **WHEN** на плане выделена стена, пользователь кликнул в поле панели и нажал Delete
- **THEN** стена осталась, а в поле удалён символ

### Requirement: Блок примечаний в PDF
Страница PDF плана, у которого список примечаний не пуст, ДОЛЖНА содержать блок примечаний: прямоугольник шириной 185 мм (как у основной надписи) без линий, правая сторона которого совпадает с правой стороной рамки, а нижняя — с верхней границей основной надписи; блок НЕ ДОЛЖЕН заходить левее основной надписи. Страница плана с пустым списком блока не имеет. Все размеры блока абсолютны (мм на бумаге), одинаковы на всех форматах A4–A0 и не зависят от масштаба чертежа.

Содержимое блока (шрифт PTSans, чёрный, кегль 3,5 мм): строка-заголовок «Примечание:» (всегда в единственном числе) с подчёркиванием тонкой линией 0,25 мм по ширине слова; под ней пункты, каждый начинается с номера «N.» на отступе 3 мм от левой стороны блока, текст пункта — на отступе 12 мм. Шаг строк 4,5 мм. Пункт, не помещающийся в ширину 170 мм (185 − 12 − 3 мм отступа справа), ДОЛЖЕН переноситься по пробелам на следующие строки с тем же отступом текста (номер только у первой строки); слово, не помещающееся целиком, разбивается по символам. Высота блока: 3 мм сверху + 5 мм строка заголовка + 4,5 мм × число строк всех пунктов + 2 мм снизу.

#### Scenario: Положение блока
- **WHEN** экспортируется на A4 страница с одним коротким пунктом
- **THEN** блок занимает ширину 185 мм (x от 107 до 292 мм), его низ лежит на y = 150 мм, высота 14,5 мм (3 + 5 + 4,5 + 2); левее x = 107 мм блока нет

#### Scenario: Заголовок и нумерация
- **WHEN** на странице три пункта
- **THEN** выведено «Примечание:» с подчёркиванием, ниже «1.», «2.», «3.» на отступе 3 мм, тексты пунктов на отступе 12 мм

#### Scenario: Перенос длинного пункта
- **WHEN** пункт не помещается в 170 мм
- **THEN** он занимает несколько строк, номер только у первой, остальные начинаются на отступе 12 мм; ни одна строка не выходит за правую сторону блока

#### Scenario: Пустой список
- **WHEN** у плана нет примечаний
- **THEN** на его странице ни заголовка, ни линий, ни пространства под блок нет

#### Scenario: Примечания у каждой страницы свои
- **WHEN** у планов разные списки
- **THEN** на каждой странице выведены только примечания её плана

#### Scenario: Размеры не зависят от формата
- **WHEN** экспортируются страницы на A4 и на A0 с одним списком
- **THEN** ширина, кегль, отступы, шаг и высота блока одинаковы
