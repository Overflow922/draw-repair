## Purpose

Планы чертежа: чертёж ремонта делится на планы, каждый план содержит только объекты своего типа и выводится на отдельную страницу PDF; в чертеже в каждый момент активен один план.

## Requirements

### Requirement: Каталог планов
Приложение ДОЛЖНО иметь упорядоченный каталог планов; у каждого плана есть постоянный идентификатор и название. Каталог ДОЛЖЕН содержать планы «Обмерочный план» (идентификатор `measure`), «Демонтаж» (идентификатор `demolition`), «Монтаж» (идентификатор `mounting`), «Черновые работы» (идентификатор `rough`), «Реконструкция» (идентификатор `reconstruction`), «Мебель» (идентификатор `furniture`), «Сантехника» (идентификатор `plumbing`), «Потолки и освещение» (идентификатор `ceiling`) и «Группы включения» (идентификатор `switching`) в этом порядке. Порядок каталога определяет порядок планов в переключателе и порядок страниц в PDF. Каталог един для всех чертежей: все чертежи имеют один и тот же набор планов.

План «Обмерочный план» ДОЛЖЕН содержать стены, размеры и элементы стены (проёмы, окна, двери) чертежа — те самые объекты, которые чертёж содержал до введения планов; их редактирование, отображение и правила остаются прежними. План «Демонтаж» ДОЛЖЕН содержать только пометки сноса (`demolition-plan`). План «Монтаж» ДОЛЖЕН содержать собственные стены, проёмы, двери, окна и размеры и показывать остатки обмерочного плана после сноса как подложку только для чтения (`mounting-plan`). План «Черновые работы» ДОЛЖЕН содержать только пометки штукатурки и стяжки помещений и показывать результат плана «Монтаж» как подложку только для чтения (`rough-works-plan`). План «Реконструкция» ДОЛЖЕН содержать только стены гипсокартона и их размеры и показывать результат плана «Черновые работы» (без стяжки, штукатурка серым) как подложку только для чтения (`reconstruction-plan`). План «Мебель» ДОЛЖЕН содержать только столы и размеры плана и показывать результат плана «Реконструкция» (штукатурка серым, гипсокартон зелёным) как подложку только для чтения (`furniture-plan`). План «Сантехника» ДОЛЖЕН содержать только размеры плана и показывать результат плана «Реконструкция» и приборы плана «Мебель», подключаемые к воде, как подложку только для чтения (`plumbing-plan`). План «Потолки и освещение» ДОЛЖЕН содержать только натяжные потолки помещений и показывать результат плана «Мебель» (подложку «Мебели» и все предметы мебели без габаритов) как подложку только для чтения (`ceiling-plan`). План «Группы включения» ДОЛЖЕН содержать только метки линий освещения, выноски и примечания и показывать результат плана «Потолки и освещение» (подложку «Мебели», все предметы мебели без габаритов и все объекты освещения, без натяжных потолков и расстояний) как подложку только для чтения (`switching-plan`). Коммуникации чертежа (`communications`) не принадлежат ни одному плану: они общие, показываются на всех планах, а правятся только на обмерочном плане.

#### Scenario: Состав каталога
- **WHEN** приложение открыто
- **THEN** каталог планов содержит «Обмерочный план» (`measure`), «Демонтаж» (`demolition`), «Монтаж» (`mounting`), «Черновые работы» (`rough`), «Реконструкция» (`reconstruction`), «Мебель» (`furniture`), «Сантехника» (`plumbing`), «Потолки и освещение» (`ceiling`) и «Группы включения» (`switching`) в этом порядке

#### Scenario: Обмерочный план содержит объекты чертежа
- **WHEN** у чертежа, сохранённого до введения планов, есть стены, размеры и проёмы
- **THEN** в плане «Обмерочный план» отображаются и редактируются те же стены, размеры и проёмы

#### Scenario: План «Монтаж» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Монтаж»
- **THEN** план «Монтаж» показывает остатки обмерочного плана и не содержит собственных объектов

#### Scenario: План «Черновые работы» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Черновые работы»
- **THEN** план «Черновые работы» показывает результат плана «Монтаж» и не содержит пометок штукатурки и стяжки

#### Scenario: План «Реконструкция» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Реконструкция»
- **THEN** план «Реконструкция» показывает результат плана «Черновые работы» серым без стяжки и не содержит стен гипсокартона

#### Scenario: План «Мебель» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Мебель»
- **THEN** план «Мебель» показывает результат плана «Реконструкция» и не содержит столов

#### Scenario: План «Сантехника» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Сантехника»
- **THEN** план «Сантехника» показывает результат плана «Реконструкция» и приборы плана «Мебель» и не содержит собственных размеров, выносок и примечаний

#### Scenario: План «Потолки и освещение» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Потолки и освещение»
- **THEN** план показывает результат плана «Мебель» и не содержит натяжных потолков, выносок и примечаний

#### Scenario: План «Группы включения» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Группы включения»
- **THEN** план показывает результат плана «Потолки и освещение» без натяжных потолков и расстояний и не содержит выносок и примечаний

#### Scenario: Коммуникации общие
- **WHEN** на обмерочном плане поставлен стояк
- **THEN** он виден на планах «Демонтаж», «Монтаж», «Черновые работы», «Реконструкция», «Мебель», «Сантехника», «Потолки и освещение» и «Группы включения» и не входит в собственные объекты ни одного из них

### Requirement: Активный план чертежа
У каждого чертежа ДОЛЖЕН быть активный план; по умолчанию активен «Обмерочный план». Холст и инструменты ДОЛЖНЫ отображать и изменять объекты активного плана. Активный план ДОЛЖЕН быть собственным для каждого чертежа и сохраняться вместе с чертежом (см. `drawing-storage`). Подобранный масштаб печати (`drawing-scale`), вид (масштаб экрана и панорамирование) и формат страницы PDF общие для всех планов чертежа и НЕ ДОЛЖНЫ меняться при переключении плана.

#### Scenario: Активный план по умолчанию
- **WHEN** создан новый чертёж или открыт чертёж без сохранённого активного плана
- **THEN** активен «Обмерочный план»

#### Scenario: Вид не меняется при переключении
- **WHEN** пользователь изменил зум и панорамирование, затем переключил план
- **THEN** вид (масштаб экрана и сдвиг) и подобранный масштаб печати остались прежними

#### Scenario: Активный план у каждого чертежа свой
- **WHEN** в двух чертежах выбраны разные активные планы и пользователь переключает вкладки
- **THEN** после каждого переключения вкладки активен план, который был активен в этом чертеже

### Requirement: Переключатель планов
В верхней панели, вторым рядом под вкладками чертежей и кнопкой «+», ДОЛЖЕН находиться переключатель планов — ряд кнопок-сегментов по образцу переключателя единиц «м / см / мм»: по одной кнопке на каждый план каталога в порядке каталога, подписанной названием плана; кнопка активного плана ДОЛЖНА быть визуально выделена. Нажатие на кнопку неактивного плана ДОЛЖНО делать этот план активным; нажатие на кнопку активного плана НЕ ДОЛЖНО ничего менять. Переключатель ДОЛЖЕН отражать активный план активного чертежа и обновляться при переключении вкладок.

При переключении плана ДОЛЖНЫ быть сброшены выделение, незавершённая цепочка рисования стены (в том числе стены гипсокартона), черновик размера, незавершённая протяжка пометки (сноса или штукатурки), призрак стола и другие незавершённые жесты; открытое поле правки подписи натяжного потолка закрывается, а набранное значение применяется по правилу потери фокуса (`ceiling-plan` «Подпись натяжного потолка и правка на месте») к потолку прежнего плана; выбранный инструмент ДОЛЖЕН быть сброшен на инструмент плана по умолчанию (`Инструменты плана`).

#### Scenario: Переключатель показывает каталог
- **WHEN** приложение открыто
- **THEN** в верхней панели вторым рядом под вкладками и «+» расположен ряд сегментов «Обмерочный план», «Демонтаж», «Монтаж», «Черновые работы», «Реконструкция», «Мебель», «Сантехника», «Потолки и освещение» и «Группы включения»; выделен сегмент активного плана

#### Scenario: Повторное нажатие на активный план
- **WHEN** пользователь нажимает кнопку уже активного плана
- **THEN** активный план, выделение и вид не изменились

#### Scenario: Переключение сбрасывает выделение и жесты
- **WHEN** выделена стена, начата цепочка рисования, и план переключается на «Демонтаж», «Монтаж», «Черновые работы», «Реконструкцию», «Мебель», «Сантехнику», «Потолки и освещение» или «Группы включения»
- **THEN** выделение снято, цепочка прервана, черновик размера отброшен

#### Scenario: Цепочка гипсокартона сбрасывается
- **WHEN** на плане «Реконструкция» начата цепочка стен гипсокартона, и план переключается
- **THEN** цепочка прервана, незавершённая стена не создана

#### Scenario: Протяжка штукатурки сбрасывается
- **WHEN** на плане «Черновые работы» идёт протяжка штукатурки, и план переключается
- **THEN** протяжка прервана, пометка не создана

#### Scenario: Призрак стола сбрасывается
- **WHEN** на плане «Мебель» активен инструмент «Стол» и под указателем призрак стола, и план переключается
- **THEN** призрак исчез, стол не поставлен

#### Scenario: Черновик размера на «Сантехнике» сбрасывается
- **WHEN** на плане «Сантехника» задана первая точка размера на центре раковины, и план переключается
- **THEN** черновик размера отброшен, размер не создан

#### Scenario: Правка подписи потолка при переключении
- **WHEN** на плане «Потолки и освещение» открыто поле правки подписи «-50мм» с набранным 80, и план переключается
- **THEN** поле закрыто, выделение снято, опускание потолка стало 80 одним шагом истории плана «Потолки и освещение»

#### Scenario: Переключатель следует за вкладкой
- **WHEN** пользователь переключает вкладки чертежей с разными активными планами
- **THEN** выделенным сегментом всегда является активный план показываемого чертежа

#### Scenario: Переключение сохраняется
- **WHEN** пользователь переключил план на «Мебель» и перезагрузил страницу
- **THEN** чертёж открывается на плане «Мебель»

### Requirement: Одна страница PDF на каждый план
Каждый план каталога ДОЛЖЕН выводиться на отдельную страницу PDF (см. `pdf-export`); порядок страниц ДОЛЖЕН совпадать с порядком каталога планов. Страница плана содержит объекты этого плана и общие коммуникации чертежа (`communications` «Коммуникации в PDF»).

#### Scenario: Число страниц равно числу планов
- **WHEN** экспортируется чертёж, каталог планов содержит N планов
- **THEN** PDF содержит ровно N страниц в порядке каталога

#### Scenario: Коммуникации на каждой странице
- **WHEN** экспортируется чертёж со стояком
- **THEN** стояк нарисован на каждой из N страниц

### Requirement: Инструменты плана
У каждого плана ДОЛЖЕН быть собственный набор инструментов и инструмент по умолчанию. Панель инструментов ДОЛЖНА показывать кнопки только инструментов активного плана. План «Обмерочный план»: «Стена», группа «Проёмы» («Проём», «Дверь»), «Окно», «Батарея», группа «Коммуникации» («Стояк», «Воздуховод»), «Размер», «Выноска», «Линейка», «Примечания», «Ластик»; по умолчанию «Стена». План «Демонтаж»: «Демонтаж», «Выноска», «Линейка», «Примечания», «Ластик» (на плане «Демонтаж» ластик удаляет только пометки сноса, `demolition-plan` «Ластик на плане «Демонтаж»»); по умолчанию «Демонтаж». План «Монтаж»: тот же набор и тот же порядок, что у обмерочного плана, кроме группы «Коммуникации» («Стена», группа «Проёмы», «Окно», «Батарея», «Размер», «Выноска», «Линейка», «Примечания», «Ластик»); по умолчанию «Стена»; инструменты действуют на собственные объекты плана «Монтаж» (`mounting-plan` «Собственные объекты плана «Монтаж»»), «Линейка» измеряет по остаткам и собственным стенам, «Ластик» удаляет только собственные объекты «Монтажа». План «Черновые работы»: «Штукатурка», «Стяжка», «Линейка», «Ластик» (`rough-works-plan`; «Выноска» и «Примечания» есть на каждом плане, `rough-works-plan` «Выноски и примечания плана «Черновые работы»»); по умолчанию «Штукатурка»; «Линейка» измеряет по подложке, «Ластик» удаляет только пометки штукатурки, стяжки и выноски плана (`rough-works-plan` «Ластик на плане «Черновые работы»»). План «Реконструкция»: «Гипсокартон», «Размер», «Выноска», «Линейка», «Примечания», «Ластик» (`reconstruction-plan` «Инструменты плана «Реконструкция»»); по умолчанию «Гипсокартон»; «Линейка» измеряет по подложке и стенам гипсокартона, «Ластик» удаляет только стены гипсокартона, размеры и выноски плана. План «Мебель»: группа «Мебель» («Стол»), «Размер», «Выноска», «Линейка», «Примечания», «Ластик» (`furniture-plan` «Инструменты плана «Мебель»»); по умолчанию «Стол»; «Линейка» измеряет по подложке, «Ластик» удаляет только столы, размеры и выноски плана. План «Сантехника»: «Размер», «Выноска», «Линейка», «Примечания», «Ластик» (`plumbing-plan` «Инструменты плана «Сантехника»»); по умолчанию «Размер»; «Линейка» измеряет по подложке и приборам, «Ластик» удаляет только размеры, выноски и примечания плана. План «Потолки и освещение»: «Натяжной потолок», группа «Освещение» («Точечный встроенный светильник», «Датчик пожарной сигнализации потолочный», «Люстра», «Бра», «Электровывод для освещения»), «Выноска», «Линейка», «Примечания», «Ластик» (`ceiling-plan` «Инструменты плана «Потолки и освещение»»); по умолчанию «Натяжной потолок»; «Линейка» измеряет по подложке и предметам мебели, «Ластик» удаляет только натяжные потолки, объекты освещения и выноски плана. План «Группы включения»: «Линия освещения», «Выноска», «Линейка», «Примечания», «Ластик» (`switching-plan` «Инструменты плана «Группы включения»»); по умолчанию «Линия освещения»; «Линейка» измеряет по подложке и предметам мебели, «Ластик» удаляет только метки линий и выноски плана. Коммуникации (`communications`) на планах «Демонтаж», «Монтаж», «Черновые работы», «Реконструкция», «Мебель», «Сантехника», «Потолки и освещение» и «Группы включения» — подложка только для чтения (`communications` «Коммуникации на всех планах»). При переключении плана и чертежа активным становится инструмент плана по умолчанию. Горячие клавиши и жесты инструментов других планов (стрелки смены материала и сдвига стен, Delete стен, размеров, элементов и коммуникаций, правка стен) НЕ ДОЛЖНЫ действовать на плане, где этих инструментов нет, и на плане «Монтаж» не затрагивают объекты других планов; на плане «Реконструкция» они действуют только на стены гипсокартона и размеры этого плана; на плане «Мебель» — только на столы и размеры этого плана; на плане «Сантехника» — только на размеры этого плана (приборы на нём не выделяются, не сдвигаются стрелками и не удаляются); на плане «Потолки и освещение» Delete удаляет только выделенный натяжной потолок или выделенный объект освещения, стрелки ничего не двигают (предметы мебели на нём не выделяются, не сдвигаются и не удаляются); на плане «Группы включения» Delete удаляет только выделенную метку линии освещения, стрелки ничего не делают (предметы мебели и объекты освещения на нём не выделяются, не сдвигаются и не удаляются).

#### Scenario: Инструменты обмерочного плана
- **WHEN** активен «Обмерочный план»

### Requirement: Выноски — объекты плана
Каждый план («Обмерочный план», «Демонтаж», «Монтаж») ДОЛЖЕН иметь собственный список выносок (`callout`). Выноски активного плана отображаются и правятся на холсте; выноски других планов НЕ ДОЛЖНЫ отображаться, выделяться и стираться. Инструмент «Выноска» входит в набор инструментов каждого плана (`canvas-app`, «Кнопка «Выноска»»); инструмент плана по умолчанию не меняется («Стена» у обмера и «Монтажа», «Демонтаж» у демонтажа). План «Демонтаж», кроме пометок сноса, ДОЛЖЕН содержать собственные выноски; остальные правила плана «Демонтаж» (подложка обмера только для чтения, остальные инструменты) не меняются. Переключение плана ДОЛЖНО сбрасывать незавершённое размещение выноски и закрывать поле ввода, сохраняя набранный текст по правилам `callout` («Ввод текста на месте»).

#### Scenario: Выноска видна только на своём плане
- **WHEN** на плане «Демонтаж» поставлена выноска, и пользователь переключился на «Монтаж» и «Обмерочный план»
- **THEN** на этих планах выноски нет; на «Демонтаже» она на месте

#### Scenario: Инструмент по умолчанию не изменился
- **WHEN** пользователь переключается между планами
- **THEN** активным становится прежний инструмент плана по умолчанию, не «Выноска»

#### Scenario: Переключение плана при вводе
- **WHEN** открыто поле ввода новой выноски с набранным текстом, и пользователь переключил план
- **THEN** поле закрыто, выноска создана на прежнем плане с набранным текстом, на новом плане её нет

#### Scenario: Переключение плана при размещении
- **WHEN** задана точка стрелки, и пользователь переключил план
- **THEN** черновик сброшен, выноска не создана
