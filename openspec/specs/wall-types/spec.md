## Purpose

Типы стен (несущая, перегородка, гипрок) с разным цветом отображения на чертеже для различения конструкций на планах ремонта.

## Requirements

### Requirement: Выбор типа стены
Панель инструментов ДОЛЖНА содержать выбор типа стены цветными образцами: «Несущая», «Перегородка», «Гипрок»; активный тип ДОЛЖЕН быть визуально выделен; по умолчанию ДОЛЖЕН быть выбран тип «Перегородка». Тип применяется к новым стенам. Стрелки вверх/вниз ДОЛЖНЫ переключать тип (вверх — предыдущий, вниз — следующий, с зацикливанием); в поле толщины стрелки ДОЛЖНЫ сохранять нативное поведение.

#### Scenario: Выбор образцом
- **WHEN** пользователь нажимает образец типа
- **THEN** тип становится активным (образец выделен), новые стены и превью рисуются цветом этого типа

#### Scenario: Выбор стрелками
- **WHEN** пользователь нажимает стрелку вниз (или вверх)
- **THEN** активным становится следующий (предыдущий) тип по списку с зацикливанием, превью и новые стены меняют цвет

#### Scenario: Стрелки в поле толщины
- **WHEN** поле толщины в фокусе и нажимается стрелка вверх/вниз
- **THEN** тип стены не переключается, значение толщины меняется нативным степпером

#### Scenario: Дефолтный тип
- **WHEN** приложение открыто
- **THEN** активен тип «Перегородка»

### Requirement: Цвет стены по типу
Каждая стена ДОЛЖНА отображаться цветом своего типа и ДОЛЖНА сохранять тип, с которым была нарисована; смена типа НЕ ДОЛЖНА менять уже нарисованные стены.

#### Scenario: Смена типа не перекрашивает нарисованные стены
- **WHEN** нарисована стена одного типа и пользователь переключает тип
- **THEN** нарисованная стена сохраняет свой цвет, следующая рисуется новым цветом
