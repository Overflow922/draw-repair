## Purpose

Менеджер чертежей: несколько чертежей одновременно, каждый на своей вкладке, с созданием по «+» и удалением при закрытии вкладки.

## Requirements

### Requirement: Вкладки чертежей
Над холстом ДОЛЖНА отображаться панель вкладок: каждый чертёж — вкладка с именем и кнопкой закрытия, активная вкладка ДОЛЖНА быть визуально выделена. Холст и инструменты ДОЛЖНЫ отображать и изменять только активный чертёж. Переключение вкладок ДОЛЖНО показывать выбранный чертёж с его стенами и видом.

#### Scenario: Переключение между чертежами
- **WHEN** открыты два чертежа с разными стенами и пользователь переключается на другую вкладку
- **THEN** холст показывает стены и вид выбранного чертежа

#### Scenario: Независимость чертежей
- **WHEN** пользователь рисует на одной вкладке и переключается на другую
- **THEN** стены первой вкладки остаются в своём чертеже и не появляются на другой

### Requirement: Создание чертежа
Кнопка «+» на панели вкладок ДОЛЖНА создавать новый пустой чертёж и делать его активным. Новому чертежу ДОЛЖНО присваиваться имя вида «Чертёж N», уникальное среди открытых чертежей.

#### Scenario: Новый чертёж
- **WHEN** пользователь нажимает «+»
- **THEN** появляется новая вкладка с пустым холстом и она становится активной

#### Scenario: Уникальное имя по умолчанию
- **WHEN** существует чертёж с именем «Чертёж 1» и пользователь нажимает «+»
- **THEN** новый чертёж получает имя, не совпадающее с именами открытых чертежей

### Requirement: Закрытие вкладки
Закрытие вкладки ДОЛЖНО удалять её чертёж безвозвратно и ВСЕГДА ДОЛЖНО требовать подтверждения, независимо от содержимого чертежа. При подтверждении вкладка и её чертёж ДОЛЖНЫ исчезнуть; при отказе ничего НЕ ДОЛЖНО измениться.

#### Scenario: Подтверждённое удаление
- **WHEN** пользователь нажимает кнопку закрытия вкладки и подтверждает удаление
- **THEN** вкладка исчезает, чертёж удаляется безвозвратно

#### Scenario: Отказ от удаления
- **WHEN** пользователь нажимает кнопку закрытия вкладки и отменяет подтверждение
- **THEN** вкладка и чертёж остаются без изменений

#### Scenario: Подтверждение для пустого чертежа
- **WHEN** пользователь закрывает вкладку чертежа без стен
- **THEN** подтверждение запрашивается так же, как для непустого чертежа

### Requirement: Последняя вкладка
При закрытии последней вкладки приложение ДОЛЖНО автоматически создать новый пустой чертёж и сделать его активным.

#### Scenario: Закрытие единственной вкладки
- **WHEN** пользователь подтверждает закрытие единственной вкладки
- **THEN** приложение показывает новый пустой чертёж на новой вкладке

### Requirement: Переименование вкладки
Пользователь ДОЛЖЕН иметь возможность переименовать чертёж, дважды кликнув по имени вкладки: имя ДОЛЖНО превратиться в поле ввода с текущим именем. Ввод по Enter или потеря фокуса ДОЛЖНЫ применять непустое имя к вкладке и чертежу; пустое имя применять НЕ ДОЛЖНО; Escape ДОЛЖЕН отменять редактирование. Новое имя ДОЛЖНО сохраняться и восстанавливаться после перезагрузки.

#### Scenario: Редактирование имени
- **WHEN** пользователь делает двойной клик по имени вкладки
- **THEN** имя становится полем ввода с текущим именем

#### Scenario: Применение нового имени
- **WHEN** пользователь вводит новое непустое имя и нажимает Enter или переводит фокус
- **THEN** вкладка и чертёж получают новое имя, оно сохраняется в хранилище

#### Scenario: Пустое имя не применяется
- **WHEN** пользователь очищает поле и подтверждает ввод
- **THEN** имя остаётся прежним

#### Scenario: Отмена редактирования
- **WHEN** пользователь нажимает Escape в поле редактирования
- **THEN** имя остаётся прежним, редактирование закрывается
