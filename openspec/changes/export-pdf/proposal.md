## Why

Чертёж существует только внутри приложения: сохранить его наружу нельзя. Нужен экспорт текущей вкладки в PDF — универсальный формат обмена чертёжной документацией, пригодный для печати и отправки.

## What Changes

- Добавляется экспорт текущей вкладки в PDF: векторный вывод стен (контуры, штриховки материалов по ГОСТ) и подписей длины через jsPDF и его Canvas-шим `doc.context2d`, с переиспользованием существующего рендера.
- Подписи длины («3500 мм») выводятся кириллицей — в PDF встраивается кириллический TTF-шрифт (jsPDF сабсетит его автоматически).
- Формат страницы выбирает пользователь: выпадающий список A4–A0 в нижней панели управления; ориентация страницы определяется автоматически по пропорциям чертежа, содержимое вписывается в поля страницы.
- Имя файла: `<имя чертежа>_<дата-время>.pdf` (локальная дата-время с точностью до секунды, например `Чертёж 1_2026-09-05_14-32-07.pdf`); имя чертежа санитизируется.
- Экспорт не включает экранные элементы: сетку, выделение, ручки, превью рисуемой стены.
- При пустом чертеже экспорт недоступен (кнопка неактивна).
- Добавляется рантайм-зависимость `jspdf` (первая в проекте) и файл шрифта.

## Capabilities

### New Capabilities
- `pdf-export`: экспорт активной вкладки в векторный PDF — выбор формата страницы A0–A4, вписывание чертежа, состав выводимых элементов, именование файла.

## Impact

- `package.json` — новая зависимость `jspdf`; новый ассет — кириллический TTF-шрифт.
- `src/main.ts` — кнопка экспорта и select формата, сборка имени файла, скачивание через Blob.
- `src/render.ts` — небольшая параметризация рендера для экспорта (отключение сетки/выделения).
- Новый модуль экспорта (например `src/export/pdf.ts`): подгонка bbox чертежа под страницу (чистая функция — покрыть тестами), генерация PDF, санитизация имени файла.
- Спайк перед реализацией: проверить поддержку `setLineDash` (штрих-пунктир бетона/ж/б), clip-полигонов и повёрнутого текста в `doc.context2d`; при провале шима — запасной план (свой слой PDF-операторов поверх низкоуровневого API jsPDF).
