## MODIFIED Requirements

### Requirement: Объекты плана «Группы включения» в документе
Чертёж в документе хранилища ДОЛЖЕН хранить собственные объекты плана «Группы включения» (`switching-plan`) в необязательном поле; формат документа остаётся версии 3, версия не повышается. Поле содержит список меток линий освещения в порядке постановки (`Метки линий освещения в документе`), список выключателей в порядке постановки (`Выключатели в документе`), а также выноски и примечания плана (по правилам `Выноски в документе` и `Примечания планов в документе`). Подложка, предметы мебели и объекты освещения в поле НЕ ДОЛЖНЫ храниться: они берутся из нижних планов и плана «Потолки и освещение». Чертёж без поля ДОЛЖЕН открываться с пустым содержимым плана (поле при загрузке не дописывается); такой документ НЕ ДОЛЖЕН считаться повреждённым. Некорректная выноска ДОЛЖНА отбрасываться при загрузке по одной; остальные данные чертежа ДОЛЖНЫ восстанавливаться, документ повреждённым не считается. Идентификатор активного плана `switching` ДОЛЖЕН читаться как допустимый (`Активный план чертежа в документе`). Любая правка объектов плана ДОЛЖНА сохраняться автоматически.

#### Scenario: Выноска и примечание сохраняются
- **WHEN** на плане «Группы включения» поставлены выноска с текстом «Выключатель у двери» и примечание, и страница перезагружена
- **THEN** выноска и примечание восстановлены на плане «Группы включения» и не появились на других планах

#### Scenario: Освещение не копируется
- **WHEN** на «Потолках и освещении» стоит светильник, открыт план «Группы включения», и чертёж сохранён
- **THEN** в поле плана нет объектов освещения; светильник хранится только в объектах плана «Потолки и освещение»

#### Scenario: Старый документ
- **WHEN** в хранилище лежит документ версии 3, чертежи которого не содержат объектов плана «Группы включения»
- **THEN** чертежи открываются без изменений, поле в чертеже не появляется

#### Scenario: Активный план «Группы включения»
- **WHEN** пользователь переключил чертёж на план «Группы включения» и перезагрузил страницу
- **THEN** чертёж открывается на плане «Группы включения»

#### Scenario: Прочие планы не затронуты
- **WHEN** документ содержит объекты плана «Группы включения»
- **THEN** объекты всех других планов читаются из прежних полей без изменений

#### Scenario: Автосохранение
- **WHEN** на плане «Группы включения» поставлена выноска
- **THEN** изменение попадает в сохранённый документ без отдельного действия пользователя

### Requirement: Выключатели в документе
Поле плана «Группы включения» ДОЛЖНО хранить выключатели (`light-switch`) необязательным списком в порядке постановки: идентификатор, центр блока (два конечных числа), угол нормали грани (конечное число) и список клавиш — от одной до шести, у каждой список имён линий вида `L<n>` или `LV<n>` (`n` — целое число больше нуля, без повторов в клавише; список может быть пустым). Выключатель без идентификатора, с нечисловым центром или углом, без клавиш, с числом клавиш больше шести, с недопустимым именем или повтором имени в клавише некорректен и ДОЛЖЕН отбрасываться при загрузке целиком, по одному; остальные выключатели и данные чертежа восстанавливаются, документ повреждённым не считается. Выключатель, чья грань исчезла (стену удалили на нижнем плане), не делает документ повреждённым: он сохраняется на прежнем месте и показывается. Пустой список не записывается; поле без списка читается как план без выключателей. Любая правка выключателей ДОЛЖНА сохраняться автоматически.

#### Scenario: Выключатель сохраняется
- **WHEN** на плане поставлен выключатель из трёх клавиш с линиями `L2,LV1`, `L3`, `L4,L5`, и страница перезагружена
- **THEN** выключатель восстановлен с тем же центром, направлением и линиями клавиш

#### Scenario: Битый выключатель отбрасывается
- **WHEN** среди выключателей есть выключатель без клавиш, выключатель из семи клавиш, выключатель с линией `L0` и корректный выключатель
- **THEN** документ открывается как рабочий: три некорректных отброшены, корректный восстановлен

#### Scenario: Стена удалена на нижнем плане
- **WHEN** стена, на грани которой стоит выключатель, удалена на «Монтаже»
- **THEN** документ не повреждён, выключатель сохранён и показан на прежнем месте

#### Scenario: Старый документ
- **WHEN** в хранилище лежит документ с полем плана «Группы включения» без списка выключателей
- **THEN** выключателей нет, поле при загрузке не меняется
