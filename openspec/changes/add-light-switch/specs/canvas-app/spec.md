## MODIFIED Requirements

### Requirement: Группы инструментов
Кнопки панели инструментов ДОЛЖНЫ идти тремя группами сверху вниз: инструменты построения («Стена», кнопка группы «Проёмы», «Окно», на обмерочном плане — кнопка группы «Коммуникации»), инструменты измерения («Размер», «Линейка»), затем «Ластик». Между соседними группами ДОЛЖЕН отображаться разделитель. Инструменты «Проём» и «Дверь» НЕ ДОЛЖНЫ иметь собственных кнопок на панели инструментов: они выбираются в панели группы «Проёмы» (требование «Панель группы «Проёмы»»). Инструменты «Стояк» и «Воздуховод» НЕ ДОЛЖНЫ иметь собственных кнопок на панели инструментов: они выбираются в панели группы «Коммуникации» (требование «Панель группы «Коммуникации»»). Инструмент «Стол» НЕ ДОЛЖЕН иметь собственной кнопки на панели инструментов: он выбирается в панели группы «Мебель» (`furniture-plan` «Панель группы «Мебель» и инструмента «Стол»»). На плане «Черновые работы» панель показывает только инструменты этого плана (`drawing-plans` «Инструменты плана»): первыми идут «Штукатурка», «Прямой угол» и «Стяжка» — по одной кнопке, без групп (`rough-works-plan`), затем «Выноска», «Линейка», «Примечания» и «Ластик». На плане «Реконструкция» панель показывает только инструменты этого плана: первым идёт «Гипсокартон» — одна кнопка, без групп (`reconstruction-plan`), затем «Размер», «Выноска», «Линейка», «Примечания» и «Ластик». На плане «Мебель» панель показывает только инструменты этого плана: первой идёт кнопка группы «Мебель» (`furniture-plan`), затем «Размер», «Выноска», «Линейка», «Примечания» и «Ластик». На плане «Сантехника» панель показывает только инструменты этого плана (`plumbing-plan`): инструментов построения нет, первым идёт «Размер», затем «Выноска», «Линейка», «Примечания» и «Ластик». На плане «Потолки и освещение» панель показывает только инструменты этого плана (`ceiling-plan`): первым идёт «Натяжной потолок» — одна кнопка, без группы, затем кнопка группы «Освещение» (требование «Панель группы «Освещение»»), затем «Выноска», «Линейка», «Примечания» и «Ластик». Инструменты видов освещения НЕ ДОЛЖНЫ иметь собственных кнопок на панели инструментов: они выбираются в панели группы «Освещение». На плане «Группы включения» панель показывает только инструменты этого плана (`switching-plan`): первыми идут «Линия освещения» и «Выключатель» — по одной кнопке, без групп (`light-lines`, `light-switch`), затем «Выноска», «Линейка», «Примечания» и «Ластик».

## ADDED Requirements

### Requirement: Кнопка «Выключатель»
На плане «Группы включения» кнопка «Выключатель» ДОЛЖНА стоять второй на панели инструментов, сразу после «Линия освещения» (`Группы инструментов`). Значок кнопки — знак одной клавиши выключателя красным цветом освещения. Нажатие на кнопку неактивного инструмента делает его активным и открывает вспомогательную панель справа с полем «Клавиш» (целое число от 1 до 6, по умолчанию 1; `light-switch` «Панель инструмента «Выключатель»»); нажатие на кнопку активного инструмента переключает панель (`Вспомогательная панель инструмента`). Панель закрывается при смене плана и вкладки.

#### Scenario: Панель выключателя
- **WHEN** пользователь нажимает кнопку «Выключатель»
- **THEN** кнопка активна, справа открыта панель с полем «Клавиш», в поле 1

#### Scenario: Повторное нажатие
- **WHEN** инструмент активен, и пользователь нажимает его кнопку
- **THEN** панель закрывается, инструмент остаётся активным

#### Scenario: Выделение открывает панель
- **WHEN** без инструмента выделен выключатель из трёх клавиш
- **THEN** панель открыта, в поле 3
