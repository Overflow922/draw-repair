## MODIFIED Requirements

### Requirement: Каталог планов
Приложение ДОЛЖНО иметь упорядоченный каталог планов; у каждого плана есть постоянный идентификатор и название. Каталог ДОЛЖЕН содержать планы «Обмерочный план» (идентификатор `measure`), «Демонтаж» (идентификатор `demolition`), «Монтаж» (идентификатор `mounting`), «Черновые работы» (идентификатор `rough`), «Реконструкция» (идентификатор `reconstruction`), «Мебель» (идентификатор `furniture`), «Сантехника» (идентификатор `plumbing`), «Потолки и освещение» (идентификатор `ceiling`) и «Группы включения» (идентификатор `switching`) в этом порядке. Порядок каталога определяет порядок планов в переключателе и порядок страниц в PDF. Каталог един для всех чертежей: все чертежи имеют один и тот же набор планов.

План «Обмерочный план» ДОЛЖЕН содержать стены, размеры и элементы стены (проёмы, окна, двери) чертежа — те самые объекты, которые чертёж содержал до введения планов; их редактирование, отображение и правила остаются прежними. План «Демонтаж» ДОЛЖЕН содержать только пометки сноса (`demolition-plan`). План «Монтаж» ДОЛЖЕН содержать собственные стены, проёмы, двери, окна и размеры и показывать остатки обмерочного плана после сноса как подложку только для чтения (`mounting-plan`). План «Черновые работы» ДОЛЖЕН содержать только пометки штукатурки и стяжки помещений и показывать результат плана «Монтаж» как подложку только для чтения (`rough-works-plan`). План «Реконструкция» ДОЛЖЕН содержать только стены гипсокартона и их размеры и показывать результат плана «Черновые работы» (без стяжки, штукатурка серым) как подложку только для чтения (`reconstruction-plan`). План «Мебель» ДОЛЖЕН содержать только столы и размеры плана и показывать результат плана «Реконструкция» (штукатурка серым, гипсокартон зелёным) как подложку только для чтения (`furniture-plan`). План «Сантехника» ДОЛЖЕН содержать только размеры плана и показывать результат плана «Реконструкция» и приборы плана «Мебель», подключаемые к воде, как подложку только для чтения (`plumbing-plan`). План «Потолки и освещение» ДОЛЖЕН содержать только натяжные потолки помещений и показывать результат плана «Мебель» (подложку «Мебели» и все предметы мебели без габаритов) как подложку только для чтения (`ceiling-plan`). План «Группы включения» ДОЛЖЕН содержать только метки линий освещения, выключатели, выноски и примечания и показывать результат плана «Потолки и освещение» (подложку «Мебели», все предметы мебели без габаритов и все объекты освещения, без натяжных потолков и расстояний) как подложку только для чтения (`switching-plan`). Коммуникации чертежа (`communications`) не принадлежат ни одному плану: они общие, показываются на всех планах, а правятся только на обмерочном плане.

#### Scenario: Состав каталога
- **WHEN** приложение открыто
- **THEN** каталог планов содержит «Обмерочный план» (`measure`), «Демонтаж» (`demolition`), «Монтаж» (`mounting`), «Черновые работы» (`rough`), «Реконструкция» (`reconstruction`), «Мебель» (`furniture`), «Сантехника» (`plumbing`), «Потолки и освещение» (`ceiling`) и «Группы включения» (`switching`) в этом порядке

#### Scenario: Обмерочный план содержит объекты чертежа
- **WHEN** у чертежа, сохранённого до введения планов, есть стены, размеры и проёмы
- **THEN** в плане «Обмерочный план» отображаются и редактируются те же стены, размеры и проёмы

#### Scenario: План «Монтаж» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Монтаж»
- **THEN** план «Монтаж» показывает остатки обмерочного плана и не содержит собственных объектов

#### Scenario: План «Черновые работы» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Черновые работы»
- **THEN** план «Черновые работы» показывает результат плана «Монтаж» и не содержит пометок штукатурки и стяжки

#### Scenario: План «Реконструкция» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Реконструкция»
- **THEN** план «Реконструкция» показывает результат плана «Черновые работы» серым без стяжки и не содержит стен гипсокартона

#### Scenario: План «Мебель» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Мебель»
- **THEN** план «Мебель» показывает результат плана «Реконструкция» и не содержит столов

#### Scenario: План «Сантехника» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Сантехника»
- **THEN** план «Сантехника» показывает результат плана «Реконструкция» и приборы плана «Мебель» и не содержит собственных размеров, выносок и примечаний

#### Scenario: План «Потолки и освещение» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Потолки и освещение»
- **THEN** план показывает результат плана «Мебель» и не содержит натяжных потолков, выносок и примечаний

#### Scenario: План «Группы включения» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Группы включения»
- **THEN** план показывает результат плана «Потолки и освещение» без натяжных потолков и расстояний и не содержит выносок и примечаний

#### Scenario: Коммуникации общие
- **WHEN** на обмерочном плане поставлен стояк
- **THEN** он виден на планах «Демонтаж», «Монтаж», «Черновые работы», «Реконструкция», «Мебель», «Сантехника», «Потолки и освещение» и «Группы включения» и не входит в собственные объекты ни одного из них

### Requirement: Инструменты плана
У каждого плана ДОЛЖЕН быть собственный набор инструментов и инструмент по умолчанию. Панель инструментов ДОЛЖНА показывать кнопки только инструментов активного плана. План «Обмерочный план»: «Стена», группа «Проёмы» («Проём», «Дверь»), «Окно», «Батарея», группа «Коммуникации» («Стояк», «Воздуховод»), «Размер», «Выноска», «Линейка», «Примечания», «Ластик»; по умолчанию «Стена». План «Демонтаж»: «Демонтаж», «Выноска», «Линейка», «Примечания», «Ластик» (на плане «Демонтаж» ластик удаляет только пометки сноса, `demolition-plan` «Ластик на плане «Демонтаж»»); по умолчанию «Демонтаж». План «Монтаж»: тот же набор и тот же порядок, что у обмерочного плана, кроме группы «Коммуникации» («Стена», группа «Проёмы», «Окно», «Батарея», «Размер», «Выноска», «Линейка», «Примечания», «Ластик»); по умолчанию «Стена»; инструменты действуют на собственные объекты плана «Монтаж» (`mounting-plan` «Собственные объекты плана «Монтаж»»), «Линейка» измеряет по остаткам и собственным стенам, «Ластик» удаляет только собственные объекты «Монтажа». План «Черновые работы»: «Штукатурка», «Стяжка», «Линейка», «Ластик» (`rough-works-plan`; «Выноска» и «Примечания» есть на каждом плане, `rough-works-plan` «Выноски и примечания плана «Черновые работы»»); по умолчанию «Штукатурка»; «Линейка» измеряет по подложке, «Ластик» удаляет только пометки штукатурки, стяжки и выноски плана (`rough-works-plan` «Ластик на плане «Черновые работы»»). План «Реконструкция»: «Гипсокартон», «Размер», «Выноска», «Линейка», «Примечания», «Ластик» (`reconstruction-plan` «Инструменты плана «Реконструкция»»); по умолчанию «Гипсокартон»; «Линейка» измеряет по подложке и стенам гипсокартона, «Ластик» удаляет только стены гипсокартона, размеры и выноски плана. План «Мебель»: группа «Мебель» («Стол»), «Размер», «Выноска», «Линейка», «Примечания», «Ластик» (`furniture-plan` «Инструменты плана «Мебель»»); по умолчанию «Стол»; «Линейка» измеряет по подложке, «Ластик» удаляет только столы, размеры и выноски плана. План «Сантехника»: «Размер», «Выноска», «Линейка», «Примечания», «Ластик» (`plumbing-plan` «Инструменты плана «Сантехника»»); по умолчанию «Размер»; «Линейка» измеряет по подложке и приборам, «Ластик» удаляет только размеры, выноски и примечания плана. План «Потолки и освещение»: «Натяжной потолок», группа «Освещение» («Точечный встроенный светильник», «Датчик пожарной сигнализации потолочный», «Люстра», «Бра», «Электровывод для освещения»), «Выноска», «Линейка», «Примечания», «Ластик» (`ceiling-plan` «Инструменты плана «Потолки и освещение»»); по умолчанию «Натяжной потолок»; «Линейка» измеряет по подложке и предметам мебели, «Ластик» удаляет только натяжные потолки, объекты освещения и выноски плана. План «Группы включения»: «Линия освещения», «Выключатель», «Выноска», «Линейка», «Примечания», «Ластик» (`switching-plan` «Инструменты плана «Группы включения»»); по умолчанию «Линия освещения»; «Линейка» измеряет по подложке и предметам мебели, «Ластик» удаляет только метки линий, выключатели и выноски плана. Коммуникации (`communications`) на планах «Демонтаж», «Монтаж», «Черновые работы», «Реконструкция», «Мебель», «Сантехника», «Потолки и освещение» и «Группы включения» — подложка только для чтения (`communications` «Коммуникации на всех планах»). При переключении плана и чертежа активным становится инструмент плана по умолчанию. Горячие клавиши и жесты инструментов других планов (стрелки смены материала и сдвига стен, Delete стен, размеров, элементов и коммуникаций, правка стен) НЕ ДОЛЖНЫ действовать на плане, где этих инструментов нет, и на плане «Монтаж» не затрагивают объекты других планов; на плане «Реконструкция» они действуют только на стены гипсокартона и размеры этого плана; на плане «Мебель» — только на столы и размеры этого плана; на плане «Сантехника» — только на размеры этого плана (приборы на нём не выделяются, не сдвигаются стрелками и не удаляются); на плане «Потолки и освещение» Delete удаляет только выделенный натяжной потолок или выделенный объект освещения, стрелки ничего не двигают (предметы мебели на нём не выделяются, не сдвигаются и не удаляются); на плане «Группы включения» Delete удаляет только выделенную метку линии освещения или выделенный выключатель, стрелки ничего не делают (предметы мебели и объекты освещения на нём не выделяются, не сдвигаются и не удаляются).

#### Scenario: Инструменты обмерочного плана
- **WHEN** активен «Обмерочный план»
- **THEN** на панели инструментов кнопки «Стена», «Проёмы», «Окно», «Батарея», «Коммуникации», «Размер», «Выноска», «Линейка», «Примечания», «Ластик»; активна «Стена»

#### Scenario: Инструменты плана «Демонтаж»
- **WHEN** активен план «Демонтаж»
- **THEN** на панели инструментов только кнопки «Демонтаж», «Выноска», «Линейка», «Примечания» и «Ластик»; активна «Демонтаж»

#### Scenario: Инструменты плана «Монтаж»
- **WHEN** активен план «Монтаж»
- **THEN** на панели инструментов кнопки «Стена», «Проёмы», «Окно», «Батарея», «Размер», «Выноска», «Линейка», «Примечания», «Ластик»; кнопки «Коммуникации» нет; активна «Стена»

#### Scenario: Инструменты плана «Черновые работы»
- **WHEN** активен план «Черновые работы»
- **THEN** на панели инструментов кнопки «Штукатурка», «Стяжка», «Выноска», «Линейка», «Примечания» и «Ластик» (выноски и примечания есть на каждом плане); кнопок инструментов других планов нет; активна «Штукатурка»

#### Scenario: Инструменты плана «Реконструкция»
- **WHEN** активен план «Реконструкция»
- **THEN** на панели инструментов кнопки «Гипсокартон», «Размер», «Выноска», «Линейка», «Примечания» и «Ластик»; кнопок инструментов других планов нет; активен «Гипсокартон»

#### Scenario: Инструменты плана «Мебель»
- **WHEN** активен план «Мебель»
- **THEN** на панели инструментов кнопки «Мебель», «Размер», «Выноска», «Линейка», «Примечания» и «Ластик»; кнопок инструментов других планов нет; активен «Стол»

#### Scenario: Инструменты плана «Сантехника»
- **WHEN** активен план «Сантехника»
- **THEN** на панели инструментов кнопки «Размер», «Выноска», «Линейка», «Примечания» и «Ластик»; кнопок инструментов других планов, в том числе «Мебель», нет; активен «Размер»

#### Scenario: Инструменты плана «Потолки и освещение»
- **WHEN** активен план «Потолки и освещение»
- **THEN** на панели инструментов кнопки «Натяжной потолок», «Освещение», «Выноска», «Линейка», «Примечания» и «Ластик»; кнопок инструментов других планов, в том числе «Размер», «Стяжка» и «Мебель», нет; активен «Натяжной потолок»

#### Scenario: Инструмент освещения сбрасывается при смене плана
- **WHEN** на плане «Потолки и освещение» активна «Люстра», и пользователь переключается на «Мебель» и обратно
- **THEN** на «Мебели» кнопки «Освещение» нет; после возврата активен «Натяжной потолок»

#### Scenario: Delete на «Потолках и освещении» удаляет светильник
- **WHEN** на плане «Потолки и освещение» без инструмента пользователь кликнул по знаку светильника и нажал Delete
- **THEN** светильник удалён одним шагом истории плана; объекты других планов не изменены

#### Scenario: Инструменты плана «Группы включения»
- **WHEN** активен план «Группы включения»
- **THEN** на панели инструментов кнопки «Линия освещения», «Выключатель», «Выноска», «Линейка», «Примечания» и «Ластик»; кнопок инструментов других планов, в том числе «Освещение», «Натяжной потолок» и «Размер», нет; активна «Линия освещения»

#### Scenario: Delete на «Группах включения» ничего не удаляет
- **WHEN** на плане «Группы включения» без инструмента пользователь кликнул по знаку светильника и нажал Delete
- **THEN** ничего не выделено и не удалено; светильник на «Потолках и освещении» остался

#### Scenario: Инструмент линии сбрасывается при смене плана
- **WHEN** на плане «Группы включения» активна «Линия освещения», и пользователь переключается на «Мебель» и обратно
- **THEN** на «Мебели» кнопки «Линия освещения» нет; после возврата активна «Линия освещения» (инструмент плана по умолчанию)

#### Scenario: Возврат на обмерочный план
- **WHEN** пользователь переключается с «Демонтаж» на «Обмерочный план»
- **THEN** на панели снова кнопки обмерочного плана, активна «Стена»

#### Scenario: Ластик не переходит между планами
- **WHEN** на плане «Демонтаж», «Монтаж», «Черновые работы», «Реконструкция», «Мебель», «Сантехника», «Потолки и освещение» или «Группы включения» активен «Ластик» и пользователь переключается на «Обмерочный план»
- **THEN** активна «Стена»; ластик прежнего плана не действует на объекты обмерочного плана

#### Scenario: Ластик «Монтажа» не трогает обмер
- **WHEN** на плане «Монтаж» активен «Ластик» и пользователь кликает по остатку стены
- **THEN** стена обмерочного плана осталась, шага истории нет

#### Scenario: Ластик «Черновых работ» не трогает подложку
- **WHEN** на плане «Черновые работы» активен «Ластик» и пользователь кликает по стене подложки
- **THEN** стена осталась, шага истории нет

#### Scenario: Ластик «Реконструкции» не трогает подложку
- **WHEN** на плане «Реконструкция» активен «Ластик» и пользователь кликает по стене подложки или по штукатурке
- **THEN** стена и штукатурка остались, шага истории нет

#### Scenario: Ластик «Мебели» не трогает подложку
- **WHEN** на плане «Мебель» активен «Ластик» и пользователь кликает по стене подложки, штукатурке или стене гипсокартона
- **THEN** ничего не удалено, шага истории нет

#### Scenario: Ластик «Сантехники» не трогает приборы
- **WHEN** на плане «Сантехника» активен «Ластик» и пользователь кликает по раковине, стене подложки или штукатурке
- **THEN** ничего не удалено, раковина на «Мебели» осталась, шага истории нет

#### Scenario: Delete на «Сантехнике» не удаляет приборы

- **THEN** раковина не выделена и не удалена ни на «Сантехнике», ни на «Мебели»

#### Scenario: Delete на «Потолках и освещении» не удаляет мебель
- **WHEN** на плане «Потолки и освещение» без инструмента пользователь кликнул по столу вне подписи потолка и нажал Delete
- **THEN** ничего не выделено и не удалено; стол на «Мебели» остался
