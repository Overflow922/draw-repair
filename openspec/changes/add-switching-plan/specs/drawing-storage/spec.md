## ADDED Requirements

### Requirement: Объекты плана «Группы включения» в документе
Чертёж в документе хранилища ДОЛЖЕН хранить собственные объекты плана «Группы включения» (`switching-plan`) в необязательном поле; формат документа остаётся версии 3, версия не повышается. Поле содержит выноски и примечания плана (по правилам `Выноски в документе` и `Примечания планов в документе`). Подложка, предметы мебели и объекты освещения в поле НЕ ДОЛЖНЫ храниться: они берутся из нижних планов и плана «Потолки и освещение». Чертёж без поля ДОЛЖЕН открываться с пустым содержимым плана (поле при загрузке не дописывается); такой документ НЕ ДОЛЖЕН считаться повреждённым. Некорректная выноска ДОЛЖНА отбрасываться при загрузке по одной; остальные данные чертежа ДОЛЖНЫ восстанавливаться, документ повреждённым не считается. Идентификатор активного плана `switching` ДОЛЖЕН читаться как допустимый (`Активный план чертежа в документе`). Любая правка объектов плана ДОЛЖНА сохраняться автоматически.

#### Scenario: Выноска и примечание сохраняются
- **WHEN** на плане «Группы включения» поставлены выноска с текстом «Выключатель у двери» и примечание, и страница перезагружена
- **THEN** выноска и примечание восстановлены на плане «Группы включения» и не появились на других планах

#### Scenario: Освещение не копируется
- **WHEN** на «Потолках и освещении» стоит светильник, открыт план «Группы включения», и чертёж сохранён
- **THEN** в поле плана нет объектов освещения; светильник хранится только в объектах плана «Потолки и освещение»

#### Scenario: Старый документ
- **WHEN** в хранилище лежит документ версии 3, чертежи которого не содержат объектов плана «Группы включения»
- **THEN** чертежи открываются без изменений, поле в чертеже не появляется

#### Scenario: Активный план «Группы включения»
- **WHEN** пользователь переключил чертёж на план «Группы включения» и перезагрузил страницу
- **THEN** чертёж открывается на плане «Группы включения»

#### Scenario: Прочие планы не затронуты
- **WHEN** документ содержит объекты плана «Группы включения»
- **THEN** объекты всех других планов читаются из прежних полей без изменений

#### Scenario: Автосохранение
- **WHEN** на плане «Группы включения» поставлена выноска
- **THEN** изменение попадает в сохранённый документ без отдельного действия пользователя
