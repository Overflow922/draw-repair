# Test Plan

## Scope

Поведение по дельтам `specs/wall-drawing/spec.md` и `specs/length-input/spec.md`,
проверяемое юнит-тестами `vitest` на чистые функции (design D1–D5):

- `wall-angle.ts`: `startRefOf`, `wallAngleDeg`, `angleReferenceRay`, `orthoDirection`,
  `typedDirection`, `parseAngleDeg`;
- `wall-snap.ts`: `snapOnRay`; изменённая ветка `orthoFrom` в `snapVertex`;
  неперечислимое поле `target`;
- `wall-chain.ts`: `chainSegment` — единый расчёт превью и фиксации.

UI (поле угла, Tab, активность поля, дуга на холсте) автотестами не покрывается — в
проекте нет DOM-тестов; ручная проверка в браузере (раздел Out of Scope → tasks).

### Соглашения

- `R(z) = snapRadiusCm(z)` = `12 / (2·z)`: 6 см при `z = 1`, 30 см при `z = 0.2`.
  `GRID = 10`. Толщина новой стены `t = 20` (`newHalf = 10`, зона прилипания
  `max(R, 10)` = 10 при `z = 1`).
- Экран: y вниз. «Против часовой на экране» поворачивает `(1,0)` к `(0,−1)`.
- Сцены (толщина 20, если не указано): **S** `W=(0,0)→(100,0)` (грани y=±10, торцы x=0,
  x=100); **L** `A=(0,0)→(300,0)`, `B=(0,0)→(0,300)`; **T** `A=(0,0)→(300,0)`,
  `C=(150,10)→(150,200)`; **N** `A=(0,0)→(300,0)`, `C1=(100,10)→(100,200)`,
  `C2=(125,10)→(125,200)`; **P** (параллельные) `A=(0,0)→(100,0)`, `B=(0,50)→(100,50)`;
  **G30** `G=(0,0)→(100cos30°, 100sin30°)`.
- Сравнение направлений и точек — `toBeCloseTo(·, 9)`, если не указано иное.

### wall-angle.ts

- **REF-FACE-1** — `startRefOf(snapVertex((50,14), S, R(1), GRID, 20))` =
  `{kind:"face", normal:(0,1)}`.
- **REF-CAP-1** — `startRefOf(snapVertex((106,0), S, …))` = `{kind:"cap", normal:(1,0)}`.
- **REF-CORNER-1** — сцена L в порядке `[A,B]` и `[B,A]`, курсор (18,12): прилипание к
  верхней грани A в точке (20,10) вплотную к B; `startRefOf` в обоих порядках =
  `{face, (0,1)}`.
- **REF-GRID-1** — курсор (500,500) без стен рядом → `startRefOf` = `null`.
- **REF-SHAPE-1** — результат `snapVertex` с прилипанием: `Object.keys` = `["point","source"]`,
  `target` читается (`"face"` / `"cap"`).
- **ANG-FACE-1** — ref `{face,(0,1)}`: dir (0,1) → 90.
- **ANG-FACE-2** — dir (cos60°, sin60°) → 60; dir (−cos60°, sin60°) → 60;
  dir (cos30°, sin30°) → 30 (точность 1e-9).
- **ANG-CAP-1** — ref `{cap,(1,0)}`: dir (1,0) → 180.
- **ANG-CAP-2** — dir (0,1) → 90 и dir (0,−1) → 90; dir (cos45°, sin45°) → 135.

  для (−cos60°, sin60°) = (−1,0); для cap — всегда (−1,0) (луч внутрь стены).
- **ORTHO-FACE-1** — ref `{face, n}` с `n = (−sin30°, cos30°)` (G30): v — n, повёрнутая на

- **ORTHO-FACE-2** — граница: v — n, повёрнутая на 15° → n; на 15.1° → `null`.
- **ORTHO-FACE-3** — v под 10° к грани (ref `{face,(0,1)}`, v = (cos10°, sin10°)) → `null`
  (вдоль грани не притягивается); v (0.1, −1) — внутрь стены → `null`.

- **ORTHO-CAP-2** — v (0.2, 1) → (0,1); v (0.2, −1) → (0,−1).

- **ORTHO-FREE-1** — ref `null`: v (1, 0.2) → (1,0); v (−0.2, 1) → (0,1); v (−1, −0.1) → (−1,0).
- **ORTHO-FREE-2** — ref `null`: v под 20° → `null`.

- **TYPED-FACE-2** — 60°, v (−1,1) → (−cos60°, sin60°).
- **TYPED-CAP-1** — ref `{cap,(1,0)}`: 180° → (1,0); 90°, v (0.5,1) → (0,1);

### wall-chain.ts (`chainSegment`)

Общий вход: `radiusCm = R(1)`, `gridStepCm = 10`, `thicknessCm = 20`.

- **CH-SLANT-1** — G30, start — `snapVertex` у грани G (ref face), raw: перпендикуляр,
  повёрнутый на 10°, длина 150; `ortho = true` → `dir` = нормаль грани, `angleDeg` = 90
  (1e-9).
- **CH-FREE-1** — ref `null`, рядом G30 вне зоны, raw под 8° к горизонтали, `ortho` → dir
  (1,0) или (−1,0) по стороне, не нормаль G30.
- **CH-FREE-2** — ref `null`, `typedAngleDeg = 60`, `ortho = false` → `dir` по курсору,

- **CH-OFF-1** — S, start (50,10) (ref face (0,1)), raw = start + 200·(sin17°, cos17°),
  `ortho = false` → `dir` ≠ (0,1), `angleDeg` ∈ [72.5, 73.5] (сетка смещает точку
  курсора), `Math.round(angleDeg)` = 73.
- **CH-LEN-1** — то же с отклонением 5°, `typedLengthCm = 300`, `ortho = false` →
  `end = start + 300·unit(snap.point − start)`, угол ≠ 90 (не фиксируется перпендикуляр).
- **CH-LEN-2** — `ortho = true`, отклонение 5°, длина 300 → `end = (50, 310)` точно.
- **CH-LEN-3** — `typedAngleDeg = 90`, `typedLengthCm = 300` → `end = (50,310)`.
- **CH-TYPED-1** — `ortho = true`, `typedAngleDeg = 80`, raw вдоль (0,1) с небольшим
  смещением вправо → `angleDeg` = 80, `dir` ≠ (0,1).
- **CH-TYPED-2** — `typedAngleDeg = 120` (грань), `ortho = true`, raw под 5° → `dir` =
  (0,1) (значение не применено, работает орто); `typedAngleDeg = 0` → то же.
- **CH-TYPED-3** — P-подобная сцена: A (0,0)→(300,0), B (0,200)→(300,200); start (100,10)

- **CH-COMMIT-1** — превью и фиксация — один расчёт: одинаковые входы дают одинаковые

## Invariants

- Конец при заданном направлении всегда на луче: для набора курсоров в сценах L, T, N, S
  с началами у граней и торцов `cross(end − start, dir) ≈ 0` и `dot(end − start, dir) ≥ 0`
  (INV-RAY-1).
- Прилипший конец на луче: квадрат установки без наложения (`maxOverlap ≤ 1e-6`) и
  конец не строго внутри тел (INV-RAY-2).
- Превью и фиксация: `chainSegment` — единственный источник конца (CH-COMMIT-1,
  CH-DET-1).
- Угол в диапазоне: `wallAngleDeg` для face ∈ [0,90], для cap ∈ [0,180] на сетке
  направлений (INV-ANG-1).

## Integration Cases

- `snapVertex` с `orthoFrom` использует луч (SNAP-ORTHO-WALL-1) и сохраняет
  утверждённые SNAP-ORTHO-*, SNAP-CHAIN-2/3, CAP-*, CE-*, INV-CHAIN-END-1.
- `chainSegment` + `startRefOf(snapVertex(...))` — реальная цепочка от прилипания начала
  до конца (CH-SLANT-1, CH-END-1, CH-TYPED-3).

## Mutation Targets

- `<=` → `<` в допуске орто (ORTHO-FACE-2) и зоне прилипания (RAY-REACH-EQ-1).
- Перепутанные диапазоны face/cap (TYPED-RANGE-1, ANG-*).
- Знак стороны в `typedDirection` (TYPED-FACE-2, TYPED-CAP-1, TYPED-TIE-1).
- Возврат проекции курсора вместо пересечения луча (RAY-FACE-1, SNAP-ORTHO-WALL-1).
- Пропуск проверки наложения в `snapOnRay` (RAY-NOROOM-1).
- Пропуск проверки открытости (RAY-CLOSED-1).
- Выбор первого пересечения вдоль луча вместо ближайшего к курсору (RAY-NEAREST-1).
- `<` → `<=` в выборе ближайшего (RAY-TIE-1).
- Сетка по координатам на наклонном луче / по длине на осевом (RAY-SLANT-1, RAY-AXIS-1).
