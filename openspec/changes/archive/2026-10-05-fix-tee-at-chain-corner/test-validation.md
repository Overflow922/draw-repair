Эталон. В scratch-каталоге (вне репозитория) лежит копия `src/wall-geometry.ts` с эталонным `endShape` по design D1–D3 и мутациями, которые переключаются через `process.env.MUT`. Эталон сверен с текущим `src/wall-geometry.ts` через `git diff --no-index`: отличается только `endShape` (и заголовок с локальными типами), остальной код совпадает. Сверка с design:
- D1 — попарная проверка всех пар соседей с порогом `jointTol(cᵢ, cⱼ) + SLICE`, нестрогое сравнение; клика → прежний плоский торец, все соседи в `exempt`;

- D3 — почти коллинеарная выбранная пара в непопарном наборе → плоский торец без срезов и без `exempt`.

Тестовый файл скопирован в scratch без изменений, кроме пути импорта и локальных типов `Point`/`Wall`. Эталон проходит все 16 тестов. Кроме того, эталон подставлен вместо `wall-geometry.ts` в полную копию `src/` в scratch: весь набор проекта (1116 тестов, включая существующие тесты стыков) проходит. ## Findings

- Тесты обнаруживаются раннером. Результаты до реализации (11 FAIL / 5 PASS) совпадают с test-suite.md. Эталон по design D1–D3 проходит все 16 тестов и весь набор проекта (1116).
- Все обязательные и рекомендованные изменения раунда 2 внесены: TC-13 убивает пороги с толщиной стены H, TC-14 — проверку только с первым соседом, дополненный TC-8 — `exempt` всех соседей в почти коллинеарном наборе.
- Все критические мутации из задания убиты: удаление попарной проверки, `<` вместо `<=`, поздняя и ближайшая соседняя вместо ранней, все неверные пороги пары (своей стены, минимум пары, максимум с участием стены, `jointTol(wall, cᵢ)`, `jointTol(wall, cⱼ)`), проверка только первого соседа, непопарный → плоский, срез по биссектрисе в непопарном наборе, пропуск проверки почти коллинеарного стыка, все соседи в `exempt`.
- Остаются две некритичные выжившие мутации, обе касаются только наборов из трёх и более соседей: порог по максимальной толщине всех соседей и проверка только соседних по порядку пар. Конфигурации редкие, а основной сценарий изменения и правило «порог своей пары» для двух соседей защищены с обеих сторон. Блокером не считаются.
- Непопарная ветка для превью (`iWall = −1`) не проверяется. По design D4 код общий; мутация «удаление попарной проверки» ломает Q3, но в файле такого теста нет. Некритично.
