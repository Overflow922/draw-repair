Реализация под утверждённые тесты (VERDICT: PASS, test-validation.md раунд 3). Правило 4: production code адаптируется к тестам; `src/wall-geometry.test.ts` и существующие тесты не изменяются.

Контракт и ссылки: design.md (D1–D6), дельты `specs/wall-drawing/` и `specs/wall-joints/`, утверждённые тесты `src/wall-geometry.test.ts` (43 теста, ID из test-suite.md).

## 1. Канонический модуль `src/wall-geometry.ts`

- [x] 1.1 `displayPolygons(wall, walls): Point[][]` — тотальная классификация стыков: 0 соседей в пороге → свободный плоский торец; 1 → угловой/T-стык; 2+ → плоские торцы (spec wall-joints: «Особые конфигурации вершин», «Допуск вершины стыка»). Допуск прямого угла 0.5°; коллинеарность → прямоугольный контакт со сведением зазора; иначе клин принадлежит поздней стене («поздняя» = индекс в массиве); ранняя — нетронутый прямоугольник; легаси-оси в общей вершине → поздняя доведена до дальней грани. Тесты: JOINT-FREE-1, JOINT-RIGHT-1/2/3, JOINT-OBLIQUE-1/2/3/4, JOINT-91-1, JOINT-COLLIN-1, JOINT-OVERLAP-1, JOINT-MULTI-1, JOINT-LEGACY-1, JOINT-PREVIEW-1, BOUND-DEGENERATE-1
- [x] 1.2 `snapVertex(p, walls, radiusCm, gridStepCm, newWallThicknessCm, orthoFrom?)` — приоритет: грань/торец/продолжение → орто-ось (15° включительно) → узел сетки; детерминизм (равные расстояния → меньший индекс); орто гридит только подвижную координату (неподвижная = координата последней вершины точно); вершина углового прилипания на полутолщине новой стены от торца; результат `{ point, source }`. Тесты: SNAP-GRID-1, SNAP-FACE-1/2, SNAP-END-1/2/3/4, SNAP-CONT-1, SNAP-PRIO-1/2, SNAP-ORTHO-1/2/3/4/5, SNAP-ORTHO-VERT-1, SNAP-ORTHO-FIXED-1, SNAP-RADIUS-1/2, SNAP-DET-1/2 (spec wall-drawing: дельта)
- [x] 1.3 `snapRadiusCm(zoom) = SNAP_RADIUS_PX / (PX_PER_CM * zoom)` — единственная точка вывода радиуса (design D4). Тест: SNAP-RADIUS-PX-1
- [x] 1.4 `hitWall(p, walls, toleranceCm)` — попадание по `displayPolygons` (позже в массиве — выше); полосный допуск оси сохранён для совместимости с wall-selection; вырожденные стены игнорируются. Тесты: HIT-WEDGE-1, HIT-COVER-1, HIT-EMPTY-1, HIT-BAND-1, HIT-CONS-1, BOUND-DEGENERATE-1
- [x] 1.5 Инвариант чистоты: ни одна функция модуля не мутирует входные стены (spec wall-joints: «Оси и длины не меняются»). Тест: INV-PURE-1

## 2. Потребители (production code, без тестов)

- [x] 2.1 `src/render.ts`: `drawWall`/`drawOutline`/`strokeContour` потребляют `displayPolygons` (заливка/штриховка — клип по полигонам; контур — рёбра тех же полигонов с подавлением шва однотипных и отображением у разнотипных). Старые wall-функции остаются в `geometry.ts` только как легаси-экспорты утверждённых тестов `geometry.test.ts` (Rule 4); production их не вызывает (spec wall-joints: «Согласованность отображаемой формы»; компенсация юнит-скороупа шва — код-ревью этой задачи)
- [x] 2.2 `src/geometry.ts`: `hitWall` реэкспортирует каноническую реализацию из `wall-geometry` (три существующих теста hitWall проходят без изменений); мёртвый старый `hitWall`/`inBand` удалены. Старые `findVertexSnap`/`snapVertex`/`orthoAxis`/`lockedDirection`/`subtractCovered`/`wallDisplayPolys`/`sameTypeJoint`/`pointInConvex` сохранены — их фиксируют утверждённые тесты `geometry.test.ts` (Rule 4); production их не вызывает
- [x] 2.3 `src/main.ts`: `updateWallCursor` вызывает `snapVertex` со `snapRadiusCm(view.zoom)`, орто-флагом и текущей толщиной для ОБЕИХ вершин цепочки (вторая вершина получает сетку и орто); `commitPoint` фиксирует по результату снаппера; квадрат ставится по наружной нормали из снаппера (неэнумерируемое вспомогательное поле `normal`, контракт `{point, source}` замороженных тестов не затронут) (spec wall-drawing: дельта; разводка — компенсация Out of Scope, проверяется в 3.4)
