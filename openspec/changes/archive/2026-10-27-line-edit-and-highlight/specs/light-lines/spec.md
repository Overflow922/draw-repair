## MODIFIED Requirements

### Requirement: Панель инструмента «Линия освещения»
Панель инструмента ДОЛЖНА содержать одно поле «Линия» с целым числом `n` больше нуля (по умолчанию 1), по образцу поля опускания натяжного потолка (`ceiling-plan`). Значение панели применяется к новым меткам. Выделение метки (`Выделение, правка и удаление метки`) открывает панель инструмента и показывает в поле `n` выделенной метки; правка поля меняет имя выделенной метки одним шагом истории плана. Недопустимое значение (`Линия освещения и метка`) не применяется, поле возвращает прежнее значение. Изменение поля при активном инструменте без выделенной метки меняет только значение для новых меток.

Выделение светильника, который может нести метку, или вытяжки без инструмента (`canvas-app` «Выделение и правка только без инструмента») ТАКЖЕ ДОЛЖНО открывать панель. Если у выделенного объекта есть показанная метка, в поле её номер `n`, иначе поле пустое. Ввод допустимого значения ставит метку выделенному объекту (светильнику `L<n>`, вытяжке `LV<n>`) или меняет имя существующей метки одним шагом истории плана; ввод имени, равного текущему, шага не создаёт. Недопустимое значение не применяется, поле возвращает прежний вид. Правка поля у выделенного объекта не меняет значение панели для новых меток. Выделение датчика пожарной сигнализации панель НЕ ДОЛЖНО открывать. Снятие выделения закрывает панель.

#### Scenario: Значение для новых меток
- **WHEN** пользователь ввёл в поле 4 и кликнул по светильнику
- **THEN** метка `L4`

#### Scenario: Выделение показывает значение
- **WHEN** выделена метка `L7`
- **THEN** панель открыта, в поле 7

#### Scenario: Правка в панели
- **WHEN** выделена метка `L7`, и в поле введено 9
- **THEN** метка `L9`, один шаг истории

#### Scenario: Выделен светильник с меткой
- **WHEN** без инструмента выделен светильник с меткой `L7`
- **THEN** панель открыта, в поле 7

#### Scenario: Постановка метки выделенному светильнику
- **WHEN** выделен светильник без метки, поле пустое, и в нём введено 3
- **THEN** у светильника метка `L3`, один шаг истории; светильник остаётся выделенным; инструмент не выбирался

#### Scenario: Смена линии выделенного светильника
- **WHEN** выделен светильник с меткой `L3`, и в поле введено 5
- **THEN** метка `L5`, один шаг истории; отмена возвращает `L3`

#### Scenario: Выделена вытяжка
- **WHEN** выделена вытяжка, поле пустое, и в нём введено 2
- **THEN** у вытяжки метка `LV2`, один шаг истории

#### Scenario: Недопустимое значение у светильника
- **WHEN** выделен светильник с меткой `L3`, и в поле введено `abc`
- **THEN** метка осталась `L3`, шага истории нет, в поле снова 3

#### Scenario: Датчик
- **WHEN** без инструмента выделен датчик пожарной сигнализации
- **THEN** панель «Линия освещения» не открыта

#### Scenario: Значение для новых меток не меняется
- **WHEN** в панели для новых меток значение 4, выделенному светильнику вводят 9, затем выбирают инструмент «Линия освещения»
- **THEN** в поле по-прежнему 4
