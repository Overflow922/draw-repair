## Purpose

Долговременное хранение чертежа: JSON-документ в localStorage браузера с автосохранением при каждом изменении и восстановлением при загрузке страницы.

## ADDED Requirements

### Requirement: Формат документа
Чертёж ДОЛЖЕН храниться как JSON-документ версии 1, содержащий номер версии, список стен и вид (масштаб и панорамирование). Координаты вершин и толщины ДОЛЖНЫ храниться в сантиметрах, тип каждой стены — идентификатором типа. Представление документа НЕ ДОЛЖНО зависеть от единиц отображения.

#### Scenario: Сохранённый документ соответствует формату
- **WHEN** чертёж сохранён
- **THEN** в хранилище лежит валидный JSON с версией 1, списком стен (концы в см, толщина в см, идентификатор типа) и видом (масштаб, панорамирование)

### Requirement: Автосохранение при изменениях
Каждое изменение чертежа — добавление или правка стены (перемещение, перетаскивание конца, ввод длины, изменение толщины или типа), а также изменение вида (зум, панорамирование) — ДОЛЖНО сохраняться автоматически, без явного действия пользователя. Сохранённое состояние ДОЛЖНО оставаться актуальным в любой момент, в том числе при немедленном закрытии страницы после изменения.

#### Scenario: Стены восстанавливаются после перезагрузки
- **WHEN** пользователь нарисовал или отредактировал стены и перезагрузил страницу
- **THEN** все стены восстановлены: геометрия, толщина и тип каждой стены совпадают

#### Scenario: Вид восстанавливается после перезагрузки
- **WHEN** пользователь изменил зум или панорамирование и перезагрузил страницу
- **THEN** вид (масштаб и сдвиг) восстановлен

#### Scenario: Сохранение без явного действия
- **WHEN** пользователь завершил изменение и сразу закрыл вкладку браузера
- **THEN** при следующем открытии страницы изменение присутствует; отдельная команда сохранения не требуется

### Requirement: Восстановление при загрузке
При открытии страницы приложение ДОЛЖНО восстановить чертёж из хранилища. Если данных в хранилище нет, приложение ДОЛЖНО открыться с пустым чертежом.

#### Scenario: Пустое хранилище
- **WHEN** страница открывается впервые и данных в хранилище нет
- **THEN** приложение открывается с пустым чертежом

### Requirement: Повреждённые данные
Если сохранённые данные не читаются как документ чертежа (битый JSON или структура не соответствует формату), приложение ДОЛЖНО открыться с пустым чертежом и ДОЛЖНО остаться работоспособным; последующие сохранения ДОЛЖНЫ записывать корректный документ.

#### Scenario: Битый JSON
- **WHEN** в хранилище лежит строка, не являющаяся валидным JSON, и пользователь открывает страницу
- **THEN** приложение открывается с пустым чертежом и продолжает работать

#### Scenario: Структура не соответствует формату
- **WHEN** в хранилище лежит валидный JSON, но структура не соответствует формату документа, и пользователь открывает страницу
- **THEN** приложение открывается с пустым чертежом и продолжает работать

### Requirement: Данные неизвестной будущей версии
Если в хранилище документ с номером версии новее поддерживаемой, приложение ДОЛЖНО открыться с пустым чертежом и ДОЛЖНО работать, но НЕ ДОЛЖНО ничего записывать в хранилище, пока там находится документ такой версии. Хранимые данные ДОЛЖНЫ остаться неизменными.

#### Scenario: Открытие документа будущей версии
- **WHEN** в хранилище документ версии больше поддерживаемой и пользователь открывает страницу
- **THEN** приложение открывается с пустым чертежом, данные в хранилище не изменяются

#### Scenario: Сессия поверх документа будущей версии
- **WHEN** пользователь рисует в такой сессии и перезагружает страницу
- **THEN** нарисованные в этой сессии изменения не сохранились, документ будущей версии остался в хранилище без изменений
