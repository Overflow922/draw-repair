Результаты прогона (Firefox, dev-сервер Vite):

- Первое открытие: пустое хранилище → пустой холст, ключ в localStorage не создаётся до первой мутации.
- Рисование: после двух кликов в хранилище валидный документ v1 (стены в см, `thicknessCm`, id типа, вид).
- Перезагрузка после рисования: обе стены восстановлены (геометрия, толщина, тип, подписи длин) — скриншот.
- Зум/пан: вид `{zoom, pan}` сохранён; после перезагрузки вид восстановлен (значения и рендер совпадают).
- Битый JSON: приложение открылось и работает; первая мутация перезаписала хранилище валидным документом.
- Чужая структура (`{version:1}` без стен/вида): открытие пустым, работает, мутация восстанавливает валидный документ.
- Документ `version: 2`: открытие пустым; рисование и зум в сессии НЕ изменили хранилище (read-only подтверждён побайтно).
