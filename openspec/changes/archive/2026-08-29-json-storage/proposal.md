## Why

Чертёж существует только в памяти страницы: перезагрузка или случайное закрытие вкладки браузера уничтожает всю работу. Нужен формат хранения чертежа и автосохранение, чтобы рисунок переживал перезагрузку страницы.

## What Changes

- Вводится JSON-формат документа чертежа (версия 1): `version`, `walls`, `view` — зеркально рантайм-модели, координаты и толщины в сантиметрах.
- Текущий чертёж автоматически сохраняется в localStorage при каждой мутации (стены, выделение-модификации, зум/пан) и восстанавливается при загрузке страницы.
- Восстановление валидирует данные: битый JSON → пустой чертёж; неизвестная будущая `version` → режим «только чтение» без перезаписи хранилища.
- Новый модуль `storage.ts` с чистыми функциями сериализации/десериализации и тонкой обвязкой над localStorage.

## Capabilities

### New Capabilities

- `drawing-storage`: формат документа чертежа JSON v1, автосохранение текущего чертежа в localStorage и восстановление при загрузке страницы, включая поведение при повреждённых или будущих данных.

### Modified Capabilities

_(нет — существующие требования не меняются)_

## Impact

- `src/main.ts`: точки мутаций помечают dirty-флаг; сохранение выполняется при перерисовке после мутации; при старте выполняется загрузка из хранилища.
- Новый файл `src/storage.ts`; модель типов в `src/types.ts` дополняется типом документа.
- Зависимостей не добавляет; размер хранилища не критичен (чертёж ≈ килобайты при лимите ~5 МБ).
- Закладывает шов для менеджера чертежей: смена схемы хранения локализуется в `storage.ts`.
