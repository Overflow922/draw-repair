## MODIFIED Requirements

### Requirement: Выделение проёма кликом
Вне рисования цепочки, вне активного ластика и вне активного инструмента «Размер» клик по проёму — участку между откосами через всю толщину стены — ДОЛЖЕН выделять проём вместо опорной стены. Клик по размеру выделяет размер (`dimension-selection`). Выделенный проём ДОЛЖЕН отображаться подсветкой выделения по контуру участка проёма; его размеры и подпись правятся на месте (требование «Ввод чисел размеров проёма»). Выделение проёма НЕ ДОЛЖНО открывать вспомогательную панель и менять текущий инструмент группы «Проёмы» (`canvas-app`).

Когда активен инструмент установки элементов стены — «Проём», «Дверь» или «Окно» — и клик выделил существующий элемент стены любого вида, инструмент ДОЛЖЕН деактивироваться: активного инструмента не остаётся (как после Esc), призрак исчезает, вспомогательная панель группы «Проёмы» закрывается, выделение элемента сохраняется. Так же инструмент установки ДОЛЖЕН деактивироваться, когда нажатие правит уже выделенный элемент: клик по его правимому числу (требование «Ввод чисел размеров проёма») или в зону направления выделенной двери (`door`, «Направление выделенной двери»); выделение при этом сохраняется. То же верно для выделения рамкой: если рамка захватила хотя бы один элемент стены, инструмент установки деактивируется, а выделение (в том числе стен и размеров, захваченных рамкой) сохраняется; рамка, не захватившая ни одного элемента стены, инструмент не снимает. Установка нового элемента инструмент НЕ деактивирует. Нажатие, которое ничего не правит и ничего не выделяет, инструмент установки не снимает. Далее выделенный элемент правится как при любом другом выделении: числа — на месте, зоны направления двери (`door`, «Направление выделенной двери»), перетаскивание, стрелки. Параметры новых элементов и текущий инструмент группы «Проёмы» при этом НЕ ДОЛЖНЫ меняться. При остальных активных инструментах («Стена») выделение элемента НЕ ДОЛЖНО менять активный инструмент. Деактивация НЕ ДОЛЖНА создавать записи в истории.

#### Scenario: Клик по проёму выделяет проём
- **WHEN** активен инструмент «Стена», цепочка не рисуется, и пользователь кликнул внутри участка проёма
- **THEN** выделен проём, стена не выделена, цепочка не начинается, видны размеры проёма

#### Scenario: Выделение проёма не открывает панель
- **WHEN** текущий инструмент группы «Проёмы» — «Дверь», панель группы закрыта, и пользователь выделил проём кликом
- **THEN** панель группы закрыта, текущий инструмент группы — «Дверь»; размеры проёма и подпись «H=…» подчёркнуты как правимые

#### Scenario: Выделение двери выводит из установки
- **WHEN** активен инструмент «Дверь», на стене W стоит дверь, и пользователь кликнул внутри её участка
- **THEN** дверь выделена, активного инструмента нет, призрака нет, панель группы закрыта, текущий инструмент группы — «Дверь»; новая дверь не поставлена, запись в истории не создана

#### Scenario: Выделение окна при инструменте «Проём»
- **WHEN** активен инструмент «Проём», и пользователь кликнул внутри участка окна
- **THEN** окно выделено, активного инструмента нет

#### Scenario: Направление двери меняется сразу после выделения
- **WHEN** активен инструмент «Дверь», пользователь кликнул по существующей двери (петли у `a`, открывание `left`), затем кликнул в зону петель `b`, `right` (`door`, «Направление выделенной двери»)
- **THEN** у двери петли у `b`, открывание `right`; дверь по-прежнему выделена; активного инструмента нет; в истории одна новая запись

#### Scenario: Клик в зону направления при инструменте установки
- **WHEN** активен инструмент «Дверь», только что поставленная дверь выделена, и пользователь кликнул в зону другого направления (в том числе по её штриховому полотну)
- **THEN** направление двери изменилось одной записью, дверь выделена, активного инструмента нет, панель группы закрыта, новая дверь не поставлена

#### Scenario: Выделение рамкой при инструменте установки
- **WHEN** активен инструмент «Дверь», и пользователь рамкой захватил существующую дверь
- **THEN** дверь выделена, активного инструмента нет, панель группы закрыта

#### Scenario: Рамка без элементов не снимает инструмент
- **WHEN** активен инструмент «Дверь», и пользователь рамкой захватил только участок стены без элементов или пустое место
- **THEN** инструмент «Дверь» остаётся активным

#### Scenario: Клик по правимому числу при инструменте установки
- **WHEN** активен инструмент «Дверь», дверь выделена, и пользователь кликнул по числу её ширины
- **THEN** открыто поле ввода ширины, дверь выделена, активного инструмента нет

#### Scenario: Инструмент «Стена» остаётся активным
- **WHEN** активен инструмент «Стена», цепочка не рисуется, и пользователь выделил дверь кликом
- **THEN** дверь выделена, активным остаётся инструмент «Стена»

#### Scenario: Клик по пустому месту в инструменте установки ставит элемент
- **WHEN** активен инструмент «Дверь», призрак отображается на стене, не на существующем элементе, и пользователь кликнул
- **THEN** поставлена новая дверь и выделена; инструмент «Дверь» остаётся активным
