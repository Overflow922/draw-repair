# Test Plan

## Scope

Выбор цели нажатия левой кнопки — чистая функция `pressPick` (design D1): маркеры одиночной выделенной стены
(конец `a`, конец `b`, середина) главнее размера, элемента стены (проём, окно) и тела стены; доступность среднего
маркера, размеров и элементов задаётся опциями. Дополнительно — сквозные проверки сценариев: стена,
перемещённая за средний маркер над проёмом, уносит проём без изменения его данных; проём, нажатый вне маркеров,
сдвигается на проекцию смещения.

Файл тестов: `src/doorway/press-pick.test.ts`. Попадание в средний маркер `midpointAt` уже покрыто
`src/geometry.test.ts` («midpointAt», добавлено в `b30c4d0`) и входит в набор.

## Сцены

- **F** — свободная стена W `(0, 0)–(500, 0)` толщиной 20 (`sceneF`), середина `(250, 0)`.
- **DC** — F + проём `door("W", "a", 205)`: откосы `x = 205` и `x = 295`, середина W внутри участка.
- **WC** — F + окно `win("W", "a", 190)` шириной 120: участок `x` 190…310, середина внутри.
- **DA** — F + проём `door("W", "a", 0)`: участок `x` 0…90 накрывает конец `a`.
- **RD** — комната R (`sceneR`) + размер между внутренними углами W `(10, 10)–(490, 10)` с выносом −5 (размерная
  линия на `y = 5`, число размера — около `(250, 5)`), проходит в 5 см от середины W.
- **RF** — комната R + тот же размер с выносом 90 (размерная линия на `y = 100`, вдали от стен).
- **S** — короткая стена `(0, 0)–(8, 0)` толщиной 20.
- Радиус привязки в тестах — 6 см (12 px при масштабе 1, `SNAP_RADIUS_PX / PX_PER_CM`), `textFactor = 2` (как в `main.ts`).
- Опции по умолчанию — все цели доступны: `{ middleMarker: true, dimensions: true, elements: true }`.

## Invariants

- При одиночной выделенной стене попадание в её маркер всегда даёт `end`/`middle`, что бы ни лежало под точкой.
- Маркеры принадлежат только `selectedWall`: маркеры других стен не существуют.
- Порядок: конец `a` → конец `b` → середина → размер → элемент → тело стены → `null`.
- Опции отключают только свою цель; отключение среднего маркера не отключает концевые (PP-17).
- Перемещение стены за середину над проёмом не меняет данных проёма (сторона, расстояние, ширина) и не нарушает
  инвариант проёма (PP-20).

## Integration Cases

- PP-20: DC — `moveWallsBounded(walls, [W], (0, −50), { ortho: false, doorways: [d] })` возвращает `(0, −50)`, W на
  `y = −50`, проём не изменён, `doorwayHolds` истинно.
- PP-21: DC — нажатие `(220, 0)` при выделенной W даёт `doorway`; `slideDoorway(d, walls, (−30, 0))` даёт
  проём с расстоянием привязки 175 и той же стороной `a`.
- Маршрутизация `main.ts` (`switch` по `kind`, вычисление опций по инструменту, `selectedWall = null` при
  мультивыделении) — ручная проверка в браузере (DOM-тестов жестов в проекте нет, пункт в `TODO.md`).

## Mutation Targets

- Перестановка проверок маркеров после элемента или размера → PP-01, PP-02, PP-04, PP-05, PP-06.
- Перестановка середины перед концами → PP-07, PP-08, PP-09.
- Перестановка `b` перед `a` → PP-09.
- `<=` → `<` в радиусе середины → PP-18; расширение радиуса → PP-19.
- Игнорирование `middleMarker` → PP-11, PP-12; применение `middleMarker` к концам → PP-17.
- Игнорирование `elements` → PP-14; игнорирование `dimensions` → PP-15; `elements` выключает и средний маркер → PP-22.
- Середина как `a + b / 2` → PP-23; `null` вместо `wall` без выделения → PP-24; радиус 0 у `hitDoorway`/`hitWall` → PP-25;
  элемент перед размером → PP-26.
- Маркеры по любой стене под точкой, а не по `selectedWall` → PP-16.
- Возврат `wall` вместо `null` на пустом месте → PP-13.
- Подмена `wall`-объекта (не та стена) → точное сравнение объекта (`toBe`) во всех `wall`/`end`/`middle` проверках.

## Out of Scope

- Числа размеров выделенного элемента (`pressNumber`) — не конкурируют с маркерами (design Non-Goals).
- Выбор между несколькими размерами в радиусе.
- DOM-обработчик `pointerdown` и инструменты как таковые — ручная проверка.
