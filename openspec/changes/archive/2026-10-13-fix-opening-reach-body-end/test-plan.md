# Test Plan

## Scope

Положение окна, двери и проёма у конца опорной стены, где тело выступает за ось до плоскости стыка
(`doorway`: «Проём и опорная стена», «Расстояния проёма сквозь коллинеарные стены»), и хранение
отрицательного расстояния привязки (`drawing-storage`: «Отрицательное расстояние привязки элемента стены»).

Тесты проверяют наблюдаемое поведение через публичные функции установки, перетаскивания, сдвига, ввода чисел
и загрузки/сохранения документа. Общая раскладка F (из спеки): бетонная стена C с осью `(510, 0)–(700, 0)`
(рисуется раньше), блочная W с осью `(0, 0)–(500, 0)`, обе толщиной 20 см; тело W доходит до `x = 510`.
Раскладка G — то же с порядком «W раньше C» (вершина стыка на `x = 500`). Раскладка K — кирпичные W0
`(0, 0)–(250, 0)` и W `(250, 0)–(700, 0)` из спеки `fix-opening-distance-collinear`.
Тесты — рядом с существующими: `src/doorway/collinear-distance*.test.ts` (положение) и
`src/doorway/*-storage.test.ts` (хранилище); утилиты раскладок — `collinear-distance.test-utils.ts`.

## Negative Cases

| Case | Expected behavior |
|---|---|
| Окно тащат вправо за стык F | не заходит на бетонную стену C, не меняет `wallId`, остаётся на W |
| Ввод расстояния меньше нуля у стыка F | применяется ближайшее допустимое значение, число показывает фактическое |
| Призрак при курсоре далеко за стыком C | призрак не уходит на выступ дальше стыка: `x ≤ 510`, остаётся на W |
| Конец с продолжением того же материала: ввод больше допустимого | остаётся на оси, не отрицательный `offsetCm` |
| Два элемента у стыка | второй элемент не налагается на первый, касание откосов допустимо; расстояние между ними 0 |
| Загруженный документ с `offsetCm = null`, `NaN`, строкой | элемент отброшен, остальные восстановлены |
| Загруженный элемент с `offsetCm` ниже выступа (вне тела) | не блокирует правки, нарушение не растёт (правило нарушенных документов) |
| Правка без изменения положения | записи в истории нет |
| Перетаскивание на выступ и обратно | положение следует за указателем при обратном движении |

## Invariants

- Откосы любого элемента при любой правке лежат в теле опорной стены: `doorwayHolds` для каждого элемента
  после установки, перетаскивания, стрелок, ввода расстояния и ширины.
- Расстояния до стыка на обеих гранях ≥ 0 после любой правки (кроме нарушенных документов).
- Положение откосов в плане не зависит от стороны привязки: `jambsT` для `a` и `b` с пересчитанным `offsetCm` совпадают.
- Элемент не меняет опорную стену и сторону привязки при перетаскивании и вводе чисел.
- `offsetCm < 0` возможен только у конца, за которым нет коллинеарной стены того же материала.
- Подписи расстояний, участки граней и границы материала в раскладках F, G, K не меняются (регрессионные ожидания T-04–T-10).
- Round-trip хранилища: сохранить → загрузить даёт тот же `offsetCm` (включая отрицательный).

## Integration Cases

- **Сквозной сценарий пользователя.** Фрагмент реального чертежа: блочная стена `(760.1, 863.65)–(289.9, 863.65)`
  толщиной 20 см (позже), бетонная `(770.1, 863.65)–(850.3, 863.65)` и `(279.9, 863.65)–(213.7, 863.65)` (раньше),
  окно `f9adac8e` шириной 151.2 см у конца `a`: ввод расстояния 0 справа и перетаскивание вправо доводят окно до
  `x = 770.1` (`offsetCm = −10`), подпись показывает 0 (то же для окна `f4c93eec` у конца `b`).
- **Помещение, нарисованное стена за стеной.** Комната из 4 стен, у которой две соседние стены разных материалов
  коллинеарны на стороне окна; порядок рисования меняет границу материала (F и G), положение окна проверяется
  при обоих порядках.
- **Окно, дверь, проём.** Один набор сценариев T-11–T-16 повторяется для каждого вида элемента (T-20).
- **Перезагрузка.** Окно на выступе → сохранение → загрузка → `doorwayHolds` истинно, откосы в плане те же.
- **История.** Установка/перетаскивание/ввод у стыка — одна запись; «Отменить» возвращает прежнее положение, включая
  возврат с отрицательного `offsetCm` на неотрицательный.
- **Удлинение стены слиянием** (T-21): элемент с `offsetCm = −10` у удлиняемого конца остаётся на месте в плане,
  пересчитывается привязка (`wall-merge`).
- **План «Монтаж»** (T-22): элемент на выступе при построении остатков (`mounting-scene`, `mounting-workspace`) остаётся
  в плане на том же месте; элемент, оказавшийся вне остатка, обрабатывается как раньше.

## Mutation Targets

- Граница в `freeIntervals`: `0`/`len` против `±Infinity` и признак продолжения того же материала
  (`limitT === null && extendCm > 0`). Мутанты: всегда обрезать по оси (ловят T-03, T-11–T-14); никогда не обрезать
  по оси (ловят T-16, граница K); поменять `a`/`b`; поменять `>` на `>=` в `extendCm > 0` (ловит «граница на оси» T-15
  и случай свободного торца).
- Знак `offsetCm` в `withStart` для привязки `b` (`len − j1 − width`): ловит T-11 с `b`, зеркало с `a`.
- Условие `x.offsetCm >= 0` в `storage.ts`: ловят T-17 (отрицательное принимается) и T-18 (нечисловое отвергается).
- Выбор вершины стыка по порядку стен (`indexOf(link.wall) < indexOf(cur)`): ловят T-11 против T-15.
- Пересчёт привязки в `wall-merge.ts:52-53` для отрицательного `offsetCm`: ловит T-21.
- Остаток при переходе к «Монтаж» (`mounting-scene.ts:29`, `mounting-workspace.ts:54`): ловит T-22.
- Округление положения до целого сантиметра у стыка (шаг стрелок/перетаскивание): ловят граничные случаи 1 см и стрелки.

Реализации, проходящие поверхностно, но неверные: (1) снимающая ограничение по оси совсем — пройдёт T-03/T-11,
но провалит T-16 (элемент перепрыгнет на W0) и G (граница на оси); (2) двигающая границу к `limitT` без проверки
продолжения того же материала; (3) разрешающая отрицательный `offsetCm` в загрузчике, но не в правках (T-11–T-14
поймают); (4) правящая только подпись (число расстояния 0 при откосе на оси — ловит проверка откосов в плане);
(5) принимающая в загрузчике любой `offsetCm`, включая не конечный (T-18).

## Out of Scope

- Визуальный вид выреза и оконного блока на выступе (отображение не меняется; существующие render/pdf-тесты — регрессия).
- Геометрия стыков стен и выбор границы материала (`wall-joints`).
- Подписи и размерные цепочки у стыка (`add-opening-dimension-anchors`); проверяются только как регрессия.
- Поведение при нарушенных документах сверх существующих тестов.
