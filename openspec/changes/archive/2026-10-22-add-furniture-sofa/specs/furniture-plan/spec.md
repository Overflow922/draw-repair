## MODIFIED Requirements

### Requirement: Каталог видов мебели
Предметы плана «Мебель» ДОЛЖНЫ быть предметами одного устройства: центр, ширина, длина, угол (требование «Стол» описывает это устройство для вида «Стол»; те же правила действуют для любого вида), и различаться ДОЛЖНЫ только видом. Вид задаётся каталогом, а запись каталога определяет для вида: название («Стол»), слово для плашки пересечений («стол»), размеры по умолчанию, рисунок вида и иконку кнопки в панели группы «Мебель». Все остальное поведение (постановка кликом, призрак, выделение, перемещение, правка полей, стрелки, Delete, ластик, пересечения, история, хранение, PDF) НЕ ДОЛЖНО зависеть от вида; пересечения, выделение по клику и рамкой считаются по прямоугольнику предмета (центр, ширина, длина, угол), а не по линиям рисунка. Сейчас в каталоге три вида, в этом порядке: «Стол» (ширина 80 см, длина 160 см, угол 0), «Стул» (ширина 45 см, длина 45 см, угол 0; слово плашки «стул») и «Диван» (ширина 200 см, длина 90 см, угол 0; слово плашки «диван»); все требования плана, где говорится о столе, действуют и для стула и дивана, с заменой названия и значений вида.

Рисунок вида — схематичный вид сверху, набор линий в системе координат предмета: начало в углу прямоугольника предмета при угле 0 слева сверху (ось X — вдоль ширины, ось Y — вдоль длины, вниз), рисунок целиком лежит внутри прямоугольника предмета и поворачивается и смещается вместе с ним. Размеры деталей рисунка (радиусы скруглений, отступы линий, толщина подлокотника и спинки) заданы в сантиметрах и не растягиваются вместе с предметом: у предмета другой ширины или длины контур и линии идут по его сторонам, а детали остаются тех же размеров; если меньшая сторона предмета меньше меньшей стороны его размеров по умолчанию (80 см у стола, 45 см у стула, 90 см у дивана), все детали уменьшаются в отношении этих двух сторон, чтобы рисунок не выходил за прямоугольник и линии не пересекались. Рисунок вида «Стол» — прямоугольник со скруглёнными углами радиуса 10 см и внутренняя линия кромки с отступом 6 см от контура (углы внутренней линии скруглены радиусом 5 см). Рисунок вида «Стул» — силуэт, у которого верхние (при угле 0) углы скруглены дугой радиуса 18 см, а нижние прямые, внутренняя линия спинки и подлокотников с отступом 7 см от боковых сторон и верхнего края (две вертикальные линии, соединённые дугой) и сиденье — прямоугольник со скруглёнными углами радиуса 6 см с отступом 11 см от боковых сторон, 13 см от верхнего края и 4 см от нижнего. Спинка стула обращена к верху предмета при угле 0 и поворачивается вместе с предметом. Рисунок вида «Диван» — прямоугольник со скруглёнными углами радиуса 10 см и сиденье — прямоугольник со скруглёнными углами радиуса 6 см с отступами 16 см от боковых сторон (подлокотники), 22 см от верхнего края (спинка) и 8 см от нижнего. Спинка дивана обращена к верху предмета при угле 0, ширина дивана — вдоль спинки, и поворачивается вместе с предметом.

```text
 вид сверху, схематично, не в масштабе; угол 0, размеры в см

 Стол 80 x 160 (ширина по X, длина по Y)       Стул 45 x 45

   .-----------------.   <-- радиус 10               .---------------.   <-- дуга радиуса 18
  /  .-------------.  \                             .'  .-----------.  '.
 |  /               \  |                            |   /             \   |   <-- спинка, 7 от верха
 | |                 | |                            |  |  .---------.  |  |
 | |                 | |   160                      |  |  |  сиденье|  |  |
 | |                 | |                            |  |  '---------'  |  |
 |  \               /  |                            |  |               |  |   <-- подлокотники, 7 от боков
  \  '-------------'  /     6 = отступ кромки        +--+---------------+--+
   '-----------------'                                          45
           80
```

Панель группы «Мебель» ДОЛЖНА содержать по одной кнопке инструмента на каждый вид каталога, в порядке каталога; поля «Ширина», «Длина», «Угол» общие для всех видов и показывают значения для новых предметов активного вида. Значения для новых предметов запоминаются в сеансе отдельно по каждому виду, начальные — из каталога, и в чертеже не сохраняются. Правка выделенного предмета меняет его, а не значения вида (требование «Панель группы «Мебель» и инструмента «Стол»»). Рисунки видов каталога различимы между собой на светлой и тёмной схеме: по форме рисунка, а не по цвету. Легенда страницы «Мебель» в PDF содержит запись с названием и образцом — миниатюрой рисунка — для каждого вида, чьи предметы есть на странице, в порядке каталога (`pdf-export` «Легенда на странице PDF»); записи вида без предметов на странице нет.

#### Scenario: Единственный вид — стол
- **WHEN** открыта панель группы «Мебель»
- **THEN** (название сценария сохранено для архива, в каталоге теперь три вида) в ней три кнопки в порядке «Стол», «Стул», «Диван»; размеры по умолчанию стола: ширина 80, длина 160, угол 0; стула: ширина 45, длина 45, угол 0; дивана: ширина 200, длина 90, угол 0

```text
План, вид сверху (схематично, не в масштабе). Т — стол 80×160, С — стул 45×45, Д — диван 200×90 (см)

  +--------+
  |   Т    |  160
  |        |        +----+
  +--------+        | С  | 45
     80             +----+
                      45

  Д — диван 200×90

  +------------------------+
  |           Д            |  90
  +------------------------+
              200
```

#### Scenario: Рисунок стола
- **WHEN** поставлен стол 80 x 160 с углом 0
- **THEN** нарисованы контур со скруглёнными углами радиуса 10 см и внутренняя линия на расстоянии 6 см от контура по всем сторонам; заливки нет

#### Scenario: Рисунок стола другого размера
- **WHEN** поставлен стол 100 x 200
- **THEN** контур 100 x 200, радиус скругления по-прежнему 10 см, внутренняя линия по-прежнему на расстоянии 6 см от контура

#### Scenario: Рисунок стула
- **WHEN** поставлен стул 45 x 45 с углом 0
- **THEN** нарисованы силуэт с дугой спинки у верхнего края, внутренняя линия спинки и подлокотников на расстоянии 7 см от боков и верха и сиденье со скруглёнными углами; заливки нет

#### Scenario: Спинка поворачивается с предметом
- **WHEN** стул с углом 0 повернут на 90°
- **THEN** спинка обращена вправо от центра на экране, подлокотники — сверху и снизу

#### Scenario: Маленький стул
- **WHEN** поставлен стул 30 x 30
- **THEN** рисунок целиком внутри прямоугольника 30 x 30; детали (дуга, подлокотники, сиденье) уменьшены пропорционально, линии не пересекаются и не выходят за его стороны

#### Scenario: Рисунок дивана
- **WHEN** поставлен диван 200 x 90 с углом 0
- **THEN** нарисованы контур со скруглёнными углами радиуса 10 см и сиденье со скруглёнными углами радиуса 6 см с отступами 16 см от боков, 22 см от верха и 8 см от низа; заливки нет

```text
 вид сверху, схематично, не в масштабе; диван 200 x 90 (ширина по X, длина по Y), угол 0

   .--------------------------------.   <-- контур, радиус 10
  /                                  \
 |    (спинка, 22 от верха)           |
 |   .----------------------------.   |  <-- сиденье, радиус 6
 |   |          сиденье           |   |
 |   '----------------------------'   |  <-- 8 от низа
  \                                  /
   '--------------------------------'
   |<-->|  подлокотник, 16 от бока
```

#### Scenario: Спинка дивана поворачивается с предметом
- **WHEN** диван с углом 0 повернут на 90°
- **THEN** спинка обращена вправо от центра на экране, подлокотники — сверху и снизу

#### Scenario: Узкий диван
- **WHEN** поставлен диван 200 x 60
- **THEN** рисунок целиком внутри прямоугольника 200 x 60; детали (скругления, отступы) уменьшены в отношении 60/90, линии не пересекаются и не выходят за его стороны
#### Scenario: Пересечение считается по прямоугольнику
- **WHEN** угол прямоугольника стула 45 x 45, не занятый дугой спинки, заходит в стену на 3 см
- **THEN** область наложения подсвечена (пересечение считается по прямоугольнику предмета), плашка называет «стена»

#### Scenario: Запись легенды по виду
- **WHEN** на странице «Мебель» есть стол
- **THEN** в легенде запись «Стол» с миниатюрой рисунка стола; если столов нет, записи нет; так же для стула — запись «Стул» с миниатюрой рисунка стула, только если на странице есть стулья, и для дивана — запись «Диван» с миниатюрой рисунка дивана, только если на странице есть диваны

#### Scenario: Значения новых предметов по видам
- **WHEN** в каталоге несколько видов, и для вида A в панели задана ширина 100, а затем выбран вид B
- **THEN** поля показывают значения вида B (по умолчанию из каталога), а значение вида A сохранено до конца сеанса

#### Scenario: Плашка пересечений называет стул
- **WHEN** выделен или поставлен стул, пересекающий стену
- **THEN** плашка читает «Стул пересекается: стена»; если стул пересекает ещё и стол — «Стул пересекается: стена, стол»

#### Scenario: Плашка пересечений называет диван
- **WHEN** выделен или поставлен диван, пересекающий стену и стул
- **THEN** плашка читает «Диван пересекается: стена, стул»
