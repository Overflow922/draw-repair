# Test Plan

## Scope

Фиксация оси орто на жест: `wall-selection` «Орто без боковой составляющей», «Перемещение стены за средний маркер», «Изменение длины перетаскиванием конца»; `multi-selection` «Групповое перетаскивание стен».

Тестируемые единицы (design D1, D3, D5):

- `src/ortho-axis.ts` — `dominantAxis`, `latchAxis`, `onAxis`;
- `src/geometry.ts` — `snapAlongAxis(cursor, walls, grid, r, through, axis)`;
- `src/wall-edit.ts` — `moveWallsBounded`, `moveEndpointBounded` при `{ ortho: true }` с произвольным (в т.ч. диагональным) вектором или целью;
- `src/ortho-gesture.ts` — `startOrthoGesture`, `orthoGestureStep` (design D2): защёлка оси, направляющий вектор, точка привязки, стены в привязке.

Жест целиком проверяется прогоном (`src/ortho-gesture.test-utils.ts`), который вызывает производственный `orthoGestureStep` и правку с ограничениями в той же последовательности, что `main.ts`: снимок начала; на каждом шаге указателя — восстановить снимок, шаг жеста, правка при наличии цели. Правил жеста в тестовом коде нет. Эталоны выведены из сценариев спецификации. DOM-обвязка `main.ts` (создание жеста на `pointerdown`, хранение между `pointermove`, удаление на `pointerup`) автоматически не тестируется — ручная проверка в браузере в tasks.

Сетка 10 см, радиус привязки 5 см, толщина стен 20 см, если не указано иное. Сравнение координат — `toBeCloseTo(x, 6)`; инварианты «координата поперёк оси не изменилась» — точное равенство (`toBe`).

Сцены (см, ось y вниз):

- **R** — комната 400 × 300: top `(0,0)-(400,0)`, right `(400,0)-(400,300)`, bottom `(400,300)-(0,300)`, left `(0,300)-(0,0)`.
- **R2** — две комнаты: T1 `(0,0)-(400,0)`, T2 `(400,0)-(800,0)`, R `(800,0)-(800,300)`, B `(800,300)-(0,300)`, L `(0,300)-(0,0)`, P `(400,0)-(400,300)`.
- **U** — раскладка снимка пользователя (`img.png`): внешний контур с нишей, горизонтальная стена S, к левому концу которой стыком присоединена вертикаль, к нижней грани примкнута вертикаль нижней комнаты; S перемещают.
- **F** — две несоединённые стены A `(0,0)-(200,0)`, B `(0,100)-(200,100)`.
- **H** — свободная горизонтальная стена `(0,0)-(300,0)`.
- **D30** — свободная стена `(0,0)-(100,58)`.
- **TS** — существующая сцена `sceneTS()` (опорная H, ножка S на грани).

## Invariants

- **INV-AXIS (WE-INV):** при орто для любого ненулевого вектора v применённый вектор `moveWallsBounded` имеет нулевую составляющую поперёк `dominantAxis(v)` (перебор 16 направлений × 3 длины на сценах R и R2).
- **INV-NO-CASCADE:** при орто в R и R2 ни один жест (16 направлений) не сдвигает все стены чертежа сразу, если вектор перпендикулярен перемещаемой стене по доминирующей оси.
- **INV-LATCH:** после выбора оси никакая последовательность указателя (перебор 8 последовательностей) не меняет её до конца жеста; координата опорного конца поперёк оси равна исходной на каждом шаге.
- **INV-SNAP:** `snapAlongAxis` всегда возвращает точку с координатой поперёк оси, равной координате `through` (сцены OS-INV + курсоры под 30°, 45°, 60°).

## Integration Cases

- Прогон жеста (GS-*, GE-*, GG-*): на каждом шаге указателя от снимка — производственный `orthoGestureStep` (защёлка, привязка вдоль оси, исключение увлекаемых стен) → `moveWallsBounded` / `moveEndpointBounded`; проверяется итог после серии шагов указателя. Правила жеста — только в производственном коде.
- Существующие тесты орто-правок (TB-16, TB-16a, TB-17, TB-19, `wall-edit-follow`, `wall-collision`, `ortho-stretch`, `geometry-ortho-snap`) остаются зелёными без изменений.
- TB-19a заменяется по запросу на изменение утверждённого теста (`test-change-request.md`, design D6).

## Mutation Targets

- `|v.x| >= |v.y|` → `>`: ловит AX-2, AX-3, AX-9.
- `dominantAxis` возвращает ось по знаку или первой ненулевой составляющей: ловит AX-1, AX-6.
- `latchAxis` или `orthoGestureStep` пересчитывает ось при каждом шаге: ловит AX-4, AX-5, OG-4, GS-3, GS-4.
- `latchAxis` выбирает ось при нулевом векторе (`"x"` по умолчанию): ловит AX-7, AX-8.
- Направляющий вектор конца — смещение указателя, а не от противоположного конца: ловит OG-9, GE-3 (стена развернулась бы вертикально).
- Конец защёлкивает ось при любом шаге с ненулевым вектором от противоположного конца (без проверки смещения от точки нажатия): ловит OG-10, GE-6.
- `projectEnd` берёт ось по `target − base` вместо `target − other`: ловит GE-5.
- Увлекаемые стены участвуют в привязке (фильтр по плану убран): ловит OG-15, OG-16 (ожидаемые точки вне узлов и концов увлекаемых стен; OG-12, OG-14 эту мутацию не различают).
- План увлечения строится по другой оси или по сырому диагональному смещению: ловит OG-16, OG-17.
- Из привязки исключаются только стены, увлекаемые целиком, а растягиваемые (смещается один конец) притягивают к прежнему стыку: ловит OG-18, OG-19.
- Шаг жеста мутирует переданное состояние: ловит OG-6.
- `orthoAxisOf` с сохранённым конусом 15°: ловит WE-1, WE-2, GE-4.
- `snapAlongAxis` игнорирует `axis` и выбирает ось по курсору: ловит SA-5, INV-SNAP.
- `onAxis` обнуляет не ту составляющую: ловит AX-10 (`onAxis({3,4},"x") = {3,0}`, `"y"` → `{0,4}`).
- Новый жест наследует ось: ловит OG-1 (на уровне модуля); хранение жеста в `main.ts` между жестами — только ручная проверка (DOM).
