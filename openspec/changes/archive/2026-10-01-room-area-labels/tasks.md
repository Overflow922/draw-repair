## 3. Помещения (новый модуль room-area.ts)

- [x] 3.1 `Room`, `findRooms(walls)`: куски `displayPolygons(wall, walls)` только по стенам чертежа (без превью), вырожденные стены пропускаются, затем `unionRegions` с δ = 0,001 см. Обход дерева: помещение — дыра с непосредственными островами как `holes`, дыры островов рекурсивно. Внешний контур помещением не является. Входной массив и стены не мутируются, кэша нет (design D1, D3, D4; спеки «Определение помещения», «Вложенные контуры», «Разрыв в стенах соединяет области», «Актуальность помещений»; тесты ROOM-*, NEST-*, GAP-*, AREA-BOX-1, INV-PURE-1, INV-ORDER-1, UPD-*, RND-LIVE-1, RND-THICK-LIVE-1)
- [x] 3.2 Площадь: `polygonArea(outline) − Σ polygonArea(holes)`. Порог 0,1 м² применяется к площади за вычетом островов. Сравнение `≥ 1000` устойчиво к погрешности, чтобы ровно 1 000 см² проходило (спека «Площадь помещения»; тесты AREA-*, AREA-MIN-ISLAND-1, INV-AREA-1, INV-SUM-1)
- [x] 3.3 `labelAt`: `polylabel` по `[outline, ...holes]` с точностью 1 см (design D5 в исходной редакции; пересмотрено в 6.1)
- [x] 3.4 `formatArea(areaCm2)`: `Math.round(areaCm2 / 100)` сотых м² в целых, затем целая часть, запятая, две цифры, « м²» (U+0020, U+00B2). Без `toFixed` и разделителей тысяч (design D6; спека «Подпись площади»; тесты FMT-*)
