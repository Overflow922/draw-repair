## MODIFIED Requirements

### Requirement: Закрытие вкладки
Закрытие вкладки ДОЛЖНО убирать чертёж из открытых, перемещая его в корзину истории, откуда он ДОЛЖЕН быть доступен для возврата отменой, и ВСЕГДА ДОЛЖНО требовать подтверждения, независимо от содержимого чертежа. При подтверждении вкладка ДОЛЖНА исчезнуть; при отказе ничего НЕ ДОЛЖНО измениться.

#### Scenario: Подтверждённое удаление
- **WHEN** пользователь нажимает кнопку закрытия вкладки и подтверждает удаление
- **THEN** вкладка исчезает, чертёж убирается из открытых в корзину истории и доступен для возврата отменой

#### Scenario: Отказ от удаления
- **WHEN** пользователь нажимает кнопку закрытия вкладки и отменяет подтверждение
- **THEN** вкладка и чертёж остаются без изменений

#### Scenario: Подтверждение для пустого чертежа
- **WHEN** пользователь закрывает вкладку чертежа без стен
- **THEN** подтверждение запрашивается так же, как для непустого чертежа
