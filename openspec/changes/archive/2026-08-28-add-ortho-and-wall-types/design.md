## Context

Реализовано сразу по запросу пользователя поверх трёх незаархивированных изменений. Документ фиксирует решения пост-фактум.

## Goals / Non-Goals

**Goals:**

- Ровные осевые стены без прицеливания по сетке; различимые типы стен на плане.

**Non-Goals:**

- Перекраска существующих стен, свои типы/палитра, принудительный ortho по Shift.

## Decisions

- **Орто в общем конвейере `snap`**: необязательный параметр `orthoFrom` (последняя вершина); порядок приоритетов «стены → 90° → сетка» сохраняет замыкание контуров главным. Допуск 15° через сравнение |dy| ≤ tan(15°)·|dx| — без тригонометрии на точку.
- **Орто применяется до сетки, но не трогает фиксированную координату**: при горизонтальном снапе y берётся от вершины (в т.ч. вне узлов сетки — например, после коммита точной длины), к сетке округляется только свободная координата.
- **Типы — константа `WALL_TYPES` в `types.ts`** (id, подпись, цвет), `Wall.type` хранится в стене при создании аналогично толщине; рендер ищет цвет по типу, неизвестный тип откатывается к серому.
- **UI типов** — вертикальная колонка цветных образцов 40×12 в панели под толщиной, активный — синяя рамка с обводкой; дефолт «Перегородка» (серый #44403c — прежний вид стен), что сохраняет привычный вид чертежа. Переключение — кликом по образцу или стрелками ↑/↓ (в общем `keydown`, зацикливание по модулю; при фокусе в поле толщины стрелки пропускаются — там нативный степпер). Общий `setWallType` для клика и стрелок.
- **Взаимодействие с точной длиной**: орто-привязанный курсор задаёт осевое направление, `previewPoint`/`commitPoint` масштабируют его до введённой длины — комбинация даёт строго осевые стены точной длины.

## Risks / Trade-offs

- [Допуск 15° может мешать диагоналям около осей] → осознанный обмен; при необходимости добавить принудительный ortho по Shift позже.
- [Только три предустановленных типа] → палитра/свои типы отдельным изменением при необходимости.
