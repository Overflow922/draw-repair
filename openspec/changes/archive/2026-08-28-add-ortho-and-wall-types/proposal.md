## Why

Для чертежей помещений нужны ровные оси: без привязки 90° горизонтальные/вертикальные стены приходится «попадать» точно по сетке. Типы стен (несущая/перегородка/гипрок) с разным цветом — стандартное обозначение на планах ремонта. Обе функции реализованы сразу по запросу пользователя; изменение фиксирует состоявшееся поведение.

## What Changes

- Орто-привязка 90°: при рисовании цепочки направление в пределах ±15° от горизонтали/вертикали притягивается к оси; приоритет привязок: стены → 90° → сетка; диагонали доступны при отклонении больше допуска.
- Типы стен: «Несущая» (#b91c1c), «Перегородка» (#44403c), «Гипрок» (#2563eb); выбор цветными образцами в панели инструментов слева, по умолчанию «Перегородка».
- Тип, как и толщина, фиксируется в стене при создании и не меняется у нарисованных стен; превью рисуется цветом текущего типа.

### Non-goals

- Редактирование типа/цвета уже нарисованных стен.
- Пользовательские типы и настройка палитры; орто-режим по Shift (принудительный).

## Capabilities

### New Capabilities

- `wall-types`: типы стен с цветовой дифференциацией на чертеже.

### Modified Capabilities

- `wall-drawing`: добавляется требование орто-привязки 90° (дельта ADDED в `specs/wall-drawing/spec.md`; базовая capability вводится незаархивированным изменением `add-wall-drawing`).
