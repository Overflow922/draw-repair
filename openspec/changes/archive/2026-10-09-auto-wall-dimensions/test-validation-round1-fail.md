## Findings (в объёме)

### F1. Торец на оси или внутри тела другой стены (мутант G03)

Spec «Автоматические размеры стены»: «Свободным торцом ... конец стены ... который не лежит на грани или оси другой стены и не лежит внутри тела другой стены». Тесты проверяют только торец на грани (AD-6) и угол. Мутант, убирающий `pointInPolygon` из `wallEndOccupied`, проходит все 33 теста, а пользователь рисует стену, заходящую в тело другой (дифференциальный сценарий: ножка до `(250, -5)` получает лишний размер толщины 20 на торце внутри тела).

Добавить (новый describe в `src/auto-dimensions.test.ts`; импорты `expectThickness`, `split`, `placeAll`, `w` уже есть):

```ts
describe("AD-28: свободный торец не лежит на оси и внутри тела другой стены", () => {
  it("торец ножки на оси или внутри тела перекладины толщины не получает (оба порядка фиксации)", () => {
    for (const endY of [-5, 0]) {
      for (const swap of [false, true]) {
        const W = w(0, 0, 500, 0, "W")
        const S = w(250, -300, 250, endY, "S")
        const after = placeAll(swap ? [S, W] : [W, S])
        const s = split(after, S)
        expect(s.thickness, `endY=${endY} swap=${swap}`).toHaveLength(1)
        expectThickness(s.thickness[0], S, 0, -1)
        expect(split(after, W).thickness, `endY=${endY} swap=${swap} W`).toHaveLength(2)
      }
    }
  })
})
```

### F2. Сравнение набора при пересчёте и «набор не изменился» (мутанты M30, M31, M32, M33, M61, M62)

Spec «Пересчёт»: набор отличается по «числу размеров, положению точек замера или смещению» — заменить; не отличается — «размеры стены ДОЛЖНЫ оставаться без изменений». Выживают мутанты: ключ без смещения, без `from`, без `to`, сравнение только числа или только первого размера, и «всегда заменять» (AD-14 и AD-15 сравнивают через `toEqual`, а заменённые одинаковые по значению размеры равны). Тест AD-15 по названию проверяет «прежними», но принимает замену.

Добавить (нужны дополнительные импорты `Dimension` уже есть; `measure`, `dimsOf`, `syncAutoDimensions`, `placeWall` есть):

```ts
describe("AD-29/AD-30: сравнение набора при пересчёте", () => {
  const W = () => w(0, 0, 500, 0, "W")
  const edge = (wallId: string, e: number) => ({ wallId, edge: e })

  it("AD-29: набор того же числа размеров, но с иной точкой замера или смещением, заменяется целиком", () => {
    const base = placeAll([W()])
    const target = base.dimensions.find((x) => x.offset === 40 && Math.abs(measure(x, base.walls).length - 500) < 1e-6)
    if (!target) throw new Error("нет размера")
    const pairs: [Dimension, Dimension][] = [
      ...base.dimensions.map((d): [Dimension, Dimension] => [d, { ...d, offset: d.offset * 2 }]),
      [target, { ...target, from: { a: edge("W", 1), b: edge("W", 2) } }],
      [target, { ...target, to: { a: edge("W", 1), b: edge("W", 3) } }],
    ]
    for (const [original, mod] of pairs) {
      const scene: Scene = { ...base, dimensions: base.dimensions.map((d) => (d === original ? mod : d)) }
      const synced = syncAutoDimensions(scene)
      expect(synced.dimensions).toHaveLength(4)
      expect(synced.dimensions).not.toContainEqual(mod)
      for (const d of base.dimensions) expect(synced.dimensions).toContainEqual(d)
    }
  })

  it("AD-30: неизменившийся набор остаётся без изменений (эквивалентная запись точки сохраняется)", () => {
    const A = w(0, 0, 500, 0, "A")
    const base = placeAll([A, w(0, 300, 500, 300, "B"), w(0, 600, 500, 600, "C")])
    const target = base.dimensions.find((d) => d.auto === "A" && d.offset === 40 && Math.abs(measure(d, base.walls).length - 500) < 1e-6)
    if (!target) throw new Error("нет размера")
    const swapped: Dimension = { ...target, from: { a: target.from.b, b: target.from.a } }
    const prepared: Scene = { ...base, dimensions: base.dimensions.map((d) => (d === target ? swapped : d)) }
    const after = placeWall(prepared, w(250, 310, 250, 500, "T"))
    if (!after) throw new Error("стена не зафиксирована")
    expect(dimsOf(after, "B").length).toBeGreaterThan(4)
    expect(after.dimensions).toContainEqual(swapped)
    expect(after.dimensions).not.toContainEqual(target)
  })
})
```

AD-30 опирается на симметрию `dimPointPoint` (пара граней в любом порядке даёт одну точку) и на то, что неизменившийся набор не заменяется (design D4).

### F3. Невалидное `auto` отклоняет только размер (мутант S09)

Spec «Метка автоматического размера»: «значение не строка при загрузке ДОЛЖНО приводить к отклонению размера как некорректного ... как любой размер с неверным полем» (у существующих размеров с неверным полем отбрасывается только размер, `filter(isDimension)`). AD-25 принимает любой результат, где размеров нет, в том числе отказ от всего чертежа (потеря стен пользователя). Мутант, делающий `isDrawing` строгим по размерам, проходит AD-25.

```ts
describe("AD-31: некорректное поле auto отклоняет только размер", () => {
  const wall = w(0, 0, 300, 0, "w1")
  const marked: Dimension = {
    from: { a: { wallId: "w1", edge: 2 }, b: { wallId: "w1", edge: 0 } },
    to: { a: { wallId: "w1", edge: 3 }, b: { wallId: "w1", edge: 0 } },
    offset: 40,
    auto: "w1",
  }
  const plain: Dimension = { from: marked.from, to: marked.to, offset: 50 }
  const drawing = (dims: unknown[]): Drawing => ({ id: "a", name: "t", walls: [wall], dimensions: dims as Dimension[], view: { zoom: 1, pan: { x: 0, y: 0 } }, scale: 100 })
  it("чертёж, стены и остальные размеры загружаются", () => {
    const store: DrawingStore = { version: 3, activeId: "a", drawings: [drawing([plain, { ...marked, auto: 5 }, marked])] }
    const loaded = parseStore(serializeStore(store))
    expect(loaded).not.toBeNull()
    expect(loaded?.store.drawings[0].walls).toHaveLength(1)
    expect(loaded?.store.drawings[0].dimensions).toEqual([plain, marked])
  })
})
```

(`as Dimension[]` — каст в тестовой подготовке невалидных данных; альтернатива: `unknown`-параметр и сериализация без типа.)

### F4. Грань, целиком закрытая телом другой стены (мутант M64)

Spec: куски определяются «участком грани, не закрытым телом другой стены»; «размер длины, видимая длина которого не положительна, НЕ ДОЛЖЕН создаваться». В test-plan.md это «Boundary Cases» («Кусок ровно в 0 длины: грань целиком закрыта соседом — размер не создаётся»), но теста нет. Мутант «закрытая грань получает размер на всю длину» проходит все 33 теста.

```ts
it("AD-32: стена целиком внутри тела другой стены не получает размеров (оба порядка фиксации)", () => {
  for (const swap of [false, true]) {
    const W = w(0, 0, 500, 0, "W", 40)
    const S = w(100, 0, 300, 0, "S", 20)
    const scene = placeAll(swap ? [S, W] : [W, S])
    expect(dimsOf(scene, "S"), `swap=${swap}`).toEqual([])
    expect(dimsOf(scene, "W"), `swap=${swap}`).toHaveLength(4)
    expect(scene.dimensions, `swap=${swap}`).toHaveLength(4)
  }
})
```

В порядке `[S, W]` одновременно проверяется, что пересчёт убирает прежние размеры закрытой стены.

## Заметки (не блокируют)

- N1. Косые стыки в spec не описаны (есть только одиночная наклонная стена). Эталон по design D2 даёт на косых стыках потери: например, W `(0,0)-(500,0)` и V `(500,0)-(250,433.01)` (угол 120/60 градусов) даёт у V размер длины с разрешённой длиной 0 и пропуск второго; ножка под 45 градусов к грани даёт один размер длины вместо двух. Это следствие привязки `nearestEdgeIntersection` с радиусом 1 см к точкам пробных линий `faceRuns` (design «Risks» это допускает). Тестов косых стыков нет, потому что без решения по spec их нельзя вывести; рекомендую либо записать это в TODO.md, либо расширить spec отдельным изменением. Предложение «размер длины, видимая длина которого не положительна, НЕ ДОЛЖЕН создаваться» на этих сценах нарушается нулевым размером (достижимо при реализации строго по design D2), поэтому на этапе реализации стоит добавить защиту по разрешённой длине (пропуск размера с длиной меньше 1e-6).
- N2. `tasks.md` устарел (описывает первую модель с `FaceEndPoint`). Перед этапом реализации его надо переписать под D1–D6; в `test-suite.md` повреждены символы (`irst-model`, `	est-plan.md`, `uto`, пустые строки вместо `null`) и в разделе «Initial Result» указан прогон против прежней реализации.
- N3. Пустая строка в `auto`: spec говорит «идентификатор (строка)»; допустимость пустой не определена, неоднозначность без последствий (id стен непустые).
- N4. Подключение в `main.ts` (`placeWall`, замена `dimensions`, сброс `auto` при перетаскивании, `syncAutoDimensions` после слияния) вне автотестов; ручная проверка в браузере остаётся в плане (test-plan «Out of Scope»).
- N5. Порядок размеров (M01), позиция новой стены в массиве (M48), допуски (M15–M17, M56, M57, M65) в spec не заданы; не блокируют.
