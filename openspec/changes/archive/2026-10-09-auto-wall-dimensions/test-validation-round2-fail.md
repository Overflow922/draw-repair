## Findings (в объёме)

### F5. Пороги по размеру: короткие куски, короткие стены, много размеров, один оставшийся размер (N08, N09, N10, N21, N22, N35)

Spec «Автоматические размеры стены»: «по одному размеру на кусок», размеры получает каждая стена, кроме стены нулевой длины; «Пересчёт»: пересчитывается «каждая стена, у которой уже есть автоматические размеры». Все сцены тестов крупные (куски от 240 см, стены от 290 см, у стены не больше 5 размеров, у пересчитываемой всегда несколько размеров). Мутанты «пропустить куски не длиннее 5/20/100 см», «пропустить стену короче 20 см», «не пересчитывать стену с числом размеров больше 6», «не пересчитывать стену, у которой остался один автоматический размер» проходят все 38 тестов; пользователь достигает каждого (ножка у края стены, короткая перемычка, длинная стена с четырьмя ножками, стена, у которой три размера передвинуты и потеряли метку).

Добавить в `src/auto-dimensions.test.ts` (импорты `placeWall`, `dimsOf`, `expectLength`, `expectThickness`, `measure`, `placeAll`, `split`, `w`, `Scene`, `Dimension` уже есть):

```ts
describe("AD-33: короткие куски и стена с большим числом размеров", () => {
  const W = () => w(0, 0, 500, 0, "W")
  const legs = () => [w(60, -10, 60, -300, "S1"), w(150, -10, 150, -300, "S2"), w(250, -10, 250, -300, "S3"), w(486, -10, 486, -300, "S4")]

  it("каждый видимый кусок получает размер, в том числе короткий (4 и 50 см); четыре ножки подряд", () => {
    for (const reverse of [false, true]) {
      const order = reverse ? [W(), ...legs().reverse()] : [W(), ...legs()]
      const scene = placeAll(order)
      const Ws = W()
      const s = split(scene, Ws)
      const pieces: [number, number][] = [[0, 50], [70, 140], [160, 240], [260, 476], [496, 500]]
      expect(s.minus, `reverse=${reverse}`).toHaveLength(5)
      pieces.forEach(([t0, t1], i) => expectLength(s.minus[i], Ws, -1, t0, t1))
      expect(s.plus).toHaveLength(1)

      expect(s.thickness).toHaveLength(2)
      expect(dimsOf(scene, "W"), `reverse=${reverse}`).toHaveLength(8)
    }
  })
})

describe("AD-34: короткая стена", () => {

describe("AD-35: пересчёт стены с единственным автоматическим размером", () => {

    if (!after) throw new Error("стена не зафиксирована")

    expect(after.dimensions.filter((d) => d.auto === undefined)).toHaveLength(3)
```

### F6. Сдвиг одной точки замера без смены числа размеров (N33, N34)

Spec «Пересчёт»: набор отличается «положением точек замера» ⇒ все автоматические размеры стены заменяются. AD-29 проверяет сдвиг по нормали (координата y); мутанты, игнорирующие координату x у `from` или у `to`, проходят все тесты. Достижимо: ножка, чьё тело заходит на край грани, укорачивает кусок вдоль оси (например, ножка в 5 см от конца перекладины даёт кусок от 15 вместо 0), а число размеров не меняется.

```ts
describe("AD-37: кусок укорачивается без изменения числа размеров", () => {

      for (const swap of [false, true]) {
```

### F7. Торец, стыкующийся в пределах допуска вершины стыка (G01)

Spec: свободный торец — тот, «с которой не стыкуется ни одна другая стена». Стык определён в `wall-joints` («Допуск вершины стыка»: концы в пределах полутолщины). Все сцены тестов, где торцы сходятся, перекрываются проверкой «точка внутри тела» (граница включена), поэтому мутант без проверки стыка проходит все 38 тестов. Достижимо: угол, нарисованный с неточным совпадением концов (в пределах допуска), даёт лишний размер толщины.

### F8. Поворот чертежа: набор размеров не должен зависеть от ориентации (R1; найдено фаззингом и проверкой поворота)

Все сцены тестов лежат вдоль осей координат (кроме одиночной наклонной стены). Предложения spec о T, угле и комнате («ножка делит грань», «набор не зависит от порядка», «по одному размеру на кусок») не привязаны к ориентации, а у пользователя повёрнутые комнаты обычны. Эталон 1, написанный строго по design D2 (куски берутся из `faceRuns`), на повёрнутой комнате ломается: `faceRuns` из-за дробного шума делит один кусок на два (например, для грани B получаются куски `[-10, 400.00000000000006]` и `[400.00000000000017, 410.00000000000017]`), и появляются лишние размеры (10 см), а у соседних стен пропадают наружные. Наблюдалось: комната повёрнута на 30 градусов — неверный набор в 20 порядках из 24; на 0.1 рад — в 24 из 24; на 45 градусов — в 14 из 24; на 180 градусов — в 8 из 24; угол при 180 градусах теряет размер 410. Тесты этого не замечают (мутант R1 — эталон 1 против эталона 2 — проходит все 38 тестов). Корректная реализация существует: эталон 2 (склейка кусков с зазором меньше 1e-4) проходит поворот на всех углах и в 24 порядках.

```ts
// AD-38: набор размеров не зависит от поворота чертежа целиком (T, угол, крест, комната в 24 порядках)
const rotate = (x: Wall, rad: number): Wall => {
  const c = Math.cos(rad)
  const s = Math.sin(rad)
  const r = (p: { x: number; y: number }) => ({ x: p.x * c - p.y * s, y: p.x * s + p.y * c })
  return { ...x, a: r(x.a), b: r(x.b) }
}
const signature = (walls: readonly Wall[]): string => {
  const scene = placeAll(walls)
  expectOutsideBodies(scene)
  return scene.dimensions
    .map((d) => `${d.auto} ${measure(d, scene.walls).length.toFixed(3)} ${d.offset}`)
    .sort()
    .join("|")
}
const ANGLES = [Math.PI / 6, Math.PI / 4, 0.1, Math.PI / 2, Math.PI]

describe("AD-38: поворот чертежа не меняет набор размеров", () => {
  const cases: [string, () => Wall[]][] = [
    ["ножка (T)", () => [w(0, 0, 500, 0, "W"), w(250, -10, 250, -300, "S")]],
    ["угол", () => [w(0, 0, 500, 0, "W"), w(500, 0, 500, 400, "V")]],
    ["крест", () => [w(0, 0, 500, 0, "W"), w(250, -200, 250, 200, "S")]],
  ]
  for (const [name, make] of cases) {
    it(`${name}: размеры повёрнутого чертежа совпадают с размерами неповёрнутого`, () => {
      const base = signature(make())
      for (const angle of ANGLES) expect(signature(make().map((x) => rotate(x, angle))), `${name} ${angle}`).toBe(base)
    })
  }

  it("комната из четырёх стен, повёрнутая на 30 и 45 градусов: во всех 24 порядках те же восемь размеров", () => {
    const make = (): Wall[] => [w(0, 0, 500, 0, "A"), w(500, 0, 500, 400, "B"), w(500, 400, 0, 400, "C"), w(0, 400, 0, 0, "D")]
    const base = signature(make())
    for (const angle of [Math.PI / 6, Math.PI / 4, 0.1]) {
      for (const order of permutations(make().map((x) => rotate(x, angle)))) {
        expect(signature(order), `${angle} ${order.map((x) => x.id).join("")}`).toBe(base)
      }
    }
  })
})
```
