# Test Validation: auto-wall-dimensions

## Итог

Независимая валидация новой модели («видимые куски граней») проводилась два раунда (`test-validation-round1-fail.md`, `test-validation-round2-fail.md`). Каждый раунд: свежий валидатор строил эталонную реализацию по спеке и дизайну, прогонял на ней новые тесты, весь существующий набор и `tsc` (всё проходило, противоречий с утверждёнными тестами нет), строил мутанты и фаззинг. Раунд 1: 81 мутант, 4 группы находок (торец внутри тела, сравнение набора, невалидное `auto`, закрытая грань); раунд 2: 140 мутантов, 4 группы (пороги по размеру, сдвиг одной точки, стык в допуске, поворот чертежа, найденный фаззингом). Все находки закрыты тестами AD-28…AD-38 (набор вырос с 33 до 44 тестов); вывод раунда 2 о дробном шуме `faceRuns` на повёрнутых чертежах записан в design D2.

Вердикт последнего раунда — FAIL: независимого PASS по итоговому набору нет. По договорённости число раундов ограничено двумя; проверка продолжается мутантами на настоящей реализации (tasks 6.1). Вердикт не изменяется.

VERDICT: FAIL (число раундов ограничено двумя по договорённости; закрывающие тесты добавлены, проверка мутантами на реализации — tasks 6.1)
