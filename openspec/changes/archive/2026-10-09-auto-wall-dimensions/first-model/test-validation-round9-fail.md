## Findings

- F1 (в объёме, пункт 4). Правило 2 («внешний конец») защищено только для грани «минус» (`edge 1`) у стены с направлением вправо. - F2 (в объёме, пункт 4). Исключение «граница тела стены, параллельной W (коллинеарное продолжение), правило 2 НЕ ДОЛЖНЫ применять» защищено только для стены того же направления (ADW-38 `src/auto-dimensions-sequence.test.ts:123-131`, ADW-7b/7c/25/25b).
