# Test Validation

Раунд 6, независимый валидатор. Область раунда (согласована с владельцем): FAIL только за выживший мутант, меняющий
пользовательски видимое поведение, достижимый через публичный API в сценах, которые порождает `placeWall`
(новая стена последней в массиве), и нарушающий написанный сценарий или предложение требования спеки.

Метод: одноразовая копия вне репозитория (`scratchpad/validation-copy6`: `src/`, конфиги, `node_modules` через junction).
В копии написана эталонная реализация `src/auto-dimensions.ts` (`autoWallDimensions`, `placeWall`) строго по спеке и
design D1-D3 (не по тестам); мутанты применялись строковыми заменами в копии. В репозитории производственный код,
тесты и `src/auto-dimensions.ts` не создавались и не менялись.

- Новые тесты (`src/auto-dimensions.test.ts`, `src/auto-dimensions-place.test.ts`): 53 из 53 прошли с первого раза,

- Весь набор (`npx vitest run`, дважды): 95 файлов, 1908 тестов, все прошли.
- `npx tsc --noEmit` в копии: без ошибок.

## Findings

- 53 теста дошли до зелёного на независимой реализации с первой попытки: оракулы, сцены и порядок (новая стена последней) согласованы со спекой и дизайном; конфликтов спека/тест нет.
- Раунд-5 требования закрыты: ADW-28 разделяет часть «стык» (`jointAt` при зазоре), ADW-29 - «примыкание к грани в зоне митры», ADW-27 - «конец в теле двух стен» (числа 490/490 добавлены), ADW-25b зеркалит ADW-25, мутанты по клеткам правила точки замера на концах убиты по всем четырём клеткам.
- M1 серьёзный: вся публичная фиксация стены (`placeWall`) тестируется только на сценах без стыков (пустая сцена, `sceneR` с боковой стеной, параллельная стена), поэтому `placeWall`, не передающий в построение размеров реальные стены чертежа, проходит всё. Пользователь получает неверные числа в любом угле при рисовании в приложении.
- M2 нарушает решение раунда 5, зафиксированное в спеке и design D2 («любых стен чертежа, а не только найденных через `jointAt`»): ADW-27 покрывает только стены, у которых концы рядом с концом новой стены; стена, в теле которой лежит начало грани, но чьи концы далеко (конец новой стены внутри тела длинной стены вне оси), не покрыта.
- M3 условный: в дельта-спеке явного предложения нет, но design (Risks) требует «пропускать такие размеры», сценарий «Нулевой размер не создаётся» действует в `dimension-tool`, а в test-plan (Negative Cases) заявлено «Размер с совпадающими точками замера - не создаётся (ADW-15)»; ADW-15 проверяет лишь стену нулевой длины. Сцена достижима через `placeWall`.
- Не требуется по условию раунда: слабость ADW-13/ADW-14; ближайший против дальнейшего выхода при нескольких телах; различие `onBoundary` в предикате занятости; перетаскивание размерной линии.
