# Test Validation

Раунд 5. Валидатор read-only: в репозитории создан только этот файл. Эталонная реализация `src/auto-dimensions.ts`
(строго по спецификации и design.md, с переключателями мутаций через переменную `MUT`) писалась в одноразовой копии
вне репозитория (scratchpad `validation-copy5`, `node_modules` — junction, ничего не устанавливалось). В репозитории
нет `src/auto-dimensions.ts` и нет изменений `src/`.

Прогон:

- новые тесты (`src/auto-dimensions.test.ts`, `src/auto-dimensions-place.test.ts`) против эталона: 50 из 50 пройдено;
- весь набор в копии: 95 файлов, 1905 тестов, все пройдены; `npx tsc --noEmit`: без ошибок;
- тесты находятся раннером (`vitest` по умолчанию подбирает `src/**/*.test.ts`), `test-utils` файлом-тестом не считается.

Первый прогон эталона дал 4 падения (ADW-17, 19, 21b, 22) — ошибка эталона (перепутан порядок вершин грани «минус»),
не тестов; после исправления эталона все проходят. Конфликтов тестов со спецификацией не найдено.

## Requirement Coverage

- PASS. Каждый из 21 сценария спецификации имеет исполнимый тест (ADW-1…ADW-27, включая ADW-24b/24c, ADW-25, ADW-26,
  ADW-27 раунда 4). Сценарий «перетаскивание» сознательно без теста (поведение обычного размера). Сценарии
  «Торец, где сходятся две другие стены» и «Торец, упирающийся в грань» покрыты, но ADW-27 не фиксирует числа длины
  (см. Findings F3).

## Boundary Coverage

- FAIL. Не покрыты: (F1) стык с зазором в пределах допуска `jointAt`, когда конец не лежит в контуре соседа и не
  примыкает; (F2) примыкание торцом к грани в зоне, срезанной митрой соседа (конец на номинальной линии грани, но вне
  замкнутого контура); (F4) ADW-25 только для конца `a`, зеркала для конца `b` нет. Рекомендация: (F5) вход грани в тело
  соседа на малом расстоянии от угла.

## Findings

- F1. Определение занятости конца по `jointAt` (design D3, первая часть) ничем не защищено: во всех тестах конец,
  занятый стыком, одновременно лежит на границе или внутри замкнутого контура соседа. Стык в пределах допуска
  (`max(толщин)/2`) без совпадения точек — штатный случай (привязка не всегда точная). Проверено на эталоне: сцена
  `G = (508,0)-(800,0)`, `N = (0,0)-(500,0)`, массив `[G, N]`: `jointAt(N, N.b) != null`, контур G начинается с x=508,
  `teeEndAttached` ложен; корректно толщина на торце a, мутант без `jointAt` — на торце b в x=508.
- F2. Часть `teeEndAttached` (design D3) тоже без защиты: в тестах точка примыкания всегда лежит на границе контура соседа,
  а `teeEndAttached` истинен и там, где номинальная линия грани срезана митрой и точка вне контура. Реальная сцена
  (проверена на эталоне, диапазон 0,5…5,5 см вдоль грани): X под 45° t20 раньше C `(0,0)-(500,0)` t40, новая N
  `(3,120)-(3,20)` t10 упирается в верхнюю грань C; `jointAt` ложен, контур C и X не содержит конец. Корректно толщина на a.
- F3. Спецификация и design расходятся для конца, лежащего в теле другой стены без стыка по `jointAt` (две стены, как в
  ADW-27, либо конец утоплен вне оси соседа): текст требования («если грань от своего угла идёт внутри тела соседней
  стены — вершина, где грань выходит из тела этой стены») даёт 490 см по обеим граням ADW-27, design D2 (выход только по
  стенам из `jointAt`, при двух соседях `jointAt` = `null`) даёт 500 см. Сценарий ADW-27 числа длины не называет, тест их
  не проверяет, поэтому оба толкования проходят. Поведение не определено на уровне спецификации (правило 1 CLAUDE.md):
  нужно решение владельца спецификации и затем утверждение чисел в тесте.
- F4. ADW-25 (грань вдоль границы тела соседа) проверен только у конца `a`; у конца `b` реализация с отдельной
  обработкой не обнаруживается. После ADW-24b/24c зеркала ожидались и здесь.
- F5. Рекомендация (не блокирует): вход грани в тело соседа на малом расстоянии (ADW-24 — 8,28 см) оставляет любой шаг
  проверки до ~8 см допустимым. Тест с входом на 1–2 см отделит корректную реализацию от завышенного шага.
- ADW-13, ADW-14: слабые, но не блокируют (см. Assertion Strength).
- Конфликтов тестов со спецификацией, нереализуемых сценариев и плохих оракулов не найдено. Все числа тестов совпадают с
  числами спецификации (500, 20, 290, 490, 510, 518,28, 538,28).
- Реализация прошла тесты без подгонки; мутации знаков, величины смещения, порядка, выбора торца и всех четырёх ячеек
  «грань × конец» убиваются.

   размера, толщина на торце a (`expectThickness(толщина, N, 0, -1)`). Убивает мутанта без `jointAt`.
