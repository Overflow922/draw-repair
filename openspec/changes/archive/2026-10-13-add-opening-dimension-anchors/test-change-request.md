# Test Change Request: AD-30 (src/auto-dimensions.test.ts)

## Approved test

`src/auto-dimensions.test.ts`, тест «AD-30: неизвестный набор остаётся без изменений (эквивалентная запись точки сохраняется)».

## Why it no longer fits

Тест читает `target.from.a` и `target.from.b` у `Dimension`, полученного из `Scene`. По design D1/D8 этого change
`DimPoint` становится объединением `EdgePoint | JambPoint` (точка-откос не содержит `a`/`b`), поэтому
`tsc --noEmit` сообщает `Property 'b' does not exist on type 'JambPoint'` на этой строке. Поведение теста
(автоматический размер, пересобранный с переставленными гранями, не заменяется при пересчёте) спецификацией не
меняется: автоматические размеры по-прежнему заданы только гранями (`dimension-tool` «Автоматические размеры стены»).

## Change

Добавлена одна строка перед использованием граней — сужение типа:

```ts
if (!("a" in target.from)) throw new Error("автоматический размер задан гранями")
```

Ни ожидания, ни данные, ни проверяемое поведение не менялись; тест не ослаблен (при граневой точке ветка не
срабатывает, при откосе — тест падает с понятным сообщением).

## Decision

Решение пользователя: test-change-request (вариант «узко сузить тип»), принято в сессии explore/ff
`add-opening-dimension-anchors`. Изменённый тест подлежит повторной валидации вместе с остальным набором
(`test-validation`).
