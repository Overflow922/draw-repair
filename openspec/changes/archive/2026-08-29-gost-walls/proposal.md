## Why

Текущие типы стен («Несущая», «Перегородка», «Гипрок») — произвольный набор с плоской цветной заливкой. По строительной механике и ГОСТ 21.501-2018 стены делятся на три категории по несущей способности, а на чертежах различаются монохромной штриховкой и толщиной линий. Нужны корректные категории и чертёжный (векторный) стиль отрисовки как первый шаг к переключаемым стилям отображения.

## What Changes

- **BREAKING** Типы стен заменяются на категории несущей способности: «Несущая» (bearing), «Самонесущая» (selfbearing), «Ненесущая» (nonbearing). Тип «Гипрок» удаляется.
- По умолчанию — «Ненесущая» (преемник «Перегородки»); порядок стрелок ↑/↓: несущая → самонесущая → ненесущая, с зацикливанием.
- Отрисовка стен — монохромная векторная штриховка под 45° разной плотности по категории + контур фиксированной толщины (толстый/средний/тонкий по ГОСТ); цветная заливка удаляется.
- Черты «Ненесущая»/«Самонесущая»/«Несущая» в подпанели инструмента «Стена» — монохромные образцы-миниатюры со штриховкой.
- Миграция сохранённых чертежей: старые типы `partition` и `drywall` → `nonbearing`, `bearing` → без изменений; версия хранилища не меняется.
- Вне скоупа: переключатель стилей отображения (стиль ГОСТ — первый; структура рендера закладывается расширяемой), атрибут «материал», паттерны ГОСТ 2.306.

### New Capabilities

### Modified Capabilities

- `wall-types`: категории стен, дефолт, порядок стрелок; отрисовка штриховкой с контуром по категории вместо цвета; миграция старых значений типа. Дельта строится на тексте с учётом ещё не архивированного `floating-ui` (расположение выбора во вспомогательной панели, стрелки при закрытой панели); архивировать `floating-ui` раньше `gost-walls`.

## Impact

- `src/types.ts`: список WALL_TYPES (id, подпись, параметры штриховки/контура), функция нормализации старого значения типа.
- `src/render.ts`: отрисовка стены — контур + штриховка 45° (векторно, в мировых координатах под clip-контуром) вместо цветной заливки.
- `index.html` / `src/style.css`: образцы типов в подпанели — монохромные мини-штриховки (CSS `repeating-linear-gradient`) с рамкой по весу контура.
- `src/main.ts`: точечно — данные-типы приходят из `types.ts`; логика выбора/стрелок/выделения без изменений.
- `src/storage.ts` + тесты: нормализация значения типа при разборе хранилища; юнит-тесты миграции.
- Проверка визуальная в браузере + `npm test` / `npm run build`.
