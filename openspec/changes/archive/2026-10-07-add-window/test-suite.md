# Test Suite

Тесты `add-window`. Запуск: `npx vitest run src/doorway/window src/doorway/element-kind`. Начальный прогон (до реализации, 2026-10-06): 9 файлов, 95 тестов; 56 падают, 35 проходят, 4 не запускаются — файл (`element-kind.test.ts`) не загружается — модуля ещё нет. Остальные тесты проекта зелёные. `tsc` до реализации падает на тестовых файлах (нет `WallWindow`, `WallElement`, `placeWindow`, `setSill`, `nudgeElements`, `element-kind`, `Palette.sill`, параметра `elements`) — это ожидаемо.

Вспомогательный модуль: `src/doorway/window.test-utils.ts` — сцены RN/FN/FO/WA/WN (test-plan «Сцены»), фабрика `win(...)`, записывающий контекст `colorRecorder()` поверх `recorder()` из `doorway.test-utils.ts`: дополнительно запоминает `fillStyle` каждого `fillText` и записывает `roundRect` / `strokeRect` / `arcTo` / кривые как отрезки пути (базовый фейк их не поддерживает или игнорирует).

### Happy paths

- Установка окна (WE-09), подпись и обозначение (WL-01, WL-07), PDF (WP-01), хранение и история (WS-01, WS-05), значения по умолчанию (WT-01).
