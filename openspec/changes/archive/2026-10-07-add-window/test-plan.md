# Test Plan

## Scope

Окна как второй вид элемента стены: новая возможность `window` и дельты `doorway` («Элементы стены», «Проём и опорная стена», «Стыки грани и расстояния проёма», «Инвариант размещения проёма»), `wall-collision`, `drawing-storage`, `drawing-history`, `pdf-export`.

Как и в `add-doorway`, тесты идут в `vitest` без DOM: поведение проверяется через чистые публичные функции `src/doorway/`, `storage.ts`, `history.ts`, `wall-edit.ts`, `wall-chain.ts` и через `drawScene` / `buildPdf` с записывающим контекстом. Конфигурация инструмента по виду (значения по умолчанию, допустимость значений полей) выносится в чистую функцию (design D4) и тестируется; панель, фокус, кнопка и поле ввода на месте числа — ручные проверки (M-*).

Одобренные тесты `add-doorway` и остальные существующие тесты не меняются и должны остаться зелёными (регрессия совместимости: проём без `kind`, сигнатуры с необязательным `elements`).

### Сцены (см, толщина 20, если не указано)

- **F** — свободная стена W `(0,0)-(500,0)`.
- **R** — комната W `(0,0)-(500,0)`, R `(500,0)-(500,400)`, B `(500,400)-(0,400)`, L `(0,400)-(0,0)`; грань W `y = +10` (`side = +1`) — внутренняя, `y = −10` (`side = −1`) — наружная.
- **D0** — проём на W: `a`, 100, ширина 90, H 210 (участок `x` 100…190).
- **WN** — окно на W: `b`, 100, ширина 120, H 150, подоконник 85 (участок `x` 280…400 при длине 500).
- **RN** = R + D0 + WN; **FN** = F + D0 + WN.
- **FO** — F + D0 + окно `a`, 170, ширина 120 (участок 170…290): наложение 20 см.
- **WA** — окно на W: `a`, 100, ширина 120, H 150, подоконник 85 (участок 100…220).

Допуски: координаты `toBeCloseTo(x, 3)`; касание — `|x − эталон| ≤ 1e-3`.

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Касание соседа | RN, проём 190…280 рядом с окном 280…400 | `doorwayHolds` true, расстояние 0 |
| Наложение 0.01 | проём 100…190.01, окно 190…310 | `doorwayHolds` false |
| Подоконник 0 | `acceptField("window", "sill", 0)`; `setSill(w, 0)` | принимается |
| Подоконник −0.01 | `acceptField`, `setSill` | отклоняется |
| Ширина окна = 1.2·T | T 20, ширина 24 | стёкол нет |
| Ширина окна чуть больше 1.2·T | T 20, ширина 24.5 | две линии стекла длиной 0.5 |
| Сосед с тем же `id` | список содержит сам элемент | участок не режется |
| Призрак в точный промежуток | RN, ширина 90, промежуток 90 | ставится с касанием обоих |
| Призрак шире промежутка | RN, ширина 91, курсор в промежутке | все промежутки RN по 90 см — призрака нет (null); сдвиг к ближайшему допустимому положению — сцена F с одним проёмом (WE-02b) |
| Укорочение до касания | FN, длина 410 | ровно 410, без наложения |

## Negative Cases

| Case | Expected behavior |
|---|---|
| `setSill` с NaN / отрицательным | `rejected: invalid`, окно не меняется |
| `setSill` тем же значением | `rejected: no-change` |
| `acceptField("doorway", "sill", …)` | у проёма нет поля подоконника (false / не определено) |
| Элемент неизвестного вида в документе | отброшен, остальные восстановлены |
| Окно без `sillCm` / `sillCm: "85"` (строка) / `Infinity` | отброшено |
| Окно в снимке истории с отрицательным подоконником | история пуста, приложение работает |
| Правка стены, сдвигающая окно на проём | ограничена касанием |
| Рисование стены с примыканием внутри окна | привязка/фиксация отклоняются |
| `placeWindow` с подоконником < 0 или шириной ≤ 0 | null |

## Invariants

- После любой операции (`place*`, `set*`, `slide`, `arrowSlide`, `nudgeElements`, ограниченные правки стен, рисование) для каждого элемента со списком всех элементов `doorwayHolds = true`, если он выполнялся до операции; уже нарушенный — нарушение не растёт.
- Участки элементов одной стены попарно не налагаются (касание допустимо).
- Вид и данные вида (`kind`, `sillCm`) элемента не меняются никакой правкой положения или ширины.
- Проём сериализуется без поля `kind`; roundtrip документа с проёмом побайтно прежний.
- Обозначение окна — функция только откосов и толщины: при перестановке `a`/`b` оси и смене привязки совпадает.
- Каноническая форма стены, помещения и привязки от окон не меняются (`findRooms`, `hitWall` с окном и без — одинаково).

## Mutation Targets

Мутационного инструмента в проекте нет; тест-валидатор проверяет вручную, что каждая мутация ниже ловится хотя бы одним тестом:

- `elementRuns` не вычитает соседей / вычитает и сам элемент (`id !==` → `true`) — WF-02, WF-04.
- Соседи берутся со всех стен (нет фильтра `wallId`) — WF-06.
- Вычитание соседа только на одной грани — WF-02 (обе грани).
- Продакшн-вызов без `elements` (guard, edit, tool, layout) — WE-01…08, WG-01, WL-*.
- Диапазон сдвига не расширяется до текущего положения у нарушенного — WE-08.
- Порядок `nudgeElements` не по ведущему — WE-12.
- `setSill`: `>= 0` → `> 0` — WE-10, WT-02; `acceptField` подоконника как у ширины — WT-02.
- `kind`/`sillCm` теряются в `withStart`/`result` — WE-13; `result` не учитывает `sillCm` (setSill → no-change) — WE-10.
- Сторона квадрата `0.6·h` вместо `0.6·T`; стёкла на `±T/3` вместо `±T/6`; условие стёкол `≥` вместо `>` — WL-01, WL-03, WL-04.
- Грани окна цветом `muted` (как у проёма) — WL-06.
- Подпись окна без «H под.» / синий цвет не на той части / нет рамки — WL-07.
- Формат метров для подоконника — WL-08.
- Сериализация проёма с `kind: "doorway"` — WS-02; неизвестный вид принимается как проём — WS-04; `sillCm ≥ 0` → `> 0` в валидаторе — WS-04.
- `wallsBBox` не учитывает ширину подписи окна — WP-03.

## Ручные проверки (браузер)

- M-01: кнопка «Окно» сразу после «Проём»; Esc без выделения деактивирует инструмент.
- M-02: поля «Ширина», «H», «H под.» в мм — 1200/1500/850, в см — 120/150/85; неверное значение возвращает прежнее.
- M-03: в инструменте «Окно» клик по проёму выделяет проём и открывает панель «Проём»; клик по окну в инструменте «Проём» — панель «Окно».
- M-04: поле «H под.» выделенного окна меняет окно, одна запись истории, «Отменить» возвращает.
- M-05: после правки полей выделенного окна новые окна ставятся с прежними значениями панели.
- M-06: призрак окна скользит вдоль стены и прижимается к соседнему проёму; перетаскивание окна упирается в проём.
- M-07: число цепочки окна редактируется на месте; цепочка измеряет до соседнего элемента.
