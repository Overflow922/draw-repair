## MODIFIED Requirements

### Requirement: Каталог планов
Приложение ДОЛЖНО иметь упорядоченный каталог планов; у каждого плана есть постоянный идентификатор и название. Каталог ДОЛЖЕН содержать планы «Обмерочный план» (идентификатор `measure`), «Демонтаж» (идентификатор `demolition`) и «Монтаж» (идентификатор `mounting`) в этом порядке. Порядок каталога определяет порядок планов в переключателе и порядок страниц в PDF. Каталог един для всех чертежей: все чертежи имеют один и тот же набор планов.

План «Обмерочный план» ДОЛЖЕН содержать стены, размеры и элементы стены (проёмы, окна, двери) чертежа — те самые объекты, которые чертёж содержал до введения планов; их редактирование, отображение и правила остаются прежними. План «Демонтаж» ДОЛЖЕН содержать только пометки сноса (`demolition-plan`). План «Монтаж» ДОЛЖЕН содержать собственные стены, проёмы, двери, окна и размеры и показывать остатки обмерочного плана после сноса как подложку только для чтения (`mounting-plan`).

#### Scenario: Состав каталога
- **WHEN** приложение открыто
- **THEN** каталог планов содержит «Обмерочный план» (`measure`), «Демонтаж» (`demolition`) и «Монтаж» (`mounting`) в этом порядке

#### Scenario: Обмерочный план содержит объекты чертежа
- **WHEN** у чертежа, сохранённого до введения планов, есть стены, размеры и проёмы
- **THEN** в плане «Обмерочный план» отображаются и редактируются те же стены, размеры и проёмы

#### Scenario: План «Монтаж» у старого чертежа
- **WHEN** открыт чертёж, сохранённый до введения плана «Монтаж»
- **THEN** план «Монтаж» показывает остатки обмерочного плана и не содержит собственных объектов

### Requirement: Переключатель планов
В верхней панели, вторым рядом под вкладками чертежей и кнопкой «+», ДОЛЖЕН находиться переключатель планов — ряд кнопок-сегментов по образцу переключателя единиц «м / см / мм»: по одной кнопке на каждый план каталога в порядке каталога, подписанной названием плана; кнопка активного плана ДОЛЖНА быть визуально выделена. Нажатие на кнопку неактивного плана ДОЛЖНО делать этот план активным; нажатие на кнопку активного плана НЕ ДОЛЖНО ничего менять. Переключатель ДОЛЖЕН отражать активный план активного чертежа и обновляться при переключении вкладок.

При переключении плана ДОЛЖНЫ быть сброшены выделение, незавершённая цепочка рисования стены, черновик размера, незавершённая протяжка пометки и другие незавершённые жесты; выбранный инструмент ДОЛЖЕН быть сброшен на инструмент плана по умолчанию (`Инструменты плана`).

#### Scenario: Переключатель показывает каталог
- **WHEN** приложение открыто
- **THEN** в верхней панели вторым рядом под вкладками и «+» расположен ряд сегментов «Обмерочный план», «Демонтаж» и «Монтаж»; выделен сегмент активного плана

#### Scenario: Повторное нажатие на активный план
- **WHEN** пользователь нажимает кнопку уже активного плана
- **THEN** активный план, выделение и вид не изменились

#### Scenario: Переключение сбрасывает выделение и жесты
- **WHEN** выделена стена, начата цепочка рисования, и план переключается на «Демонтаж» или «Монтаж»
- **THEN** выделение снято, цепочка прервана, черновик размера отброшен

#### Scenario: Переключатель следует за вкладкой
- **WHEN** пользователь переключает вкладки чертежей с разными активными планами
- **THEN** выделенным сегментом всегда является активный план показываемого чертежа

#### Scenario: Переключение сохраняется
- **WHEN** пользователь переключил план на «Монтаж» и перезагрузил страницу
- **THEN** чертёж открывается на плане «Монтаж»

### Requirement: Инструменты плана
У каждого плана ДОЛЖЕН быть собственный набор инструментов и инструмент по умолчанию. Панель инструментов ДОЛЖНА показывать кнопки только инструментов активного плана. План «Обмерочный план»: «Стена», группа «Проёмы» («Проём», «Дверь»), «Окно», «Размер», «Линейка», «Ластик»; по умолчанию «Стена». План «Демонтаж»: «Демонтаж», «Линейка», «Ластик» (на плане «Демонтаж» ластик удаляет только пометки сноса, `demolition-plan` «Ластик на плане «Демонтаж»»); по умолчанию «Демонтаж». План «Монтаж»: тот же набор и тот же порядок, что у обмерочного плана («Стена», группа «Проёмы», «Окно», «Размер», «Линейка», «Ластик»); по умолчанию «Стена»; инструменты действуют на собственные объекты плана «Монтаж» (`mounting-plan` «Собственные объекты плана «Монтаж»»), «Линейка» измеряет по остаткам и собственным стенам, «Ластик» удаляет только собственные объекты «Монтажа». При переключении плана и чертежа активным становится инструмент плана по умолчанию. Горячие клавиши и жесты инструментов других планов (стрелки смены материала и сдвига стен, Delete стен, размеров и элементов, правка стен) НЕ ДОЛЖНЫ действовать на плане, где этих инструментов нет, и на плане «Монтаж» не затрагивают объекты других планов.

#### Scenario: Инструменты обмерочного плана
- **WHEN** активен «Обмерочный план»
- **THEN** на панели инструментов кнопки «Стена», «Проёмы», «Окно», «Размер», «Линейка», «Ластик»; активна «Стена»

#### Scenario: Инструменты плана «Демонтаж»
- **WHEN** активен план «Демонтаж»
- **THEN** на панели инструментов только кнопки «Демонтаж», «Линейка» и «Ластик»; активна «Демонтаж»

#### Scenario: Инструменты плана «Монтаж»
- **WHEN** активен план «Монтаж»
- **THEN** на панели инструментов кнопки «Стена», «Проёмы», «Окно», «Размер», «Линейка», «Ластик»; активна «Стена»

#### Scenario: Возврат на обмерочный план
- **WHEN** пользователь переключается с «Демонтаж» на «Обмерочный план»
- **THEN** на панели снова кнопки обмерочного плана, активна «Стена»

#### Scenario: Ластик не переходит между планами
- **WHEN** на плане «Демонтаж» или «Монтаж» активен «Ластик» и пользователь переключается на «Обмерочный план»
- **THEN** активна «Стена»; ластик прежнего плана не действует на объекты обмерочного плана

#### Scenario: Ластик «Монтажа» не трогает обмер
- **WHEN** на плане «Монтаж» активен «Ластик» и пользователь кликает по остатку стены
- **THEN** стена обмерочного плана осталась, шага истории нет
