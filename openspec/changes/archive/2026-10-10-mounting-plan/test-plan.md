# Test Plan

## Scope

Поведение плана «Монтаж» на уровне модели, хранилища, истории и PDF (интерфейсы — `design.md`, раздел «Interfaces»):

- вычисление остатков стен `remnantWalls` (`mounting-plan` «Остатки — живая производная»);
- сцена плана `mountingScene`: остатки + собственные стены, видимость старых и собственных элементов, размеры
  (`Остатки только для чтения`, `Элементы и размеры на остатках`, `Старые элементы стены на плане «Монтаж»`);
- стыки новых стен с остатками через существующую геометрию (`Стыки новых стен с остатками`);
- каталог планов, инструменты, ключ истории (`drawing-plans`);
- хранение (`drawing-storage` «Объекты плана «Монтаж» в документе»);
- история (`drawing-history` «История плана «Монтаж»»);
- страница PDF (`pdf-export` «Страница плана «Монтаж»»).

Вне автоматических тестов (проверяется вручную в браузере, фиксируется в `TODO.md`): жесты `main.ts` — клик, рамка,
ластик, клавиши по остаткам; переключатель; рисование на холсте.

Эталонные числа выведены из спецификации: стена `W` — ось `(0,0)–(500,0)`, 20 см, кирпич; идентификатор остатка —
`W~<начало в мм>`.

## Negative Cases

| Case | Expected behavior |
|---|---|
| Пометка на железобетоне | вычета нет, стена целиком |
| Пометка через участок окна | вычета нет |
| Пометка на отсутствующую стену | игнорируется |
| Собственный размер с привязкой к исчезнувшему остатку | не в `dimensions` сцены, в чертеже остаётся |
| Собственный проём на снесённом остатке | не в `doorways` сцены, в чертеже остаётся |
| Чертёж без `mounting` | `own` пуст, поле не создаётся |
| Битая стена в `mounting.walls` | отброшена, остальные восстановлены |
| `mounting` не объект / `walls` не массив | чертёж открывается, «Монтаж» пуст |
| Вызов `mountingScene` | входной чертёж не мутирован (глубокая заморозка) |

## Invariants

- `scene.walls` = `scene.remnants` ++ `scene.own` (по порядку); `own` содержит только стены из `drawing.mounting`.
- Остатки не пересекаются по оси и лежат внутри исходной стены; сумма длин остатков + сумма действующих пометок =
  длина стены (для стены без перекрытий).
- Идентификаторы остатков уникальны и не совпадают с идентификаторами стен обмера и собственных стен.
- `serializeStore → parseStore` не добавляет остатки и не теряет собственные объекты (круговой тест).
- Операции «Монтажа» не меняют `drawing.walls`, `drawing.dimensions`, `drawing.doorways`, `drawing.demolition`.
- Контур исходной стены после «достройки» остатков совпадает с исходным (суммарная площадь форм).

## Integration Cases

- `remnantWalls` на реальных `effectiveMarks` (включая блокировку окном и железобетон).
- Остатки + собственная стена → `displayPolygons` и `findRooms` (замкнутое помещение с площадью).
- `parseStore(serializeStore(...))` с `mounting` и `activePlan: "mounting"`.
- `pagesOf` → `buildPdfPages` → число страниц, графа 5 «Монтаж», отсутствие красного на третьей.
- `planHistory` для трёх планов не пересекаются.

## Mutation Targets

- порог `EPS_CM` при отбрасывании остатка (`>` vs `>=`);
- пересчёт `offsetCm` для `anchor: "b"` (знак/перепутаны концы);
- «касается» против «пересекает» для старых элементов (`<` vs `<=`);
- разный допуск для собственных элементов (включительно);
- забытая фильтрация размеров с исчезнувшей привязкой;
- `walls` в обратном порядке (собственные раньше остатков);
- мутация входа (`push` в `drawing.walls`);
- ключ истории совпадает с ключом демонтажа;
- третья страница использует `drawing.walls` вместо сцены (снесённое видно);
- страница «Монтаж» копирует размеры обмера;
- удаление поля `mounting` при загрузке/сохранении;
- запись остатков в документ.
