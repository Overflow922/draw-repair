## Why

Категории несущей способности не определяют вид штриховки: по ГОСТ 2.306-68 графическое обозначение в сечении задаётся МАТЕРИАЛОМ стены (кирпич — сплошные линии, бетон — штрихпунктир, железобетон — комбинированные, древесина — волокна). Нужен атрибут материала стены и четыре векторных паттерна штриховки по ГОСТ вместо плотностных вариантов по категории.

## What Changes

- **BREAKING** Тип стены = материал стены: «Кирпич», «Бетон», «Железобетон», «Дерево (вдоль)». Категории «Несущая/Самонесущая/Ненесущая» удаляются.
- Штриховка по ГОСТ 2.306-68, векторно на Canvas 2D, в ЭКРАННЫХ миллиметрах: шаг — константа на экране (диапазон 1–10 мм «на бумаге», дефолт ~3 мм); линейные штриховки — строго 45° к рамке независимо от угла и зума.
  - кирпич — сплошные тонкие линии 45°;
  - бетон — штрихпунктирные линии 45°;
  - железобетон — чередование сплошных и штрихпунктирных линий 45°;
  - дерево (вдоль) — волнистые линии вдоль волокон.
- Контур стены — единая основная линия (~2px) для всех материалов; выделение (циановая обводка) и превью с полупрозрачностью сохраняются.
- Образцы в подпанели — «легенда»: мини-превью паттерна (мини-канвас, рисуется теми же функциями) + подпись материала; дефолт — «Кирпич»; стрелки ↑/↓ циклируют материалы в порядке списка.
- Выпадающий список стиля отображения в нижней панели — единственный пункт «ГОСТ» (каркас будущих переключаемых стилей).
- Миграция хранилища: любые старые значения типа (`partition`, `drywall`, `bearing`, `selfbearing`, `nonbearing`) → «Кирпич»; версия хранилища не меняется.
- Вне скоупа: масштаб листа (1:50/1:20), цветные стили отображения, переключение между несколькими стилями (входит только каркас-список), штриховка торца древесины (удалена по решению пользователя).

### Modified Capabilities

- `wall-types`: тип стены = материал; выбор из четырёх образцов «легендой» (мини-превью + подпись), дефолт «Кирпич»; требование о штриховке переписано под ГОСТ 2.306-68 (паттерны по материалу, экранная метрика, строгие 45° для линейных штриховок); миграция всех legacy-значений в «Кирпич». Дельта строится на тексте после архивации `gost-walls`.
- `canvas-app`: нижняя панель получает выпадающий список стиля отображения (единственный пункт «ГОСТ»).

## Impact

- `src/types.ts`: `MATERIALS` (id/label) вместо `WALL_TYPES`, `normalizeMaterial` (любое неизвестное → `brick`).
- `src/render.ts`: рефактор отрисовки стены в экранные координаты (полигон → экран, клип, паттерн), функции паттернов, контур 2px, `setLineDash` для штрихпунктира.
- `index.html` / `src/style.css` / `src/main.ts`: четыре свотча-легенды с мини-канвасами и подписями, селектор стиля отображения в нижней панели, дефолт `brick`, обработчики и стрелки по материалам.
- `src/storage.ts` + тесты: нормализация в `parseStore`; обновление тестов миграции.
- Проверка в браузере (паттерны, 45°, шаг при зуме, миграция) + `npm test` / `npm run build`.
