## Context

Мотивация — в `proposal.md`, поведение — в `specs/`. Что есть (после `add-switching-plan` и `add-light-lines`):

- `src/switching/`: сцена «Групп включения», рабочий набор, отрисовка, поле `Drawing.switching` (метки линий, выноски, примечания), инструмент метки со значением в панели.
- `src/ceiling/light-tool.ts`, `light-reach.ts`: постановка бра с прилипанием к чистовой грани (40 px), перетаскивание вдоль граней, расчёт чистовых граней с учётом штукатурки и гипсокартона.
- Подпись на месте, поле панели с целым числом — как у натяжного потолка.

## Goals / Non-Goals

**Goals:**
- Выключатель как отдельный объект плана «Группы включения» со списками имён линий по клавишам; связь с линиями — только по имени.
- Постановка на грань стены с любой стороны.

**Non-Goals:**
- Проверки целостности схемы (у каждой линии есть клавиша, у каждой клавиши — линия), подсветка группы, высота установки, вытяжка.
- Количество в легенде.

## Decisions

### D1. Модель и хранение
```
SwitchKey   { lines: string[] }                   // имена "L<n>" или "LV<n>", без повторов, порядок ввода
LightSwitch { id: string; at: Point; angle: number; keys: SwitchKey[] }   // 1 <= keys.length <= 6
SwitchingContent.switches?: LightSwitch[]
```
`at` — центр блока на грани: вдоль грани целое число сантиметров, поперёк — на грани (может быть дробной координатой), как у бра. `angle` — угол наружной нормали грани в градусах, то есть направление «от стены» к стороне, куда смотрит выключатель. Блок — один объект: клавиши не отдельные объекты. Хранится всё целиком; недопустимый выключатель (без клавиш, больше шести, недопустимое имя) при загрузке отбрасывается целиком, а не по клавише — иначе блок молча терял бы клавиши.

Отклонённая альтернатива: каждая клавиша — отдельный объект. Блок из трёх клавиш на одной грани ставится и двигается как единое целое, и подпись в примере пользователя — одна строка над блоком.

### D2. Имена в клавише
`parseKeyLines(text): string[] | null` разбирает `L2,LV1`, `l2, lv1`, `L2;LV1` (разделитель — запятая или точка с запятой, пробелы вокруг игнорируются), приводит к верхнему регистру, убирает повторы с сохранением порядка. Токен — `L<n>` или `LV<n>`, `n` — целое больше нуля. Пустая строка — клавиша без линий. Любой недопустимый токен — `null` (ввод не применяется целиком). Подпись клавиши — `lines.join(",")`.

### D3. Грани для выключателя
Выключатель стоит на любой чистовой поверхности стены — и в помещении, и снаружи (в примере выключатель висит на внешней стороне стены ванной). Расчёт граней — функция из `light-reach.ts` для бра, обобщённая на обе стороны каждой стены и грани штукатурки и гипсокартона. Участки граней внутри проёма (двери, дверного проёма, окна) и на стыках со стенами не берутся. Если нынешняя функция бра возвращает только грани, обращённые в помещение, добавляется вторая функция «все грани»; поведение бра не меняется (тесты `ceiling-lighting` остаются контрактом).

```
 вид сверху, схематично, не в масштабе: выключатель 3 клавиши на внешней грани

     L2,LV1   L3   L4,L5       <-- подписи клавиш (над блоком)
       |       |      |
       o-      o-     o-       <-- клавиши: кружок на грани, стойка, штрих
   ##########################  <-- стена; внешняя грань
   #                        #
   #      (помещение)       #
```

### D4. Знак и размеры
Клавиша: кружок диаметром 12 px / 3 мм, касающийся грани (центр на расстоянии радиуса от грани по нормали); стойка от кружка наружу 12 px / 3 мм; штрих на конце стойки длиной 10 px / 2,5 мм вдоль грани, на 90° против часовой стрелки от нормали (при взгляде сверху: вверх от стены — штрих влево, как на образце `references/lines.png`). Шаг клавиш вдоль грани 48 px / 12 мм, блок центрирован на `at`. Подпись клавиши — текст кегля метки линии, центр на 28 px / 7 мм от грани по нормали над клавишей, всегда горизонтальный. Цвет — красный цвет освещения схемы, как знаки освещения.

Числа — первое приближение по примеру пользователя; уточняются по картинке в `references/` (D6). Цель шага 12 мм — чтобы подписи вида `L2,LV1` соседних клавиш на горизонтальной грани не перекрывались.

### D5. Инструмент, панель, правка
Новый `Tool` `"lightSwitch"`. Панель — поле «Клавиш» (целое 1–6, по умолчанию 1, значение сеанса), по образцу поля линии. Призрак: ближайшая грань в 40 px, центр — ближайшая точка грани с округлением вдоль неё до целого сантиметра, направление — наружная нормаль грани в сторону курсора; нет грани — нет призрака. Перетаскивание — те же правила, что у бра. Правка числа клавиш в панели выделенного выключателя: уменьшение отбрасывает последние клавиши вместе с их линиями, увеличение добавляет пустые; один шаг истории; блок остаётся центрированным на `at`.

Список линий клавиши правится в поле на месте: клик по подписи или по кружку клавиши выделенного выключателя открывает поле с текущим текстом; Enter применяет, Escape и потеря фокуса — по правилам подписи потолка. Недопустимый ввод не применяется.

### D6. Образец вида
Образец знака выключателя — `references/lines.png` (блок из трёх клавиш на внешней стене ванной, подписи над блоком). Пользователь подтвердил (2026-10-27): штрих на конце стойки идёт влево от стойки при нормали вверх; размеры D4 остаются приближением по этой картинке.

### D7. История, PDF, легенда
Выключатели пишутся в историю плана отдельной записью вида `switches` — снимком списка выключателей до операции (как метки линий — `switching`, выноски и примечания — своими записями); отмена и повтор работают только с верхней записью своего вида. Страница PDF рисует выключатели тем же кодом, что холст, в миллиметрах. Запись легенды `{ kind: "light-switch" }` после «Линия освещения»; образец — одна клавиша с вертикальной нормалью вверх без подписи.

## Risks / Trade-offs

- [Внешние грани: расчёт граней рассчитан на помещения] → отдельная функция «все грани», отдельные тесты; у бра ничего не меняется.
- [Подписи соседних блоков на одной стене перекрываются] → без раскладки; блок двигается вручную.
- [Имя в клавише не проверяется на существование линии] → осознанно; проверки целостности — отдельное изменение (`TODO.md`).
- [Выключатель не следует за стеной, как бра] → принято, как у бра (`ceiling-lighting`); при сдвиге стены на нижнем плане он остаётся на месте.
