## MODIFIED Requirements

### Requirement: Каталог видов мебели
Предметы плана «Мебель» ДОЛЖНЫ быть предметами одного устройства: центр, ширина, длина, угол (требование «Стол» описывает это устройство для вида «Стол»; те же правила действуют для любого вида), и различаться ДОЛЖНЫ только видом. Вид задаётся каталогом, а запись каталога определяет для вида: название («Стол»), слово для плашки пересечений («стол»), размеры по умолчанию, цвет на светлой и на тёмной схеме и иконку кнопки в панели группы «Мебель». Все остальное поведение (постановка кликом, призрак, выделение, перемещение, правка полей, стрелки, Delete, ластик, пересечения, история, хранение, PDF) НЕ ДОЛЖНО зависеть от вида. Сейчас в каталоге два вида, в этом порядке: «Стол» (ширина 80 см, длина 160 см, угол 0) и «Стул» (ширина 45 см, длина 45 см, угол 0; слово плашки «стул»); все требования плана, где говорится о столе, действуют и для стула, с заменой названия и значений вида.

Панель группы «Мебель» ДОЛЖНА содержать по одной кнопке инструмента на каждый вид каталога, в порядке каталога; поля «Ширина», «Длина», «Угол» общие для всех видов и показывают значения для новых предметов активного вида. Значения для новых предметов запоминаются в сеансе отдельно по каждому виду, начальные — из каталога, и в чертеже не сохраняются. Правка выделенного предмета меняет его, а не значения вида (требование «Панель группы «Мебель» и инструмента «Стол»»). Цвет каждого вида различим от серой подложки, зелёного гипсокартона, красной подсветки пересечений и цветов других видов каталога на светлой и тёмной схеме. Легенда страницы «Мебель» в PDF содержит запись с названием и образцом цвета для каждого вида, чьи предметы есть на странице, в порядке каталога (`pdf-export` «Легенда на странице PDF»); записи вида без предметов на странице нет.

#### Scenario: Единственный вид — стол
- **WHEN** открыта панель группы «Мебель»
- **THEN** (название сценария сохранено для архива, в каталоге теперь два вида) в ней две кнопки в порядке «Стол», «Стул»; размеры по умолчанию стола: ширина 80, длина 160, угол 0; стула: ширина 45, длина 45, угол 0

```text
План, вид сверху (схематично, не в масштабе). Т — стол 80×160, С — стул 45×45 (см)

  +--------+
  |   Т    |  160
  |        |        +----+
  +--------+        | С  | 45
     80             +----+
                      45
```

#### Scenario: Запись легенды по виду
- **WHEN** на странице «Мебель» есть стол
- **THEN** в легенде запись «Стол» с образцом цвета стола; если столов нет, записи нет; так же для стула — запись «Стул» с образцом цвета стула, только если на странице есть стулья

#### Scenario: Значения новых предметов по видам
- **WHEN** в каталоге несколько видов, и для вида A в панели задана ширина 100, а затем выбран вид B
- **THEN** поля показывают значения вида B (по умолчанию из каталога), а значение вида A сохранено до конца сеанса

#### Scenario: Плашка пересечений называет стул
- **WHEN** выделен или поставлен стул, пересекающий стену
- **THEN** плашка читает «Стул пересекается: стена»; если стул пересекает ещё и стол — «Стул пересекается: стена, стол»
