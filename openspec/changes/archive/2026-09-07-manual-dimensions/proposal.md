## Why

Размеры сейчас проставляются автоматически для каждой стены: положение размерной линии выбирает эвристика (`dimensionSide`), и пользователь не может ни переместить размер, ни проставить размер там, где он нужен (например, между точками разных стен). Нужен ручной инструмент: пользователь сам указывает две точки замера на стенах и положение размерной линии.

## What Changes

- **BREAKING**: удалена автоматическая простановка размеров у каждой стены и размер превью-сегмента при рисовании цепочки
- Новый инструмент «Размер» в тулбаре: клик 1 — точка замера на стене, клик 2 — вторая точка на стене, клик 3 — положение размерной линии; Esc / двойной клик отменяют
- Размеры становятся сохраняемыми сущностями, привязанными к стенам: при перемещении, растяжении или повороте стены размер следует за ней; число размера — расстояние между точками замера в текущих единицах
- Удаление стены каскадно удаляет привязанные к ней размеры; undo возвращает стену вместе с размерами
- Ластик удаляет размеры; поставленную размерную линию можно перетаскивать, меняя её смещение
- Стенам добавлены постоянные идентификаторы для привязки; формат хранилища — версия 3 (id стен, список размеров), формат истории — версия 2 (снимки стены + размеры вместе)
- Экспорт PDF включает размеры, подбор формата страницы учитывает их габариты

## Capabilities

### New Capabilities

- `dimension-tool`: интерактивная простановка размеров — размещение тремя кликами с привязкой к стенам, следование за стенами при их правке, перетаскивание размерной линии, удаление ластиком, отрисовка в стиле чертежа, undo/redo

### Modified Capabilities

- `wall-dimensions`: удалено требование автоматического размера каждой стены и размера превью-сегмента; требование единиц измерения переформулировано под числа ручных размеров
- `drawing-storage`: формат документа — версия 3 (id стен, список размеров чертежа), миграция версий 1 и 2
- `drawing-history`: снимок истории включает размеры вместе со стенами; операции с размерами отменяемы; истории старого формата сбрасываются
- `wall-deletion`: каскадное удаление размеров при удалении стены (Delete и ластик), ластик находит размеры, новое состояние инструмента «Размер»
- `wall-joints`: прямые углы (90° в пределах допуска) исключены из митры — стык примыканием прямоугольниками, все углы контуров прямые
- `pdf-export`: в PDF входят размеры; список доступных форматов учитывает габариты размеров

## Impact

- `src/types.ts` — `Wall.id`, сущность `Dimension`, `Drawing.dimensions`
- `src/storage.ts` — версия 3, валидация и миграции v1/v2
- `src/history.ts` — сценные снимки (стены + размеры), версия 2
- `src/main.ts` — инструмент «Размер», состояния, drag размерной линии, каскадное удаление, клонирование id
- `src/geometry.ts` — удаление `dimensionSide`/`axisCrossings`, новые хелперы точек и хит-теста размера
- `src/render.ts` — удаление авто-размеров и preview-размера, отрисовка размеров из модели
- `src/export/pdf.ts` — bbox с размерами, экспорт размеров
- Тесты: `geometry`, `storage`, `history` — минус `dimensionSide`, плюс миграции, хит-тесты, геометрия размеров
