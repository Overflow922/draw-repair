## Context

Размеры сейчас полностью выводимые: `render.ts` рисует размер для каждой стены через `dimensionSide()` (голосование по примыканиям + чётность пересечений оси в `geometry.ts`), модель данных размеров не знает. У стен нет идентичности — `Wall = { a, b, thicknessCm, type }`, ссылки на стены невозможны. История — снимки `Wall[]` (`drawing-history` v1), хранилище — v2. Поведенческие требования — в дельтах спек; здесь только технические решения.

## Goals / Non-Goals

**Goals:**
- Хранимая сущность «размер», привязанная к стенам и переживающая правку стен, undo/redo, перезагрузку и PDF-экспорт
- Полное удаление авто-логики (`dimensionSide`, `axisCrossings`, цикл отрисовки в `drawScene`, preview-размер)

**Non-Goals:**
- Размерные цепочки и угловые размеры (модель должна их допускать в будущем, но не реализует)
- Перетаскивание точек замера по стене (точки двигаются только вместе со стеной)
- Ассоциативность с габаритами стен (привязка — к оси, не к контуру)

## Decisions

### D1. Идентичность стен: `Wall.id`
`Wall` получает `id: string` (uuid), назначаемый при создании в `commitPoint` и при миграции хранилища. `cloneWalls` и валидация (`isWall`) учитывают `id`.

Альтернативы: ссылки по индексу — ломаются при любом удалении/undo; хеши геометрии — коллизии при совпадающих стенах и дорогого пересчёта.

### D2. Модель размера: ссылки на грани + скалярное смещение

```
interface EdgeRef    { wallId: string; edge: 0|1|2|3 }  // 0/1 — боковые грани слева/справа от оси a→b, 2/3 — торцы у a/b
interface DimPoint   { a: EdgeRef; b: EdgeRef }         // точка = пересечение линий двух граней
interface Dimension  { from: DimPoint; to: DimPoint; offset: number }   // смещение линии, см, со знаком
```

Третий клик вырождается в скаляр: размерная линия всегда параллельна отрезку замера, поэтому из неё существенна только перпендикулярная составляющая `d = dot(p3 − A, n)`. Хранить точку `line` избыточно и вредно: при повороте стены абсолютная точка «отваливалась» бы, скаляр — едет с чертежом. Хранение позиции точки замера вычисляемой (не абсолютной) делает размеры ассоциативными: правка любой участвующей стены автоматически двигает угол.

Эволюция модели 2026-09-06/07 по обратной связи: (1) `DimEnd {wallId, t}` — позиция вдоль оси; (2) пользователь: «должно привязываться к углам стены» → `t = 0|1` (`dimEndAt`); (3) финально: «Размеры должны примыкать к ближайшей точке пересечения линий на чертеже» → `DimPoint` как пересечение линий граней (`edgeLine`, `dimPointPoint`), привязка через `nearestEdgeIntersection`. `DimEnd`/`dimEndAt`/`vertexAt`/`dimEnds` удалены. Пересечение соседних боковых граней даёт внутренний угол чертежа, торца с боковой — угол у торца; число размера — расстояние между вычисленными точками.

Альтернатива — абсолютные точки `a`, `b`, `line` с эвристикой перепривязки: сложнее, хуже поведение, отвергнута.

### D3. Рендер: выводить всё из модели
`drawDimension` переписывается: `A`, `B` — из привязок, `n` — нормаль к `A→B`, `P1/P2 = A/B + n*offset`, выносные от `A`/`B` до `P + overshoot*n`, стрелки и текст — как сейчас (поворот текста нормализуется в читаемую полуплоскость). Метрики `dimArrowPx/dimOvershootPx/dimGapPx/dimTextGapPx` остаются экранными (PDF-набор — в мм). `dimensionSide`, `axisCrossings` и их тесты удаляются; `dimOffsetPx` больше не нужен.

### D4. История: сценные снимки
`HistoryEntry` для правок становится `{ kind: "walls", walls: Wall[]; dimensions: Dimension[] }`; `record`/`cloneWalls` → работа со «сценой» (обе живые ссылки в `main.ts` перезаписываются на undo/redo и при смене вкладки). Версия истории — 2; документ v1 (снимки без id и размеров) несовместим со сценой и сбрасывается в пустые истории при загрузке — восстановить соответствие id между старым снимком и живыми стенами невозможно, одноразовая потеря undo-стеков приемлема.

Альтернатива — отдельный стек для размеров: два стека рассинхронизируются с каскадами (стена+размеры одним шагом) — отвергнуто.

### D5. Хранилище: v3
`Drawing.dimensions: Dimension[]`; парсер принимает v1–v3, `d.version > 3` — readOnly-фолбэк как сейчас. Миграция v1/v2 общая: стенам выдаются id, чертежам — `dimensions: []`; первое сохранение пишет v3. `isDimension` валидирует ссылки: `EdgeRef` — wallId непустая строка, edge целое 0..3; `DimPoint` — обе ссылки валидны; offset — число. Парсинг снисходительный к размерам (обратная связь 2026-09-06: у существующих пользователей в localStorage оставались размеры старого формата, строгий валидатор отвергал весь документ вместе со стенами): элементы `dimensions`, не прошедшие `isDimension`, отбрасываются по одному, стены и валидные размеры сохраняются.

### D6. Инструмент: черновик из трёх шагов
`type Tool = "wall" | "dimension" | "eraser" | "none"`; черновик `dimDraft: { a?: DimPoint; b?: DimPoint }` + общий `cursor`. Шаги 1–2: `nearestEdgeIntersection` — ближайшее пересечение линий граней стен в радиусе снапа; клик мимо пересечений игнорируется. Шаг 3: свободный клик, `offset = dot(cursor − A, n)`. Превью рисуется в `drawScene` рядом с draft-стеной (полупрозрачно). Esc/dblclick — сброс черновика (Esc без черновика — выход в «none», как у ластика). Орто на шаге 3 не применяется.

### D7. Удаление и каскад
`deleteWall` (Delete и ластик) дополнительно вычищает `dimensions`, ссылающиеся на стену любой из четырёх граней точек замера (`from.a/from.b/to.a/to.b.wallId`) — один `record` на всё. Ластик: хит-тест и по стенам, и по размерам, удаляется ближайший. Хит-тест размера — расстояние от курсора до отрезка [P1,P2] (с допуском в экранных пикселях) либо до точки текста.

### D8. Перетаскивание линии
Новый drag-стейт рядом с `wallMove`/`endpointDrag`: захват линии/текста размера (в любом инструменте с выделением — см. ниже), на move `offset = dot(cursor − A, n)`, на up — один `recordSnapshot`. Захват: клик по размеру вне ластика подхватывает drag без выделения размеров (у размеров нет выделения и панели — единственная правка это drag).

### D9. PDF: габариты и экспорт
`wallsBBox` расширяется до габаритов «стены + размеры»: к текущему bbox добавляются `P1`, `P2` каждого размера и запас под текст. `availableFormats`, `fitsFormat`, `placeOnPage` сигнатурно не меняются — меняется источник bbox. `drawScene` уже рендерит размеры — PDF-экспорт получает их бесплатно; черновик в PDF не попадает (не передаётся).

### D10. Порядок реализации
Модель и версии (D1, D2, D4, D5) — до UI: сцена с размерами должна ездить по undo/redo до того, как появятся размеры. Затем рендер (D3), инструмент (D6), каскад/ластик (D7), drag (D8), PDF (D9).

## Risks / Trade-offs

- [Одноразовая потеря undo-стеков у существующих пользователей (D4)] → документируется; данные чертежей не теряются, миграция v2 сохраняет всё.
- [Ссылки на удалённую стену] → каскад при любом пути удаления (Delete, ластик, undo-несовместимых путей нет); инвариант «dim.wallId существует» проверяется при рендере защитно (размер с битой ссылкой не рисуется).
- [Число размера перестаёт соответствовать ожиданиям при правке стены] — это и есть смысл привязки; следование за стеной покрывается сценариями спеки `dimension-tool`.
- [Наложения размеров и авто-раскладка] — сознательно не решаются: пользователь раскладывает сам, это цена ручного инструмента.
- [Клик по размеру в режиме «Стена»] — размеры не перехватывают клики инструмента «Стена» (рисование поверх размерной линии остаётся возможным); drag линии работает в «Без инструмента» и «Стена».

### D11. Прямые углы без митры и без роста габарита
Правка 2026-09-06 по обратной связи («габариты стены под 45 градусов, должны быть прямые углы» + «длина стены не будет меняться» + «заплатка входит в новую стену»): в `endCap` митра применяется только когда стык одного типа, в диапазоне митры И не прямой (|cos φ| ≥ sin 5°). Для немитровых стыков (прямые углы, разные типы, острые): сквозная стена (нарисованная раньше) отображается **ровно как нарисована** — плоский торец на конце оси, габарит не меняется; примыкающая подрезается по ближней грани сквозной, а её **ось утапливается на полтолщины в тело сквозной вдоль оси сквозной** (дальняя грань примыкающей проходит через конец оси сквозной) — угол закрыт без выемок при неизменных габаритах обеих стен («заплатка входит в новую стену»; промежуточный вариант «сквозная дорастает до дальней грани новой» отвергнут: «длина стены не будет меняться»). Митра остаётся только для косых однотипных углов, где впритык оставил бы клиновидную щель. `sameTypeJoint` угло-зависим: на прямом угле false — торец сквозной внешняя граница и рисуется. Спека `wall-joints` скорректирована дельтой. Превью цепочки — WYSIWYG: сцена рисуется с `[...walls, preview]`, ось превью утапливается так же, предыдущая не меняется.

## Migration Plan

Загрузка: v1/v2 хранилища → рабочая сцена (id стен, пустые размеры), история v1 → пустые истории; первое изменение записывает v3/v2 соответственно. Откат — только через git; формат localStorage обратной совместимости не требует (приложение локальное).
