## MODIFIED Requirements

### Requirement: Удаление выделенной стены клавишей Delete
Нажатие Delete при выделенной стене ДОЛЖНО удалять её независимо от активного инструмента. Если фокус находится в поле ввода (поле длины, поле толщины, поле переименования вкладки), Delete НЕ ДОЛЖЕН удалять стены. Удаление стены ДОЛЖНО каскадно удалять размеры, привязанные к ней. После удаления выделение ДОЛЖНО сниматься, поле длины ДОЛЖНО очищаться. Удаление вместе с размерами ДОЛЖНО записываться в историю одним шагом: отмена (undo) ДОЛЖНА возвращать стену вместе с её размерами, повтор (redo) — снова их удалять.

#### Scenario: Delete удаляет выделенную стену
- **WHEN** стена выделена и пользователь нажал Delete
- **THEN** стена удаляется с холста, выделение снимается, поле длины очищается

#### Scenario: Каскадное удаление размеров
- **WHEN** стена с привязанными к ней размерами удалена клавишей Delete
- **THEN** все привязанные к ней размеры удалены вместе с ней

#### Scenario: Delete при фокусе в поле ввода не удаляет
- **WHEN** стена выделена, фокус находится в поле длины (или толщины, или переименования вкладки), и пользователь нажал Delete
- **THEN** стены и размеры не удаляются, редактируется текст поля

#### Scenario: Undo возвращает удалённую стену
- **WHEN** стена с размерами удалена клавишей Delete и пользователь отменил действие
- **THEN** стена возвращается в исходное положение с прежними толщиной и типом вместе со всеми своими размерами

#### Scenario: Redo повторяет удаление
- **WHEN** удаление отменено и пользователь повторил действие
- **THEN** стена и её размеры снова удалены

### Requirement: Инструмент «Ластик»
Тулбар ДОЛЖЕН содержать кнопку инструмента «Ластик» рядом с кнопками «Стена» и «Размер». Активация ластика ДОЛЖНА прерывать рисуемую цепочку и незавершённое размещение размера, снимать выделение и закрывать панель параметров стены. Клик по стене при активном ластике ДОЛЖЕН удалять её (с каскадным удалением её размеров); клик по размеру — удалять размер; клик по пустому месту НЕ ДОЛЖЕН ничего удалять, начинать цепочку или выделение. Ластик ДОЛЖЕН оставаться активным до явного переключения на другой инструмент. Стена или размер под курсором при активном ластике ДОЛЖНЫ подсвечиваться красным как удаляемые. Курсор канваса при активном ластике ДОЛЖЕН отличаться от обычного. Удаления ластиком ДОЛЖНЫ записываться в историю undo/redo.

#### Scenario: Клик ластиком удаляет стену
- **WHEN** ластик активен и пользователь кликнул по существующей стене
- **THEN** стена удалена с каскадным удалением её размеров, ластик остаётся активным

#### Scenario: Серия удалений без перетыкания
- **WHEN** ластик активен и пользователь кликает по нескольким стенам и размерам подряд
- **THEN** каждый кликнутый объект удалён, инструмент не деактивируется

#### Scenario: Подсветка стены под курсором
- **WHEN** ластик активен и курсор находится над стеной
- **THEN** стена подсвечивается красным; после ухода курсора подсветка исчезает

#### Scenario: Подсветка размера под курсором
- **WHEN** ластик активен и курсор находится над размером
- **THEN** размер подсвечивается красным; после ухода курсора подсветка исчезает

#### Scenario: Активация ластика зачищает состояние
- **WHEN** рисуется цепочка и/или размещается размер и/или стена выделена, и пользователь активировал ластик
- **THEN** цепочка и размещение размера прерваны, выделение снято, панель параметров стены закрыта

#### Scenario: Клик по пустому месту ластиком
- **WHEN** ластик активен и пользователь кликнул по пустому месту холста
- **THEN** ничего не происходит: цепочка не начинается, выделение не появляется

#### Scenario: Escape деактивирует ластик
- **WHEN** ластик активен и пользователь нажал Esc
- **THEN** ластик деактивируется, инструмент «Стена» НЕ включается автоматически; подсветка и курсор ластика исчезают

#### Scenario: Undo возвращает стену, удалённую ластиком
- **WHEN** стена с размерами удалена ластиком и пользователь отменил действие
- **THEN** стена возвращается в исходное положение вместе со своими размерами

### Requirement: Состояния инструментов
Приложение ДОЛЖНО различать четыре состояния инструмента: «Стена» (стартовое), «Размер», «Ластик» и «Без инструмента». Активная кнопка инструмента ДОЛЖНА отображаться визуально. Клик по пустому месту ДОЛЖЕН начинать цепочку только в состоянии «Стена»; размещение размера ДОЛЖНО выполняться только в состоянии «Размер». Выделение, перетаскивание концов и перемещение стен ДОЛЖНЫ работать в состояниях «Стена» и «Без инструмента» и НЕ ДОЛЖНЫ — в состояниях «Ластик» и «Размер». Кнопки инструментов ДОЛЖНЫ переключать состояние напрямую из любого состояния. Из «Ластика» и «Размера» Escape ДОЛЖЕН переводить в «Без инструмента», когда нет незавершённого размещения.

#### Scenario: Стартовое состояние
- **WHEN** приложение открыто или вкладка активирована
- **THEN** активен инструмент «Стена», клик по пустому месту начинает цепочку

#### Scenario: Выделение доступно без инструмента
- **WHEN** состояние «Без инструмента» и пользователь кликнул по стене
- **THEN** стена выделяется, маркеры доступны для перетаскивания

#### Scenario: Цепочка не начинается без инструмента «Стена»
- **WHEN** состояние «Без инструмента», «Ластик» или «Размер» и пользователь кликнул по пустому месту
- **THEN** цепочка не начинается

#### Scenario: Инструмент «Размер» активируется кнопкой
- **WHEN** из любого состояния пользователь нажал кнопку «Размер»
- **THEN** инструмент «Размер» активен и отображается как активный

#### Scenario: Переключение кнопками из любого состояния
- **WHEN** из состояния «Без инструмента» пользователь нажал кнопку «Стена», «Размер» или «Ластик»
- **THEN** соответствующий инструмент активируется и отображается как активный

#### Scenario: Escape из режима размера
- **WHEN** активен «Размер», размещение не начато, и пользователь нажал Esc
- **THEN** состояние становится «Без инструмента»
