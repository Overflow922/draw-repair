## MODIFIED Requirements

### Requirement: Инструменты плана
У каждого плана ДОЛЖЕН быть собственный набор инструментов и инструмент по умолчанию. Панель инструментов ДОЛЖНА показывать кнопки только инструментов активного плана. План «Обмерочный план»: «Стена», группа «Проёмы» («Проём», «Дверь»), «Окно», «Размер», «Линейка», «Ластик»; по умолчанию «Стена». План «Демонтаж»: «Демонтаж», «Линейка», «Ластик» (на плане «Демонтаж» ластик удаляет только пометки сноса, `demolition-plan` «Ластик на плане «Демонтаж»»); по умолчанию «Демонтаж». При переключении плана и чертежа активным становится инструмент плана по умолчанию. Горячие клавиши и жесты инструментов других планов (стрелки смены материала и сдвига стен, Delete стен, размеров и элементов, правка стен) НЕ ДОЛЖНЫ действовать на плане, где этих инструментов нет.

#### Scenario: Инструменты обмерочного плана
- **WHEN** активен «Обмерочный план»
- **THEN** на панели инструментов кнопки «Стена», «Проёмы», «Окно», «Размер», «Линейка», «Ластик»; активна «Стена»

#### Scenario: Инструменты плана «Демонтаж»
- **WHEN** активен план «Демонтаж»
- **THEN** на панели инструментов только кнопки «Демонтаж», «Линейка» и «Ластик»; активна «Демонтаж»

#### Scenario: Возврат на обмерочный план
- **WHEN** пользователь переключается с «Демонтаж» на «Обмерочный план»
- **THEN** на панели снова кнопки обмерочного плана, активна «Стена»

#### Scenario: Ластик не переходит между планами
- **WHEN** на плане «Демонтаж» активен «Ластик» и пользователь переключается на «Обмерочный план»
- **THEN** активна «Стена»; ластик плана «Демонтаж» не действует на стены обмерочного плана
