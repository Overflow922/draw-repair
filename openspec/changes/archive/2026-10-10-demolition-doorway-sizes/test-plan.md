# Test Plan

## Scope

Поведение `demolition-doorway-sizes` (дельты `demolition-plan`, `drawing-plans`, `drawing-history`; design D1–D5). Автоматизируются: геометрия цепочек по граням, правка чисел, раскладка размеров, отрисовка на записывающем холсте, габариты и ширины в PDF, инструмент «Демонтаж» и «Ластик» (подставной хост), набор инструментов плана. `main.ts` (кнопка, подсветка ластика) — вручную.

Новые файлы тестов:

- `src/demolition/mark-chains.test.ts` — `faceBounds`, `markChains` (SZ-01 … SZ-09);
- `src/demolition/mark-numbers-faces.test.ts` — `editNumber` по граням (SZ-20 … SZ-27);
- `src/demolition/demolition-tool-faces.test.ts` — числа по граням в инструменте: `numberAt`, `applyNumber`, невыделенные не правятся (SZ-30 … SZ-32, SZ-47);
- `src/demolition/demolition-eraser.test.ts` — ластик и клик по снесённой области (SZ-40 … SZ-48);
- `src/demolition/demolition-sizes-render.test.ts` — рисование цепочек, превью, ширины в PDF, подсветка ластика (SZ-50 … SZ-61);
- `src/plan-tools.test.ts` — SZ-70, SZ-71 (дополнение набора).

Переписываются через запросы на изменение тестов (утверждённые тесты, закреплявшие осевые три числа и подписи невыделенных): `mark-numbers.test.ts`, `mark-dimensions.test.ts`, `demolition-dimensions-render.test.ts`, `demolition-render.test.ts`, `demolition-tool.test.ts`, `plan-tools.test.ts`.

Оракулы:
- свободная стена `W` (0,0)–(500,0), толщина 20: грани `y = ±10`, стыки `0` и `500` на обеих гранях;
- комната «замкнутые углы»: `W` (0,0)–(500,0), `R` (500,0)–(500,400), `B` (500,400)–(0,400), `L` (0,400)–(0,0), все 20 см, помещение со стороны `y > 0`: у `W` грань `+1` (`y = 10`) — участок `[10, 490]`, грань `−1` (`y = −10`) — `[−10, 510]`;
- смещение размерной линии `1,2 · кегль / k` от грани.

## Boundary / Negative

- Грани без свободного участка (`faceRuns` пуст) и вырожденная стена (SZ-06).
- Пометка, пересекающая Т-стык: границы зажаты участком грани (SZ-07).
- Железобетонная стена и отсутствующая стена: пометка не действует — размеров нет (SZ-08).
- Обратная и вертикальная стена, диагональ: стороны `+1`/`−1` и направление текста (SZ-09, SZ-59).
- Ластик не удаляет стены подложки, не выделяет и не начинает жест (SZ-43).

## Mutation Targets

- границы грани по оси вместо стыков (SZ-01, SZ-02);
- торцевая часть не учитывается: расстояние у торца не 0 (SZ-03);
- выбор не того участка грани при нескольких (SZ-04, SZ-07);
- сторона грани перепутана в правке (`j0`/`j1`, знак) (SZ-20 … SZ-23);
- клик по снесённой области снимает пометку (SZ-40);
- ластик удаляет не ту пометку / без шага истории / снимает инструмент (SZ-42, SZ-46, SZ-48);
- подсветка не снимается при уходе курсора (SZ-44);
- невыделенная пометка рисует размеры на экране (SZ-55); PDF без ширины (SZ-56);
- подчёркивание у превью / нет у выделенной (SZ-53, SZ-54);
- набор инструментов плана без «Ластика» (SZ-70).
