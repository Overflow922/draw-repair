## Boundary Coverage

Покрыты: нижняя граница (плоскость торца, линия грани, +0.01), верхняя граница T включительно и +0.5 по каждой оси и в дальнем углу, T = 20 и 40, существующая стена толще, масштабы 0.25/0.5/1/2/4, повороты 30/60/90/135/180/270 и зеркала, обе стороны торца, обратное направление стены, вертикальная стена. Развёртка по сетке 0.5 см (CW-8) проверяет эквивалентность "угол <=> 0 < a <= 20 и 0 < b <= 20" на 71x71 точке. Граничный допуск SLICE у нижней границы в повёрнутых сценах не наблюдаем (см. таблицу мутаций, мутант 2 - эквивалентный на этих данных).

## Negative Cases

Закрытый торец, наложение на тело, стык L (наружный и внутренний), проём, вторая вершина, нулевая стена, курсор в полосе, курсор не за плоскостью торца, за окном при масштабе 0.25. Отдельного пробела нет, кроме F3 (слабый результат отката).

## Error Handling

Не применимо (чистая геометрия, исключений нет). CW-10 проверяет неизменность замороженных входов и детерминированность.

Моков нет. Связь с внутренностями отсутствует. Замечание: проверяется неперечислимое поле `target` - уже существующий контракт тестов.

## Findings

- F1 (блокирующее): нет теста выбора между угловым кандидатом и кандидатом другой стены (мутанты 28, 29 выживают на всём наборе из 256 тестов шести файлов).
- F2 (блокирующее): переписанный GS-17 потерял исходное намерение. Было: цель - свободный торец C, "не первая среди касаемых" (касаемые [B, C], выбран C). Стало: угол торца B, то есть первая касаемая стена; проверка "не первой среди касаемых" и "у грани B места нет" не сохранена, а план обещал, что покрытие не теряется. Реализация, возвращающая всегда первую касаемую стену для окна/вне окна, не ловится GS-17.
- F3 (замечание): CW-7c/d/e/f для отклонённого кандидата проверяют только `target != corner` и отсутствие наложения, не результат отката (по спеке: "прилипание определяется остальными правилами"). Мутант "не откатывается к грани" убит другими тестами, поэтому не блокирует.
- F4 (замечание, вне изменения): в корне репозитория неотслеживаемый файл `bash.exe.stackdump` (в снимке git status на начало сессии его не было). Валидатор его не создавал намеренно и не удалял; проверить и удалить вручную, не коммитить.
