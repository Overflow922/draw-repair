## Boundary Coverage

Нижняя граница (плоскость торца, линия грани, +0.01), верхняя граница T включительно и +0.5 по каждой оси и в дальнем углу, T = 20 и 40, существующая стена толще, масштабы 0.25/0.5/1/2/4, повороты 30/60/90/135/180/270 и зеркала, обе стороны торца, обратное направление, вертикальная стена. Развёртка CW-8 по сетке 0.5 см проверяет эквивалентность «угол <=> 0 < a <= 20 и 0 < b <= 20».

## Negative Cases

Закрытый торец, наложение на тело, стык L, проём, вторая вершина, нулевая стена, полоса, не за плоскостью торца, за окном при масштабе 0.25. Достаточно.

## Implementation Independence

Только публичные `snapStartVertex`, `snapVertex`, `chainSegment`, `placementSquare`, `startRefOf`; ожидания (вершина, нормаль, квадрат, `source`, `target`) выведены из спецификации и вычислены вручную. Моков нет. Проверка неперечислимых `target`/`normal` - существующий контракт тестов.

## Assertion Strength

Сильные: точные координаты вершины, нормали и вершин квадрата, `source`, `target`; CW-12 фиксирует точные результаты обоих исходов (угол и грань (35,28) с нормалью (-1,0)). Развёртка CW-8 сильная. Проверка CW-7e только `not corner` - допустима для «не цель». Замечание: GS-17b проходит через `snapVertex` (базовая привязка уже даёт стену), а не через ветку касаемых стен `snapStartVertex`; это не снижает защиту (см. ниже мутант «только первая касаемая стена»).

## Review of rewritten existing tests
