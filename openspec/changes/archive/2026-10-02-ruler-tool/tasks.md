## 1. Расчёт замеров (новый модуль ruler.ts)

- [x] 1.1 Типы `RulerReading` (`kind: "wall"` | `kind: "space"`), `Span`, `RoomAngle` и функция `rulerReading(p, walls)`. Пустой чертёж даёт `{ kind: "space", horizontal: null, vertical: null, angles: [] }`. Вход не мутируется, кэша между вызовами нет. Зависимости: `types`, `wall-geometry`, `geometry`, `room-area` (design D1; спека «Линейка не меняет чертёж»; тесты SPAN-EMPTY-1, INV-PURE-1, INV-DET-1, WALL-EDIT-1)
- [x] 1.2 Замер стены. Кандидаты — невырожденные стены, у которых кусок `displayPolygons(wall, walls)` содержит курсор (`pointInPolygon`, граница входит). Выбор — наименьший `distanceToWall` (до отрезка оси), при равенстве меньший индекс. Без полосного допуска `hitWall`. Результат: `from = wall.a`, `to = wall.b`, длина оси (design D2; спека «Замер стены по оси»; тесты WALL-AXIS-*, WALL-OUT-1/2/3, WALL-EDGE-1, WALL-PICK-1/2/3, WALL-JOINT-1/2, WALL-ONLY-1, WALL-DEGEN-1)
- [x] 1.3 Пролёты. Лучи по ±x и ±y от курсора до первого пересечения с рёбрами всех кусков форм стен (`t > 0`, минимальный `t`; коллинеарные с лучом рёбра пропускаются, касание вершины считается). Пролёт направления есть, только если упёрлись оба луча. `from` — левая или верхняя точка, `lengthCm = |to − from|` (design D3; спека «Замер пролёта между гранями»; тесты SPAN-*, INV-SPAN-1, INV-ORDER-1, INV-SHIFT-1)
- [x] 1.4 Выбор помещения: из `findRooms(walls)` берётся то, у которого курсор внутри `outline` и вне всех `holes`. Если такого нет, углов нет (design D4; спека «Внутренние углы помещения»; тесты ANG-NEST-1/2, ANG-OUT-1, SPAN-U-1)
- [x] 1.5 Чистка контура до неподвижной точки. Рёбра короче `MIN_EDGE_CM = 0.1` стягиваются в пересечение прямых соседних рёбер, а при почти параллельных — в середину. Вершины с углом < `SPIKE_DEG = 1°` или > 359° удаляются. Меньше трёх вершин — углов нет. Контур, заливка и площадь помещения не меняются (design D4, шаг 1; тесты ANG-BEND-*, ANG-SHORT-1/2, ANG-ACUTE-1/2, ANG-F-1, ANG-T-1)
- [x] 1.6 Углы:
  - `θ = 180° − s·τ` по ориентации контура `s`, затем округление до 0,01°;
  - отбор `|θ − 180°| < 0.5` по округлённому значению;
  - `startDir` — единичный вектор к `next`, `|sweepDeg| = θ`, знак выбирается так, чтобы сектор шёл через помещение к `prev`;
  - острова не обходятся.

  (design D4, шаги 2–5; спека «Внутренние углы помещения»; тесты ANG-RECT-1, ANG-L-1, ANG-ARC-1, ANG-Q-1, ANG-ROT-1, ANG-SEAM-1, ANG-BEND-1..4, ANG-ISLAND-1, INV-SUM-1, RND-Q-E2E-1, RND-E2E-2/3/5)

## 2. Отрисовка (render.ts)

- [x] 2.1 Опция `ruler?: RulerReading | null` в `RenderOptions`. В `drawScene` рисовать её последней перед рамкой выделения — после заливки, стен, подписей площади и размеров. `null` и пустой замер ничего не рисуют (design D5; спека «Отображение замеров линейки»; тесты RND-ORDER-1, RND-NONE-1, RND-SPAN-2)
- [x] 2.2 Замер стены и пролёты — через `drawDimensionGeom(dimGeometry(from, to, 0), formatLength(lengthCm, unit), RULER_COLOR, view, m)`, где `RULER_COLOR` — цвет угла построения (`ANGLE_COLOR`) (design D5; спеки «Замер стены по оси», «Замер пролёта», «Отображение»; тесты RND-WALL-1/2, RND-UNIT-1/2, RND-SPAN-1, RND-COLOR-1, RND-WALL-ZOOM-1, RND-E2E-4)
- [x] 2.3 Выделить из `drawAngle` общую часть «дуга фиксированного экранного радиуса + подпись `Math.round(deg)°` на белой подложке на биссектрисе» с явным началом и знаковым сектором. `drawAngle` сохраняет кратчайший сектор и луч отсчёта. Углы линейки рисуются по `startDir`/`sweepDeg` без луча (design D5; тесты RND-ARC-1, RND-NORAY-1, RND-ANG-ROUND-1, RND-ZOOM-1, RND-REG-1)
