# Test Plan

## Scope

Поведение delta-спеков `demolition-plan` («Размерные линии пометок», «Выделение пометки и правка чисел на месте», «Отображение плана «Демонтаж»») и `pdf-export` («Размеры пометок на странице демонтажа»):

- цепочка размеров (расстояние до стыка `a`, ширина, расстояние до стыка `b`) на обеих гранях у **каждой** действующей пометки — на холсте и в PDF;
- нулевой размер опущен целиком (ни числа «0», ни линий);
- подчёркивание — только у чисел выделенной пометки, в PDF и у превью его нет;
- независимые цепочки нескольких пометок одной стены;
- габариты страницы PDF по всей цепочке обеих граней;
- участок, прижатый к стыку, правится другим числом (`editNumber`).

Уровни: unit (`markDimensions`, `markDimensionExtent`, `editNumber`), render (`drawDemolitionScene` на фейковом контексте, как в существующих `demolition-*-render.test.ts`), PDF (`export/pdf.ts`, как в `demolition-dimensions-pdf.test.ts`). Префикс идентификаторов — `CD-`.

Контракт API — `design.md`, решение 5.

| Case | Expected behavior |
|---|---|
| Пометка на железобетонной / отсутствующей стене | размеров нет ни на экране, ни в PDF, габариты не меняются (CD-21) |
| Вырожденная стена (нет граней) | пустой список размеров и точек габаритов (CD-22) |
| Нет пометок | ни выносных, ни размерных линий, ни красного (CD-23) |
| Невыделенная пометка | подчёркивания нет, но размеры есть (CD-03, CD-09) |
| Превью на несуществующую стену | ничего не рисует (CD-08) |

## Invariants

- Для каждой грани число размеров = 3 минус число нулевых величин; ни один размер не имеет нулевой длины и `geom == null` (CD-05..07).
- Значения цепочки неотрицательны и `gapA + width + gapB` = длина участка грани между стыками (CD-04).
- Выделение пометки не меняет набор красных линий и чисел, а только добавляет подчёркивание (CD-03).
- Цепочка пометки не зависит от других пометок стены (CD-10).
- Экранная и PDF-цепочки совпадают по составу размеров для одной пометки (CD-11).
- Габариты PDF содержат все концы выносных линий и углы чисел цепочки обеих граней (CD-15).
- Вход (`walls`, пометки) не мутируется (CD-25).
- Правка чисел (`editNumber`) и слияние участков ведут себя как раньше (регрессия, существующие `mark-numbers*.test.ts`).

## Integration Cases

- PDF: полный путь экспорта чертежа с пометкой даёт на странице демонтажа красные выносные линии, стрелки и числа цепочки на обеих гранях; на странице обмерочного плана красных линий нет (CD-11).
- PDF: список доступных форматов учитывает цепочку обеих граней (CD-16).
- PDF: размещение на листе — все красные штрихи в области чертежа при выступающей цепочке (CD-26).
- Холст: пометка выделена → цепочка та же + подчёркивание; снято выделение → подчёркивание исчезает, размеры остаются (CD-09).

## Mutation Targets

- Фильтр нулевых размеров: `<= ZERO` ↔ `< ZERO`, снят совсем (число «0» вернулось), оставлен фильтр только на грани `+1`.
- Рендер рисует цепочку только у `selectedId` (прежнее поведение) — должны упасть CD-03/CD-09.
- В PDF остаётся режим «только ширина на грани `+1`» — должны упасть CD-11/CD-14.
- Подчёркивание у всех пометок или у превью (`underline` всегда `true`/`false`).
- Грань `−1` пропущена в цепочке (экран или PDF).
- Габариты считаются по одной ширине / по одной грани — упадут CD-15/CD-16.
- Расстояния до соседней пометки вместо стыков стены — упадёт CD-10.
- Перепутаны `gapA`/`gapB` или знак смещения линии на грани `−1`.
- Нулевая ширина (`W = 0` при разрыве) не опускается.
- Опущен нулевой размер, но остаётся его выносная линия или стрелки.

## Out of Scope

- Расчёт стыков, `A/W/B` и слияние участков (покрыто существующими `mark-chains`, `mark-sections`, `mark-numbers*` тестами; меняются только отображение нулей).
- Тексты и числа на обмерочном плане, размеры проёмов.
- Визуальные оттенки цветов тем (кроме использования цвета сноса).
- Пиксельное сравнение с эталоном.

## Existing tests contradicting the new spec

- `src/demolition/mark-dimensions.test.ts`: режим `width` (DC-01..03, NU-13, DC-07 по ширине), нулевые размеры (DC-03, DC-08, NU-11).
- `src/demolition/demolition-sizes-render.test.ts`: SZ-52 (число «0» и подчёркивание нуля), SZ-53 (девять штрихов), SZ-55/56/57 (невыделенная без размеров; режим `widths`).
- `src/demolition/demolition-dimensions-render.test.ts`: DC-10 (`widths`), DC-14.
- `src/export/demolition-dimensions-pdf.test.ts`: DC-20, DC-21, DC-22, DC-24, DC-25 (ширина вместо цепочки).
- `src/export/demolition-*-pdf.test.ts`, `src/demolition/demolition-tool*.test.ts` — проверить на нулевые числа и `widths`.
