# Test Plan

## Scope

Поведение дельта-спек `length-input` («Длина стены от кромки до кромки», «Живое значение длины», «Фиксация вершины по введённой длине») и `ruler-tool` («Замер стены по оси»). Проверяется через чистые функции:

- `endOverhangCm(wall, end, walls)`, `edgeLengthCm(wall, walls)`, `startOverhangCm(ref, start, dir)`, `previewEdgeLengthCm(ref, start, end)` — новый модуль `src/wall-length.ts` (design D1–D3);
- `chainSegment` (`src/wall-chain.ts`) с `typedLengthCm` — конец сегмента при введённой длине (D2);
- `mergeContinuation` (`src/wall-merge.ts`) — удлинение на введённую длину (D4);
- `rulerReading` (`src/ruler.ts`) — замер стены (D6);
- протяжённость отображаемого тела (`displayPolygons`, независимая проверка в `src/wall-length.test-utils.ts`) — равна введённому числу, то есть совпадает с размером между углами тела;
- `axisLengthForEdgeCm(wall, walls, edgeCm)` (`src/wall-length.ts`) вместе с `resizeWallBounded` (`src/wall-edit.ts`) — ввод длины выделенной стены с поправкой на выступ (D5).

Не покрыто автотестами: тонкая проводка в `src/main.ts` (вызов `previewEdgeLengthCm`, `edgeLengthCm`, `axisLengthForEdgeCm`) — вручную в браузере.

Эталонная сцена S1 (выводится из спеки, не из кода): ранняя стена E, `a=(0,0)`, `b=(500,0)`, толщина 20, кирпич; новая стена N, `a=(510,0)`, `b=(900,0)`, толщина 20, газобетон (чтобы не сливалась); опора начала `ref = { kind: "cap", normal: (1,0), anchor: (500,0) }`, начало `(510,0)`. Тело N: x ∈ [500, 900]; выступ начала 10; длина N от кромки до кромки 400, ось 390.

| Case | Input | Expected |

| Введено ровно выступ | S1-опора, typed = 10 (выступ 10) | ввод не применяется |
| Введено чуть больше выступа | typed = 10.01 | конец на 0.01 от начала по оси |
| Коллинеарность на границе допуска | направление сегмента 0.4° от оси E | выступ начала = 10 (проекция), коллинеарно |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Введено ноль, отрицательное или нечисловое | не применяется (поведение прежнее) |
| Введено значение ≤ выступа начала | не применяется, сегмент прежний |
| Сегмент поперёк оси от торца | выступ 0, длина по оси — введённая |
| Опора `face` (стена у грани) | выступ 0 |
| Начало без опоры | выступ 0 |
| Три и более конца в пороге стыка | выступ 0 (плоские торцы) |
| Почти коллинеарный стык (0.5°–15°) | выступ 0 |
| Ранняя стена коллинеарного стыка | выступ 0, длина по оси |
| Стены разных материалов vs одного | выступ одинаков; слияние только у одного материала и толщины |

## Invariants

- Для любой стены `edgeLengthCm ≥ dist(a, b)`; равенство — когда у обоих концов выступ 0.
- Видимая длина тела стены S1 вдоль оси (по `displayPolygons`) равна `edgeLengthCm`; размер между углами тела равен `edgeLengthCm`.
- Введённая длина L при коллинеарном продолжении даёт `edgeLengthCm` новой стены ровно L (круговое свойство ввода и длины).
- Слияние: длина E после слияния = длина E до + введённое L.
- Положение вершины начала и форма тела не меняются от изменения: геометрия тел стен S1 идентична сохранённой (регрессия).
- Поведение угловых и T-стыков: длины, линейка, ввод — прежние.

## Integration Cases

- S1 целиком: `chainSegment` с введённой длиной → стена → протяжённость тела, `rulerReading`, `edgeLengthCm` дают одно число.
- Слияние: те же шаги с материалом E → `mergeContinuation`, E удлинена на L.
- Толщина 195 мм: сцена пользователя из обращения (стена 19.5, продолжение 151.2 от кромки) — длина 1512 мм и по телу, и по линейке.

## Mutation Targets

- Знак выступа в `endOverhangCm` (плюс/минус), использование полутолщины новой стены вместо расстояния до конца ранней.
- Условие коллинеарности (`>=` → `>`, 0.4°/0.6°), `ref.kind === "cap"`.
- Вычитание выступа в `chainSegment` (не вычитается / вычитается дважды).
- `typed <= overhang` (`<` вместо `<=`).
- Учёт выступа обоих концов в `edgeLengthCm` (один конец).
- Выступ у ранней стены (не должен считаться).
- Смещение концов линейки на плоскость торца (не смещаются / не в ту сторону).
- Применение выступа к углам и T-примыканиям.

- Ввод длины выделенной стены, когда подвижный конец — конец с выступом (в `TODO.md`).
