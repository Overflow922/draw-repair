# Test Suite

Файлы: `src/geometry-ortho-snap.test.ts` (OS-*), `src/ortho-stretch.test.ts` (ST-*). Оба новые; одобренные тесты не изменены.
Запуск: `npx vitest run src/geometry-ortho-snap.test.ts src/ortho-stretch.test.ts`.

Начальный прогон (до реализации):
- `geometry-ortho-snap.test.ts`: 12 failed / 2 passed (OS-6, OS-7 — регрессия прежнего поведения);
- `ortho-stretch.test.ts`: suite не загружается — модуля `src/ortho-stretch.ts` ещё нет (`Cannot find module './ortho-stretch'`). API модуля задан design D2. По той же причине `tsc --noEmit` сообщает TS2307 в этом файле до реализации.

## Coverage

### Happy paths

- ST-1, ST-2, ST-3, ST-7, ST-12, ST-16, ST-17, ST-18, OS-1…OS-5, OS-9, OS-11.

### Boundary cases

- OS-6b (14.5°/16°), OS-11 (продолжение линии стены), ST-11 (0.3°/1°), ST-0 (нулевой вектор), ST-15 (конец в 30 см — вне допуска), ST-17 (концы на диагонали угла — в допуске).

### Negative cases

- OS-4 (стена вне оси игнорируется), ST-8 / ST-9 / ST-13 / ST-19 (не увлекаются), ST-15 (несвязанные), OS-6 / OS-7 (прежнее поведение без орто).

### Invariants

- INV-AXIS (OS-INV), INV-DIR и INV-ONCE (все ST через `run`), INV-PURE (ST-14).

### Integration cases

- Проводка `main.ts` (D3 — применение от снимка, D4) проверяется в браузере в задаче реализации (E2E-1…E2E-9 test-plan): в проекте нет DOM-окружения для `main.ts`.
- Без орто — существующие одобренные тесты `moveWalls`, `moveEndpoint` и `snap` (`geometry.test.ts`, `geometry-face-joints.test.ts`). Конфликтов с ними нет: тест «привязка к стенам имеет приоритет над орто» использует курсор под 47° к оси, где орто не срабатывает.

## Unexpected Passes

- Нет (OS-6 и OS-7 — намеренные регрессионные).
