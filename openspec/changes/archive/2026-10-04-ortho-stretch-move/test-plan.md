# Test Plan

## Scope

Поведение правок положения стен при включённом орто (`wall-selection`: «Орто без боковой составляющей», «Орто-растяжение связанных стен» и изменённые требования; `multi-selection`; `wall-drawing` «Переключатель орто-привязки»).

Тестируются наблюдаемые результаты публичных функций:
- `snap(cursor, walls, gridStepCm, radiusCm, orthoFrom?)` (`src/geometry.ts`) — точка привязки (D1);
- `planOrthoStretch(walls, seed, v)` и `applyStretch(plan, v)` (`src/ortho-stretch.ts`, API из design D2) — итоговые координаты стен после правки.

Эталоны — координаты, выведенные из сценариев спецификации. Без орто поведение `moveWalls` / `moveEndpoint` / `snap` фиксируют существующие одобренные тесты (регрессия).

Сцены (толщина 20, кирпич):
- **RV** — комната с общими вершинами осей: top `(0,0)-(300,0)`, right `(300,0)-(300,200)`, bottom `(300,200)-(0,200)`, left `(0,200)-(0,0)`.
- **RF** — комната, нарисованная прилипанием (угловые стыки на грани): top `(0,0)-(300,0)`, right `(290,10)-(290,300)`, bottom `(280,290)-(0,290)`, left `(10,280)-(10,10)`.
- **TP** — top `(0,0)-(300,0)`, перегородка P `(150,0)-(150,200)` (T к оси top), основание C `(0,200)-(300,200)` (P.b на оси C).

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Граница срабатывания орто 15° | `orthoFrom (0,3)`, курсор под 14.5° и под 16° к горизонтали | 14.5° — точка на `y = 3`; 16° — привязка по обеим координатам |
| Пересечение с продолжением линии стены | ось `y = 15`, линия стены `(90,-100)–(95,-50)` за её концом, концы вне радиуса (OS-11) | точка `(101.5, 15)` |
| Допуск параллельности 0.5° | сосед повёрнут на 0.3° и на 1° от вертикали, `v` вертикален | 0.3° — растягивается (дальний конец на месте); 1° — смещается целиком |
| Стена связана с двумя сдвигаемыми | нижняя стена RV при сдвиге top на +30 по x | сдвиг ровно на +30, не на +60 |
| Стена, сдвинутая через оба конца, передаёт правило | RV + перегородка, примкнутая к оси нижней (ST-18) | перегородка смещена целиком на +30 |
| Нулевой вектор | `v = (0, 0)` | ни одна координата не изменилась |
| Граница стыка — допуск углового стыка | конец соседа на расстоянии диагонали угла от конца сдвигаемой (RF) | связан (следует) |
| Конец соседа дальше допуска | конец соседа в 30 см от конца сдвигаемой, не на её оси/грани | не связан, не смещается |

## Negative Cases

| Case | Expected behavior |

| Перегородка-ножка T от сдвинутой целиком стены к основанию (ST-8) | основание не увлекается перегородкой |

| Несвязанная стена рядом (ST-15) | не смещается |
| Без орто (`orthoFrom` не задан) | `snap` — прежнее поведение (существующие тесты) |

## Invariants

- INV-DIR: при орто каждая стена сцены после правки сохраняет направление: угол оси до и после совпадает (до 1e-9) — для всех сцен ST.
- INV-ONCE: каждый конец смещается либо на `v`, либо на 0 — никогда на кратное `v`.
- INV-PURE: `planOrthoStretch` не мутирует стены (замороженные входы); мутирует только `applyStretch`.
- INV-AXIS: при сработавшем орто точка `snap` лежит на оси через `orthoFrom` (координата поперёк оси равна координате `orthoFrom` точно) — для всех кейсов OS.
- INV-CLOSED: в сценах RV и RF после правки каждая пара состыкованных концов сохраняет взаимное смещение (стыки замкнуты).

## Integration Cases

Проводка в `src/main.ts` (D3 — применение от снимка, D4 — выбор функции по переключателю) не покрыта модульными тестами: в проекте нет DOM-окружения для `main.ts`. Она проверяется в задаче реализации в браузере (Firefox DevTools, события указателя на холсте):
- E2E-1: орто включено, комната RF, перемещение верхней стены за средний маркер вправо — все стены сохраняют направление;
- E2E-2: орто выключено — та же правка поворачивает боковые стены (прежнее поведение);
- E2E-3: орто включено, Shift+стрелка вправо при выделенной верхней стене — соседи без поворота;
- E2E-4: одно «Отменить» возвращает всю сцену;
- E2E-5: протяжка сначала вбок, затем вверх в одном жесте даёт тот же итог, что прямой жест в конечную точку (D3).
- E2E-6: орто включено, перетаскивание угла комнаты (конец верхней стены) вправо — правая стена смещена целиком, нижняя удлинена, углы прямые.
- E2E-7: орто включено, ввод длины выделенной стены — сосед на конце b смещён целиком, без поворота.
- E2E-8: орто включено, групповое перетаскивание двух стен комнаты — остальные стены без поворота.
- E2E-9: орто включено, стены, увлекаемые правкой (D4), не притягивают привязку: при перемещении верхней стены вверх её опорный конец не прилипает к прежнему положению боковых стен.

## Mutation Targets

- Округление поперёк оси оставлено (старое `snap`) — OS-1, OS-2.
- Приоритет стены над орто (старое `snap`) — OS-4.
- Нет проекции конца стены на ось — OS-5.
- Порог 15° сдвинут — граничные кейсы 14.5°/16°.
- Параллельность по `>`/`>=` или без допуска — ST-11 (0.3° / 1°).
- Нет распространения (только непосредственные соседи) — ST-2, ST-3, ST-12.
- Двойной сдвиг стены, связанной с двумя сдвигаемыми — ST-2, ST-12 (INV-ONCE).
- Стена, сдвинутая через оба конца, не передаёт правило примкнутым — ST-18.
- Приваривание концов вместо сдвига на `v` — ST-6.
- T-распространение от ножки к основанию — ST-8, ST-9.
- T-распространение от растягиваемой (не сдвигаемой целиком) стены — ST-13 (стена seed-конца), ST-19 (растягиваемый сосед).
- Пересечение оси только с отрезком стены, не с её линией — OS-11.
- Связь по `jointTol` вместо `faceCornerTol` — ST-17 (RF: концы в диагонали угла).
- Растяжение параллельного соседа заменено сдвигом целиком — ST-1, ST-4, ST-7.

## Out of Scope

- Исправление уже сохранённых поворотов (non-goal).
- Рисование цепочки (не меняется).
- Ограничение нулевой длины при растяжении (non-goal design).
