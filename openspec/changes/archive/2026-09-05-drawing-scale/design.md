## Context

Мир хранится в см, PDF — в мм; размещение сейчас делает `fitToPage` (произвольный коэффициент «вписать»). Подписи длины уже являются аннотациями с фиксированным размером на бумаге (`PDF_METRICS`), их код не меняется. Терминология: в спеке `drawing-storage` «масштабом» назван экранный зум вида; чтобы не путать, в дельтах зум именуется «масштабом экрана», а новый параметр — «масштабом чертежа». Единицы и формат страницы сегодня — in-memory; масштаб чертежа, по решению, — персистентное свойство чертежа.

## Goals / Non-Goals

**Goals:**

- Точное соотношение печати 1:X вместо «вписать» при сохранении автоориентации и центрирования в полях.
- Динамическая доступность форматов страницы: в списке — только вмещающие чертёж при текущем масштабе.
- Хранение масштаба per-drawing с миграцией v1 → v2 без потери данных.

**Non-Goals:**

- Рамка листа / принт-превью на холсте (отдельное изменение).
- Штамп «Масштаб 1:X» на листе PDF.
- Влияние на зум, подписи длины, undo/redo (масштаб — метаданные уровня имени чертежа).
- Пересмотр шага штриховки и толщины линий: они остаются бумажно-фиксированными (оформление листа, не геометрия).

## Decisions

- **Коэффициент размещения.** `mmPerCm = 10 / X` (1:100 → 0.1 мм/см). Ориентация — по пропорциям bbox, как сейчас; формат вмещает, если `bbox × mmPerCm` укладывается в контентную область (лист минус 10 мм полей) в этой ориентации. `fitToPage` удаляется; `buildPdf` получает знаменатель вместо коэффициента, подключение `drawScene` через `zoom = mmPerCm / PX_PER_CM` сохраняется. Альтернатива «вписывать, но не мельче 1:X» отклонена: молчаливо нарушает обещание точного масштаба.
- **Модель.** `Drawing.scale: number` — знаменатель из `SCALE_DENOMINATORS = [50, 100, 200, 500]` в `types.ts`; дефолт 100. Хранение знаменателя (а не строки «1:100») — без парсинга и валидации строк.
- **Хранение.** `version: 2`; валидатор параметризуется версией: v1 читается и мигрирует (`scale: 100` для всех чертежей), v2 требует `scale` из ряда, иначе документ считается повреждённым (существующее требование). Будущие версии — как сейчас, read-only.
- **Доступность форматов.** Чистая функция `availableFormats(walls, scale): PageFormat[]` в `export/pdf.ts` (порядок A4→A0), вызывается на каждом `redraw` (дёшево: bbox + 5 сравнений). `<select>` перестраивается из этого списка; текущий выбор сохраняется, если остался доступным, иначе берётся наименьший доступный. Пустой список — select и кнопка экспорта неактивны.
- **Попап.** Неблокирующий плавающий остров поверх холста (стиль существующих панелей), текст «Невозможно экспортировать в A4, A3 — чертёж не влезает», закрытие кликом. Показывается только когда набор невмещающих форматов **расширяется** (при рисовании, смене масштаба, переключении вкладок не показывается «старый» попап заново); на первом рендере сессии попапа нет. Нативный `alert()` отклонён: блокирует цикл и выбивается из плавающего UI.
- **Селектор.** `<select id="pdf-scale">` в `#size-box` рядом с `#pdf-format`; смена — запись в активный чертёж (`dirty = true`, автосохранение), `activate()` синхронизирует селектор с вкладкой.

## Risks / Trade-offs

- [Откат релиза: старая сборка видит v2-документ как повреждённый и открывается с пустым хранилищем] → данные в localStorage не удаляются, но недоступны старой версии; зафиксировать в релизных заметках.
- [Попап может появляться repeatedly при рисовании на границе вместимости] → показ только при расширении набора невмещающих форматов; сужение и повтор того же набора — без popup.
- [«Наименьший вмещающий» может конфликтовать с ожиданием пользователя сохранить крупный лист] → правило простое и предсказуемое (первый вмещающий в порядке A4→A0); ручной выбор остаётся.
- [Подписи длины при 1:500 визуально сливаются] → известное ограничение, адресуется будущей переработкой размеров; в скоуп не входит.

## Migration Plan

Прозрачная миграция при чтении localStorage (`v1 → scale: 100`), записи идут в v2; откат — см. риски. Тесты: фикстура v1-документа, округление масштабов, инварианты доступности форматов.
