# Test Plan

## Scope

Поведение требования «Расстояния проёма сквозь коллинеарные стены» (`specs/doorway/spec.md` этого изменения) для проёма, двери и окна:
- расстояния грани (`doorwayDistances`), числа цепочки (`editableNumbers`) и отрисованные размеры;
- ввод расстояния, ширины и сдвиг (`setDistance`, `setWidth`, `slideDoorway`, `arrowSlide`, установка призрака) — ограничение опорной стеной;
- отсутствие регрессий для сцен без коллинеарных стен и для потребителей `faceRuns` (автоматические размеры, пометки демонтажа).

Тесты выводятся из спеки и геометрии сцен, не из реализации. Новые тесты — в `src/doorway/collinear-distance*.test.ts` и `collinear-distance.test-utils.ts`; существующие утверждённые тесты не меняются.

Сцены (толщина всех стен 20 см, единица — см; ось y вниз не важна, комната со стороны `y > 0`):
- **CK** — кирпичные L `(0,0)→(0,400)`, W0 `(0,0)→(250,0)`, W `(250,0)→(700,0)`; окно WN на W, привязка `a`, смещение 150, ширина 120 (откосы `x = 400` и `x = 520`).
- **CB** — как CK, но W бетонная.
- **CF** — свободные W0 `(0,0)→(250,0)` и W `(250,0)→(700,0)` без L (оба свободных конца).
- **CR** — замкнутая комната-прямоугольник `(0,0)–(700,0)–(700,400)–(0,400)`, верхняя стена из двух кирпичных стен `(0,0)→(250,0)` и `(250,0)→(700,0)`; сцена строится в трёх порядках массива стен.
- **CM** — цепочка: кирпичные W1 `(0,0)→(150,0)`, W2 `(150,0)→(300,0)`, бетонная W3 `(300,0)→(700,0)`, окно на W2.
- **CT** — W0 толщиной 10 см и W толщиной 20 см, кирпич, на одной оси.
- **NC** — раскладка спеки «Расстояния по граням у прямых углов» без продолжений.

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Окно вплотную к началу опорной стены | CK, ввод расстояния слева 240 | откос `x = 250`; слева 240 на грани `y = 10` и 260 на грани `y = −10`; инвариант не нарушен |
| Ввод ровно на границе опорной стены | CK, ввод слева 570 | окно вплотную к торцу W (`x = 580…700`), справа 0 |
| Ввод на 1 см больше границы | CK, ввод слева 571 | то же, что 570: число показывает 570 |
| Ввод на 1 см меньше границы начала W | CK, ввод слева 239 | окно у начала W: слева 240 |
| Окно вплотную к торцу, затем число справа 0 | CK, окно `x = 580…700` | справа «0» без размерной линии |
| Продолжение у конца `b` (зеркало) | CK зеркально по `x`, окно на W | расстояние справа до угла R, слева до свободного торца |
| Нулевое расстояние в начале опорной стены | CB, окно у `x = 250` | слева 0 (откос на плоскости стыка материалов) |
| Цепочка из двух продолжений одного материала | CM, окно на W2 | слева до свободного конца W1 (`x = 0`), справа до плоскости стыка с W3 (`x = 300`) |
| Ступень толщины одного материала | CT, окно на W (20 см) | слева расстояние до плоскости ступени `x = 250`, не сквозь W0 |
| Допуск коллинеарности | W0 повёрнута на 0.3° от оси W | как коллинеарная (сквозь одного материала); при 2.4° — как угловой стык, не сквозь |
| Стык с зазором коллинеарных стен | W0 доходит до `x = 245`, W начинается в `x = 250` (зазор по `wall-joints`, `collinearGapCm`) | граница по вершине стыка, не по телу |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Ввод отрицательного расстояния / не числа | не применяется, записи истории нет (как прежде) |
| Ввод расстояния при отсутствии места | `no-change`, запись не создаётся |
| Окно не выходит на соседнюю стену: ввод 100 слева в CK | `wallId` остаётся W, `offsetCm ≥ 0`, откос `x ≥ 250` |
| Сдвиг перетаскиванием далеко влево в CK | окно останавливается у начала W (`x = 250`), не заходит на W0 |
| Сдвиг стрелкой у начала W | остаётся на месте, запись не создаётся |
| Рост ширины окна у начала W | ширина ограничена концом W и соседним элементом, откос привязки неподвижен |
| Ограничение стеной не ломает установку | призрак в CK над W0 стоит на W0, над W — на W; не пересекает границу |
| Кольцо/дубль: две совпадающие стены одного материала с одной осью | расчёт завершается, расстояния определены (не бесконечный обход) |
| Т-примыкание на продолжении: перегородка к грани W0 | расстояние до перегородки, не сквозь неё |
| Перегородка в стыке коллинеарных стен (CD-26, CD-26b) | грань со стороны перегородки — до её грани (140), противоположная — сквозь (410 / 390); цепочка стык с тремя концами не обрывает |
| Совпадающая и обратная дублирующая стена (CD-16c) | расстояния равны расстояниям сцены без дубля |
| Продолжение у конца `b`, правка (CD-27…CD-31, сцена CKb) | ограничение верхней границей `len`: ввод расстояния, сдвиг, стрелка, ширина, призрак, инвариант не выходят за торец опорной стены |

## Invariants

- Откосы проёма всегда внутри опорной стены: `0 ≤ j1 < j2 ≤ len`; `offsetCm ≥ 0`, `widthCm > 0` после любой правки, перетаскивания и сдвига (проверка по набору входных значений, включая «широкие» ±1000).
- `wallId` элемента не меняется ни одной правкой.
- Инвариант размещения (`doorwayHolds`) выполняется после каждой применённой правки в CK, CB, CR, CM, CT.
- Расстояние на грани не меньше 0 и в сумме `left + width + right` равно длине участка грани между концами (проверка согласованности цепочки).
- Число, показанное после правки, равно фактическому расстоянию, а не введённому.
- Порядок стен в массиве не меняет расстояния (CR в трёх порядках).
- Расстояния в сценах без коллинеарных продолжений совпадают с эталонами существующих тестов (NC).
- Правка не меняет хранимые поля, кроме `anchor`, `offsetCm`, `widthCm`, высоты, подоконника (вид и данные вида сохраняются).

## Integration Cases

- **Отрисовка (CD-18):** записывающий контекст `fillText` для выделенного окна в CK содержит числа 390 и 410 (слева, грани `y = 10` и `y = −10`) и 180 справа; в CB — 150 слева.
- **Выбор числа (CD-3):** `editableNumbers` для окна в CK возвращает `distance` слева с `valueCm = 390`; `numberAt` по его центру находит это число.
- **Полный цикл (CD-19):** `createSelectionEditing` с хостом-заглушкой: выделить окно, клик по числу слева, ввод 600 → окно у торца, одна запись истории; повторная правка того же числа вводом 100 → окно у начала W, ещё одна запись; повторный ввод того же значения — записи нет. (Покрывает повторные правки подряд.)
- **Окно, дверь, проём (CD-17):** те же сцены и значения для `kind: "doorway"`, `"door"`, `"window"`.
- **Регрессия потребителей `faceRuns`:** существующие тесты `auto-dimensions*`, `demolition/*`, `wall-merge`, `dimension-anchor*` проходят без изменений (список для эталонной проверки: `doorway-faces`, `window-faces`, `doorway-edit`, `window-edit`, `door-edit`, `doorway-guard`, `window-guard`, `editable-numbers`, `press-pick`, `door-hover`, `wall-merge`, `auto-dimensions*`, `demolition/*`).
- **Хранилище:** чертёж с окном из CK сохраняется и загружается без изменения полей (формат не меняется).

## Mutation Targets

- Расширение отрезка пробных линий по цепочке убрано или ограничено `reach` (регресс исходного бага) → CD-1, CD-2, CD-4.
- Критерий материала инвертирован или убран (всегда сквозь / всегда обрыв) → CD-1 против CD-4 (должны давать разные ответы при одной геометрии).
- Критерий материала сравнивает толщину вместо `type` → CD-1 с одинаковым материалом и разной толщиной (CT), CD-4.
- Обрезка по `[0, len]` в `freeIntervals` убрана → CD-9, CD-13 (окно заходит на W0, `offsetCm < 0`).
- Обрезка по `[0, len]` заменена на `[−reach, len + reach]` → CD-9 (откос `x = 250 − 21`), граничный 239/240.
- Обрезка применена и к расстояниям (числа показывают расстояние до начала опорной стены, а не до угла) → CD-1, CD-3.
- `>=` вместо `>` / `<` вместо `<=` в проверке принадлежности стены цепочке (допуск коллинеарности 0.3° / 2.4°) → граничные тесты допуска.
- Цепочка обрывается на стыке с тремя концами (искусственная отсечка 171 вместо 410/390) → CD-26, CD-26b.
- Ограничение сверху `len` убрано (продолжение у конца `b`) → CD-27…CD-31.
- Отсутствие множества посещённых стен → тест кольца/дубля (зависание).
- Граница материала берётся по концу тела, а не по вершине стыка → тест стыка с зазором, CD-4.
- Только конец `a` обработан, конец `b` нет → зеркальный тест.
- Число показывает введённое значение, а не фактическое → CD-7, CD-9.
- Ввод применяется дважды / запись истории пропущена или дублирована → CD-19.
- `anchor` не обновляется после ввода → CD-7, CD-9 (проверка привязки, сторона привязки — конец, в чью сторону измеряется).

## Out of Scope

- Баг «после первой правки дальнейшие правки не дают результата»: не воспроизведён, отдельного теста нет; CD-19 проверяет повторные правки на уровне логики, но не фокус поля в настоящем браузере.
- Перепривязка проёма к соседней стене.
- Изменение результатов `auto-dimensions` и `demolition` (защищены существующими тестами, новые для них не пишутся).
- Визуальная проверка в браузере (ручная проверка после реализации).
- Тесты PDF: размеры проёма не попадают в PDF.
