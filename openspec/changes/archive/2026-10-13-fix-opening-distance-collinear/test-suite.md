# Test Suite

Файлы (все новые, существующие тесты и продакшн-код не менялись):
- `src/doorway/collinear-distance.test-utils.ts` — сцены CK, CB, CF, CR, CM, CT, CKb и эталонные хелперы;
- `src/doorway/collinear-distance.test.ts` — расстояния, числа цепочки, отрисовка (28 тестов);
- `src/doorway/collinear-distance-edit.test.ts` — ввод, ширина, сдвиг, призрак, повторные правки (33 теста).

Запуск: `npx vitest run src/doorway/collinear-distance` — 61 тест, обнаружены раннером все; до реализации 49 падают (по утверждению, а не по ошибке выполнения), 12 проходят.

Решение по стыку с тремя концами принято на уровне спеки и design (сценарии «Перегородка в стыке…»); добавлены CD-26, CD-26b, CD-27…CD-31, усилен CD-16c. Typecheck (`tsc --noEmit`) чистый.

## Coverage

### Happy paths

- CD-1, CD-2, CD-3, CD-4, CD-5, CD-15, CD-15b, CD-17, CD-18: расстояния сквозь стену того же материала и до начала стены другого материала на обоих концах, на обеих гранях, для всех трёх видов элементов.
- CD-7, CD-9, CD-19: ввод расстояния, ограничение опорной стеной и повторные правки подряд.

### Boundary cases

- CD-8 / CD-8b (569, 570, 571; 591), CD-10 (239, 240, 241), CD-10b (0), CD-10c (справа 0), CD-14 / CD-14b (ширина до торца), CD-13 / CD-13b / CD-13c (сдвиг у обоих концов), CD-25 / CD-25b (призрак у обоих концов), CD-6c / CD-6d (зазор 5 см в стыке), CD-6 (ступень толщины), CD-6b (2.4°).

### Negative cases

- CD-24 (отрицательное, не число), CD-23 (no-change без записи), CD-13b (стрелка у начала W), CD-9 (элемент не уходит на W0, `wallId` сохраняется), CD-16b (перегородка прерывает сквозной счёт), CD-6b (почти коллинеарный стык не считается сквозным), CD-4b (материал — критерий).

### Invariants

- CD-22 / CD-22b: для набора значений от −1000 до 5000 по обеим граням, обеим привязкам и трём видам: `wallId`, `0 ≤ j1`, `j2 ≤ len`, ширина, `doorwayHolds`.
- CD-2: порядок стен в массиве (три порядка) не меняет расстояния.
- CD-19b: число показывает фактическое расстояние.
- CD-17b: инвариант размещения для исходных сцен.

### Integration cases

- CD-3: `editableNumbers` + `numberAt` (клик по центру числа).
- CD-18 / CD-18b: `drawScene` с выделенным элементом, числа в записывающем контексте.
- CD-19 / CD-19b: `createSelectionEditing` с фейковым хостом и полем ввода: несколько правок подряд, записи истории, порядок `record` → `replace`.

## Unexpected Passes

Тесты, прошедшие до реализации, — защитные (регресс), не новое поведение:
- CD-6 (ступень толщины), CD-6b (2.4°): текущая геометрия пробных линий уже даёт нужный результат; тесты защищают от того, что новая цепочка продолжений начнёт считать такие стыки сквозными (мутации «критерий материала сравнивает толщину», «допуск коллинеарности расширен»).
- CD-11, CD-12, CD-17b, CD-24, CD-13c, CD-14, CD-25b: поведение без коллинеарных продолжений или в сторону, где опорная стена и так ограничивает (правый торец W, ширина от начала при привязке a); защищают от регрессии при расширении участков.
- CD-16c: определяет отсутствие зависания на дубле; до реализации обхода цепочки нет, после — защита от бесконечного цикла.

## Tests That Could Not Run

Запланированные случаи, не оформленные тестами, и причины:
- Допуск коллинеарности 0.3° (через сквозной счёт): результат на повёрнутых гранях зависит от «дробного шума» пробных линий `faceRuns` (`auto-dimensions.ts`), спецификация этого не определяет; оставлен только случай 2.4° (CD-6b).
- Хранилище (сохранение/загрузка чертежа с окном из CK): формат не меняется, отдельного теста нет; существующие `*-storage.test.ts` защищают формат.
- Проверка на реальном браузере (фокус поля ввода, события мыши): вне автотестов.
- Регресс потребителей `faceRuns` (`auto-dimensions*`, `demolition/*`, `wall-merge`, `dimension-anchor*`) и существующих `doorway-*`, `window-*`, `door-*`: выполняется полным набором `npx vitest run` на эталонной реализации при валидации (см. test-plan «Integration Cases»); новые тесты для них не пишутся.
