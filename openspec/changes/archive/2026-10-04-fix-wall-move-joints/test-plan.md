# Test Plan

## Scope

Поведение из дельта-спецификаций изменения:
- `wall-selection` «Перемещение стены за средний маркер» и `multi-selection` «Групповое перетаскивание стен» — следование примкнутых стен без орто (design D2) и порог углового стыка с запасом 1 см (D1);
- `wall-joints` «Почти коллинеарный стык» (D3), «Замыкание углового стыка на грани» (порог с запасом), исключения в «Допуск вершины стыка» и «Легаси-стыки совпадающих осей».

Наблюдаемые результаты публичных функций:
- `moveWalls(walls, group, v)` (`src/geometry.ts`) — координаты концов всех стен после перемещения;
- `faceCornerTol(a, b)` (`src/wall-geometry.ts`) — значение порога;
- `displayPolygons(wall, walls)` (`src/wall-geometry.ts`) — отображаемая форма; через неё же проверяются подсветка, попадание (`hitWall`) и шов (`contourSegments`);
- `planOrthoStretch` / `applyStretch` (`src/ortho-stretch.ts`) — только согласованность порога с орто.

Эталоны выводятся из сценариев спецификации и геометрии, не из кода. Толщина по умолчанию 20 см (`h = 10`), диагональ угла `10√2 ≈ 14.142`, новый порог `≈ 15.142`.

Сцены:
- **PT** — сквозная `g (0,0)-(200,0)`; ножка `V (100,10)-(100,150)` примкнута к нижней грани `g`; третья стена `H (90,160)-(0,160)` образует с `V.b` угловой стык на грани (расстояние `√(10²+10²)`).
- **PP** — перегородка между двумя стенами: верх `g (0,0)-(300,0)`, низ `b (0,200)-(300,200)`, перегородка `P (150,10)-(150,190)` (T к граням обеих).
- **PB** — оба конца связаны с перемещаемой: `g (0,0)-(200,0)`, стена `W (100,10)-(200,...)`, у которой `a` примкнут к грани `g`, а `b` образует стык с концом `g`.
- **USR** — фикстура: снимок чертежа пользователя «Чертёж 1» до перемещения (21 стена, JSON из обсуждения), перемещение верхней стены `b9433…` на `(10, 0)`.
- **NC(θ)** — две стены с общим концом `(0,0)`: ранняя `A (−200,0)-(0,0)`, поздняя `B (0,0)-(200·cos θ, 200·sin θ)`, отклонение от коллинеарного продолжения `θ`.

| Case | Input | Expected |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Второй конец ножки в 1 см за гранью третьей стены (не стык, не T) | конец свободен — ножка целиком |
| Второй конец ножки занят стеной, которая сама стоит в группе | ножка целиком, ровно один раз |

| Вырожденная стена (нулевая длина) рядом со вторым концом | не делает конец занятым |
| Почти коллинеарные стены без общего конца (концы дальше полутолщины) | правило не применяется |
| Почти антипараллельные стены (разворот) | правило не применяется |

## Invariants

- Без орто ни одна связь (стык или примыкание), существовавшая до перемещения, не рвётся (REG-2, TS-1…TS-3).
- Каждая стена смещается не более одного раза: ни одна координата не сдвинута на `2v` (TS-4, TS-9, TS-10).
- Длина, направление и толщина стен группы не меняются (существующие тесты).
- `faceCornerTol` симметрична по аргументам (FM-1).
- Отображаемая форма в почти коллинеарном стыке не выступает за вершину дальше `h` (NC-1, REG-3).
- Данные стен не изменяются построением формы (`displayPolygons` не мутирует вход).

## Integration Cases

- REG-1…REG-3 на реальной фикстуре пользователя (21 стена, дрейф, коллинеарное продолжение).
- `hitWall`, `contourSegments` и площади помещений используют ту же форму, что и `displayPolygons` (NC-7…NC-9).
- Орто-путь использует тот же порог (FM-9).
