## Purpose

Планы чертежа: чертёж ремонта делится на планы, каждый план содержит только объекты своего типа и выводится на отдельную страницу PDF; в чертеже в каждый момент активен один план.

## ADDED Requirements

### Requirement: Каталог планов
Приложение ДОЛЖНО иметь упорядоченный каталог планов; у каждого плана есть постоянный идентификатор и название. Каталог ДОЛЖЕН содержать план «Обмерочный план» (идентификатор `measure`). Порядок каталога определяет порядок планов в переключателе и порядок страниц в PDF. Каталог един для всех чертежей: все чертежи имеют один и тот же набор планов.

План «Обмерочный план» ДОЛЖЕН содержать стены, размеры и элементы стены (проёмы, окна, двери) чертежа — те самые объекты, которые чертёж содержал до введения планов; их редактирование, отображение и правила остаются прежними.

#### Scenario: Состав каталога
- **WHEN** приложение открыто
- **THEN** каталог планов содержит единственный план «Обмерочный план» с идентификатором `measure`

#### Scenario: Обмерочный план содержит объекты чертежа
- **WHEN** у чертежа, сохранённого до введения планов, есть стены, размеры и проёмы
- **THEN** в плане «Обмерочный план» отображаются и редактируются те же стены, размеры и проёмы

### Requirement: Активный план чертежа
У каждого чертежа ДОЛЖЕН быть активный план; по умолчанию активен «Обмерочный план». Холст и инструменты ДОЛЖНЫ отображать и изменять объекты активного плана. Активный план ДОЛЖЕН быть собственным для каждого чертежа и сохраняться вместе с чертежом (см. `drawing-storage`). Масштаб чертежа, вид (масштаб экрана и панорамирование) и формат страницы PDF общие для всех планов чертежа и НЕ ДОЛЖНЫ меняться при переключении плана.

#### Scenario: Активный план по умолчанию
- **WHEN** создан новый чертёж или открыт чертёж без сохранённого активного плана
- **THEN** активен «Обмерочный план»

#### Scenario: Вид не меняется при переключении
- **WHEN** пользователь изменил зум и панорамирование, затем переключил план
- **THEN** вид (масштаб экрана и сдвиг) и масштаб чертежа остались прежними

#### Scenario: Активный план у каждого чертежа свой
- **WHEN** в двух чертежах выбраны разные активные планы и пользователь переключает вкладки
- **THEN** после каждого переключения вкладки активен план, который был активен в этом чертеже

### Requirement: Переключатель планов
В верхней панели, вторым рядом под вкладками чертежей и кнопкой «+», ДОЛЖЕН находиться переключатель планов — ряд кнопок-сегментов по образцу переключателя единиц «м / см / мм»: по одной кнопке на каждый план каталога в порядке каталога, подписанной названием плана; кнопка активного плана ДОЛЖНА быть визуально выделена. Нажатие на кнопку неактивного плана ДОЛЖНО делать этот план активным; нажатие на кнопку активного плана НЕ ДОЛЖНО ничего менять. Переключатель ДОЛЖЕН отражать активный план активного чертежа и обновляться при переключении вкладок.

При переключении плана ДОЛЖНЫ быть сброшены выделение, незавершённая цепочка рисования стены, черновик размера и другие незавершённые жесты; выбранный инструмент ДОЛЖЕН быть сброшен так же, как при переключении вкладки.

#### Scenario: Переключатель показывает каталог
- **WHEN** приложение открыто
- **THEN** в верхней панели вторым рядом под вкладками и «+» расположен ряд сегментов с одной кнопкой «Обмерочный план», выделенной как активная

#### Scenario: Повторное нажатие на активный план
- **WHEN** пользователь нажимает кнопку уже активного плана
- **THEN** активный план, выделение и вид не изменились

#### Scenario: Переключение сбрасывает выделение и жесты
- **WHEN** выделена стена, начата цепочка рисования, и план переключается на другой план каталога
- **THEN** выделение снято, цепочка прервана, черновик размера отброшен

#### Scenario: Переключатель следует за вкладкой
- **WHEN** пользователь переключает вкладки чертежей с разными активными планами
- **THEN** выделенным сегментом всегда является активный план показываемого чертежа

### Requirement: Одна страница PDF на каждый план
Каждый план каталога ДОЛЖЕН выводиться на отдельную страницу PDF (см. `pdf-export`); порядок страниц ДОЛЖЕН совпадать с порядком каталога планов. Страница плана содержит только объекты этого плана.

#### Scenario: Число страниц равно числу планов
- **WHEN** экспортируется чертёж, каталог планов содержит N планов
- **THEN** PDF содержит ровно N страниц в порядке каталога
