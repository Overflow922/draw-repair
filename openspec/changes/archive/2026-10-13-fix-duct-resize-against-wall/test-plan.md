# Test Plan

## Scope

Ввод ширины и глубины воздуховода через `applyNumber` (`src/communications/edit.ts`): рост на свободное
место вдоль оси, распределение прироста, ограничение стенами и другими коммуникациями, уменьшение от
центра, неизменность диаметра стояка. Тесты работают на уровне `applyNumber` (чистая функция,
наблюдаемый результат: `communication` и `changed`) и одним интеграционным тестом через `communicationNumbers`
(числа после правки). Запись в историю и сохранение параметров новых коммуникаций этим change не
меняются; их существующие тесты (`history.test.ts`, `communications-group.test.ts`) входят в регрессию.

Сцены: «комната» из `communications.test-utils.ts` (внутренность x ∈ [10, 290], y ∈ [10, 390]).
Эталоны выводятся из спеки и геометрии сцены, а не из кода.

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Ровно по месту | ширина 413 при L = 0, R = 113 | 413 целиком, оба расстояния 0, `changed = true` |
| Чуть больше места | 413,01 при тех же | 413 (до касания) |
| Чуть меньше места | 412,99 при тех же | 412,99 целиком, правое расстояние 0,01 |
| Одна сторона на пределе | L = 0 при росте | левая грань не двигается, центр сдвигается на d / 2 |
| Остаток ровно равен пределу другой стороны | L = 5, R = 25, ширина +30 | обе стороны касаются, ширина по месту |
| Свободно ровно поровну | L = R = 15, ширина +30 | оба по 15, центр прежний |
| Обе стороны упёрты | L = 0, R = 0, любой рост | `changed = false`, воздуховод прежний |
| Рост по другой оси не меняет центр | рост ширины | `y` и глубина прежние |
| Уменьшение у стены | воздуховод касается стены слева, ширина меньше | центр прежний, левая грань отходит от стены |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Ввод 0, отрицательный, NaN, Infinity | не применяется, `changed = false` (CE-09b; добавить NaN и Infinity для ширины) |
| Ввод, равный текущему | `changed = false` |
| Обе стороны упёрты | `changed = false`, объект равен исходному |
| Рост упирается в стояк с одной стороны, в стену с другой | растёт до касания с обеими, наложения нет |
| Исходный объект | не мутируется |
| Диаметр стояка | по-прежнему от центра, при касании с одной стороны не растёт (CE-10b) |

## Invariants

- После любого применения тело воздуховода не накладывается на стены и другие коммуникации глубже, чем до
  применения (для сцен без исходного наложения: наложения нет).
- Результат при росте: `newWidth ≤ запрошенная`, `newWidth ≥ текущая`; при `newWidth < запрошенной` обе грани касаются препятствия.
- Сумма сдвигов граней равна приросту; ось, вдоль которой размер не менялся, не изменилась (`y`, глубина).
- Рост воздуховода симметричен там, где место есть с обеих сторон (центр прежний).
- Стояк не затронут: диаметр растёт только от центра.

## Integration Cases

- DG-09: после роста с упором в стену `communicationNumbers` показывает фактическую ширину и нулевые
  расстояния у касающихся сторон, число равно фактическому значению, а не запрошенному.

## Mutation Targets

- Деление прироста поровну: `d / 2` заменено на `d` или на 0 (DG-01, DG-03).
- Перенос остатка в свободную сторону убран (DG-02, DG-03): воздуховод остаётся 300.
- Предел одной стороны перепутан со сторонами (L ↔ R): воздуховод растёт в стену (DG-02 против зеркального DG-03; нужен зеркальный случай).
- Сдвиг центра считается как `high − low` без деления на 2, или с обратным знаком (DG-02: центр +56,5).
- Предел общий вместо раздельного: рост ограничен меньшей стороной (DG-02, DG-05).
- Рост ограничивается только стенами, другие коммуникации игнорируются (DG-06).
- Глубина ведётся по оси X или ширина по Y (DG-04 против DG-01).
- Условие `h <= предел` заменено на `h < предел` (граничный случай «свободно ровно поровну»).
- Уменьшение пошло по новой ветке и сдвигает центр (DG-07).
- Диаметр стояка идёт по новой ветке (CE-10b, CE-06).
- `changed` всегда `true` или всегда `false` (обе упёрты, CE-10).
- Допуск `violation + CLEAR_CM` убран: уже накладывающийся воздуховод растёт глубже.

Реализации, которые могут пройти поверхностно: «растить до максимума независимо от запрошенного размера» (ловят
DG-01, DG-03 и 412,99); «растить только от центра» (ловят DG-02, DG-03); «растить только в свободную
сторону без симметрии» (ловит DG-01).

## Out of Scope

- Перетаскивание и другие способы изменения размера, установка, перемещение коммуникаций.
- Запись в историю и параметры новых коммуникаций (регрессия существующими тестами).
- Рост стояка (диаметр) вне регрессии CE-05, CE-06, CE-10b.
- Отрисовка (`render.test.ts`, `pdf.test.ts`): не затронуты.
