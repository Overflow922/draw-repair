## Why

В каталоге плана «Мебель» двадцать семь видов, и все кнопки видов лежат в одной панели единственной группы «Мебель». Иконки уже не помещаются, а каждый новый вид (скилл `add-furniture-kind`) делает панель теснее. Виды естественно делятся по помещениям, и панель инструментов может нести по группе на помещение.

## What Changes

- Единственная кнопка группы «Мебель» на панели инструментов плана «Мебель» заменяется четырьмя кнопками групп видов: «Комната», «Спальня», «Кухня», «Санузел». Каждая со своей иконкой и своей вспомогательной панелью по образцу групп «Проёмы», «Коммуникации», «Освещение» (`ui.md`: связанные инструменты одного семейства = кнопка группы со своей иконкой, панель с кнопками инструментов и параметрами активного).
- Состав групп (порядок внутри группы — порядок каталога):
  - «Комната» (8): Стол, Стул, Диван, Письменный стол, Компьютерное кресло, Телевизор, Подвесная тумба, Шторы;
  - «Спальня» (4): Кровать, Прикроватный столик, Шкаф-купе, Шкаф двустворчатый;
  - «Кухня» (11): Кухонный шкаф, Холодильник двустворчатый, Винный шкаф, Варочная панель, Посудомойка, Раковина, Кухонная колонна, Духовой шкаф, Микроволновка, Стиральная машина, Сушильная машина;
  - «Санузел» (4): Унитаз, Тропический душ, Трап в стену, Умывальник.
- Запись каталога получает вид группы; порядок каталога (плашка пересечений, легенда PDF) не меняется.
- Каждая группа помнит свой текущий вид; клик по кнопке группы активирует его и открывает панель. Выделение предмета открывает панель группы его вида.
- Поля «Ширина», «Длина», «Угол» (у унитаза — свои поля) остаются в панели, как сейчас, теперь в панели каждой группы. Инструмент остаётся одним (`furniture`), значения для новых предметов запоминаются по видам, как раньше.
- Не меняются: хранение чертежа, история, пересечения, рисунки видов, PDF, размеры по умолчанию, поведение постановки, выделения и правки предметов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `furniture-plan`: новое требование «Группы видов мебели»; изменяются «Панель группы «Мебель» и инструмента «Стол»», «Инструменты плана «Мебель»» и «Каталог видов мебели» (поле группы в записи, панель группы вместо одной панели на все виды).
- `canvas-app`: изменяются «Группы инструментов» (порядок кнопок плана «Мебель») и «Вспомогательная панель инструмента» (панели групп видов мебели вместо панели группы «Мебель»).
- `drawing-plans`: изменяется «Инструменты плана» (набор инструментов плана «Мебель»).

## Impact

- `src/furniture/furniture-kinds.ts` (поле группы, список групп), `src/main.ts` (кнопки групп, состояние «текущий вид группы», панели), `index.html`, `src/style.css`; тесты `furniture-ui`, `plan-tools`, `furniture-kinds`.
- Скилл `add-furniture-kind`: новый шаг «выбрать группу вида».
- Данные чертежа, PDF и другие планы не затрагиваются.
