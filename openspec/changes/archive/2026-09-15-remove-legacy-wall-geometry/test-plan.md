# Test Plan

## Scope

Поведенчески нейтральная чистка: удаляются мертвые экспорты `geometry.ts` и пинящие их тестовые блоки `geometry.test.ts`. Спецификация не меняется (skip_specs), поэтому «тестируемое поведение» — это сохранение текущего поведения приложения и целостность тестового набора после удаления. Проверяются три свойства:

1. **Ничего живого не удалено** — оставшийся набор тестов зелёный, компиляция чистая.
2. **Мертвый код удалён полностью** — ни одного вхождения удалённых символов в `src/`.
3. **Покрытие не потеряно** — все сценарии удаляемых тест-блоков имеют эквиваленты в оставшихся тестах (сверка сделана на этапе планирования, см. Requirements Coverage).

«Тестами» здесь выступают метапроверки (vitest, tsc, grep), выполняемые как шаги задач, — новых вит-тестов изменение не добавляет (кроме случая из D4, который закрыт проверкой покрытия: перенос не требуется).

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Удаляемый символ оказался живым (прод-вызов найден на этапе реализации) | греп перед удалением каждого символа | символ исключается из списка удаления, факт фиксируется в отчёте задачи; CLN-GREP-1 не требует его удаления |
| Забытый импорт удалённого символа в `geometry.test.ts` | `tsc --noEmit` с `noUnusedLocals: true` | ошибка компиляции до запуска тестов |
| Частичное удаление (код удалён, тест остался / наоборот) | CLN-TSC-1 + CLN-VITEST-1 | оба ломаются; состояние не коммитится |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Реализация удаляет живую функцию (напр. `wallShape`, `lockedDirection`) | CLN-TSC-1 падает (main.ts:374 / внутренние вызовы в geometry.ts); изменение не принято |
| Реализация «заодно» правит оставшиеся тесты | вне скоупа; задачи не содержат таких шагов, ревью diff фиксирует |

## Invariants

- Тесты `wall-geometry.test.ts` не изменяются (D4 закрыт без переноса — CLN-COVER-1 верифицирован на этапе планирования).
- Живые символы и их тесты остаются нетронутыми (список в proposal, раздел «Не трогается»). Документированное исключение: кейс `lockedDirection` «направление от грани фиксируется точно перпендикулярно» переносится целиком, без правок ассертов, из удаляемого `describe("snapVertex")` в новый `describe("lockedDirection")` — единственный переход, разрешённый в живых тестах `geometry.test.ts` (CLN-COVER-4).
- Поведение приложения, данные, формат хранения — без изменений.

## Integration Cases

- Полный прогон `npm test` — интеграционная проверка того, что `geometry.ts` и `wall-geometry.ts` согласованы после удаления.

## Mutation Targets

Инструментария мутационного тестирования в проекте нет. Роли «выживших мутантов» здесь выполняют мутации удаления; их ловят:

- CLN-TSC-1 — мутант «удалён живой символ»;
- CLN-GREP-1 — мутант «символ удалён не полностью»;
- CLN-VITEST-1 — мутант «сломано живое поведение».

## Out of Scope

- Дедупликация hitWall-тестов между `geometry.test.ts:121` и `wall-geometry.test.ts` (тесты живого реэкспорта);
- деэкспорт `wallShape`, рефакторинг инлайна орто-логики в `snap()`;
- любые изменения `wall-geometry.ts`.
