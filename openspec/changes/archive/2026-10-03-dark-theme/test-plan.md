# Test Plan

## Scope

- Выбор схемы: распознавание сохранённого значения, системная схема по умолчанию, приоритет выбора, переключение, подсказка кнопки, чтение и запись выбора с ошибками хранилища (`src/theme.ts`, чистые функции).
- Палитры: светлая — буквально прежние цвета; тёмная — полнота и контраст.
- Отрисовка: все цвета сцены и превью материалов берутся из переданной палитры, без палитры — светлая.
- PDF: экспорт рисует светлой палитрой без сетки.
- Проводка в DOM (`main.ts`, CSS, кнопка, `matchMedia`) — ручная проверка MAN-*: в проекте нет DOM-окружения тестов.

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Значение с пробелом/регистром | `" dark"`, `"Dark"`, `"DARK"` | не схема |
| Не строка | `1`, `true`, `{}`, `["dark"]`, `null`, `undefined` | не схема |
| Пустая строка | `""` | не схема |
| Без сетки в тёмной палитре | `grid: false` | нет заливки помещений |
| Сетка на тёмном фоне | контраст | от 1.1 до 2 |
| Полупрозрачные цвета выделения | поверх тёмного фона | контраст ≥ 1.5 |

## Negative Cases

| Case | Expected behavior |
|---|---|
| `getItem` бросает | `null`, без исключения |
| `setItem` бросает | `false`, без исключения |
| Значение под другим ключом | не читается |
| Неучтённый в палитре цвет в отрисовке | RND-DARK-ONLY-1/2 падают |

## Invariants

- Без опции `palette` сцена побайтно совпадает со светлой палитрой (RND-DEFAULT-1).
- В тёмной схеме ни одна операция рисования не использует цвет вне тёмной палитры (RND-DARK-ONLY-1/2).
- Двойное переключение возвращает исходную схему (TOGGLE-2).
- Выбор пользователя всегда важнее системной настройки (RES-3).

## Integration Cases

- `buildPdf` → `drawScene` с `grid: false` и светлой палитрой (PDF-LIGHT-1, через обёртку модуля).
- Ручные MAN-* в браузере (`/draw-repair/`, перезапуск dev-сервера):
  - MAN-UI-DARK — острова, поля, списки, активные кнопки, попап темнеют, текст читаем;
  - MAN-CANVAS-DARK — фон холста тёмный, сетка приглушена;
  - MAN-ROOM-DARK — заливка помещения неотличима от фона, сетка внутри скрыта;
  - MAN-PATTERN — превью материалов светлые в тёмной схеме;
  - MAN-SYS-1/2/3 — эмуляция `prefers-color-scheme` без выбора, на лету, после выбора;
  - MAN-TOGGLE-1/2 — кнопка, подсказка, состояние чертежа сохраняется;
  - MAN-PERSIST-1 — перезагрузка сохраняет выбор;
  - MAN-PDF-1 — PDF из тёмной схемы светлый.

## Mutation Targets

- `resolveTheme`: игнорирование выбора, инверсия `systemDark` — RES-1..3.
- `parseTheme`: регистронезависимость, `trim`, принятие любой строки — PARSE-2, STORE-3.
- `loadThemeChoice`/`saveThemeChoice`: удаление `try/catch`, другой ключ — STORE-4..6, STORE-KEY-1.
- `themeToggleTitle`: подсказка по текущей схеме вместо целевой — TITLE-1.
- Отрисовка: оставленный литерал цвета (`#fff` в заливке, ручках, подложке текста, обводке точки привязки; `#333` в штриховке/превью; `#555`, `#999`, `#0f172a`, подложка угла, цвета выделения) — RND-DARK-*, PATTERN-DARK-1.
- Перепутанные поля палитры (например, `muted` вместо `ink` в размерах) — RND-DARK-DIM-1, RND-DARK-DRAFT-1.
- `buildPdf`, передающий тёмную палитру или включающий сетку — PDF-LIGHT-1.

## Out of Scope

- Автотесты DOM, CSS и `matchMedia` — ручная проверка.
- Попиксельное сравнение PDF.
