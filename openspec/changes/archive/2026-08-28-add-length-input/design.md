## Context

Реализовано сразу по запросу пользователя поверх `add-wall-drawing` и `add-wall-dimensions` (оба не заархивированы). Документ фиксирует решения пост-фактум.

## Goals / Non-Goals

**Goals:**

- Точный ввод длины сегмента с клавиатуры в потоке рисования, без отрыва мыши от холста.
- Блок размеров (поле + единицы) в правом нижнем углу; крупные читаемые подписи.

**Non-Goals:**

- Клавиатурный ввод угла, ortho-режим, снап клавиатурной вершины.

## Decisions

- **Коммит по Enter или клику — единая `commitPoint(p)`**: при активном (валидном) введённом значении конечная точка = вершина + нормированное направление на `p` × длина; клик задаёт направление, а не точку. Без введённого значения — обычный снап клика. Цепочка продолжается из нового конца, фокус сохраняется для следующего ввода.
- **Живое превью при вводе**: `previewPoint()` при `lengthDirty` строит превью введённой длины вдоль направления к курсору; движение мыши во время ввода меняет направление, сохраняя длину. Некорректный ввод — превью от курсора как раньше.
- **Дефолтная единица — мм** (состояние `unit` и активная кнопка в разметке); для чертежей удобнее мм, чем введённые изначально метры.
- **Авто-фокус поля при каждом клике по холсту** — печатать можно в любой момент рисования; клик по холсту фокус не уводит (canvas нефокусируемый).
- **Флаг `lengthDirty` вместо проверки фокуса**: guard «не затирать ввод» по `document.activeElement` оказался ошибочным — авто-фокус сразу блокировал живые значения (найдено при проверке в браузере). Теперь живое значение подавляется только событием `input` от пользователя и сбрасывается на клике/Enter/завершении.
- **Выделение значения целиком (`select()`)**: при фокусе и после каждой живой подстановки значение выделяется — первый введённый символ заменяет его без ручного удаления. Очистка поля на фокусе отвергнута: поле постоянно в фокусе во время рисования, живой показ пропал бы. Поле — `type="text" inputmode="decimal"`: у `type="number"` Firefox не отдаёт API выделения и по-разному глотает запятые.
- **Единицы**: `UNIT_TO_CM: { m: 100, cm: 1, mm: 0.1 }`; поле показывает число без суффикса (единица видна рядом кнопками), парсинг принимает запятую и точку.
- **Живое значение в метрах** — `(Math.round(cm)/100)`, чтобы 50 см показывались как 0.5, а не округлялись до 1.
- **Блок `#size-box`** — absolute в `#canvas-wrap`, не перехватывает клики холста (siblings); клики по блоку не создают вершин.
- **Подписи** — 14 px sans-serif, белая обводка 4 px, отступ от стены 4 px.

## Risks / Trade-offs

- [Клавиатурная вершина не на сетке может ломать последующую привязку углов] → сознательный обмен точности на решётку; выравнивание позже при необходимости.
- [Число в поле без суффикса единицы] → единица выделена кнопкой рядом; смешений избегаем близостью переключателя к полю.
