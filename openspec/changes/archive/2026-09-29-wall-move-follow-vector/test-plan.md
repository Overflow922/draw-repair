# Test Plan — wall-move-follow-vector

## Scope

Новое правило следования стен при перемещении (`moveWalls`): стыковой конец несмещаемой стены смещается тем же вектором, что и группа, с сохранением присадки. Проверяются оба изменённых требования: «Перемещение стены за средний маркер» (`wall-selection`) и «Групповое перетаскивание стен» (`multi-selection`). Оба требования реализуются одной функцией `moveWalls` (`src/geometry.ts`) — юнит-уровень покрывает оба сценария (одиночная стена = группа из одной).

Существующий тест «приваривает стыковой конец соседа к точному новому концу группы» (`src/geometry.test.ts`) закрепляет старое поведение и заменяется тестом MV-2 по новой спеке (пересмотр по изменённой спеке, не ослабление: сценарий сохраняется, меняется ожидание конца соседа).

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Расхождение осей ровно на границе допуска | конец соседа на расстоянии `jointTol × 1.25` от пред-конца группы (толщины 20 → 12.5 см) | конец соседа смещён на `delta` (привязан) |
| Чуть за границей допуска | расстояние = допуск + 0.5 см | сосед не тронут |
| Точное совпадение осей (присадка 0) | `w.a == g.a` до перемещения | после: `w.a == g.a`, смещение 0 сохранено |
| Присадка внутри полосы | смещение осей 10 см при толщине 20 (допуск 12.5) | смещение 10 см сохранено точно |
| Нулевая длина соседа | `w.a == w.b` | сосед пропущен, не двигается и не даёт деления на ноль в детекции |
| Нулевой сдвиг | `delta = (0, 0)` | позиции всех стен без изменений |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Конец двигаемой стены упирается в грань (не в конец, не на ось) соседа | сосед не смещается (нет привязки конца и нет T-примыкания на оси) |
| Тело соседа рядом с концом группы, но оба его конца вне допуска | сосед не тронут |
| Сосед, привязанный к чужой стене вне группы | не смещается |

## Invariants

- Группа перемещается жёстко: оба конца каждой стены группы получают один и тот же `delta`; длина и направление неизменны.
- Относительное смещение осей в стыке (присадка) сохраняется точно: `w.end − g.end` до и после перемещения — равные векторы.
- Замкнутость стыка: расстояние между концами осей стыка после перемещения равно расстоянию до перемещения.
- Сосед с одним привязанным концом растягивается ровно на `delta` (второй конец неподвижен).
- T-примыкание: оба конца соседа получают один `delta` (жёсткий сдвиг), точка примыкания на оси сохраняется; при примыкании к двум стенам группы — ровно один общий вектор.
- Порядок стен в массиве (ранняя/поздняя) не влияет на результат.
- Эквивалентность накопления: n последовательных перемещений на `d1..dn` дают то же, что одно перемещение на `Σdi`.

## Integration Cases

- Все три входа (драг за маркер, групповой драг, стрелки) вызывают `moveWalls` — юнит-проверки `moveWalls` покрывают логику; проводка в `main.ts` не меняется (сущ. тесты проводки не требуют правок).
- `snapOthers` остаётся согласованным с детекцией привязки: состыкованные и примкнутые стены исключены из привязки (MV-6), иначе перемещение прилипало бы к прежнему положению стыка.

## Mutation Targets

- Замена трансляции на приварку (`w.end = g.end` вместо `w.end += delta`) — убивается MV-3: приварка проходит MV-2 (стык замкнут), но ломает сохранение присадки.
- Выпадение ветки следования (привязанный конец соседа не двигается) — убивается MV-2 (стык разомкнут).
- Изменение допуска детекции (`<=` → `<`, коэффициент 1.25) — убивается граничными случаями (ровно на границе / чуть за).
- Смещение обоих концов соседа при угловом стыке (путаница с T-веткой) — убивается MV-2/MV-3 (непривязанный конец должен остаться).
- Потеря T-ветки или двойной сдвиг T-соседа при группе из двух — убиваются MV-4.
- Детекция против пост-позиций группы вместо пред-позиций — выявляется тестом эквивалентности накопления и граничным случаем (инвариант порядка/накопления).

## Out of Scope

- Орто-привязка, клик по маркеру без сдвига, обновление поля длины, запись истории — UI-проводка `main.ts`, этим изменением не затрагивается (сценарии спеки остаются под существующей ручной/интеграционной проверкой).
- `moveEndpoint` (перетаскивание конца: приварка/затягивание сохраняются) — сущ. тесты без изменений.
- Отрисовка стыков (`jointAt`, `endCap`, `wallShape`) — не меняется, покрыта `wall-geometry.test.ts`.
- История, хранение, загрузка — не меняются.
