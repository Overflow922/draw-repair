# Test Plan

## Scope

Поведение `demolition-no-window-walls` (дельта `demolition-plan`: «Что сносится и что нет», «Элементы стены в зоне сноса»; design D1–D3). Автоматизируются модель (`canDemolish`, `effectiveMarks` с элементами), инструмент с подставным хостом, `pagesOf` страницы PDF. Подключение `main.ts` — вручную.

Новые файлы тестов:

- `src/demolition/mark-windows.test.ts` — модель (NW-01 … NW-08);
- `src/demolition/demolition-windows.test.ts` — инструмент: жесты, выбор, ластик, числа (NW-10 … NW-20);
- `src/export/demolition-windows-pdf.test.ts` — `pagesOf`: действующие пометки страницы с окном (NW-30 … NW-33).

Оракулы: свободная стена `W` (0,0)–(500,0), кирпич, 20 см; окно `window_("W", "a", 210, 90)`; проём `Doorway`, дверь `door_`.

## Test Change Requests

Нет известных: существующие тесты задают окна и пометки на одной стене только на уровне уже разрешённых пометок (`effectiveMarks` без элементов) или на разных стенах. Конфликты, найденные при прогоне полного набора на эталонной реализации, валидатор добавляет сюда.

## Requirements Coverage

| Scenario | Test ID |
|---|---|
| Стена с окном не помечается (клик и протяжка) | NW-10, NW-11 |
| Окно добавлено под пометку (пометка не действует, остаётся) | NW-02, NW-14, NW-30 |
| Окно удалено — пометка снова действует | NW-03, NW-31 |
| Проём и дверь не мешают (клик, протяжка, область включает элемент) | NW-04, NW-12, NW-32 |
| Окно на другой стене не мешает | NW-05, NW-13, NW-33 |
| Железобетон по-прежнему не помечается и не действует | NW-06, NW-15 |
| Недействующая пометка не выбирается, не стирается, числа не правятся, снова выбирается после удаления окна | NW-14, NW-16 … NW-20 |
| Сценарий «Дверь и окно в зоне сноса» (окно на другой стене): элементы рисуются как на обмерочном плане | существующие RN-… (demolition-render.test.ts), NW-30, NW-32 |

## Mutation Targets

- окно не учитывается в `canDemolish` / `effectiveMarks`;
- любой элемент (проём, дверь) блокирует снос;
- окно другой стены блокирует снос;
- инструмент создаёт пометку на стене с окном / шаг истории без изменения;
- выбор, ластик, подсветка находят скрытую пометку;
- `pagesOf` не передаёт элементы.

## Out of Scope

Запрет ставить окно на помеченную стену на обмерочном плане; различие наружных и внутренних дверей.
