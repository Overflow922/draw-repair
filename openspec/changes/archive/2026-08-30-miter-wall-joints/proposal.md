# Proposal: miter-wall-joints

## Why

Стыки стен рисуются как два независимых прямоугольника: при любом угле, кроме 90°, торцы стен перекрываются, углы обоих стен торчат наружу за грани, в зоне наложения видны пересекающиеся линии контуров и двойная штриховка. Даже на ровно 90° в углу видна «ступенька» из линий торцов. Для чертёжного вида это брак: контур стены должен быть непрерывным, без нависаний и перекрытий.

## What Changes

- Стыки стен при отрисовке приводятся к чистой геометрии «в ус» (miter): торцы обеих стен срезаются по одной общей линии — через точки пересечения их наружных и внутренних граней. Диапазон митры простирается вплоть до коллинеарных стен (у лёгких изломов срез вырождается в короткий шов и заполняет угол без щели).
- Острые углы (острее ~30°, порог — настраиваемая константа): примыкание впритык — сквозная стена (нарисованная раньше) остаётся полным прямоугольником, примыкающая сохраняет прямоугольный торец, подрезанный по ближней грани сквозной; клиновидных блоков нет.
- Коллинеарные стены (180°) — плоские торцы (стык непрерывен сам по себе).
- T-образные стыки (конец стены на оси другой): торец приходящей стены подрезается по грани сквозной стены со стороны подхода.
- 3+ стены в одной вершине — v1 рисуются с плоскими торцами (как сейчас).
- Правка только в отрисовке: оси стен, длины (осевые), данные, undo/redo, сохранение — не меняются. Многоугольник стены не может выйти за линии её граней, габарит обводки по граням верен при любом угле.
- Штриховка: фаза линий якорится через текущий трансформ к мировой точке (не к bbox полигона), чтобы линии одного материала непрерывно продолжались через стыки; шаг остаётся в экранных миллиметрах. Заодно исчезает двойная штриховка — зон наложения больше нет.
- Штриховка «Дерево (вдоль)» рисуется с запасом за пределы оси (клип обрезает), чтобы у среза не оставалось пустого клина.
- Стены-превью (призрак при рисовании цепочки) рисуются плоскими торцами; срез появляется после фиксации вершины.

## Capabilities

### New Capabilities

- `wall-joints`: отображение стыков стен — срез торцов по общей линии (митра), примыкание впритык при острых углах, подрезка T-стыков, инварианты (оси и осевые длины не меняются, обводка не выходит за грани), непрерывность штриховки одного материала через стык.

## Impact

- `src/geometry.ts` — новая чистая функция формы стены с учётом соседей (кластеризация общих вершин, расчёт линии среза, T-подрезка); покрывается юнит-тестами.
- `src/render.ts` — использование новой формы вместо плоского прямоугольника; якорь фазы штриховки; диапазон волн wood-long.
- `src/geometry.test.ts` — новые тесты (90°, 45°, острый угол с bevel, тупой > 135°, разные толщины, T-стык, коллинеарные, свободные торцы, 3+ стены).
- Данные/хранение/история — без изменений; старые чертежи отображаются корректно без миграции.
