# Test Plan

## Scope

Поведение `demolition-window-sections` (дельта `demolition-plan`: «Что сносится и что нет», «Инструмент «Демонтаж»»; design D1–D3). Автоматизируются участки окон и чистые участки (`mark-sections`), действующие пометки, инструмент с подставным хостом, страница PDF (`pagesOf`). `main.ts` — без изменений.

Новые файлы тестов:

- `src/demolition/mark-sections.test.ts` — `windowBlocks`, `cleanRanges`, `effectiveMarks` с участками (SW-01 … SW-14);
- `src/demolition/demolition-sections.test.ts` — инструмент: клик и протяжка по чистому участку и участку окна, превью, скрытые пометки (SW-20 … SW-32);
- `src/export/demolition-sections-pdf.test.ts` — `pagesOf` (SW-40 … SW-42).

Оракулы: стена `W` (0,0)–(500,0), 20 см, кирпич; перегородка `P` (300,10)–(300,400), 10 см (разрыв грани `y = 10` на `[295, 305]`); комната с замкнутыми углами `W`, `R`, `B`, `L` вокруг; окно `window_("W", "a", 100, 90)` (откосы 100–190), окно справа `window_("W", "a", 350, 90)` (350–440).

## Mutation Targets

- окно блокирует всю стену / игнорируется;
- разрыв не относится к чистому участку (границы на границу разрыва с другой стороны);
- левая и правая границы перепутаны; разрывы только одной грани;
- любой элемент (проём, дверь) блокирует; окно другой стены блокирует;
- клик помечает всю стену, а не чистый участок;
- протяжка не обрезается или обрезается по неверной границе;
- пометка, пересекающая участок окна, действует; допуск `EPS_CM` не учитывается.
