## Context

`demolition-no-window-walls` сделал `canDemolish(wall, elements)` ложным для всей стены с окном. Пользователь показал планировку: верхняя стена — один отрезок через две комнаты, окно только в левой, перегородка делит внутреннюю грань стены; правая часть должна сноситься. Участки граней между стыками уже считает `faceRuns` (`src/doorway/doorway-faces.ts`), откосы окна — `jambsT`.

## Decisions

### D1. Участки окон и чистые участки — `src/demolition/mark-sections.ts`

- `faceGaps(wall, walls): [number, number][]` — объединение разрывов `[конец участка i, начало участка i+1]` по `faceRuns` обеих граней (положительной длины), по возрастанию.
- `windowBlocks(wall, walls, elements): [number, number][]` — для каждого окна стены (`isWindow`, `wallId === wall.id`) откосы `[j1, j2] = jambsT(e, wall)`; левая граница `A` — наибольший конец разрыва, не превышающий `j1` (иначе 0), правая `B` — наименьшее начало разрыва, не меньшее `j2` (иначе длина стены); пересекающиеся участки объединяются.
- `cleanRanges(wall, walls, elements): [number, number][]` — `[0, длина]` без участков окон; пусто для железобетона и вырожденной стены.

### D2. Модель

`canDemolish(wall)` возвращается к проверке железобетона и вырожденности (без элементов). `effectiveMarks(marks, walls, elements = [])` пропускает пометку, если её стену нельзя сносить или её участок пересекает участок окна больше чем на `EPS_CM`.

### D3. Инструмент

`down`: проекция точки нажатия на ось, зажатая в `[0, длина]`, ищется среди `cleanRanges` (с допуском `EPS_CM`); не нашлась — жест не начинается. `Press` хранит чистый участок `range`. Границы протяжки (`bounds`) зажимаются в `range`; клик ставит `place(wall, range[0], range[1])`. Выбор, ластик, подсветка и числа работают только с действующими пометками (как в `demolition-no-window-walls`).

## Risks / Trade-offs

- Разрыв между участками окон с обеих сторон остаётся тонким чистым участком (толщина перегородки) — следствие правила «разрыв относится к соседнему чистому участку».
- Участки определяются только Т-примыканиями; углы и границы помещений без перегородки стену не делят (вне объёма).
