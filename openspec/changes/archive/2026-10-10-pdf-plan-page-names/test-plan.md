# Test Plan

## Scope

Поведение `pdf-plan-page-names` (дельта `pdf-export` «Заполнение основной надписи»; design D1–D2): название плана в графе 5 каждой страницы. Автоматизируются `titleBlockTexts` и сборка PDF с записью вызовов `doc.text`.

Новый файл тестов: `src/export/plan-names-pdf.test.ts` (PN-01 … PN-12).

## Test Change Requests

TCR-1: `pdf-pages.test.ts` PG-01 (три `toEqual` по `pagesOf(...)[0]`) — страница плана теперь несёт `title: "Обмерочный план"`; в ожидаемые объекты добавлено поле `title`, остальные утверждения без изменений. Остальные: тесты «графа 5 пуста» (`pdf-pages.test.ts` PG-06, `sheet-layout.test.ts` FL-3, `sheet-pdf.test.ts` FL-3) работают со страницами без плана и без `pageName`. Конфликты, найденные при прогоне полного набора на эталонной реализации, валидатор добавляет сюда.

## Mutation Targets

- название плана не выводится / выводится не в графу 5 / на обеих страницах одно и то же;
- название берётся из имени чертежа;
- `pageName` пустой выводится пустой строкой;
- графа 1 теряет имя чертежа.
