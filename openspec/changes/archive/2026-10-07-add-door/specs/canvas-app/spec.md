## MODIFIED Requirements

### Requirement: Группы инструментов
Кнопки панели инструментов ДОЛЖНЫ идти тремя группами сверху вниз: инструменты построения («Стена», кнопка группы «Проёмы», «Окно»), инструменты измерения («Размер», «Линейка»), затем «Ластик». Между соседними группами ДОЛЖЕН отображаться разделитель. Инструменты «Проём» и «Дверь» НЕ ДОЛЖНЫ иметь собственных кнопок на панели инструментов: они выбираются в панели группы «Проёмы» (требование «Группа «Проёмы»»).

#### Scenario: Порядок кнопок
- **WHEN** пользователь открывает приложение
- **THEN** кнопки идут сверху вниз: «Стена», «Проёмы», «Окно», разделитель, «Размер», «Линейка», разделитель, «Ластик»; отдельных кнопок «Проём» и «Дверь» на панели нет

## ADDED Requirements

### Requirement: Группа «Проёмы»
Кнопка группы «Проёмы» ДОЛЖНА иметь собственную иконку в стиле остальных иконок панели (вид сбоку) и вспомогательную панель по требованию «Вспомогательная панель инструмента». Панель группы ДОЛЖНА содержать кнопки инструментов «Проём» и «Дверь» в этом порядке, а под ними — параметры текущего инструмента группы (`doorway` «Инструмент «Проём»», `door` «Инструмент «Дверь»»). Кнопка текущего инструмента группы ДОЛЖНА быть визуально выделена. По умолчанию текущий инструмент группы — «Проём».

Клик по кнопке группы ДОЛЖЕН вести себя как клик по кнопке инструмента, где инструмент — текущий инструмент группы: если активен другой инструмент, текущий инструмент группы становится активным и панель группы открывается с первого нажатия; если он уже активен, клик переключает видимость панели. Кнопка группы ДОЛЖНА быть визуально выделена как активная, когда активен любой инструмент группы. Клик по кнопке инструмента в панели группы ДОЛЖЕН делать этот инструмент текущим инструментом группы и активным инструментом; панель при этом ДОЛЖНА оставаться открытой и показывать параметры выбранного инструмента. Выделение одного проёма или одной двери ДОЛЖНО делать инструмент его вида текущим инструментом группы и открывать закрытую панель группы (`doorway` «Выделение проёма», `door` «Панель выделенной двери»); активный инструмент при этом НЕ ДОЛЖЕН меняться.

#### Scenario: Панель группы содержит инструменты
- **WHEN** пользователь нажал кнопку «Проёмы»
- **THEN** активен инструмент «Проём», панель группы открыта, в ней кнопки «Проём» (выделена) и «Дверь» и поля «Ширина» и «H» проёма

#### Scenario: Выбор двери в панели группы
- **WHEN** панель группы открыта, и пользователь нажал в ней кнопку «Дверь»
- **THEN** активен инструмент «Дверь», кнопка «Дверь» выделена, панель открыта и показывает поля «Ширина», «H» и кнопку «Повернуть»; кнопка «Проёмы» выделена как активная

#### Scenario: Кнопка группы помнит последний инструмент
- **WHEN** пользователь выбрал в панели группы «Дверь», затем выбрал инструмент «Стена», затем нажал кнопку «Проёмы»
- **THEN** активен инструмент «Дверь», панель группы открыта

#### Scenario: Повторный клик закрывает панель группы
- **WHEN** активен инструмент «Дверь», панель группы открыта, и пользователь нажал кнопку «Проёмы»
- **THEN** панель группы закрыта, инструмент «Дверь» остаётся активным

#### Scenario: Выделение двери показывает её в панели группы
- **WHEN** активен инструмент «Стена», текущий инструмент группы — «Проём», панель группы закрыта, и пользователь выделил дверь кликом
- **THEN** панель группы открыта, выделена кнопка «Дверь», поля показывают параметры двери; активным остаётся инструмент «Стена»
