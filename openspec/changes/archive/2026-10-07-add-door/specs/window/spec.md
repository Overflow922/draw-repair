## MODIFIED Requirements

### Requirement: Инструмент «Окно»
Панель инструментов ДОЛЖНА содержать кнопку инструмента «Окно» сразу после кнопки группы «Проёмы» (`canvas-app`, «Группа «Проёмы»»). Вспомогательная панель инструмента ДОЛЖНА содержать поля «Ширина», «H» и «H под.» в текущих единицах измерения; по умолчанию ширина 1200 мм, высота 1500 мм, высота подоконника 850 мм. Значения полей ДОЛЖНЫ применяться к новым окнам. Значение ширины или высоты, не являющееся положительным числом, и значение высоты подоконника, не являющееся неотрицательным числом, НЕ ДОЛЖНЫ применяться; поле ДОЛЖНО возвращать прежнее значение. Значение 0 в поле «H под.» ДОЛЖНО применяться. Активация инструмента ДОЛЖНА прерывать рисуемую цепочку и незавершённое размещение размера и снимать выделение. Esc при активном инструменте без выделения ДОЛЖЕН деактивировать инструмент, как у ластика.

Установка окна ДОЛЖНА выполняться по требованию «Установка проёма» (`doorway`): призрак — окно с шириной из поля «Ширина»; клик ставит окно с шириной, высотой и высотой подоконника из полей панели и выделяет его; клик по существующему элементу стены любого вида выделяет этот элемент вместо установки нового.

#### Scenario: Кнопка после «Проём»
- **WHEN** приложение открыто
- **THEN** кнопка «Окно» находится в панели инструментов сразу после кнопки группы «Проёмы», в которой находится инструмент «Проём»

#### Scenario: Дефолтные параметры окна
- **WHEN** приложение открыто, единица — мм, и пользователь открыл панель инструмента «Окно»
- **THEN** поле «Ширина» показывает 1200, поле «H» — 1500, поле «H под.» — 850

#### Scenario: Поля окна в текущих единицах
- **WHEN** пользователь переключил единицы на сантиметры
- **THEN** поля показывают 120, 150 и 85

#### Scenario: Нулевой подоконник допустим
- **WHEN** пользователь ввёл в поле «H под.» 0 и покинул поле
- **THEN** поле показывает 0, новые окна ставятся с высотой подоконника 0

#### Scenario: Отрицательный подоконник не применяется
- **WHEN** пользователь ввёл в поле «H под.» −10 или нечисловое значение и покинул поле
- **THEN** поле показывает прежнее значение, новые окна ставятся с прежней высотой подоконника

#### Scenario: Клик ставит окно
- **WHEN** активен инструмент «Окно», призрак отображается на стене W, и пользователь кликнул
- **THEN** на W поставлено окно с параметрами из полей панели, оно выделено, видны его размеры; в истории одна новая запись

#### Scenario: Клик по проёму в инструменте «Окно» выделяет проём
- **WHEN** активен инструмент «Окно», и пользователь кликнул внутри участка проёма
- **THEN** выделен проём, новое окно не поставлено

### Requirement: Панель выделенного окна
При выделении одного окна ДОЛЖНА открываться вспомогательная панель инструмента «Окно», а её поля ДОЛЖНЫ показывать ширину, высоту и высоту подоконника выделенного окна. Изменение поля при выделенном окне ДОЛЖНО менять это окно (ширина — по правилам ввода ширины `doorway`, с ограничением по инварианту) и записываться в историю одним шагом; изменение, не меняющее окно, запись НЕ ДОЛЖНО создавать. Поля при этом НЕ ДОЛЖНЫ менять параметры новых окон. Значения, недопустимые по требованию «Инструмент «Окно»», НЕ ДОЛЖНЫ применяться. При выделении одного проёма или одной двери ДОЛЖНА открываться панель группы «Проёмы» (`doorway` «Выделение проёма», `door` «Панель выделенной двери»).

#### Scenario: Панель показывает выделенное окно
- **WHEN** единица — см, и пользователь выделил окно шириной 120, высотой 150, подоконником 85
- **THEN** открыта панель «Окно», поля показывают 120, 150 и 85

#### Scenario: Подоконник меняется полем панели
- **WHEN** выделено окно с подоконником 85 см, единица — см, и пользователь ввёл в поле «H под.» 90
- **THEN** подпись окна показывает «H под.=90», в истории одна новая запись; «Отменить» возвращает 85

#### Scenario: Поле выделенного окна не меняет новые окна
- **WHEN** выделено окно, пользователь ввёл в поле «H под.» 90, затем снял выделение и поставил новое окно
- **THEN** новое окно поставлено с высотой подоконника, которая была в поле до выделения окна
