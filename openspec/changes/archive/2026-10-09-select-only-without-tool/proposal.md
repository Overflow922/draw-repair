## Why

Сейчас активный инструмент и выделение смешаны: в инструменте «Стена» клик по телу стены выделяет её, в «Линейке» клик выделяет стену, нажатие на проём в инструментах установки выделяет его и заодно выводит из инструмента, а Esc не снимает инструмент «Стена» вовсе. Пользователь не может предсказать, что сделает клик. Нужна простая модель: выделять и править существующие объекты можно только без инструмента; чтобы выделить, инструмент нужно снять.

## What Changes

- Esc снимает активный инструмент, включая «Стена» и инструменты группы «Проёмы» (с закрытием панели). Если идёт незавершённое действие (цепочка стен, размещение размера), первый Esc отменяет его, следующий снимает инструмент. Без инструмента Esc, как и раньше, снимает выделение.
- Пока активен любой инструмент, существующие объекты нельзя выделять и править: клик по стене, размеру, проёму, двери, окну; рамка выделения; перетаскивание маркеров концов и середины стены, смещение размера; правка чисел и зоны направления на месте. Клики и жесты работают только как действие самого инструмента.
- В инструменте «Стена» клик по телу существующей стены больше не выделяет её и новую стену не начинает (квадрат установки и так лежит снаружи тел стен).
- Инструменты «Проём», «Дверь» и «Окно» после установки одного элемента деактивируются; установленный элемент остаётся выделенным (правка чисел и направления двери — уже без инструмента). Инструмент «Стена» остаётся активным.
- «Линейка» перестаёт выделять стены по клику.
- **BREAKING**: убирается поведение change deselect-tool-on-element-select («выделение элемента выводит из инструмента установки») — выделить элемент при активном инструменте теперь нельзя вовсе.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `wall-selection`: выделение стены только без инструмента; Esc снимает инструмент.
- `multi-selection`: рамка выделения только без инструмента.
- `dimension-selection`: выделение и смещение размера только без инструмента.
- `wall-drawing`: клик по телу стены в инструменте «Стена» не выделяет, а рисует; Esc снимает инструмент.
- `ruler-tool`: клик не выделяет стены.
- `doorway`: выделение и правка проёма только без инструмента; снимается выход из инструмента при выделении.
- `door`: то же для двери.
- `window`: то же для окна.
- `canvas-app`: группа «Проёмы» больше не деактивируется выделением; общее правило «инструмент блокирует выделение».

## Impact

- `src/main.ts`: обработчик Esc, `pointerdown`, `click`, маркеры, рамка, перетаскивание размера.
- `src/doorway/openings-group.ts` (`afterElementPress`) и `leavePlacing` в `main.ts` — удаляются как ненужные.
- Тесты change deselect-tool-on-element-select (`src/doorway/element-select-tool.test.ts`, `popups-ui.test.ts`) описывают снятое поведение и должны быть пересмотрены отдельным test-change-request.
