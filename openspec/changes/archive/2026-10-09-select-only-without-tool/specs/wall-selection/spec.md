## ADDED Requirements

### Requirement: Выделение стены только без инструмента
Клик по существующей стене ДОЛЖЕН выделять её только в состоянии «Без инструмента» (`canvas-app`, «Выделение и правка только без инструмента»); клик по другой стене ДОЛЖЕН переносить выделение на неё. Клик по размерной линии или числу размера ДОЛЖЕН выделять размер вместо стены, находящейся под ним, и снимать выделение стены (см. `dimension-selection`). При любом активном инструменте клик по стене НЕ ДОЛЖЕН выделять её: при активном ластике он удаляет стену (см. `wall-deletion`), при активном инструменте «Размер» — задаёт точку замера (см. `dimension-tool`), при активной «Линейке» и в инструменте «Стена» стена не выделяется (клик в тело существующей стены в инструменте «Стена» новую стену не начинает — `wall-drawing`). Активация любого инструмента ДОЛЖНА снимать выделение. Клик по пустому месту без инструмента ДОЛЖЕН снимать выделение. Esc без инструмента ДОЛЖЕН снимать выделение; при активном инструменте Esc снимает инструмент (`canvas-app`, «Esc снимает активный инструмент»).

#### Scenario: Выделение кликом по стене без инструмента
- **WHEN** активного инструмента нет и пользователь кликнул по существующей стене
- **THEN** стена выделяется

#### Scenario: Перенос выделения без инструмента
- **WHEN** активного инструмента нет, стена выделена и пользователь кликнул по другой стене
- **THEN** выделение переходит на вторую стену

#### Scenario: Клик по размеру без инструмента выделяет размер вместо стены
- **WHEN** активного инструмента нет, и пользователь кликнул по размерной линии или числу размера, перекрывающего стену
- **THEN** выделяется размер, стена не выделяется (см. `dimension-selection`)

#### Scenario: Клик по пустому месту без инструмента
- **WHEN** стена выделена, активного инструмента нет, и пользователь кликнул по пустому месту холста
- **THEN** выделение снимается, новая цепочка не начинается

#### Scenario: Инструмент «Стена» не выделяет
- **WHEN** активен инструмент «Стена», цепочка не рисуется, и пользователь кликнул в тело существующей стены
- **THEN** стена не выделена, новая стена не начата

#### Scenario: Линейка не выделяет
- **WHEN** активна «Линейка» и пользователь кликнул по существующей стене
- **THEN** стена не выделена

#### Scenario: Активация любого инструмента снимает выделение
- **WHEN** стена выделена и пользователь активировал любой инструмент
- **THEN** выделение снимается, панель параметров стены закрывается

#### Scenario: Ластик удаляет стену вместо выделения
- **WHEN** ластик активен и пользователь кликнул по существующей стене
- **THEN** стена удаляется, выделение не появляется

#### Scenario: Инструмент «Размер» размещает точку вместо выделения
- **WHEN** инструмент «Размер» активен и пользователь кликнул по существующей стене
- **THEN** точка замера задаётся, выделение не появляется

#### Scenario: Esc без инструмента снимает выделение стены
- **WHEN** стена выделена, активного инструмента нет, и пользователь нажал Esc
- **THEN** выделение снимается

## REMOVED Requirements

### Requirement: Выделение стены
**Reason**: Выделение стены допускалось в инструменте «Стена», при активной «Линейке» и во время рисования; теперь выделять объекты можно только без инструмента.
**Migration**: Заменено требованием «Выделение стены только без инструмента».
