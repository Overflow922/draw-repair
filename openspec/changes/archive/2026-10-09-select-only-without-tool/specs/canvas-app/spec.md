## ADDED Requirements

### Requirement: Выделение и правка только без инструмента
Выделять и править существующие объекты чертежа (стены, размеры, проёмы, двери, окна) ДОЛЖНО быть можно только в состоянии «Без инструмента». Пока активен любой инструмент («Стена», «Проём», «Дверь», «Окно», «Размер», «Линейка», «Ластик»), нажатия и жесты на холсте ДОЛЖНЫ выполнять только действие самого инструмента и НЕ ДОЛЖНЫ: выделять объект кликом, протягивать рамку выделения, перетаскивать маркеры концов и середины стены, смещать вынос размера, перетаскивать элементы стены, открывать правку чисел на месте, менять направление двери. Чтобы выделить или править объект, пользователь ДОЛЖЕН сначала снять инструмент (Esc или выбор состояния «Без инструмента»). Активация инструмента по-прежнему ДОЛЖНА снимать выделение.

Единственное исключение — установка элемента стены: инструменты «Проём», «Дверь» и «Окно» после установки элемента ДОЛЖНЫ деактивироваться, а установленный элемент ДОЛЖЕН оставаться выделенным (`doorway`, «Установка проёма»).

#### Scenario: Клик по стене при инструменте не выделяет
- **WHEN** активен любой инструмент (в том числе «Размер», «Линейка», «Стена») и пользователь кликнул по существующей стене
- **THEN** стена не выделена, панель параметров стены не открыта; клик обработан только как действие инструмента

#### Scenario: Рамка при инструменте не рисуется
- **WHEN** активен любой инструмент и пользователь протянул указатель от пустого места холста
- **THEN** рамка не рисуется, ничего не выделяется

#### Scenario: Маркеры недоступны при инструменте
- **WHEN** активен инструмент «Стена», «Размер» или «Линейка», и пользователь нажал на место, где находился бы маркер конца или середины стены
- **THEN** стена не перемещается и не меняет длину

#### Scenario: Без инструмента выделение работает
- **WHEN** активного инструмента нет и пользователь кликнул по стене, размеру или элементу стены
- **THEN** объект выделен по правилам `wall-selection`, `dimension-selection`, `doorway`

#### Scenario: Снять инструмент и выделить
- **WHEN** активен инструмент «Стена», пользователь нажал Esc и кликнул по стене
- **THEN** инструмент снят, стена выделена

### Requirement: Esc снимает активный инструмент
Esc ДОЛЖЕН снимать активный инструмент (состояние «Без инструмента»), включая «Стена» и инструменты группы «Проёмы» («Проём», «Дверь»), «Окно», «Размер», «Линейка», «Ластик». Если у инструмента есть незавершённое действие (незавершённый жест стены, начатое размещение размера), Esc ДОЛЖЕН сначала отменить его, не снимая инструмент; следующий Esc ДОЛЖЕН снять инструмент. При снятии инструмента группы «Проёмы» панель группы ДОЛЖНА закрываться, текущий инструмент группы ДОЛЖЕН сохраняться. Без инструмента Esc ДОЛЖЕН снимать выделение (`wall-selection`).

#### Scenario: Esc снимает инструмент «Стена»
- **WHEN** активен инструмент «Стена», незавершённого жеста нет, и пользователь нажал Esc
- **THEN** активного инструмента нет, кнопка «Стена» не выделена

#### Scenario: Первый Esc отменяет жест, второй снимает инструмент
- **WHEN** активен инструмент «Стена», начало стены зафиксировано, и пользователь нажал Esc дважды
- **THEN** после первого Esc стена не поставлена, инструмент «Стена» активен; после второго активного инструмента нет

#### Scenario: Esc снимает инструмент группы «Проёмы»
- **WHEN** активен инструмент «Дверь», панель группы открыта, и пользователь нажал Esc
- **THEN** активного инструмента нет, панель группы закрыта, текущий инструмент группы — «Дверь»

#### Scenario: Esc в «Размер» с начатым размещением
- **WHEN** активен инструмент «Размер», задана первая точка замера, и пользователь нажал Esc дважды
- **THEN** после первого Esc черновик размера сброшен, инструмент активен; после второго активного инструмента нет

#### Scenario: Esc без инструмента снимает выделение
- **WHEN** активного инструмента нет, выделена стена, и пользователь нажал Esc
- **THEN** выделение снято

## MODIFIED Requirements

### Requirement: Панель группы «Проёмы»
Кнопка группы «Проёмы» ДОЛЖНА иметь собственную иконку в стиле остальных иконок панели (вид сбоку) и вспомогательную панель по требованию «Вспомогательная панель инструмента». Панель группы ДОЛЖНА содержать только кнопки инструментов «Проём» и «Дверь» в этом порядке. Кнопка текущего инструмента группы ДОЛЖНА быть визуально выделена. По умолчанию текущий инструмент группы — «Проём».

Клик по кнопке группы ДОЛЖЕН вести себя как клик по кнопке инструмента, где инструмент — текущий инструмент группы: если активен другой инструмент, текущий инструмент группы становится активным и панель группы открывается с первого нажатия; если он уже активен, клик переключает видимость панели. Кнопка группы ДОЛЖНА быть визуально выделена как активная, когда активен любой инструмент группы. Клик по кнопке инструмента в панели группы ДОЛЖЕН делать этот инструмент текущим инструментом группы и активным инструментом; панель при этом ДОЛЖНА оставаться открытой. Выделение проёма или двери НЕ ДОЛЖНО менять текущий инструмент группы. Установка проёма или двери ДОЛЖНА деактивировать инструмент группы и закрывать панель группы, текущий инструмент группы при этом сохраняется (`doorway`, «Установка проёма»). Выделить существующий элемент при активном инструменте нельзя (требование «Выделение и правка только без инструмента»).

#### Scenario: Панель группы содержит инструменты
- **WHEN** пользователь нажал кнопку «Проёмы»
- **THEN** активен инструмент «Проём», панель группы открыта, в ней только кнопки «Проём» (выделена) и «Дверь»

#### Scenario: Выбор двери в панели группы
- **WHEN** панель группы открыта, и пользователь нажал в ней кнопку «Дверь»
- **THEN** активен инструмент «Дверь», кнопка «Дверь» выделена, панель открыта и содержит только кнопки «Проём» и «Дверь»; кнопка «Проёмы» выделена как активная

#### Scenario: Кнопка группы помнит последний инструмент
- **WHEN** пользователь выбрал в панели группы «Дверь», затем выбрал инструмент «Стена», затем нажал кнопку «Проёмы»
- **THEN** активен инструмент «Дверь», панель группы открыта

#### Scenario: Повторный клик закрывает панель группы
- **WHEN** активен инструмент «Дверь», панель группы открыта, и пользователь нажал кнопку «Проёмы»
- **THEN** панель группы закрыта, инструмент «Дверь» остаётся активным

#### Scenario: Выделение двери не трогает группу
- **WHEN** активен инструмент «Стена», текущий инструмент группы — «Проём», панель группы закрыта, и пользователь кликнул по двери
- **THEN** дверь не выделена, панель группы закрыта, текущий инструмент группы — «Проём», активным остаётся инструмент «Стена»

#### Scenario: Выделение двери при инструменте группы деактивирует его
Название сценария сохранено для архивации; выделение двери происходит только установкой.
- **WHEN** активен инструмент «Дверь», панель группы открыта, призрак двери отображается на стене, и пользователь кликнул (дверь поставлена и выделена)
- **THEN** активного инструмента нет, кнопка группы не выделена как активная, панель группы закрыта, текущий инструмент группы — «Дверь», дверь выделена

#### Scenario: Клик по существующей двери при инструменте группы не выделяет
- **WHEN** активен инструмент «Дверь», панель группы открыта, на стене нет свободного места для призрака, и пользователь кликнул по существующей двери
- **THEN** дверь не выделена, новая дверь не поставлена, инструмент «Дверь» остаётся активным, панель группы открыта

#### Scenario: Кнопка группы после выделения возвращает инструмент
- **WHEN** после установки двери (инструмент деактивирован, дверь выделена) пользователь нажал кнопку «Проёмы»
- **THEN** активен инструмент «Дверь», панель группы открыта; выделение снято (активация инструмента снимает выделение)
