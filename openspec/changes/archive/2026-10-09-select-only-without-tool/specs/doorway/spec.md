## MODIFIED Requirements

### Requirement: Установка проёма
При активном инструменте «Проём», когда курсор находится в радиусе привязки от тела стены, ДОЛЖЕН отображаться призрак проёма на этой стене с размерами по требованию «Размеры выделенного проёма». Ширина призрака — ширина из параметров новых проёмов. Центр призрака ДОЛЖЕН находиться в проекции курсора на ось стены; расстояние центра от конца `a` вдоль оси ДОЛЖНО округляться до целого сантиметра. Если в этом положении проём нарушает инвариант, призрак ДОЛЖЕН занимать ближайшее допустимое положение на этой стене. Если допустимого положения на стене нет, призрак НЕ ДОЛЖЕН отображаться. Вне радиуса привязки от стен призрак НЕ ДОЛЖЕН отображаться.

Клик при отображаемом призраке ДОЛЖЕН ставить проём в положение призрака с шириной и высотой из параметров новых проёмов (требование «Инструмент «Проём» и параметры новых проёмов») и выделять его. Сторона привязки нового проёма — конец стены, ближайший к проёму (по расстоянию вдоль оси от конца до ближнего откоса); при равенстве — `a`. Клик без призрака НЕ ДОЛЖЕН ставить проём. Клик по существующему проёму НЕ ДОЛЖЕН выделять его (`canvas-app`, «Выделение и правка только без инструмента»). Установка ДОЛЖНА записываться в историю одним шагом. После установки инструмент ДОЛЖЕН деактивироваться (состояние «Без инструмента»), призрак ДОЛЖЕН исчезнуть, панель группы «Проёмы» ДОЛЖНА закрыться, текущий инструмент группы ДОЛЖЕН сохраниться, а установленный элемент ДОЛЖЕН остаться выделенным.

#### Scenario: Призрак следует вдоль стены
- **WHEN** активен инструмент «Проём», и курсор находится над стеной W в точке `(203.4, 5)`
- **THEN** призрак ширины 90 см отображается с центром в `(203, 0)`, откосы проходят через `(158, 0)` и `(248, 0)`

#### Scenario: Призрак прижимается к стыку
- **WHEN** в раскладке с углом L курсор находится над стеной W в точке `(30, 0)`
- **THEN** призрак ширины 90 см стоит вплотную к грани L: ближний откос проходит через `x = 10`

#### Scenario: Нет места — нет призрака
- **WHEN** курсор над стеной, на которой нет свободного участка для проёма текущей ширины
- **THEN** призрак не отображается, клик не ставит проём

#### Scenario: Клик ставит и выделяет
- **WHEN** призрак отображается, и пользователь кликнул
- **THEN** проём поставлен в положение призрака, он выделен, его размеры видны; в истории одна новая запись

#### Scenario: Установка снимает инструмент
- **WHEN** активен инструмент «Проём», панель группы открыта, призрак отображается, и пользователь кликнул
- **THEN** активного инструмента нет, призрака нет, панель группы закрыта, текущий инструмент группы — «Проём», поставленный проём выделен

#### Scenario: Сторона привязки по ближнему концу
- **WHEN** проём ширины 90 см поставлен на стену W длиной 500 см с ближним откосом в 100 см от конца `a`
- **THEN** сторона привязки проёма — `a`, расстояние привязки 100 см

## ADDED Requirements

### Requirement: Выделение проёма без инструмента
Без активного инструмента клик по проёму — участку между откосами через всю толщину стены — ДОЛЖЕН выделять проём вместо опорной стены. Клик по размеру выделяет размер (`dimension-selection`). Выделенный проём ДОЛЖЕН отображаться подсветкой выделения по контуру участка проёма; его размеры и подпись правятся на месте (требование «Ввод чисел размеров проёма»). Выделение проёма НЕ ДОЛЖНО открывать вспомогательную панель и менять текущий инструмент группы «Проёмы» (`canvas-app`).

При любом активном инструменте (в том числе «Проём», «Дверь», «Окно», «Стена») клик по существующему элементу стены, рамка, захватившая элемент, перетаскивание элемента, клик по его правимому числу и клик в зону направления двери НЕ ДОЛЖНЫ выделять и править элемент (`canvas-app`, «Выделение и правка только без инструмента»). Единственный случай, когда элемент оказывается выделенным при инструменте, — его установка этим инструментом: тогда инструмент деактивируется и элемент остаётся выделенным (требование «Установка проёма»). Далее выделенный элемент правится как при любом другом выделении без инструмента: числа — на месте, зоны направления двери (`door`, «Направление выделенной двери»), перетаскивание, стрелки. Параметры новых элементов и текущий инструмент группы «Проёмы» при выделении НЕ ДОЛЖНЫ меняться.

#### Scenario: Клик по проёму выделяет проём
- **WHEN** активного инструмента нет, и пользователь кликнул внутри участка проёма
- **THEN** выделен проём, стена не выделена, цепочка не начинается, видны размеры проёма

#### Scenario: Выделение проёма не открывает панель
- **WHEN** текущий инструмент группы «Проёмы» — «Дверь», панель группы закрыта, активного инструмента нет, и пользователь выделил проём кликом
- **THEN** панель группы закрыта, текущий инструмент группы — «Дверь»; размеры проёма и подпись «H=…» подчёркнуты как правимые

#### Scenario: Клик по существующей двери в инструменте «Дверь» не выделяет
- **WHEN** активен инструмент «Дверь», на стене W стоит дверь, места для призрака на W нет, и пользователь кликнул внутри участка двери
- **THEN** дверь не выделена, новая дверь не поставлена, инструмент «Дверь» остаётся активным

#### Scenario: Клик по окну в инструменте «Проём» не выделяет
- **WHEN** активен инструмент «Проём», и пользователь кликнул внутри участка окна, где призрак не отображается
- **THEN** окно не выделено, инструмент «Проём» остаётся активным

#### Scenario: Рамка при инструменте установки
- **WHEN** активен инструмент «Дверь», и пользователь протянул указатель от пустого места через существующую дверь
- **THEN** рамка не рисуется, дверь не выделена, инструмент «Дверь» остаётся активным

#### Scenario: Правка числа при инструменте недоступна
- **WHEN** выделена дверь, пользователь активировал инструмент «Дверь» (выделение снялось) и кликнул по месту, где было число её ширины
- **THEN** поле ввода не открывается

#### Scenario: Инструмент «Стена» не выделяет элемент
- **WHEN** активен инструмент «Стена», цепочка не рисуется, и пользователь кликнул внутри участка двери
- **THEN** дверь не выделена, активным остаётся инструмент «Стена»

#### Scenario: Установленный элемент редактируется после снятия инструмента
- **WHEN** пользователь поставил дверь инструментом «Дверь» (инструмент деактивировался, дверь выделена) и кликнул по числу её ширины
- **THEN** открыто поле ввода ширины, дверь выделена, активного инструмента нет

## REMOVED Requirements

### Requirement: Выделение проёма кликом
**Reason**: Элемент стены выделялся кликом при любом инструменте, а инструменты установки после выделения деактивировались; теперь выделять и править элементы можно только без инструмента.
**Migration**: Заменено требованием «Выделение проёма без инструмента»; установка элемента сама снимает инструмент и оставляет элемент выделенным (требование «Установка проёма»).
