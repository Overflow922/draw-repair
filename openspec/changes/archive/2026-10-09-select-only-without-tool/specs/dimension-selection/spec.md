## ADDED Requirements

### Requirement: Выделение размера только без инструмента
Клик по размерной линии или числу размера ДОЛЖЕН выделять этот размер только в состоянии «Без инструмента» (`canvas-app`, «Выделение и правка только без инструмента»); клик по другому размеру ДОЛЖЕН переносить выделение на него. При любом активном инструменте, включая «Размер» и ластик, размер НЕ ДОЛЖЕН выделяться и вынос размерной линии НЕ ДОЛЖЕН меняться перетаскиванием: при активном ластике клик удаляет размер (см. `dimension-tool`), в инструменте «Размер» клик по существующему размеру ставит точку замера по правилам инструмента. Выделение размера ДОЛЖНО снимать выделение стены; клик по существующей стене без инструмента ДОЛЖЕН снимать выделение размера. Клик по пустому месту без инструмента ДОЛЖЕН снимать выделение размера. Esc без инструмента ДОЛЖЕН снимать выделение размера; при активном инструменте Esc снимает инструмент (`canvas-app`, «Esc снимает активный инструмент»). Смена инструмента, «Отменить», «Повторить» и переключение вкладки ДОЛЖНЫ снимать выделение размера. Если удаление стены каскадно удалило выделенный размер, выделение ДОЛЖНО сниматься. Точки замера выделенного размера НЕ ДОЛЖНЫ иметь средств правки: перетаскивание размера ДОЛЖНО менять только вынос размерной линии. Выделение размера НЕ ДОЛЖНО открывать вспомогательную панель (`canvas-app`); число выделенного размера НЕ ДОЛЖНО быть правимым и подчёркнутым.

#### Scenario: Выделение размера кликом без инструмента
- **WHEN** активного инструмента нет, и пользователь кликнул по размерной линии или числу размера
- **THEN** размер выделяется, вспомогательная панель не открывается, поле ввода не появляется

#### Scenario: Перенос выделения на другой размер без инструмента
- **WHEN** размер выделен, активного инструмента нет, и пользователь кликнул по другому размеру
- **THEN** выделение переходит на второй размер

#### Scenario: Клик по размеру в инструменте «Размер» не выделяет
- **WHEN** инструмент «Размер» активен, черновик размещения пуст, и пользователь кликнул по существующему размеру
- **THEN** размер не выделяется, вынос не меняется

#### Scenario: Перетаскивание размера при инструменте
- **WHEN** активен любой инструмент и пользователь нажал на размерную линию и потянул
- **THEN** вынос размера не изменился, размер не выделен

#### Scenario: Ластик удаляет размер вместо выделения
- **WHEN** ластик активен и пользователь кликает по размеру
- **THEN** размер удаляется, выделение не появляется

#### Scenario: Выделение размера снимает выделение стены
- **WHEN** стена выделена, активного инструмента нет, и пользователь кликнул по размеру
- **THEN** выделяется размер, выделение стены снято, панель стены закрыта

#### Scenario: Клик по стене снимает выделение размера
- **WHEN** размер выделен, активного инструмента нет, и пользователь кликнул по существующей стене
- **THEN** выделяется стена, выделение размера снято

#### Scenario: Клик по пустому месту снимает выделение размера
- **WHEN** размер выделен, активного инструмента нет, и пользователь кликнул по пустому месту холста
- **THEN** выделение размера снято; новая цепочка не начинается

#### Scenario: Esc без инструмента снимает выделение размера
- **WHEN** размер выделен, активного инструмента нет, и пользователь нажал Esc
- **THEN** выделение размера снято

#### Scenario: Активация инструмента снимает выделение размера
- **WHEN** размер выделен и пользователь активировал любой инструмент
- **THEN** выделение размера снято

#### Scenario: Отмена и повтор снимают выделение размера
- **WHEN** размер выделен и пользователь выполнил «Отменить» или «Повторить»
- **THEN** выделение размера снято

#### Scenario: Переключение вкладки снимает выделение размера
- **WHEN** размер выделен и пользователь переключился на другой чертёж
- **THEN** выделение размера снято

#### Scenario: Каскад удаления стены снимает выделение размера
- **WHEN** выделен размер, привязанный к стене, и пользователь удалил эту стену (ластиком или клавишей Delete)
- **THEN** размер исчез вместе с выделением

#### Scenario: Перетаскивание выделенного размера не двигает точки замера
- **WHEN** активного инструмента нет и пользователь перетащил выделенный размер
- **THEN** точки замера остались на прежних пересечениях линий граней стен, изменился только вынос размерной линии, число размера прежнее

## REMOVED Requirements

### Requirement: Выделение размера
**Reason**: Размер выделялся в любом инструменте, кроме ластика, и Esc снимал выделение раньше инструмента; теперь размер выделяется только без инструмента.
**Migration**: Заменено требованием «Выделение размера только без инструмента».
