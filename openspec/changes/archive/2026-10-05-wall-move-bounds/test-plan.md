# Test Plan

## Scope

Ограничение правок положения и длины стен: `wall-selection` «Границы перемещения примкнутой стены», изменённое «Изменение длины выделенной стены с клавиатуры»; `wall-collision` «Стены не проходят сквозь друг друга».

Тестируются наблюдаемые результаты публичных функций `src/wall-edit.ts` (design D1):
- `moveWallsBounded(walls, group, v, { ortho })` — применённый вектор и итоговые координаты всех стен;
- `moveEndpointBounded(walls, wall, end, target, { ortho })` — итоговое положение конца и координаты всех стен;
- `resizeWallBounded(walls, wall, lengthCm, { ortho })` — `ResizeResult` и координаты.

Текущая геометрия `walls` — начало жеста. «Следование за указателем» проверяется повторным вызовом от восстановленного снимка, как это делает `main.ts` (D6). Эталоны выведены из сценариев спецификации, а не из кода. Правила следования без ограничений (`moveWalls`, `moveEndpoint`, `planOrthoStretch`) фиксируют существующие одобренные тесты; они не меняются.

Допуски сравнения: координаты `toBeCloseTo(x, 3)` (1e-3 см) там, где ответ — точное число; для касания — `|x − эталон| ≤ 1e-3`.

Сцены (координаты в см):
- **TS** — опорная H `(0,0)-(0,400)` t20, свободные концы; ножка S `(10,200)-(110,200)` t10, конец a на правой грани H.
- **TA** — как TS, но ножка на оси: S `(0,200)-(100,200)` t10.
- **TI** — TS + T `(0,0)-(300,0)` t20 (угол с общей вершиной, S на внутренней стороне).
- **TO** — TS + T `(0,0)-(-300,0)` t20 (S на наружной стороне угла).
- **PP** — верхняя `(0,0)-(300,0)` t20, нижняя `(0,300)-(300,300)` t20, перегородка P `(150,10)-(150,290)` t10 (торцы на гранях).
- **PN** — H1 `(0,0)-(0,400)` t20, H2 `(400,0)-(0,400)` t20 (45°), P `(10,200)-(200,200)` t10 (a на грани H1, b на оси H2).
- **CM** — препятствие X `(200,0)-(200,400)` t20; свободная M `(0,200)-(100,200)` t10.
- **CF** — A `(0,0)-(200,0)` t10; W `(100,0)-(100,100)` t10 (T к оси A, второй конец свободен); Z `(0,140)-(200,140)` t10.
- **CR** — комната RV t20: top `(0,0)-(300,0)`, right `(300,0)-(300,200)`, bottom `(300,200)-(0,200)`, left `(0,200)-(0,0)`; препятствие O `(-50,-50)-(350,-50)` t20.
- **CO** — A `(0,0)-(200,0)` t20; B `(100,-5)-(100,100)` t10 (тела налагаются на 15 см, нет стыка и примыкания).
- **U** — снимок чертежа пользователя `userWalls()` (`move-joints.test-utils.ts`).

### Инварианты на реальном чертеже

| ID | Проверка |
|---|---|
| INV-1 | U: для каждой стены как seed — 8 направлений × длины {10, 60, 200}, без орто и с орто, от исходной геометрии. Каждое исходное T-примыкание (`teeEndAttached`, без углового стыка) после правки сохраняется по спецификации: поперечное смещение конца в системе новой оси опорной равно исходному (1e-6), продольная координата в пределах грани с продолжением за конец оси до наружного угла (запас — толщина стены, состыкованной с этим концом опорной). |

## Invariants

- Примкнутый конец остаётся на грани своей опорной стены в пределах диапазона после любой правки (TB-17, INV-1).
- Нет новых пересечений тел между несвязанными стенами (INV-2); площадь исходных наложений не растёт.
- Применённый вектор не превышает запрошенного и равен ему, если запрос допустим (INV-3, C-5, TB-11).
- Длина и направление стены при перемещении неизменны (TB-3, TB-8, C-3 — проверка обоих концов).
- Опорная стена ножки при её перемещении не сдвигается (TB-1..TB-7).

## Integration Cases

- Перемещение с орто-планом: ограничение действует на увлекаемые стены (C-10).
- Следование соседей без орто сохраняется под ограничителем (C-9, C-16, LI-7).
- Ограничение T и препятствие вместе: внутренний угол (TB-6) — скольжение вдоль H останавливается касанием T, поперечная составляющая не возникает.
- Связь с `main.ts` (снимок, история, поле длины): E2E-1..E2E-3.

## Mutation Targets

Инструмента мутационного тестирования в проекте нет. Мутации, которые тесты должны ловить (проверяет валидатор вручную):
- порог глубины `> 0.01` ↔ `>= 0.01` / `> 0` (C-13); остановка на глубине допуска вместо касания (C-14);
- проверка только конечного положения без пути (C-2, C-15);
- шаг пути не зависит от толщины (C-15);
- отсутствие скольжения: возврат `vc` вместо касательной (C-3, TB-3);
- проекция не обнуляет поперечную составляющую / не ограничивает диапазон (TB-1, TB-4);
- диапазон по оси опорной вместо видимой грани (TB-7 — наружный угол; TB-4 — след ножки);
- `f = h_S` вместо `h_S/|sin θ|` (TB-14);
- непараллельные опорные не обнуляют вектор (TB-9);
- опорная в той же группе всё равно ограничивает (TB-11);
- увлекаемые стены не проверяются на столкновение (C-9, C-10);
- исключение связанных пар отсутствует (C-16) или распространяется на все пары (C-1);
- исключение по оси не работает (C-12, C-12b), срабатывает без привязки (C-12a, C-12c) или распространяется на всё тело (C-12e; C-12d — то же для третьей стены на пути);
- диапазон перегородки только по одной опорной — первой или последней (TB-20, TB-20a); грубый шаг пути (C-15b);
- существующие наложения блокируют всё (C-17, C-17a) или не проверяются (C-18);
- ввод длины всегда двигает b (LI-1), не отвергает два примкнутых конца (LI-3), не укорачивает до касания (LI-4);
- ножка не следует за опорной — правка блокируется (HF-1, HF-2, HF-5, HF-6); расстояние от конца a вместо неподвижного (HF-1, HF-5; HF-4 — орто); ножка со свободным концом смещается только концом (HF-1, HF-5) или с занятым — целиком (HF-2); укорочение опорной не ограничено диапазоном (HF-3); следование в один проход без распространения (HF-7); стены следования вне проверки столкновений (HF-8).
