# Test Suite

Файлы (все новые; одобренные тесты не изменены):
- `src/wall-edit-tee.test.ts` — TB-*, LI-1..LI-3, LI-6..LI-8;
- `src/wall-collision.test.ts` — C-*, LI-4, LI-5;
- `src/wall-edit-invariants.test.ts` — INV-1..INV-3 (чертёж пользователя `userWalls()`);
- `src/wall-edit.test-utils.ts` — сцены, снимок и восстановление, независимый оракул тел (SAT-глубина, площадь пересечения отсечением), исходные T-примыкания.

Запуск: `npx vitest run src/wall-edit-tee.test.ts src/wall-collision.test.ts src/wall-edit-invariants.test.ts`.

Начальный прогон (до реализации): все три suite не загружаются — модуля `src/wall-edit.ts` ещё нет (`Cannot find module './wall-edit'`). API задан design D1. По той же причине `tsc --noEmit` сообщает TS2307 в этих трёх файлах, других ошибок типов нет. Остальной набор: 37 файлов, 1023 теста — зелёные. Оракул тестового помощника проверен отдельным временным прогоном (CO: глубина 10, площадь 150; CM: касание 0, наложение 5 см → площадь 50; TS: одно примыкание S.a → H; PP: два), временный файл удалён.

## Coverage

### Happy paths

- Скольжение ножки вдоль опорной (TB-3, TB-8, TB-12, TB-16a), опорная в группе (TB-11), свободный конец (TB-15), ввод длины с переключением подвижного конца (LI-1, LI-2, LI-6..LI-8), свободное перемещение до касания (C-5), привязка к оси (C-12, C-12a).

### Boundary cases

- Диапазон у свободных торцов опорной (TB-4, TB-4a, TB-18), внутренний и наружный угол (TB-6, TB-7), след косой ножки (TB-14), порог глубины 0.01 см (C-13, C-14), касание ровно (C-5), тонкое препятствие (C-15), нулевой вектор.

### Negative cases

- Отрыв и вдавливание (TB-1, TB-2, TB-16, TB-19), непараллельные опорные (TB-9), ввод длины при двух примкнутых концах (LI-3), в упоре (LI-5, C-7), углубление наложения (C-18), большой шаг (C-2, C-15).

### Invariants

- Конец ножки на грани и в диапазоне для 80 векторов (TB-17); все T-примыкания чертежа пользователя сохраняются (INV-1); нет новых пересечений, площадь наложений не растёт (INV-2); допустимые запросы не ограничиваются и совпадают с примитивом (INV-3). Длина и направление при перемещении — проверка обоих концов в TB-3, TB-8, C-3.

### Integration cases

- Орто-план под ограничителем (C-10, LI-8, TB-16), следование соседей без орто (C-9, C-16, LI-7), T-ограничение вместе со столкновением (TB-6). Связь с `main.ts` (снимок, история, поле длины) — браузерные E2E-1..E2E-3 из test-plan на этапе верификации.

## Ревизия после валидации (VERDICT: FAIL)

Решения пользователя на уровне спецификации: остановка в касании (0.01 см — только допуск распознавания), примкнутость — по видимой грани с продолжением до наружного угла, исключение по оси — только при реальной привязке (`EditMode.snappedAxis`). Спецификации и design обновлены.
