## Why

Чертежи живут только в localStorage одного браузера: их нельзя передать другому человеку, сохранить резервную копию
или перенести на другую машину. PDF (`pdf-export`) предназначен для печати и обратно в программу не читается.

## What Changes

- Две кнопки на панели `#size-box` рядом с `pdf-export` (по образцу существующих кнопок панели): «Сохранить в файл» и
  «Открыть из файла».
- Экспорт: активная вкладка скачивается как файл `<имя чертежа>.json`. Один файл — одна вкладка со всеми её планами
  (обмерочный, демонтаж, черновые работы, мебель, сантехника, потолки, электрика, выноски, примечания, помещения),
  видом и активным планом.
- Загрузка: файл читается стандартным выбором файла и открывается **новой вкладкой**, не заменяя текущую. Чертёж
  получает новый идентификатор и уникальное в открытых чертежах имя. Частично повреждённые элементы отбрасываются по
  правилам хранилища; нечитаемый файл и файл более новой версии отклоняются с сообщением, ничего не меняя.
- История правок (undo/redo) и корзина в файл не входят; загруженный чертёж начинает с пустой истории.
- Правила чтения одного чертежа выделяются из чтения документа хранилища и используются и хранилищем, и файлом.

## Capabilities

### New Capabilities
- `drawing-file`: файл чертежа — формат, экспорт активной вкладки, загрузка в новую вкладку, отклонение нечитаемых и
  будущих версий.

### Modified Capabilities
- `drawing-storage`: правила чтения чертежа (отбрасывание битых элементов, миграции полей, игнорирование масштаба) —
  общие для хранилища и файла; поведение хранилища не меняется.

## Impact

- `src/storage.ts`: выделение чтения одного чертежа; новый модуль файла чертежа (конверт, сериализация, разбор).
- `src/main.ts`, `index.html`: две кнопки, скачивание, выбор файла, сообщение об ошибке, добавление вкладки.
- Новых зависимостей нет. Формат localStorage (версия 3) не меняется.
