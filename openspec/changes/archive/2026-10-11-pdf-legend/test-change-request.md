# Test change request TCR-4: тесты PDF под колонку легенды

Правило 5 (CLAUDE.md): реализация показала, что 20 одобренных тестов закреплены на прежней полной ширине области
чертежа (272 мм на A4) или меряют габариты всей страницы, куда теперь попадают линии легенды. Спека изменена намеренно
(delta `pdf-export`: «Легенда на странице PDF», «Область чертежа внутри рамки», «Формат страницы выбирает пользователь»),
поэтому тесты больше не выражают спецификацию. Запрос одобрен пользователем («да»).

## Что изменено

| Файл | Тесты | Изменение |
|---|---|---|
| `src/export/pdf-pages.test.ts` | PG-04 (×2), PG-05 (×3), PG-17 | `ink()` меряет контуры правее колонки легенды (`legendWidthMm(pages)`); область — `drawingArea("A4", columnMm)` |
| `src/export/pdf-pages.test.ts` | PG-11 (×2) | граница ширины: `242 − legendWidthMm(...)` вместо 242, шаг +0,1 мм сохранён |
| `src/export/sheet-pdf.test.ts` | PL-2, PL-5 (×2) | то же; крупный чертёж 25 м → 21 м (с легендой 25 м уже не помещается на A4) |
| `src/export/demolition-pdf.test.ts` | PG-03, PG-17, PG-18 (×2) | измерения правее колонки (красные и серые линии образцов легенды исключены) |
| `src/export/demolition-pdf.test.ts` | PG-06 | чертёж без пометок: сравнение операторов с `buildPdf` остаётся точным (с пометкой столбец страницы демонтажа шире, чем у одностраничного `buildPdf`) |
| `src/export/demolition-pdf.test.ts` | PG-07, `mounting-pdf.test.ts` MP-90 | граница `floor(242 − W)` см и +1 см (целые см вместо 0,1 мм: решение не зависит от погрешности на границе) |
| `src/export/demolition-dimensions-pdf.test.ts` | DC-24, DC-25 | область с колонкой самой широкой страницы; красные штрихи образца легенды исключены из измерения |

Намерение каждого теста (масштаб, центрирование, граница вместимости, габариты по всем стенам) сохранено; ослаблений
нет, кроме перехода границ PG-07 и MP-90 с 1 см на целые сантиметры (в формулировках с 0,1 мм граница зависит от
значения ширины колонки в плавающей точке).
