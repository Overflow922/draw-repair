# Test Suite

Ревизия 2 (2026-10-11, референс `img_1.png`): из легенды убраны проём, дверь, окно; образцы 16×8 мм (2:1) с отступом слева; шаг записей; перенос длинных подписей по пробелам. Тесты переписаны по `test-plan.md` (LG-3, LG-9, LG-11, LG-14, LG-15) до реализации; новых зависимостей нет. Запуск: `npx vitest run src/export/legend.test.ts src/export/legend-area.test.ts src/export/legend-pdf.test.ts`.

Что тесты требуют от реализации (API из design.md D1–D3, D5, D7):

- `src/export/legend.ts`: `legendEntries(page: PlanPage)` → записи материалов и сноса с полем `label`; `wrapLabel(label)` → строки подписи; `legendWidthMm(pages)` → число мм по самой широкой строке (0, если нигде нет стен).
- `src/export/sheet-layout.ts`: `drawingArea(format, legendMm = 0)` и `legendArea(format, legendMm)`.
- `src/export/pdf.ts`: `fitsFormat`, `placeOnPage` с параметром `legendMm`; `availableFormatsForPages` считает колонку по списку страниц; `buildPdfPages` рисует легенду.
- Подписи выводятся вызовом `doc.text` (по одному на строку подписи): тесты положения читают координаты, кегль и выравнивание из записи вызовов, ширину текста считают реальным PTSans; предельная ширина подписи 28 мм (design D6) проверяется по реальной ширине.
- Образцы рисуются отдельной функцией рендера, а не через `drawScene`/`drawDemolitionScene` (design D4).
- Тестовая утилита `src/export/pdf-style.test-utils.ts`: штрихи страницы с толщиной, цветом, пунктиром, признаком кривой и клиппингом. Границы образцов проверяются по сплошным линиям (толще штриховки).

Initial result (ревизия 2): до реализации из 111 прогонов упали 31 — все новые или изменённые требования: нет `wrapLabel`; записи и подписи проёма, двери, окна; перенос «Демонтируемая стена»; отступ, шаг и пропорции 2:1; положение подписи по центру образца; максимум записей 5. Остальные 80 описывают неизменные части (область, форматы, материалы, цвета, инварианты) и проходят до и после.

LG-13 (нет легенды на холсте) автотестом не покрыт: проверяется обзором диффа и `grep` (`legend*` импортируется только из `src/export/pdf.ts`; в `main.ts` и `index.html` нет управления легендой; `drawDoorways` не отличается от HEAD).

Существующие тесты, изменённые для колонки легенды (TCR-4), перечислены в `test-change-request.md`.

## Известные пересечения с существующими тестами

Нет новых: ширина колонки в старых тестах считается через `legendWidthMm` и от состава записей зависит только через подписи материалов и сноса; ревизия 2 их не затрагивает (полный набор проходит).
