# Test Plan

## Scope

Поведение легенды PDF и её влияние на область чертежа, вместимость форматов и размещение (`pdf-export`: «Легенда на странице PDF», «Область чертежа внутри рамки», «Формат страницы выбирает пользователь»). Проверяется наблюдаемое: состав и порядок записей страницы, ширина колонки, положение и вид образцов в операциях PDF, доступные форматы, смещение чертежа. Не проверяется внутреннее устройство мини-сцен.

Уровни: unit (состав записей, ширина колонки, область, вместимость), integration (`buildPdfPages` с реальным `jsPDF`: разбор операций страницы, положение текста, цвет и наличие штриховки), e2e на уровне UI не нужны (интерфейс не меняется; список форматов проверяется через `availableFormatsForPages`).

Описание тестов:

- **LG-1** Страница с кирпичной и бетонной стенами (стены заданы в порядке «бетон, кирпич»): записи — «Кирпич», «Бетон» в порядке каталога; на листе справа от образцов эти подписи.
- **LG-2** Страница только с кирпичной стеной: единственная запись «Кирпич»; подписей «Железобетон», «Дерево (вдоль)», «Демонтируемая стена» нет ни в списке записей, ни среди текстов страницы.
- **LG-3** Страница с дверью, окном и проёмом (по отдельности и вместе): записи только материалов; подписей «Проём», «Дверь», «Окно» нет ни в списке записей, ни среди текстов страницы; на странице «Демонтаж» с такими элементами — материалы и «Демонтируемая стена», без элементов; ширина колонки с элементами и без них одинакова.
- **LG-4** Страница «Демонтаж» с кирпичной стеной и одной действующей пометкой: записи «Кирпич», «Демонтируемая стена».
- **LG-5** Страница «Демонтаж» без пометок: «Демонтируемая стена» нет. Пометка, не являющаяся действующей (вне `effectiveMarks`), записи не даёт.
- **LG-6** Обмер с кирпичом, «Монтаж» только с бетоном: записи страниц различаются; колонка на листах одинаковой ширины (одинаковый левый край чертежа).
- **LG-7** Страница без стен: записей нет; на листе нет подписей легенды.
- **LG-8** Ни на одной странице нет стен: ширина колонки 0, записей нет.
- **LG-9** Ширина колонки определяется самой широкой строкой подписей среди всех страниц после переноса: добавление страницы с «Демонтируемая стена» увеличивает ширину колонки у остальных страниц; страница с только «Кирпич» без неё даёт меньшую ширину; ширина не меньше «отступ + образец + зазор + оценка самой широкой строки + отступ до чертежа».
- **LG-10** Положение: подписи и образцы легенды начинаются в границах `legendArea` (x не левее левого края области; верх первой записи не выше верха области); первая запись — самая верхняя, остальные ниже в порядке записей.
- **LG-11** Легенда не пересекает рамку и основную надпись: все её операции внутри области на A4–A0 при максимальном числе записей (5: четыре материала и снос).
- **LG-14** Отступ и шаг: левый край образцов правее левой границы области на положительный отступ, одинаковый у всех записей и всех страниц; соседние записи (однострочные подписи) отстоят по вертикали на один и тот же шаг; образцы 2:1 (ширина вдвое больше высоты) и не выше шага.
- **LG-15** Перенос: «Демонтируемая стена» выводится двумя вызовами текста «Демонтируемая» и «стена» (вторая ниже первой, слева на одном `x`, обе не шире предельной ширины подписи); образец вертикально по центру блока двух строк; следующая запись ниже блока; «Кирпич» — одним вызовом, по центру образца; слово не разрывается (слово шире предела остаётся целым).
- **LG-12** Образец «Демонтируемая стена» содержит красные операции (цвет `demolitionColor`) и штриховку под 135°; образцы материалов на странице «Демонтаж» — серые (`muted`), на остальных страницах — чёрные.
- **LG-13** Легенда не попадает в экранную отрисовку: `drawScene`/`drawDemolitionScene` без легенды не меняют своей разметки (набор операций сцены не изменился), в `main.ts` нет переключателя легенды.
- **AR-1** `drawingArea("A4")` без легенды = 272×145 с x=20, y=5.
- **AR-2** `drawingArea("A4", W)` = (272 − W)×145, x = 20 + W, y = 5.
- **AR-3** Документ без стен: область равна полной.
- **AR-4** Чертёж, габариты которого равны области формата (с легендой W): формат доступен, габариты не заходят на колонку легенды, рамку и основную надпись.
- **AR-5** Габариты (272 − W)×145 — A4 доступен; +0,1 мм по ширине или по высоте — нет.
- **AR-6** `placeOnPage`: чертёж центрирован в области за вычетом колонки; его левый край правее правого края колонки.
- **FM-1** Габариты по ширине 272 мм при наличии стен: A4 отсутствует в списке, A3 доступен. Те же габариты на странице без стен (легенды нет) — A4 доступен.
- **FM-2** Габариты 100×200: A4 нет; A3 есть.
- **FM-3** Габариты 180×170: A4 нет, выбирается A3.
- **FM-4** Формат ограничен самой крупной страницей; результат совпадает с расчётом по `drawingArea` с учётом общей колонки.

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Ровно на границе области | габариты (272 − W)×145 на A4 | A4 доступен |
| Превышение на 0,1 мм | (272 − W + 0,1)×145 | A4 нет |
| Превышение по высоте 0,1 мм | (272 − W)×145,1 | A4 нет |
| Ни одной записи | пустой документ | W = 0, область полная |
| Максимум записей | 4 материала + снос | 5 записей, внутри области на A4 |
| Одна запись | один материал | колонка по подписи материала |
| Самая широкая строка | «Демонтируемая стена» присутствует на одной странице из трёх | W одинаково на всех страницах |
| Подпись ровно по пределу / на символ шире | строка в пределе / длиннее | в пределе — одна строка; шире — перенос по пробелу |
| Слово шире предела | единственное слово длиннее предела | остаётся целым в одной строке, колонка шире |
| Неизвестный материал | `type` вне каталога | запись «Кирпич» |
| Материал дважды | несколько стен одного материала | одна запись |
| Подряд несколько разных действующих пометок | три пометки | одна запись «Демонтируемая стена» |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Страница без стен | легенды нет, область чертежа на ней всё равно сужена колонкой документа, если есть другие страницы со стенами |
| Страница «Демонтаж» без пометок | «Демонтируемая стена» нет |
| На странице «Обмер» пометки сноса в данных чертежа | «Демонтируемая стена» нет (только на странице «Демонтаж») |
| Элемент стены (проём, дверь, окно), в том числе без стены на странице | записи не создаётся ни в каком случае; страница не падает |
| Документ из одной пустой страницы | экспорт невозможен по прежним правилам, легенда не ломает расчёт |
| Нет объектов, которых нет в приложении | в легенде нет «Газобетон», «Вентканал», «Канализация», «Радиатор» |

## Invariants

- Ширина колонки легенды одна на всех страницах документа и не зависит от формата и масштаба.
- Размеры легенды (образцы, кегль, высота строки) не зависят от масштаба чертежа: два экспорта разных масштабов дают одинаковую легенду.
- Легенда не пересекает область чертежа: правый край колонки не правее левого края области чертежа.
- Чертёж по габаритам не меняет состав и ширину легенды; добавление/удаление стен меняет только состав записей.
- Образец рисуется тем же стилем (цвет, штриховка), что и объект на странице, у которой он стоит.
- Холст, экспортируемые данные чертежа и файл хранения не меняются легендой.
- Результат остаётся векторным (нет растровых изображений).

## Integration Cases

- `buildPdfPages` с тремя страницами (обмер, демонтаж, монтаж): на каждой странице подписи легенды именно её записей; левый край чертежа одинаков на всех страницах.
- Разбор операций PDF реальной страницы: подписи легенды на листе, положение `x` подписей правее образцов, цвета штриховки образцов (красный на сносе, серый подложки на «Демонтаж», чёрный на остальных).
- Совместно с существующим сквозным тестом выбора формата: рост чертежа переводит формат с A4 на A3 из-за колонки легенды.
- Подпись «Демонтируемая стена» помещается в колонку: реальная ширина текста PTSans не больше расчётной ширины колонки.

## Mutation Targets

- Условия вхождения записи: `some` → `every`, пропущенное `normalizeMaterial`, пропущенное условие `page.demolition` — убиваются LG-2, LG-5, граничным «неизвестный материал».
- Порядок записей: перестановка материалов/сноса — LG-1, LG-4. Возврат записей элементов — LG-3.
- Ширина колонки: `max` → `min` по страницам, пропущенный зазор или отступ, ширина по непереносимой подписи, ширина только по текущей странице — LG-9, LG-6, AR-2.
- Отступ и шаг: нулевой отступ, шаг, зависящий от числа строк, образец не 2:1 — LG-14.
- Перенос: не переносить, переносить не по пробелу, разрывать слово, образец не по центру блока, следующая запись не ниже блока — LG-15.
- Сдвиг области: `x + legend` и `w − legend` (знак и пропуск) — AR-2, AR-5, AR-6.
- Граница `<=`/`<` в `fitsFormat` — AR-5, FM-1.
- Нулевая колонка без стен — LG-8, AR-3.
- Цвет и угол образца сноса, серость на «Демонтаже» — LG-12.
- Образцы элементов в тексте страницы: «H=…» от образцов не появляется (нет образцов элементов).

Потенциально выживающие мутации, на которые направлены тесты: «сделать колонку всегда нулевой» (наивная реализация, при которой формат не меняется), «рисовать легенду поверх чертежа» (область не сужена), «ширина по одной странице» (ширина разная у разных страниц).

## Out of Scope

- Новые материалы и объекты из референса (газобетон, вентканал, канализация, радиатор).
- Переключатель легенды и вывод легенды на холсте.
- Визуальное сравнение с эталонным PDF по пикселям: проверяются операции и координаты.
- Мутационное тестирование всего экспорта: цели ограничены новым кодом легенды и областью чертежа.
