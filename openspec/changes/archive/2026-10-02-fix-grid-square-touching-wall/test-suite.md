## Coverage

### Happy paths

- GS-01 — узел сетки ровно в полутолщине от грани: вершина на грани, нормаль
  (1, 0), цель «грань», квадрат касается грани и не налагается.
- GS-03 — грань вне линий сетки (стена 25 см): вершина на грани без наложения.
- GS-04 — свободный торец: продолжение по оси, вершина (0, 0), цель «торец».

### Boundary cases

- GS-01 — зазор между квадратом по сетке и гранью ровно 0 → прилипание.
- GS-06 — зазор 1 см → сетка (точное равенство результата).
- GS-02 — края интервала курсора, дающего узел x = 20 (20.01 и 24.99).
- GS-05 — сразу за интервалом (узел x = 30) → сетка.

### Negative cases

- GS-05, GS-06 — квадрат по сетке не касается стены → результат строго
  `{point, source: "grid"}` (точное сравнение, лишние перечислимые поля
  запрещены).
- GS-07 — касание есть, но места для прилипшего квадрата нет (`sceneN`) →
  сетка; предусловие касания проверяется в самом тесте.
- GS-08 — свободный конец после первого клика не прилипает по расширенной зоне.

### Invariants

- GS-09 — развёртка курсора (шаг 5 см, ±40 см от стен, вне тел) по пяти сценам
  и четырём масштабам: сеточный квадрат не имеет общих точек с телами
  (независимая проверка касания с допуском 1e-6); прилипший квадрат не
  налагается, вершина не строго внутри тела.
- GS-10 — в обычной зоне (когда `snapVertex` прилип) результат совпадает с
  `snapVertex` (точка, `normal`, `target`); тест требует хотя бы одного
  сравнения.
- DET — повторный вызов даёт тот же результат; сцены заморожены `deepFreeze`
  (мутация входа бросила бы исключение).

### Integration cases

- Подмена вызова в `src/main.ts` модульными тестами не покрыта (DOM-модуль без
  тестов) — ручная проверка в браузере по test-plan.
