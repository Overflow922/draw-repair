# Test Plan

## Scope

Требование `wall-drawing` «Квадрат по сетке не касается стен»: привязка начальной
вершины до первого клика (`snapStartVertex`, design D1–D3) и неизменность
привязки свободного конца (`chainSegment`). Тесты — модульные (vitest), над
чистыми функциями `src/wall-snap.ts` и `src/wall-chain.ts`; новый файл
`src/wall-snap-start.test.ts`.

Общие параметры, если не указано иное: шаг сетки 10 см, толщина новой стены
20 см, масштаб 0.8 → радиус привязки `snapRadiusCm(0.8)` = 7.5 см, зона
прилипания `max(7.5, 10)` = 10 см. Стены строятся утилитой `W` из
`src/wall-snap.test-utils.ts`.

Проверка «касания» в тестах — независимая от продакшн-кода утилита (расстояние
между выпуклыми многоугольниками ≤ 1e-6 либо пересечение с замкнутыми
полуплоскостями), по образцу `maxOverlap`.

### Тесты

- **GS-01** Стена `W(0,0,0,200,20)` (грань x = 10). Курсор (22, 100).
  Ожидание: `source: "wall"`, вершина ровно (10, 100); неперечислимая `normal`
  = (1, 0), `target` = `"face"`; квадрат `placementSquare` касается грани и не
  налагается на тело (`maxOverlap` = 0).
- **GS-02** То же, ширина полосы: курсор x ∈ {20.01, 22, 24.99} при y = 100 →
  вершина (10, 100) в каждом случае (весь интервал, где узел сетки x = 20).
- **GS-03** Стена `W(0,0,0,200,25)` (грань x = 12.5). Курсор (24, 100).
  Ожидание: вершина (12.5, 100), `source: "wall"`, квадрат не налагается на
  тело, вершина не строго внутри тела.
- **GS-04** Стена `W(-100,0,0,0,20)`. Курсор (12, 0) (в полосе за торцом,
  дальше зоны 10 см). Ожидание: вершина (0, 0), `target` = `"cap"`,
  `normal` = (1, 0).
- **GS-05** Стена `W(0,0,0,200,20)`. Курсор (27, 100). Ожидание: точно
  `{ point: (30, 100), source: "grid" }`; квадрат по сетке на 10 см от грани.
- **GS-06** Граница касания, отрицательная сторона: стена `W(0,0,0,200,20)`,
  толщина новой стены 18 (полтолщины 9, зона 9). Курсор (22, 100) → узел (20,
  100), квадрат 11..29 — зазор 1 см. Ожидание: `{ point: (20, 100), source:
  "grid" }`.
- **GS-07** Сцена `sceneN` (стена `W(0,0,300,0)` и две примыкающие снизу на x =
  100 и x = 125; открытый участок грани между ними 5 см), масштаб 1 (радиус 6).
  Курсор (112.5, 22) → узел (110, 20), квадрат касается/налагается на тела, но
  места для прилипшего квадрата нет. Ожидание: `{ point: (110, 20), source:
  "grid" }`.
- **GS-08** `chainSegment` с началом (100, 60), стена `W(0,0,0,200,20)`, курсор
  (22, 60), без орто, угла и длины, масштаб 0.8. Ожидание: `snap.source` =
  `"grid"`, `end.x` = 20 (свободный конец не прилипает к грани x = 10).
- **GS-09** Инвариант-развёртка: сцены `sceneS`, `sceneL`, `sceneT`, отдельная
  стена толщиной 25 и наклонная стена под 45°; масштабы 0.25, 0.8, 1, 4;
  курсор по сетке шага 5 см (со смещением от узлов) в окрестности 40 см от
  стен (вне тел). `sceneN` не входит: в ней есть законные положения «касание
  без цели» (GS-07). Для каждого
  результата `snapStartVertex`:
  - `source === "grid"` → квадрат `placementSquare` не имеет общих точек ни с
    одним телом (независимая проверка);
  - `source === "wall"` → `maxOverlap(placementSquare) ≤ 1e-6` и вершина не
    строго внутри тела.
- **GS-10** Та же развёртка: если `snapVertex` возвращает `source: "wall"`,
  `snapStartVertex` возвращает ту же точку (и те же `normal`, `target`).
- **GS-11** Вне полосы у конца стены: стена `W(0,0,0,200,20)`, курсор (22, -3)
  → узел (20, 0), квадрат касается грани x = 10 у торца. Ожидание: прилипание
  к грани (`target` = `"face"`, `normal` = (1, 0)), вершина на x = 10, квадрат
  не налагается.

| Case | Expected behavior |
|---|---|

## Invariants

- Квадрат по сетке до первого клика не имеет общих точек с телами стен там, где
  есть место для прилипшего квадрата (GS-09).
- Прилипший квадрат никогда не налагается на тела, вершина не строго внутри
  тела (GS-09).
- В обычной зоне прилипания результат совпадает с `snapVertex` (GS-10).
- Детерминированность: повторный вызов с теми же входами даёт тот же результат,
  входные стены не мутируются (deepFreeze сцены в GS-09).

## Integration Cases

- Подмена вызова в `src/main.ts` (превью до первого клика и `wallClickAction`)
  модульными тестами не покрывается — ручная проверка в браузере (dev-сервер
  `/draw-repair/`): воспроизвести сценарий скриншота (масштаб ~0.8, стены
  20 см), убедиться, что квадрат у грани и поставленная стена без зазора.

## Mutation Targets

Мутационного инструмента в проекте нет; критические мутации проверяются
рассуждением в test-validation:

- Касание `> LINE_TOL` ↔ `>= ` / допуск 0 / проверка на наложение вместо
  касания (`overlapsBodies`) → GS-01 (зазор ровно 0) должен упасть.
- Расширенная зона для всех стен без проверки касания → GS-05, GS-06.
- Пропуск проверки неналожения в расширенном проходе → GS-07.
- Кандидаты только у первой касаемой стены / первой давшей кандидата → GS-16,
  GS-17.
- Расширенная зона для всех стен при касании любой (`allwallsext`) → GS-18a,
  GS-18b.
- AABB или разделяющие оси только по осям экрана при проверке касания → GS-13,
  GS-15.
- Выбор дальней грани / торца вместо грани вне полосы → GS-11, GS-01 (normal).
- Возврат сетки при отсутствии касания заменён на прилипание к ближайшей стене
  → GS-05.
- Применение расширения в `chainSegment` → GS-08.
- `snapStartVertex` всегда возвращает `snapVertex` → GS-01..GS-04.

## Out of Scope

- Привязка при заданном направлении (`snapOnRay`), трекинг.
- Отрисовка (`render.ts`) и обработчики `main.ts` (ручная проверка).
- Существующие тесты привязки — не изменяются.
