# Test Plan

## Scope

Поведение изменения `demolition-show-elements` (дельты `demolition-plan`, `pdf-export`; design D1–D3): на плане «Демонтаж» все элементы стены рисуются полностью и поверх области сноса, не скрываются; габариты страницы демонтажа учитывают элементы.

Автоматизируются: `drawDemolitionScene` (записывающий контекст), `pagesOf`/`availableFormatsForPages`/`buildPdfPages` (разбор операторов страницы). `main.ts` проверяется вручную.

## Test Change Requests (разрешённые правки approved-тестов)

Новая спецификация сознательно отменяет скрытие элементов; тесты скрытия и подпись «элементов нет» меняются или удаляются.

| ID | Файл / тест | Что меняется |
|---|---|---|
| TCR-1 | `src/demolition/mark-region.test.ts`, блок «скрытие элементов стены» (RG-05 … RG-15) и их импорты | удаляется целиком: `hiddenElements`/`visibleElements` удалены (design D2); тесты `markRegion` остаются |
| TCR-2 | `src/demolition/demolition-render.test.ts` RN-05 «подписи элементов стены на подложке не рисуются» | заменяется: подпись «H=210» рисуется один раз |
| TCR-3 | `src/export/demolition-pdf.test.ts` PG-11 (два теста `pagesOf`: проём, пересекающийся с участком, не передаётся / проём вне участка остаётся) | ожидание: вторая страница несёт все элементы (`[DOOR]`) в обоих случаях |
| TCR-4 | `src/export/demolition-pdf.test.ts` PG-04 «нет подписей площади и подписей элементов (H=…)» | подпись площади по-прежнему отсутствует; подпись «H=…» есть на обеих страницах |

Остальные approved-тесты не меняются.

## Boundary Cases

| Case | Expected |
|---|---|
| Проём внутри / частично внутри / касается участка | отображается полностью во всех трёх (RN-14, RN-15, PG-21) |
| Вся стена помечена, на ней дверь и окно | полотно, дуга и обе подписи нарисованы (RN-16) |
| Участок и проём не пересекаются | отображается (PG-21) |

## Negative Cases

| Case | Expected |
|---|---|
| Подпись площади помещения на странице демонтажа | отсутствует (PG-04) |
| Размеры на странице демонтажа | отсутствуют (PG-04) |
| Подпись элемента скрыта пометкой | не происходит (RN-14) |

## Invariants

- `pagesOf(d)[1].doorways` равен списку элементов чертежа (все, в том же порядке) при любых пометках.
- Элементы рисуются после закраски бумагой области сноса (RN-17).
- Цвет элементов — серый подложки, не ink (RN-18).

## Integration Cases

- `pagesOf` → `buildPdfPages` → страница 2: вырез и подпись «H=210» над красной областью; габариты и форматы учитывают элементы (PG-22, PG-23).

## Mutation Targets

- слой элементов не рисуется на подложке / рисуется до закраски бумагой (область закрывает его) / рисуется чёрным (ink) — RN-14, RN-17, RN-18;
- `pagesOf` по-прежнему скрывает элементы, пересекающиеся с пометкой — PG-21;
- `pageBounds` страницы демонтажа без элементов — PG-23;
- элементы выбираются только вне области сноса — RN-14, RN-15.
