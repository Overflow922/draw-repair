## Context

`eraserTarget` (src/main.ts) ищет ближайший размер без порога: `dimDist` сравнивается с `Infinity`, когда под курсором нет стены, поэтому любой размер на чертеже становится hover-целью и удаляется кликом по пустому месту. Спеки уже требовали «под курсором» и «пустой клик ничего не удаляет» — реализация дефектная, см. proposal.

## Goals / Non-Goals

**Goals:** подсветка и удаление размера ластиком только в радиусе привязки (`radiusCm()`); сохранение приоритета «размер поверх стены» при конфликте под курсором.

**Non-Goals:** изменение ветки стены (`hitWall` уже толерантен по радиусу), ветки выделения размера в `pointerdown` (там порог уже есть), переработка `eraserTarget` в модуль с юнит-тестами.

## Decisions

1. **Порог в размерной ветке `eraserTarget`:** кандидат принимается только при `dd <= tol` (`tol = radiusCm()`), далее прежнее правило `dimDist < wallDist`. Альтернатива «вынести таргетинг в geometry.ts ради юнит-тестов» отклонена — минимальный дифф; поведение проверяется браузером.
2. **Спеки уточняются явно** (радиус привязки в подсветке/удалении + сценарий пустого места): дефект возник из-за неопределённости «под курсором».

## Risks / Trade-offs

- [Регрессия приоритета «размер над стеной»] → условие `dimDist < wallDist` не трогается; браузерная проверка конфликта стена+размер под курсором.
