# Test Plan

## Scope

Поведение, заданное дельта-спеками:

- `wall-drawing` («Прилипание к грани, продолженной блоком диагонального стыка»): `snapStartVertex`, `snapRadiusCm`;
- `dimension-tool` («Торцы, закрытые блоком диагонального стыка, без размера толщины»): `placeWall`, разбор размеров через `measure`, `split`, `dimsOf` из `src/auto-dimensions.test-utils.ts`;
- `wall-joints` («Диагональный угловой стык», изменено — конец продолжения): `displayPolygons`.

Новые файлы (существующие тесты не меняются): `src/wall-snap-block-face.test.ts`, `src/auto-dimensions-block.test.ts`, `src/wall-geometry-diagonal-continuation.test.ts`. Эталоны выводятся из спецификации и геометрии сцен (A (−100,0)→(0,0), B (10,10)→(10,110), t = 20, блок x ∈ [0,20], y ∈ [−10,10], центр дальней стороны блока для B — F = (10,−10), для A — (20,0); масштаб 1: радиус привязки 6 см, зона = max(6, 10) = 10 см), а не из продакшн-кода.

## Invariants

- Оси и длины стен при привязке, отображении и пересчёте размеров не меняются.
- Квадрат установки не налагается на тела стен (`maxOverlap`).
- Отображаемые куски разных стен не налагаются друг на друга (`BJ-1a`, `BJ-2`, `BJ-6`).
- Ни одна размерная линия автоматических размеров A и B не лежит внутри блока.
- Результат привязки и размеров не зависит от порядка стен A, B (BS-1d, BD-6).
- Число размеров: у A, B и C — по одному размеру толщины, на свободном торце.

## Integration Cases

- IC-1: цепочка A, B, C — три размера толщины всего.
- IC-2: те же шаги при t = 195.
- BJ-6: привязка начала под блоком, затем C от вершины привязки: полоса x ∈ [0,20], y ∈ [−110,110] закрыта без просвета и наложения.

## Mutation Targets

- Зона прилипания по оси стены вместо расстояния до открытого участка (BS-1, BS-4); расширение зоны на 0 и на 5 см (BS-2a, BS-2c); на 11 см (BS-2b).
- Расширение зоны для граней без блока (BS-5, BS-5c).
- Признак «торец закрыт блоком»: всегда false (BD-1, BD-2), всегда true (BD-4, дальний торец).
- Конец продолжения: игнорируется всегда (BJ-1, BJ-2); принимается любой конец на границе блока (BJ-5, BJ-5a); допуск 0 или 2 см (BJ-3, BJ-4); направление не проверяется (BJ-5a); количество не проверяется (BJ-5b); учитывается только B или только A (BJ-1, BJ-2).

Мутационного инструмента в проекте нет (только vitest); N/A, мутации проверяет валидатор вручную.

## Out of Scope

- Размеры длины граней (в том числе по контуру с блоком) и их пропажа до установки третьей стены.
- Диагональное прилипание (`cornerCandidate`), построение блока, порядок стен.
- Перемещение и правка стен (`followingEnds`, `wallEndOccupied`).
- UI-проверки в браузере.
