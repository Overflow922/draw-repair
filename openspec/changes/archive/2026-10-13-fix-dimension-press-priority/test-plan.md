# Test Plan

## Scope

Выбор цели нажатия без инструмента (`pressPick` после D1 из design.md): размер против тела коммуникации (воздуховод, стояк), порядок остальных целей, допуски, а также неизменность ластика. Тесты — на чистой функции `pressPick` и `erasePick` с уровнем наблюдаемого результата (какая цель выбрана), без обращения к `main.ts`. Перетаскивание и история — существующие тесты `communications` и `dimension-selection` остаются как регрессия и не меняются.

## Boundary Cases

| Case | Input | Expected |
|---|---|---|
| Нажатие ровно на допуске размера внутри тела воздуховода | расстояние до размера = допуск | цель — размер (DP-09) |
| Нажатие чуть дальше допуска размера внутри тела | расстояние = допуск + ε | цель — воздуховод (DP-04) |
| Нажатие на краю тела воздуховода, размера нет | расстояние до тела = допуск коммуникации | цель — воздуховод (DP-06) |
| Нажатие чуть дальше допуска коммуникации, размера нет | допуск + ε | цели нет или стена (DP-06) |
| Стояк: размер проходит через центр | нажатие в центре | цель — размер (DP-02) |
| Размер привязан к стене, коммуникация касается той же стены | нажатие на размер | цель — размер (DP-01) |

## Negative Cases

| Case | Expected behavior |
|---|---|
| Коммуникации недоступны (планы «Демонтаж»/«Монтаж») | цель — размер или стена; коммуникация не выбирается (DP-10) |
| Размера под указателем нет | коммуникация выбирается как прежде (DP-06) |
| Размер вне тела коммуникации, нажатие в её теле | цель — коммуникация (DP-04) |
| Нажатие по размеру при отключённой опции `dimensions` (активен инструмент) | размер не выбирается (регрессия `selectionAllowed`) (DP-11) |

## Invariants

- Если в точке нажатия размер в допуске, цель — размер, независимо от числа и положения коммуникаций (DP-01, DP-02, DP-09).
- Цель нажатия определяется однозначно: порядок маркеры → размер → коммуникация → проём → стена не зависит от порядка элементов в списках (DP-12).
- Ластик в той же точке выбирает ту же цель-размер, что и нажатие (DP-05).

## Integration Cases

- Сцена с воздуховодом, через который проходит размер между двумя стенами: нажатие на линию → размер, на тело в стороне → воздуховод (DP-01 + DP-04 одним сценарием).
- Комната, нарисованная по стенам, со стояком и размером вдоль стены, проходящим над стояком (DP-02).

## Mutation Targets

- Перестановка размера и коммуникации в `pressPick` (DP-01, DP-02).
- Замена допуска размера на допуск коммуникации или наоборот (DP-09, DP-04).
- Условие «опция `dimensions` отключена» (DP-11).
- Условие доступности коммуникаций (DP-10).
- Порядок «коммуникация → проём» (DP-08).
- Реализация «размер главнее только для воздуховода, не для стояка» (DP-02) и наоборот — даёт ложный проход, если проверить лишь один вид.
- Реализация, которая всегда игнорирует коммуникацию (DP-04, DP-06).

## Out of Scope

- Визуальная проверка в браузере (ручная проверка при apply).
- Изменение допусков, отрисовки, правки чисел коммуникации.
