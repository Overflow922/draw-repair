## Boundary Coverage

Пометки одинакового участка на двух стенах, постановка до / между / левее существующих пометок, слияние при пометке другой стены позже в списке, пересечение и поглощение, постановка при выделенной другой пометке. Достаточно. Обрезка lo/hi в `place` недостижима (границы уже обрезаны `snapAlong`).

## Negative Cases

Снятие кликом, железобетон, клик мимо, отсутствие нажатия, Escape, протяжка внутри снесённого участка: `null`, выделение не меняется. Достаточно.

## Error Handling

Не применимо (нет исключений); отказ выражен `null`.

## Invariants

`up` не `null` только при изменении списка; возвращённый идентификатор совпадает с `selectedId()`; выбранная пометка принадлежит поставленной стене и покрывает поставленный участок (TL-28). Защищено.

## State Transitions

Нет выделения -> постановка -> выделена; A -> постановка B -> B; выделена -> снятие её -> нет выделения; снятие другой -> выделение сохраняется; Escape/пустая операция -> без изменений. Покрыто.
