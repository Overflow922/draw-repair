# Test Plan

## Scope

Поведение `demolition-select-after-mark` (дельта `demolition-plan` «Инструмент «Демонтаж»»; design D1–D2). Автоматизируется `createDemolitionTool` с подставным хостом (`src/demolition/demolition-tool.test.ts`); `main.ts` проверяется вручную.

## Test Change Requests

Нет: существующие тесты не противоречат (возвращаемое значение `up` ими не используется; выделение после постановки не проверялось). Тесты добавляются.

## Requirements Coverage

| Requirement / Scenario | Test ID |
|---|---|
| Клик помечает стену целиком: пометка выделена | TL-23 |
| Протяжка помечает участок: пометка выделена | TL-23 |
| Слияние выделяет слитую пометку | TL-24 |
| Повторный клик снимает пометку: инструмент остаётся (возвращает null) | TL-25 |

| Операция без изменений: null, выделение не меняется | TL-26 |
| Числа правятся сразу после постановки | TL-27 |

## Boundary / Negative

- Постановка при уже выделенной другой пометке переносит выделение на новую (TL-23).
- Снятие выделенной пометки сбрасывает выделение; снятие другой — не меняет его (TL-25).
- Отклонённые и пустые операции возвращают `null` и не меняют выделение (TL-25, TL-26).

## Mutation Targets

- `up` не возвращает идентификатор / возвращает его при снятии или при отказе — TL-23, TL-25, TL-26;
- выделение не ставится / ставится после `commit` (перерисовка без выделения) — TL-23;
- выбирается не слитая пометка — TL-24;
- выделение остаётся на удалённой пометке — TL-25.

## Ручные проверки
