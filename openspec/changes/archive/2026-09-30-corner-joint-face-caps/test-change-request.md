# Test Change Request: corner-joint-face-caps — принадлежность доращиваний

## Причина

При проверке в браузере (`img_4.png`) выделение упёртой стены подсвечивало тонкий клин в углу сквозной стены. Это доращивание торца сквозной до наружной грани упёртой: по утверждённой спеке все закрывающие угол области принадлежат поздней стене. Пользователь квалифицировал это как визуальный дефект («рудимент») и подтвердил смену правила.

## Изменение поведения (решение пользователя)

- **Было:** все доращивания, закрывающие угол углового стыка на грани, принадлежат поздней стене пары (заливка, штриховка, подсветка, попадание, удаление).
- **Стало:** каждая стена владеет своим доращиванием — торец доведён до своей целевой линии, и это её собственное тело:
  - сквозная — срезанный по наружной грани упёртой прямоугольник плюс продолжение до этой линии;
  - упёртая — прямоугольник плюс продолжение до внутренней грани сквозной.
- Порядок в массиве решает только наложение тел: где тела обеих стен перекрываются, отображается ранняя; поздняя не рисуется внутри тела ранней, включая её доращивание.
- Геометрия замкнутого угла (объединение областей) не меняется.

## Затронутые утверждённые тесты (`src/wall-geometry-corner.test.ts`)

| Тест | Почему больше не отражает спеку | Новое ожидание |
|---|---|---|
| Эталон `faceParts` / `expectedOwner` | Заливка (fill) приписана поздней стене | Доращивание входит в собственное тело стены; владелец точки: тела обеих — ранняя, иначе стена своего тела |
| CJ-2, CJ-3 | Выемка и просвет ожидаются у поздней | Выемка (доращивание сквозной) — у сквозной, просвет (доращивание упёртой) — у упёртой, в обоих порядках |
| CJ-5 | Ранняя упёртая — точный прямоугольник; заливки у поздней | Каждая стена — своё тело с доращиванием при любом порядке (по эталону); `hitWall` в доращивании — его стена |
| CJ-5o | Заливки у поздней из пары при посторонних стенах | Доращивания у своих стен при посторонних стенах (по эталону и `hitWall`) |
| CJ-3b | `expectRaw` ранней стены | Ранние стены с доращиваниями — не прямоугольники; проверка по эталону |
| CJ-12 | Точка в доращивании S внутри тела U — всегда у U | Наложение тел: у ранней из пары; ровно один кусок |
| CJ-13d | Шов разных типов по сырому торцу S (доращивание S у поздней U) | Сырой торец S — внутренняя граница S, шва нет; шов разных типов — по сырому торцу U на участке, где тело U граничит с доращиванием S, и по внутренней грани S под доращиванием U |
| CJ-13t | Шов по сырому торцу S и по всему торцу U | Шов по сырому торцу U на участке наложения с доращиванием S |
| CJ-14b | Площади: доращивание S у поздней; ранняя U — точный прямоугольник | Площади: каждая стена — своё тело с доращиванием; ранняя U = прямоугольник + доращивание U |

Остальные тесты (распознавание, пороги, легаси-вершины, габарит, контур, превью, чистота) не меняются. Существующие тесты `wall-geometry.test.ts`, `geometry.test.ts`, `geometry-face-joints.test.ts` не затрагиваются: их проверяемые точки не попадают в доращивание сквозной.
