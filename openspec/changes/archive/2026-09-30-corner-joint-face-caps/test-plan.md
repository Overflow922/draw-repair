# Test Plan: corner-joint-face-caps

## Scope

Проверяется каноническая отображаемая форма стен (`displayPolygons`, `contourSegments`, `hitWall` из `src/wall-geometry.ts`) в угловых стыках, в том числе после поворота одной из стен:
- угловой стык на грани: концы осей дальше `jointTol`, но в пределах `faceCornerTol`;
- угол с общей вершиной осей: легаси и прилипание к торцу.

Интеграционно проверяется цепочка «`moveWalls` → отображение» на замкнутом контуре. `faceCornerTol` проверяется как единый допуск для переноса и отрисовки.

**Фикстура углового стыка на грани.** Толщина 20 (h = 10), тип `brick`.
- Сквозная `S = (0,0)-(200,0)`.
- Упёртая `U = (10,10)-(10,200)`: конец U на верхней грани S, в 10 от торца S. Расстояние между концами 10√2 — диагональ угла.
- **R+**: `S = (0,0)-(200,60)`, поворот ≈16.7°. У нижнего угла торца S выемка, верхний угол выступает за линию наружной грани U (x = 0).
- **R−**: `S = (0,0)-(200,−60)`. Под торцом U просвет. У верхнего угла торца S выемка, нижний угол выступает.
- **Поворот через перенос**: `moveWalls([S,U], [U], {x:0, y:60})`.

**Стороны целевых линий** определяются направлением тел, а не положением концов осей: наружная грань U обращена от тела S, внутренняя грань S обращена к телу U.

**Эталон с принадлежностью (ревизия по test-change-request.md).** Эталон не зависит от реализации. У каждой стены своя форма:
- **сквозная S** — сырой прямоугольник, срезанный по линии наружной грани U, плюс её продолжение до этой линии;
- **упёртая U** — сырой прямоугольник плюс продолжение до линии внутренней грани S.

Ожидаемый владелец точки: формы обеих стен (наложение) — ранняя из пары; форма одной стены — эта стена; иначе никто.

Для общей вершины: ранняя — её сырой прямоугольник; поздняя — сырой прямоугольник, срезанный по линии дальней грани ранней, плюс продолжение до этой линии. Владелец: наложение — ранняя, иначе стена своей формы.
**Выборка.** Сетка с шагом 0.25 см, сдвинутая на 0.0137, в квадрате 40–50 см вокруг стыка. Точки, у которых принадлежность любой из трёх областей меняется при сдвиге границ на ±0.05 см, пропускаются. В каждой оставшейся точке:
- ровно ожидаемый владелец (или никто);
- не более одного куска отображения.

## Invariants

- **Принадлежность** (выборка). Точка с ожидаемым владельцем покрыта ровно им; точка вне эталона не покрыта никем; в точке не больше одного куска.
- **Продолжение торца — у своей стены, наложение — у ранней из пары** (CJ-5, CJ-3b, CJ-12, CJ-5b). Ранняя без стыка на грани — точный прямоугольник: CJ-1, CJ-9, CJ-9b, CJ-14.
- **Срез при любом порядке** (CJ-4). Точка в сыром теле S за линией наружной грани U не покрыта никем.
- **Габарит** (CJ-10). Каждая вершина каждого куска обеих стен лежит в полосе граней S или U и не дальше линии наружной грани U, без исключений.
- **Превью = фиксированная** (CJ-5s) для упёртой и сквозной как превью.
- **Порядок не влияет на объединение** (CJ-6).
- **Чистота** (CJ-15).

## Integration Cases

- **CJ-7.** Замкнутый контур 400×300:
  - `w1 = (0,0)-(400,0)`, `w2 = (400,0)-(400,300)`, `w3 = (400,300)-(0,300)`, `w4 = (10,290)-(10,10)`: два угла с общей вершиной, w4 упирается обоими концами в грани w1 и w3.
  - По очереди каждая стена переносится вдоль своего направления на 40 см. Проверяется, что повернулись ровно две стены и все четыре угла удовлетворяют эталону.
- **CJ-16b.** `moveWalls` поворачивает сквозную при переносе упёртой; угол удовлетворяет эталону.
- **CJ-13 / CJ-13d.** `contourSegments` на R−:
  - однотипные, оба порядка: на линии сырого торца S в части, граничащей с заливкой (параметр 0.1–9.9), и на линии сырого торца U по всей длине (x ∈ [0.1, 19.9]) нет отрезков обводки;
  - разные типы: при S ранней шов по торцу S покрыт обводкой на ≥ 9.7; при U ранней шов по торцу U — на ≥ 18.
- **CJ-5 / CJ-2 / CJ-3 / CJ-5o.** `hitWall` в точке продолжения торца возвращает стену этого торца; в зоне наложения — раннюю из пары.

## Mutation Targets

- Нижняя граница распознавания относительно `jointTol` (CJ-9: общая вершина идёт в свою ветку).
- Верхняя граница `≤ faceCornerTol` (CJ-B1, CJ-B2, CJ-B2b).
- Условие роли «строго внутри (0, len)» (CJ-N1).
- Знак стороны целевой линии: инверсия даёт заливку в пустоту (CJ-10, выборка) или выемку (CJ-2).
- Срез: отсутствие (CJ-4) или срез только у поздней сквозной (CJ-4 при S ранней).
- Продолжение только одного угла торца (выборка R+/R−: выемка у другого угла).
- Порог 15° (CJ-B3) и допуск 0.5° (CJ-14).
- Принадлежность продолжений: у поздней / у ранней / по роли вместо своей стены (CJ-2, CJ-3, CJ-5, выборка); наложение у поздней (CJ-12, CJ-5b); «поздняя» для стены целиком вместо пары (CJ-5b); превью как ранняя (CJ-5s).
- Поздняя не вычитает продолжение ранней партнёра: двойные куски (выборка, CJ-12, CJ-5b). Допуск «обе упёртые»: дыры в поздней (CJ-N3).
- Третий конец проверяется только с одной стороны (CJ-N2).
- Легаси: сдвиг центра (`tSlide`) вместо пересечения по углам (CJ-9, CJ-9b).
- Скрытие шва независимо от типа (CJ-13d) и нескрытие однотипного (CJ-13).

**Реализации, которые пройдут поверхностные проверки, но неверны:**
- Залить треугольник «конец оси — угол — грань», как старый клин: выемка у дальнего угла. Выборка ловит.
- Продолжать углы без среза: зуб. CJ-4, CJ-10.
- Срезать только когда сквозная поздняя: CJ-4 при S ранней.
- Отдавать продолжения поздней стене (старое правило): CJ-2, CJ-3, CJ-5.
