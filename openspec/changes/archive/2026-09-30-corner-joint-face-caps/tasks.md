## 2. Распознавание углового стыка на грани (spec «Замыкание углового стыка на грани», design D2)

- [x] 2.1 Реализовать чистую `faceCornerAt(wall, E, walls)`. Условия:
  - концы дальше `jointTol = max(t)/2`, но в пределах `faceCornerTol`;
  - ни у `E`, ни у конца партнёра нет других концов в пороге `faceCornerTol`, включая концы ближе `jointTol`;
  - угол между осями не меньше 15° от параллели и антипараллели;
  - ровно одна стена упёртая: проекция конца строго внутри длины соседа, у сквозной — за концом упёртой.

  Результат: партнёр, роль и целевая линия. Стороны целевых линий определяются направлением тел: наружная грань упёртой обращена от тела сквозной, внутренняя грань сквозной — к телу упёртой. Тесты: CJ-B1, CJ-B2, CJ-B2b, CJ-B3, CJ-8, CJ-N1, CJ-N2, CJ-N2b, CJ-N3, CJ-9n, CJ-9m, CJ-A.

## 3. Форма стен углового стыка на грани (design D3, D3a, D4)

- [x] 3.1 Доращивание торца `capExtension`: полоса граней за сырым торцом, отсечённая по целевой линии. Выпуклый многоугольник через `clipHalfPlane`, пустые области отбрасываются. В пределах 0.5° прямого угла доращивание и срез не строятся. Тесты: CJ-2, CJ-3, CJ-3b, CJ-14, CJ-14b.
- [x] 3.2 Срез торца сквозной по линии наружной грани упёртой — всегда и при любом порядке в массиве; это единственное изменение формы ранней стены. Тесты: CJ-4, CJ-10, CJ-11, CJ-5, CJ-A.
- [x] 3.3 Принадлежность в `displayPolygons`:
  - стена, поздняя относительно своего партнёра (или превью), получает своё доращивание и доращивание партнёра; доращивание партнёра очищается от её сырого тела;
  - ранняя стена получает только срез;
  - старый треугольный клин для угловых стыков на грани не строится, ветка `wedge` остаётся только для T-примыкания.

  Тесты: CJ-5, CJ-5o, CJ-5h, CJ-5s, CJ-6, CJ-12, выборка CJ-2/3s, существующие JOINT-OBLIQUE-*, HIT-*, JOINT-PREVIEW-1.

- [x] 3.4 Подсветка выделения (spec «Подсветка выделения повторяет форму стены»): заливка всех кусков формы, обводка только внешней границы (`outlineSegments`, общая с `contourSegments`) со скруглёнными стыками. Иначе на острых вершинах заливок обводка `miter` давала шипы за пределы стены, а на границах между телом и заливками — тёмные полосы (найдено при проверке в браузере, `img_4.png`).

- [x] 3.5 Ревизия принадлежности (`test-change-request.md`): продолжение торца — у своей стены при любом порядке; поздняя из пары (решение по каждой паре) не отображается внутри продолжения ранней — `subtractConvex` через общий `subtractPlanes` с `subtractBody`. Подсветка больше не захватывает клин соседней стены. Тесты: CJ-2, CJ-3, CJ-5, CJ-5o, CJ-5b, CJ-12, CJ-13d, CJ-13t, CJ-14b, CJ-N3; повторная валидация — PASS.
