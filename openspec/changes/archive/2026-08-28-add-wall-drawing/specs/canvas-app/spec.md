## Purpose

Оболочка браузерного приложения для черчения: область холста и вертикальная панель инструментов слева, в которую добавляются инструменты рисования.

## ADDED Requirements

### Requirement: Панель инструментов слева
Приложение ДОЛЖНО отображать вертикальную панель инструментов в левой части окна рядом с областью холста.

#### Scenario: Открытие приложения
- **WHEN** пользователь открывает приложение в браузере
- **THEN** слева от области рисования отображается вертикальная панель инструментов

### Requirement: Выбор активного инструмента
Панель инструментов ДОЛЖНА содержать кнопки инструментов; активный инструмент ДОЛЖЕН быть визуально выделен.

#### Scenario: Переключение инструмента
- **WHEN** пользователь нажимает кнопку инструмента на панели
- **THEN** инструмент становится активным, его кнопка визуально выделена, и поведение указателя на холсте соответствует выбранному инструменту

### Requirement: Область холста
Основную область окна рядом с панелью ДОЛЖЕН занимать холст, на котором активный инструмент создаёт графические элементы.

#### Scenario: Холст доступен для инструментов
- **WHEN** активен любой инструмент рисования
- **THEN** его действия выполняются на холсте в основной области окна
