## Purpose

Удаление нарисованных стен двумя способами: клавишей Delete на выделенной стене и инструментом «Ластик» для серийного удаления; включает явные состояния инструментов, hover-подсветку и запись удалений в undo/redo.

## ADDED Requirements

### Requirement: Удаление выделенной стены клавишей Delete
Нажатие Delete при выделенной стене ДОЛЖНО удалять её независимо от активного инструмента. Если фокус находится в поле ввода (поле длины, поле толщины, поле переименования вкладки), Delete НЕ ДОЛЖЕН удалять стены. После удаления выделение ДОЛЖНО сниматься, поле длины ДОЛЖНО очищаться. Удаление ДОЛЖНО записываться в историю: отмена (undo) ДОЛЖНА возвращать стену в исходное положение, повтор (redo) — снова её удалять.

#### Scenario: Delete удаляет выделенную стену
- **WHEN** стена выделена и пользователь нажимает Delete
- **THEN** стена удаляется с холста, выделение снимается, поле длины очищается

#### Scenario: Delete при фокусе в поле ввода не удаляет
- **WHEN** стена выделена, фокус находится в поле длины (или толщины, или переименования вкладки), и пользователь нажимает Delete
- **THEN** стены не удаляются, редактируется текст поля

#### Scenario: Undo возвращает удалённую стену
- **WHEN** стена удалена клавишей Delete и пользователь отменяет действие
- **THEN** стена возвращается в исходное положение с прежними толщиной и типом

#### Scenario: Redo повторяет удаление
- **WHEN** удаление отменено и пользователь повторяет действие
- **THEN** стена снова удаляется

### Requirement: Инструмент «Ластик»
Тулбар ДОЛЖЕН содержать кнопку инструмента «Ластик» рядом с кнопкой «Стена». Активация ластика ДОЛЖНА прерывать рисуемую цепочку, снимать выделение и закрывать панель параметров стены. Клик по стене при активном ластике ДОЛЖЕН удалять её; клик по пустому месту НЕ ДОЛЖЕН начинать цепочку или выделение. Ластик ДОЛЖЕН оставаться активным до явного переключения на другой инструмент, позволяя удалять несколько стен подряд. Стена под курсором при активном ластике ДОЛЖНА подсвечиваться красным контуром по тому же контуру, что и обводка выделения. Курсор канваса при активном ластике ДОЛЖЕН отличаться от обычного. Удаление ластиком ДОЛЖНО записываться в историю undo/redo.

#### Scenario: Клик ластиком удаляет стену
- **WHEN** ластик активен и пользователь кликает по существующей стене
- **THEN** стена удаляется, ластик остаётся активным

#### Scenario: Серия удалений без перетыкания
- **WHEN** ластик активен и пользователь кликает по нескольким стенам подряд
- **THEN** каждая кликнутая стена удаляется, инструмент не деактивируется

#### Scenario: Подсветка стены под курсором
- **WHEN** ластик активен и курсор находится над стеной
- **THEN** стена подсвечивается красным контуром; после ухода курсора подсветка исчезает

#### Scenario: Активация ластика зачищает состояние
- **WHEN** рисуется цепочка и/или стена выделена, и пользователь активирует ластик
- **THEN** цепочка прерывается, выделение снимается, панель параметров стены закрывается

#### Scenario: Клик по пустому месту ластиком
- **WHEN** ластик активен и пользователь кликает по пустому месту холста
- **THEN** ничего не происходит: цепочка не начинается, выделение не появляется

#### Scenario: Escape деактивирует ластик
- **WHEN** ластик активен и пользователь нажимает Esc
- **THEN** ластик деактивируется, инструмент «Стена» НЕ включается автоматически; подсветка и курсор ластика исчезают

#### Scenario: Undo возвращает стену, удалённую ластиком
- **WHEN** стена удалена ластиком и пользователь отменяет действие
- **THEN** стена возвращается в исходное положение с прежними толщиной и типом

### Requirement: Состояния инструментов
Приложение ДОЛЖНО различать три состояния инструмента: «Стена» (стартовое), «Ластик» и «Без инструмента». Активная кнопка инструмента ДОЛЖНА отображаться визуально. Клик по пустому месту ДОЛЖЕН начинать цепочку только в состоянии «Стена». Выделение, перетаскивание концов и перемещение стен ДОЛЖНЫ работать в состояниях «Стена» и «Без инструмента». Кнопки инструментов ДОЛЖНЫ переключать состояние напрямую: из любого состояния в «Стену» и из любого — в «Ластик»; из «Ластика» Escape ДОЛЖЕН переводить в «Без инструмента».

#### Scenario: Стартовое состояние
- **WHEN** приложение открыто или вкладка активирована
- **THEN** активен инструмент «Стена», клик по пустому месту начинает цепочку

#### Scenario: Выделение доступно без инструмента
- **WHEN** состояние «Без инструмента» и пользователь кликает по стене
- **THEN** стена выделяется, маркеры доступны для перетаскивания

#### Scenario: Цепочка не начинается без инструмента «Стена»
- **WHEN** состояние «Без инструмента» или «Ластик» и пользователь кликает по пустому месту
- **THEN** цепочка не начинается

#### Scenario: Переключение кнопками из любого состояния
- **WHEN** из состояния «Без инструмента» пользователь нажимает кнопку «Стена» или «Ластик»
- **THEN** соответствующий инструмент активируется и отображается как активный
