## MODIFIED Requirements

### Requirement: Выделение стены
Вне рисования цепочки и вне активного ластика клик по существующей стене ДОЛЖЕН выделять её; клик по другой стене ДОЛЖЕН переносить выделение на неё. При активном ластике клик по стене ДОЛЖЕН удалять её вместо выделения (см. `wall-deletion`), а активация ластика ДОЛЖНА снимать выделение. Клик по пустому месту ДОЛЖЕН снимать выделение; начинать новую цепочку он ДОЛЖЕН только при активном инструменте «Стена». Esc ДОЛЖЕН снимать выделение, если цепочка не рисуется. Во время рисования цепочки клики ДОЛЖНЫ продолжать цепочку и НЕ ДОЛЖНЫ выделять стены.

#### Scenario: Выделение кликом по стене
- **WHEN** ластик не активен, цепочка не рисуется и пользователь кликает по существующей стене
- **THEN** стена выделяется, цепочка не начинается

#### Scenario: Перенос выделения
- **WHEN** стена выделена и пользователь кликает по другой стене (ластик не активен)
- **THEN** выделение переходит на вторую стену

#### Scenario: Клик по пустому месту
- **WHEN** стена выделена, активен инструмент «Стена», и пользователь кликает по пустому месту холста
- **THEN** выделение снимается и начинается новая цепочка

#### Scenario: Клик по пустому месту вне инструмента «Стена»
- **WHEN** стена выделена, активен ластик или состояние «Без инструмента», и пользователь кликает по пустому месту холста
- **THEN** выделение снимается, новая цепочка не начинается

#### Scenario: Активация ластика снимает выделение
- **WHEN** стена выделена и пользователь активирует ластик
- **THEN** выделение снимается, панель параметров стены закрывается

#### Scenario: Ластик удаляет вместо выделения
- **WHEN** ластик активен и пользователь кликает по существующей стене
- **THEN** стена удаляется, выделение не появляется

#### Scenario: Esc снимает выделение
- **WHEN** стена выделена, цепочка не рисуется, и пользователь нажимает Esc
- **THEN** выделение снимается

#### Scenario: Клик во время цепочки не выделяет
- **WHEN** цепочка начата и пользователь кликает по существующей стене
- **THEN** вершина цепочки фиксируется с привязкой к стене, выделение не появляется
