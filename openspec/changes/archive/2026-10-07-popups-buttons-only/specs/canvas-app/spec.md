## MODIFIED Requirements

### Requirement: Вспомогательная панель инструмента
Вспомогательная панель инструмента — блок правее кнопки инструмента на панели инструментов. Панель ДОЛЖНА содержать только кнопки: выбор инструмента группы, образцы материалов. Поля ввода, списки, подписи значений и другие элементы, кроме кнопок, в панели НЕ ДОЛЖНЫ находиться; числовые параметры объектов правятся на холсте (`doorway` «Ввод чисел размеров проёма», `window` «Правка подписи окна»). Исключение — поле толщины в панели «Стена» (`wall-drawing` «Толщина стены»).

Панель ДОЛЖНЫ иметь только кнопка «Стена» (образцы материалов и поле толщины) и кнопка группы «Проёмы» (требование «Панель группы «Проёмы»»). Кнопки «Окно», «Размер», «Линейка» и «Ластик» панели НЕ ДОЛЖНЫ иметь: клик по такой кнопке ДОЛЖЕН только делать инструмент активным, повторный клик по кнопке активного инструмента ничего не меняет.

Клик по кнопке инструмента с панелью ДОЛЖЕН переключать видимость его панели. Выделение стены ДОЛЖНО открывать закрытую панель инструмента «Стена». Выделение элемента стены, размера или нескольких объектов НЕ ДОЛЖНО открывать никакую панель. Снятие выделения НЕ ДОЛЖНО менять видимость панели.

#### Scenario: Переключение по клику
- **WHEN** пользователь нажимает кнопку «Стена»
- **THEN** вспомогательная панель открывается; повторное нажатие закрывает её

#### Scenario: Открытие при выборе инструмента
- **WHEN** активен другой инструмент и пользователь нажимает кнопку «Стена»
- **THEN** «Стена» становится активным инструментом и её вспомогательная панель открывается с первого нажатия

#### Scenario: Авто-открытие при выделении
- **WHEN** панель закрыта и пользователь выделяет стену кликом
- **THEN** панель открывается, значения толщины и типа показывают параметры выделенной стены

#### Scenario: Ручное закрытие при выделенной стене
- **WHEN** стена выделена и пользователь закрывает панель кликом по кнопке
- **THEN** панель остаётся закрытой, пока не произойдёт новое выделение стены

#### Scenario: Сохранение при снятии выделения
- **WHEN** панель открыта и выделение снимается (Esc, клик мимо, окончание цепочки)
- **THEN** панель остаётся открытой

#### Scenario: Инструменты без панели
- **WHEN** пользователь нажимает кнопку «Окно», «Размер», «Линейка» или «Ластик», затем нажимает её ещё раз
- **THEN** инструмент становится активным; ни после первого, ни после второго нажатия никакая вспомогательная панель не открыта, инструмент остаётся активным

#### Scenario: Выделение элемента или размера не открывает панель
- **WHEN** все вспомогательные панели закрыты, и пользователь выделяет кликом проём, дверь, окно или размер
- **THEN** ни одна вспомогательная панель не открыта

#### Scenario: Панели не содержат полей
- **WHEN** открыта панель группы «Проёмы» при любом текущем инструменте группы
- **THEN** в панели нет полей ввода и других элементов, кроме кнопок

### Requirement: Группы инструментов
Кнопки панели инструментов ДОЛЖНЫ идти тремя группами сверху вниз: инструменты построения («Стена», кнопка группы «Проёмы», «Окно»), инструменты измерения («Размер», «Линейка»), затем «Ластик». Между соседними группами ДОЛЖЕН отображаться разделитель. Инструменты «Проём» и «Дверь» НЕ ДОЛЖНЫ иметь собственных кнопок на панели инструментов: они выбираются в панели группы «Проёмы» (требование «Панель группы «Проёмы»»).

#### Scenario: Порядок кнопок
- **WHEN** пользователь открывает приложение
- **THEN** кнопки идут сверху вниз: «Стена», «Проёмы», «Окно», разделитель, «Размер», «Линейка», разделитель, «Ластик»; отдельных кнопок «Проём» и «Дверь» на панели нет

## REMOVED Requirements

### Requirement: Группа «Проёмы»
**Reason**: Панель группы больше не содержит параметров инструментов, а выделение элемента не открывает её и не меняет текущий инструмент группы; прежние сценарии описывают удаляемое поведение.
**Migration**: Требование «Панель группы «Проёмы»»: та же кнопка группы и выбор «Проём» / «Дверь», без полей и без реакции на выделение.

## ADDED Requirements

### Requirement: Панель группы «Проёмы»
Кнопка группы «Проёмы» ДОЛЖНА иметь собственную иконку в стиле остальных иконок панели (вид сбоку) и вспомогательную панель по требованию «Вспомогательная панель инструмента». Панель группы ДОЛЖНА содержать только кнопки инструментов «Проём» и «Дверь» в этом порядке. Кнопка текущего инструмента группы ДОЛЖНА быть визуально выделена. По умолчанию текущий инструмент группы — «Проём».

Клик по кнопке группы ДОЛЖЕН вести себя как клик по кнопке инструмента, где инструмент — текущий инструмент группы: если активен другой инструмент, текущий инструмент группы становится активным и панель группы открывается с первого нажатия; если он уже активен, клик переключает видимость панели. Кнопка группы ДОЛЖНА быть визуально выделена как активная, когда активен любой инструмент группы. Клик по кнопке инструмента в панели группы ДОЛЖЕН делать этот инструмент текущим инструментом группы и активным инструментом; панель при этом ДОЛЖНА оставаться открытой. Выделение проёма или двери НЕ ДОЛЖНО менять текущий инструмент группы, видимость панели группы и активный инструмент.

#### Scenario: Панель группы содержит инструменты
- **WHEN** пользователь нажал кнопку «Проёмы»
- **THEN** активен инструмент «Проём», панель группы открыта, в ней только кнопки «Проём» (выделена) и «Дверь»

#### Scenario: Выбор двери в панели группы
- **WHEN** панель группы открыта, и пользователь нажал в ней кнопку «Дверь»
- **THEN** активен инструмент «Дверь», кнопка «Дверь» выделена, панель открыта и содержит только кнопки «Проём» и «Дверь»; кнопка «Проёмы» выделена как активная

#### Scenario: Кнопка группы помнит последний инструмент
- **WHEN** пользователь выбрал в панели группы «Дверь», затем выбрал инструмент «Стена», затем нажал кнопку «Проёмы»
- **THEN** активен инструмент «Дверь», панель группы открыта

#### Scenario: Повторный клик закрывает панель группы
- **WHEN** активен инструмент «Дверь», панель группы открыта, и пользователь нажал кнопку «Проёмы»
- **THEN** панель группы закрыта, инструмент «Дверь» остаётся активным

#### Scenario: Выделение двери не трогает группу
- **WHEN** активен инструмент «Стена», текущий инструмент группы — «Проём», панель группы закрыта, и пользователь выделил дверь кликом
- **THEN** панель группы закрыта, текущий инструмент группы — «Проём», активным остаётся инструмент «Стена»
