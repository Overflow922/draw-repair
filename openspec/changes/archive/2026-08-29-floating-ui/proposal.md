## Why

Интерфейс прибит к краям окна: панель инструментов тянется на всю высоту с рамкой до границ окна, полоса вкладок — на всю ширину. Толщина и тип стен занимают тулбар постоянно, хотя нужны только при работе со стенами. Нужны компактные «парящие» блоки поверх полноэкранного чертежа и переносимый механизм вспомогательных панелей инструментов — фундамент для будущих инструментов.

## What Changes

- Холст становится полноэкранным (занимает всё окно); блоки интерфейса — плавающими островами поверх него.
- Общий стиль острова (`.panel`) — белый фон, рамка, скруглённые углы, тень, отступ 12px от краёв окна — по рецепту существующего `#size-box`.
- Полоса вкладок становится парящим островом сверху; поведение вкладок (создание, переключение, переименование, закрытие) не меняется.
- Панель инструментов становится компактным парящим островом слева, кнопки — по центру вертикали окна, 12px от левого края.
- Кнопка инструмента может открывать вспомогательную панель правее себя (toggle по клику). Для инструмента «Стена» в панель переезжают толщина и тип стен; логика редактирования сохраняется (выделена стена — её параметры, иначе — значения по умолчанию для новых стен).
- Подпанель «Стены» открывается автоматически при выделении стены; при снятии выделения остаётся в текущем состоянии (не закрывается принудительно).
- Переключение типа стен стрелками ↑/↓ работает независимо от видимости подпанели.
- Вне скоупа: удаление элементов чертежа.

### New Capabilities

(нет)

### Modified Capabilities

- `canvas-app`: раскладка оболочки — полноэкранный холст, плавающие острова (вкладки, инструменты, нижняя панель) с отступами и скруглениями; новое требование о вспомогательной панели инструмента (toggle, авто-открытие при выделении, сохранение при снятии).
- `wall-types`: выбор типа стены переносится из тулбара во вспомогательную панель инструмента «Стена»; выбор образцом, стрелки и правило перекраски выделенной стены — без изменений.

## Impact

- `index.html` / `src/style.css`: новая структура блоков (полноэкранный холст, острова, подпанель), общий стиль `.panel`.
- `src/main.ts`: точечные правки — toggle-логика подпанели, авто-открытие при выделении, те же id элементов.
- `src/render.ts`, `src/geometry.ts`, `src/history.ts`, `src/storage.ts` и их тесты не затрагиваются; проверка — в браузере.
