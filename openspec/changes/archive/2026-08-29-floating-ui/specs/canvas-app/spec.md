## MODIFIED Requirements

### Requirement: Панель инструментов слева
Приложение ДОЛЖНО отображать вертикальную панель инструментов как плавающий остров в левой части окна поверх холста: компактный блок с отступом 12px от левого края окна; кнопки инструментов ДОЛЖНЫ быть выровнены по центру вертикали окна.

#### Scenario: Открытие приложения
- **WHEN** пользователь открывает приложение в браузере
- **THEN** слева поверх холста отображается компактный вертикальный остров инструментов с отступом от левого края, а его кнопки выровнены по центру вертикали окна

### Requirement: Область холста
Холст ДОЛЖЕН занимать всё окно; блоки интерфейса ДОЛЖНЫ располагаться поверх холста. Активный инструмент создаёт графические элементы на холсте.

#### Scenario: Холст доступен для инструментов
- **WHEN** активен любой инструмент рисования
- **THEN** его действия выполняются на холсте

#### Scenario: Блоки интерфейса не создают элементов
- **WHEN** пользователь нажимает на блок интерфейса (вкладки, панель инструментов, вспомогательную или нижнюю панель)
- **THEN** на холсте не создаётся элементов и выделение не меняется

## ADDED Requirements

### Requirement: Плавающие блоки интерфейса
Все блоки интерфейса (полоса вкладок, панель инструментов, вспомогательные панели инструментов, нижняя панель управления) ДОЛЖНЫ отображаться плавающими островами поверх холста с отступом 12px от соответствующих краёв окна. Границы блока ДОЛЖНЫ заканчиваться на границе его содержимого, не доходя до границ окна; углы блоков ДОЛЖНЫ быть скруглены.

#### Scenario: Вкладки — остров
- **WHEN** пользователь открывает приложение
- **THEN** полоса вкладок отображается компактным островом сверху с отступом от края окна, а не полосой на всю ширину

#### Scenario: Нижняя панель — остров
- **WHEN** пользователь открывает приложение
- **THEN** нижняя панель управления отображается островом с отступом 12px от нижнего края окна

### Requirement: Вспомогательная панель инструмента
Кнопка инструмента ДОЛЖНА иметь вспомогательную панель, расположенную правее кнопки и содержащую параметры инструмента. Клик по кнопке инструмента ДОЛЖЕН переключать видимость его панели. Выделение стены ДОЛЖНО открывать закрытую панель инструмента «Стена». Снятие выделения НЕ ДОЛЖНО менять видимость панели.

#### Scenario: Переключение по клику
- **WHEN** пользователь нажимает кнопку «Стена»
- **THEN** вспомогательная панель открывается; повторное нажатие закрывает её

#### Scenario: Авто-открытие при выделении
- **WHEN** панель закрыта и пользователь выделяет стену кликом
- **THEN** панель открывается, значения толщины и типа показывают параметры выделенной стены

#### Scenario: Ручное закрытие при выделенной стене
- **WHEN** стена выделена и пользователь закрывает панель кликом по кнопке
- **THEN** панель остаётся закрытой, пока не произойдёт новое выделение стены

#### Scenario: Сохранение при снятии выделения
- **WHEN** панель открыта и выделение снимается (Esc, клик мимо, окончание цепочки)
- **THEN** панель остаётся открытой
