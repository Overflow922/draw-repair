## MODIFIED Requirements

### Requirement: Выбор типа стены
Выбор типа стены цветными образцами: «Несущая», «Перегородка», «Гипрок» ДОЛЖЕН находиться во вспомогательной панели инструмента «Стена»; активный тип ДОЛЖЕН быть визуально выделен; по умолчанию ДОЛЖЕН быть выбран тип «Перегородка». Тип применяется к новым стенам. Стрелки вверх/вниз ДОЛЖНЫ переключать тип (вверх — предыдущий, вниз — следующий, с зацикливанием) независимо от видимости вспомогательной панели; в поле толщины стрелки ДОЛЖНЫ сохранять нативное поведение.

#### Scenario: Выбор образцом
- **WHEN** пользователь нажимает образец типа во вспомогательной панели
- **THEN** тип становится активным (образец выделен), новые стены и превью рисуются цветом этого типа

#### Scenario: Выбор стрелками
- **WHEN** пользователь нажимает стрелку вниз (или вверх)
- **THEN** активным становится следующий (предыдущий) тип по списку с зацикливанием, превью и новые стены меняют цвет

#### Scenario: Выбор стрелками при закрытой панели
- **WHEN** вспомогательная панель «Стены» закрыта и пользователь нажимает стрелку вниз (или вверх)
- **THEN** активным становится следующий (предыдущий) тип, панель остаётся закрытой, следующая стена рисуется новым цветом

#### Scenario: Стрелки в поле толщины
- **WHEN** поле толщины в фокусе и нажимается стрелка вверх/вниз
- **THEN** тип стены не переключается, значение толщины меняется нативным степпером

#### Scenario: Дефолтный тип
- **WHEN** приложение открыто
- **THEN** активен тип «Перегородка»
