# Test Plan

## Scope

Поведение изменения `demolition-plan`: спецификации `demolition-plan` (новая), `drawing-plans`, `drawing-storage`, `drawing-history`, `pdf-export` (дельты); решения D0–D11 в `design.md`.

Автоматизируются чистые модули (в проекте нет DOM-стенда):

- `src/plans.ts` — каталог, `toolsOf`, `defaultToolOf`;
- `src/demolition/marks.ts`, `mark-region.ts`, `mark-snap.ts`, `mark-numbers.ts`, `mark-follow.ts` — домен;
- `src/storage.ts`, `src/history.ts` — пометки в документе и история пометок;
- `src/demolition/demolition-render.ts` — отрисовка в записывающий контекст канваса;
- `src/export/pdf.ts` — страница демонтажа;
- `src/demolition/demolition-tool.ts` — жесты инструмента через `DemolitionToolHost` с подставными зависимостями (DOM-редактор числа не тестируется; применение числа — `editNumber`).

Интеграция в `main.ts`, `index.html`, `style.css` проверяется вручную в браузере (раздел «Ручные проверки»).

Регрессия: весь существующий набор тестов остаётся зелёным; единственные допустимые правки существующих тестов — запросы на изменение ниже.

Тестовые утилиты: новые тесты используют существующие (`pdf-ops.test-utils.ts`, `doorway.test-utils.ts` `recorder`) без правок; разбор цвета операторов PDF (`RG`/`rg`) — в новом файле `src/export/pdf-colors.test-utils.ts`.

Новые файлы тестов: `src/plan-tools.test.ts`, `src/demolition/marks.test.ts`, `mark-region.test.ts`, `mark-snap.test.ts`, `mark-numbers.test.ts`, `mark-follow.test.ts`, `mark-storage.test.ts`, `mark-history.test.ts`, `demolition-render.test.ts`, `demolition-pdf.test.ts`, `demolition-tool.test.ts`.

## Invariants

- Входные массивы и объекты (`marks`, `walls`, `elements`) не мутируются ни одной функцией домена.
- После `addMark`/`editNumber`/`mergeAll` участки одной стены не пересекаются и не соприкасаются (расстояние между соседними > 0,01 см); у каждой пометки `0 ≤ from < to ≤ len`, ширина ≥ 1 см у пометок, созданных `addMark`/`editNumber`.
- `effectiveMarks` — подсписок хранимых пометок (по стене/материалу/длине) с обрезкой; не меняет список.
- Для действующей пометки `span` в координатах от конца `a` не зависит от конца привязки: одна и та же область при `anchor: "a"` и эквивалентной записи с `anchor: "b"`.
- `addMark` идемпотентен: повторная пометка того же участка не меняет список.
- `reanchorMarks` не меняет область сноса пометок в мире (область до слияния равна области после, пока стена не сместилась).
- Обмерочный план не меняется демонтажем; история обмерочного плана и история демонтажа независимы (разные ключи `historyKey`).
- `toolsOf(plan)` содержит `defaultToolOf(plan)`; инструменты `measure` и `demolition` пересекаются только по `ruler`.
- Формат документа хранилища остаётся версии 3, истории — 2.

## Mutation Targets

Проект не имеет инструмента мутационного тестирования; валидатор проверяет ручными мутациями:

- `canDemolish` пропускает `reinforced`; `effectiveMarks` не отфильтровывает `reinforced`/отсутствующие стены/нулевую ширину; сравнение `> EPS` ↔ `>= EPS` — DM-06, DM-07, DM-11, DM-12.
- `addMark` не сливает соприкасающиеся (`<` вместо `<=` по зазору), сливает с участками другой стены, теряет идентификатор, не нормализует якорь, не отклоняет ширину < 1 — DM-02 … DM-04, DM-13 … DM-16, DM-19.
- `span` для `anchor: "b"` без инверсии — DM-02, FL-02.
- `markRegion` не обрезает по плоскостям / обрезает у `from = 0` и `to = len` (теряет торцевые части) / перепутаны концы — RG-01 … RG-04.
- `hiddenElements`: касание считается пересечением / частичное перекрытие не скрывает / учитывает чужую стену / `jambsT` для `anchor: "b"` — RG-05 … RG-08.
- `alongNodes` без откосов / без границ чужих стен / без концов; `snapAlong` с `<` вместо `<=` в радиусе, без округления, без зажима — ND-01 … ND-06.
- `editNumber`: перепутаны `gapA`/`gapB`; ширина сохраняет конец вместо начала; нет зажима; не отклоняет ширину < 1 и NaN; не сливает; теряет id — NU-01 … NU-07.
- `markNumberLayout`: числа не на стороне нормали, центры перепутаны, невыделенная показывает три числа — NU-09, NU-10.
- `reanchorMarks`: не переносит привязку / переносит у неподвижного конца / путает концы — FL-04, FL-05, FL-06.
- Хранение: пропуск валидации, отсутствие отбрасывания по стене, слияние не выполняется, поле добавляется при отсутствии — ST-02 … ST-05.
- История: `undoMarks` не кладёт обратный снимок в повтор, не срезает ветку повтора, лимит, ключ без суффикса — HI-01 … HI-04.
- Отрисовка: подложка не серая / с размерами / с подписью площади, область не закрашена бумагой, штриховка 45° вместо 135°, цвет не красный, подпись ширины пропущена, скрытые элементы рисуются — RN-01 … RN-05.
- PDF: вторая страница без красного / с сеткой / с размерами; первая страница получает красное; габариты считаются по пометкам вместо стен — PG-02 … PG-08.
- Инструмент: клик по пометке не снимает / помечает вместо снятия, протяжка не проецируется, мёртвая зона `<` ↔ `<=`, нет Escape, шаг истории при отсутствии изменений, пометка железобетона записывает шаг — TL-01 … TL-13.
- `toolsOf`: наборы перепутаны / `defaultToolOf` не из набора — PT-02, PT-03.
