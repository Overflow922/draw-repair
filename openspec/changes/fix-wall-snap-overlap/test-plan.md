# Test Plan

## Scope

Поведение привязки вершины и квадрата установки в инструменте «Стена» по дельте
`specs/wall-drawing/spec.md`:

- `snapVertex(p, walls, radiusCm, gridStepCm, newThicknessCm, orthoFrom?)` —
  результат `{point, source}` и неперечислимая `normal` в многостенных сценах и при
  разных масштабах;
- `placementSquare(snap, sizeCm)` — форма и ориентация квадрата (design D6);
- `wallClickAction(raw, snap, walls, toleranceCm)` — выделить или рисовать
  (design D7);
- инвариант «квадрат не налагается на тела стен» — проверка свойства на сетке
  положений курсора.

Все тесты юнит-тесты `vitest` на чистые функции. Новые тесты импортируют API из
`./wall-snap`; утверждённые тесты продолжают импортировать `snapVertex` и
`snapRadiusCm` из `./wall-geometry` (реэкспорт, design D8).

### Соглашения

- `R(z) = snapRadiusCm(z)`: 6 см при `z = 1`, 24 см при `z = 0.25`, 1.5 см при
  `z = 4`. Шаг сетки `GRID = 10`. Толщина новой стены 20 (`h = 10`), если не
  указано иное.
- Сцены (все стены толщиной 20, если не указано иное):
  - **L**: `A = (0,0)→(300,0)`, `B = (0,0)→(0,300)`; внутренний угол (10,10),
    наружный (−10,−10);
  - **T**: `A = (0,0)→(300,0)`, `C = (150,10)→(150,200)` — торец C на верхней
    грани A; открытые участки верхней грани A: x ∈ [0,140] и [160,300];
  - **S**: одиночная `W = (0,0)→(100,0)`;
  - **N** (нет места): `A = (0,0)→(300,0)`, `C1 = (100,10)→(100,200)`,
    `C2 = (125,10)→(125,200)`; просвет на грани A x ∈ [110,115] — 5 см;
  - **LX** (разные толщины): `A = (0,0)→(300,0)` 20 см, `B = (0,0)→(0,300)` 40 см;
    внутренний угол (20,10);
  - **ACUTE**: `A = (0,0)→(300,0)`, `D = (0,0)→(150, 150·√3)` — угол 60°;
  - **DIAG**: `G = (0,0)→(100,100)`.
- Проверка «наложения нет» в тестах: площадь пересечения квадрата с каждым
  куском `displayPolygons` каждой стены ≤ 1e-6 (тестовая утилита — отсечение
  выпуклого многоугольника, независимая от продакшн-кода).
- `normal` читается напрямую (`r.normal`), она неперечислима и в `toEqual` не
  участвует.

## Invariants

- **INV-NOOVERLAP-1**: сцена `L ∪ T` со смещением и свободными торцами
  (L в начале координат, T сдвинута на (600,0)); курсор проходит сетку с шагом
  2 см по окрестности стен (bbox всех стен + 30 см); масштабы 0.25, 1, 4; толщины
  новой стены 10, 20, 40. Для каждого результата с `source = "wall"`:
  1) пересечение `placementSquare(r, t)` с каждым куском `displayPolygons` ≤ 1e-6;
  2) `r.point` не лежит строго внутри ни одного куска;
  3) `r.normal` определена, единичная.
  Дополнительно: хотя бы в N позициях прилипание есть (защита от тривиальной
  реализации «никогда не прилипать»): не менее 25 % позиций в полосе reach
  вокруг граней дают `source = "wall"`.
- **INV-DET-1**: повторный вызов в той же точке после вызовов в других точках даёт
  тот же результат (включая `normal`) на сцене L при z = 0.25.
- **INV-PURE-2**: `snapVertex`, `placementSquare`, `wallClickAction` не мутируют
  глубоко замороженные входы (сцены L и T).
- **INV-SHAPE-1**: результат `snapVertex` сравнивается `toEqual({point, source})` —
  `normal` не перечисляется (совместимость с утверждёнными тестами).
- Утверждённые тесты `wall-geometry.test.ts` (кроме пересматриваемого SNAP-DET-2),
  `geometry-face-joints.test.ts` (FJ-3i, FJ-T1) и все остальные наборы проходят
  без изменений.

## Integration Cases

Автотестов для `main.ts`/`render.ts` нет (e2e не настроены); проверяется вручную
в браузере на этапе verify (dev-сервер, путь `/draw-repair/`):

- до первого клика квадрат у внутреннего угла L стоит вплотную к обеим стенам;
- квадрат у диагональной стены повёрнут по грани;
- квадрат у свободного торца снаружи плоскости торца;
- клик по квадрату у свободного торца при отдалённом виде начинает стену, клик в
  тело у торца / у стыка выделяет стену;
- второй конец резиновой линии не прилипает к точке стыка;
- размер квадрата следует за толщиной; в инструментах «Размер»/ластик квадрата
  нет (регрессия).

Проверка, что `main.ts` действительно использует `placementSquare` и
`wallClickAction` (а не собственную логику), — в код-ревью.

(дальняя грань A). Без D4 результат — сетка `(50,0)` внутри тела.

## Пересматриваемые утверждённые тесты

| Тест | Причина | Замена |
|---|---|---|
| SNAP-DET-2 (`wall-geometry.test.ts`) | Сцена с зазором 4 см противоречит требованию «Квадрат не налагается на тела стен»: квадрат 20 см у грани первой стены налагается на вторую | SNAP-DET-2R — тот же тай-брейк по порядку массива на сцене с зазором 20 см (касание по стороне) |

Прочие утверждённые тесты не меняются. Если прогон эталонной реализации на
этапе test-validation покажет расхождение с каким-либо ещё утверждённым тестом,
это оформляется как test-change-request с обоснованием по спецификации.

## Out of Scope

- Форма стыка при подходе второго конца к грани под произвольным углом.
- Перетаскивание концов и перемещение стен (`snap`, `snapOthers` в `geometry.ts`).
- Привязка инструмента «Размер».
- Дальность коллинеарного продолжения вдоль оси за торцом (существующее
  поведение).
- Производительность (нагрузочные тесты не пишутся).
