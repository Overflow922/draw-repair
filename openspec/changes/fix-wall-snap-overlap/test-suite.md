## Coverage

### Happy paths

- Грань вплотную к соседу у внутреннего угла и T-примыкания: SNAP-IN-1/2,
  SNAP-T-STOP-1/2.
- Продолжение за наружный угол: SNAP-OUT-1/2.
- Продолжение от свободного торца с нормалью: SNAP-CAP-N1, SQ-CAP-1.
- Ориентация квадрата: SQ-FACE-1, SQ-CAP-1, SQ-DIAG-1, SQ-FREE-1, SQ-SIZE-1.
- Клик: CLICK-BODY-1, CLICK-SQ-1/2, CLICK-EMPTY-1.

### Boundary cases

- Сжатие у вогнутой вершины включительно: SNAP-IN-3 (19/20 → 20).
- Сжатие у выпуклой вершины: SNAP-OUT-1 (−15,0), SNAP-END-5.
- Разные толщины (новая тоньше и толще соседа): SNAP-IN-THICK-1.
- Масштаб, при котором R = h (z = 0.6), и крайние 0.25 / 4: SNAP-SCALE-2.
- Граница полосы при R > h (ровно h и h + 0.001): SNAP-SCALE-3.
- Просвет ровно равен стороне квадрата / на 2 см короче: SNAP-FIT-1.
- Зазор между параллельными стенами ровно в сторону квадрата (касание):
  SNAP-DET-2R.
- Острый угол 60° (cot θ): SNAP-ACUTE-1.

### Negative cases

- Точка оси стыка не цель: SNAP-JOINT-1/2, SNAP-CHAIN-1.
- Закрытый торец не даёт продолжения: SNAP-CAP-CLOSED-1.
- Нет места — нет прилипания; кандидат с наложением на несмежную стену
  отброшен: SNAP-NOROOM-1, SNAP-FIT-1.
- Нет прилипания «углом к углу»: SNAP-OUT-3.
- Клик в тело у торца/стыка не рисует: CLICK-BODY-1, CLICK-JOINT-1.

### Invariants

- Нулевая площадь наложения квадрата, вершина не строго внутри тела, единичная
  нормаль у каждого прилипшего результата — сетка курсоров (шаг 3 см, 7 окон
  60×60 см), масштабы 0.25/1/4, толщины 10/20/40: INV-NOOVERLAP-1; острый угол:
  SNAP-ACUTE-1. Защита от «никогда не прилипать»: доля прилипаний ≥ 25 % и
  `stuckToA > 0`.
- Детерминированность с нормалью: SNAP-DET-3, SNAP-DET-2R, SNAP-IN-1.
- Форма результата `{point, source}` + неперечислимая `normal`: INV-SHAPE-1.
- Чистота: INV-PURE-2, SQ-PURE-1, CLICK-PURE-1 (глубоко замороженные входы:
  мутация бросает исключение в строгом режиме ES-модуля).

### Integration cases

- Автотестов для `main.ts` / `render.ts` нет (e2e не настроены). Ручная проверка

## Unexpected Passes

Прошли до реализации. Это ожидаемо — тесты фиксируют требования, которые текущий
код уже выполняет в этих конкретных точках, и защищают от регрессии при
переписывании:

- **SNAP-OUT-3** — текущий код не прилипает в этой точке (вне зон граней при
  масштабе 1); тест ловит реализацию с прилипанием к вершине наружного угла.
- **SNAP-END-5** — сжатие у свободного торца уже равно `newHalf` (как SNAP-END-1).
- **SNAP-T-STOP-2** — текущий клемп `s ≥ newHalf` по оси C случайно совпадает с
  правильным ответом, потому что торец C лежит ровно на грани A. Тест остаётся
  как защита для контурной реализации (участок грани C от вогнутой вершины).
- **SNAP-DET-3**, **INV-SHAPE-1**, **INV-PURE-2** — свойства, которые текущий код
  уже обеспечивает.
- **SNAP-CHAIN-2/3** — положение вершины при перпендикулярном подходе к грани и
  при подходе к свободному торцу уже корректно; проверяют, что последний блок без
  наложения, после переписывания.
- **SNAP-DET-2R** — замена утверждённого теста; текущий код даёт тот же тай-брейк.

## Tests That Could Not Run
